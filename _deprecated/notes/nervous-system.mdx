神經系統靠神經元上的電位變化傳遞訊息，再由突觸把訊號交給下一個細胞。本篇從神經元結構與靜止電位談起，帶到動作電位、突觸傳遞、神經系統的劃分與行為類型。

## 一、神經元的基本結構

神經元（neuron）是神經系統的功能單位：

| 部位 | 功能 |
|---|---|
| **樹突（dendrite）** | 接收來自其他神經元的訊號 |
| **細胞體（soma）** | 含核，整合訊號 |
| **軸突（axon）** | 傳導動作電位（電訊號）往下傳 |
| **髓鞘（myelin sheath）** | 絕緣層，由許旺細胞（PNS）或寡樹突細胞（CNS）包覆 |
| **蘭氏節（Nodes of Ranvier）** | 髓鞘間的裸露節點，動作電位在此「跳」 |

## 二、靜止電位（Resting Membrane Potential）

靜止電位大約 **−70 mV**（細胞內相對細胞外為負）。

**形成原因：鈉鉀幫浦（Na⁺-K⁺ ATPase）**

| 方向 | 離子 | 數量 |
|---|---|---|
| 幫浦「泵出」（主動） | Na⁺ | 3 個 Na⁺ 出 |
| 幫浦「泵入」（主動） | K⁺ | 2 個 K⁺ 入 |

- 淨效果：持續把正電荷（Na⁺ 多出 1）泵出 → 維持細胞內負電位。
- 靜止時 K⁺ 通道部分開放，K⁺ 沿濃度梯度外漏，使內部更負。

**平衡電位（Equilibrium Potential）—— 這個觀念常出題**

每種離子都有自己的「平衡電位（＝反轉電位 reversal potential）」：當這個離子的「濃度梯度想推它走的方向」與「電位梯度想拉它回來的方向」剛好抵銷、淨流為零時的膜電位。

**怎麼推出每個離子的平衡電位是正是負（不用背數值）**：先看這個離子細胞內外哪邊濃度高 → 它順濃度往低濃度側流 → 它帶的電荷在那側累積 → 膜被充到「能擋住它繼續流」就停。

- **K⁺**：細胞內高、會往外漏 → 帶正電出去使內部變負 → 負到約 **−90 mV** 才擋得住，故 E_K ≈ −90 mV（負）。
- **Na⁺**：細胞外高、會往內衝 → 帶正電進來使內部變正 → 正到約 **+60 mV** 才擋得住，故 E_Na ≈ +60 mV（正）。
- 通則：**膜現在對哪個離子最「通」，膜電位就被拉向那個離子的平衡電位。** 靜止時膜對 **K⁺ 通透性最高** → 靜止電位（−70 mV）最靠近 E_K（但因仍有一點 Na⁺ 漏入把它往正拉，比 −90 稍偏正）；動作電位去極化時 Na⁺ 通透性暴增 → 高峰被拉向 E_Na。
- 一句話：靜止膜電位 ≈ K⁺ 平衡電位（接近但不完全相等，且比 E_K 偏正）。動作電位高峰則趨近 Na⁺ 平衡電位。

## 三、動作電位（Action Potential）

動作電位是「全或無（all-or-none）」反應：達到閾值（−55 mV）才觸發，一觸發就走完完整波形，無法「半觸發」。

**四個階段：**

| 階段 | 離子動作 | 膜電位變化 |
|---|---|---|
| ① 靜止 | Na⁺ 通道關 | −70 mV |
| ② **去極化（Depolarization）** | 電位依存性 Na⁺ 通道大量**開啟**，Na⁺ 湧入 | −70 → +30 mV |
| ③ **再極化（Repolarization）** | Na⁺ 通道關閉，K⁺ 通道**開啟**，K⁺ 外流 | +30 → −70 mV |
| ④ **不反應期（Refractory period）** | Na⁺ 通道暫時無法再開（絕對不反應期） | 確保訊號單向傳導 |

## 四、跳躍傳導（Saltatory Conduction）

- 有髓鞘的軸突：動作電位只在**蘭氏節**（髓鞘間的裸露段）發生，從節跳到節。
- 優點：**速度快**（可達 120 m/s）、**耗能少**。
- 無髓鞘神經：依序連續去極化，速度較慢（約 0.5–2 m/s）。

## 五、突觸（Synapse）與神經傳遞物

突觸是神經元之間的訊號傳遞接合點，多數為**化學突觸**：

1. 動作電位到達**突觸前神經末梢** → Ca²⁺ 通道開啟 → Ca²⁺ 內流。
2. 突觸小泡（vesicle）與細胞膜融合 → **神經傳遞物（neurotransmitter）** 釋放進突觸間隙。
3. 神經傳遞物結合突觸後膜受體 → 引發**興奮性（EPSP）**或**抑制性（IPSP）**後電位。

| 神經傳遞物 | 主要效果 | 例子 |
|---|---|---|
| **乙醯膽鹼（ACh）** | 興奮（神經肌肉接合處）；在心臟為抑制 | 骨骼肌收縮、自律神經 |
| **多巴胺（Dopamine）** | 獎賞、動作控制 | 帕金森症（多巴胺神經元退化） |
| **血清素（Serotonin）** | 情緒調節、睡眠 | 抗憂鬱藥（SSRI）阻止回收 |
| **GABA** | 主要<b>抑制性</b>傳遞物 | 安眠藥/酒精增強 GABA 作用 |
| **麩胺酸（Glutamate）** | 主要<b>興奮性</b>傳遞物 | 學習與記憶 |
| **正腎上腺素（NE）** | 「戰或逃」反應 | 交感神經末梢釋放 |

**神經傳遞物如何被「關掉」→ 反推藥物機制（不用背個別藥）**

訊號要停，突觸間隙的神經傳遞物必須被清掉，只有兩條路：**①被回收（reuptake）送回突觸前** 或 **②被酵素分解**。掌握這把鑰匙，藥理題可自己推：

- **想「增強」某神經傳遞物的作用** → 擋掉它的清除路：**抑制回收** 或 **抑制分解酵素**，間隙濃度就升高、作用變強。
  - 百憂解／SSRI（抗憂鬱）＝**抑制血清素回收** → 血清素停留變久 → 情緒改善（憂鬱症常與血清素不足有關）。
  - 愛憶欣（Aricept，治阿茲海默症）＝**抑制乙醯膽鹼酯酶（AChE）** → ACh 不被分解 → ACh 增加、改善傳遞。
- **想「減弱」作用** → 反過來：擋住釋放，或用拮抗劑（antagonist）佔住受體。
  - 肉毒桿菌毒素＝**阻止含 ACh 的囊泡與膜融合** → ACh 放不出來 → 肌肉麻痺（神經肌肉接合處傳遞被切斷）。

**幾個必記的「傳遞物／構造 ↔ 疾病」配對**（直接送分）：

| 疾病 | 關鍵異常 |
|---|---|
| **帕金森症** | 黑質**多巴胺**神經元退化（動作控制變差） |
| **阿茲海默症** | 腦中**β-澱粉樣蛋白斑塊**堆積；ACh 不足 |
| **多發性硬化症（MS）** | 自體免疫攻擊**髓鞘** → 傳導變慢／失敗（傷的是髓鞘，不是神經元本體或皮質） |
| **憂鬱症** | **血清素**等不足 → 用 SSRI 拉高 |

## 六、中樞與周邊神經系統

| 系統 | 組成 | 功能 |
|---|---|---|
| **中樞神經系統（CNS）** | 腦 ＋ 脊髓 | 整合、決策、反應 |
| **周邊神經系統（PNS）** | 腦神經（12 對）＋ 脊神經（31 對）| 傳入（感覺）/傳出（運動） |

PNS 傳出分兩支：
- **軀體神經**：隨意控制骨骼肌。
- **自律神經**：不隨意控制內臟，分交感（「戰或逃」）與副交感（「休息消化」）。

**交感「戰或逃」的器官效應——用一個目的推全部，不用背**

原則：身體準備「打架或逃跑」→ 凡是**幫你應戰的就開大、幫你消化休養的就關小**。順著這句就能判每一條：

- 開大（戰鬥需要）：**心跳加快**、**瞳孔放大**（看清楚）、支氣管擴張（吸更多氧）、**肝臟釋放葡萄糖**（供能）、血流導向骨骼肌。
- 關小（現在不急）：**腸胃道蠕動與消化減少**（所以「腸胃活動增加」是副交感、不是交感——常見陷阱）。

副交感則相反（「休息與消化」），如心跳變慢、促進腸胃蠕動。記神經傳遞物：交感節後末梢多放**正腎上腺素**；副交感與神經肌肉接合處放**乙醯膽鹼**。

## 七、大腦皮質的功能分區（會考「某迴管什麼」）

大腦皮質分四葉。考試最常考**中央溝兩側的兩條迴**：

| 構造 | 位置 | 功能 |
|---|---|---|
| **中央前迴（precentral gyrus）** | 額葉，中央溝**前** | **主要運動皮質**：發出隨意運動指令到骨骼肌 |
| **中央後迴（postcentral gyrus）** | 頂葉，中央溝**後** | **主要體感皮質**：接收皮膚觸覺、痛覺等 |
| 額葉其他區 | 額葉 | 思考、決策、語言發聲（布洛卡區）、面部表情控制 |
| 枕葉 | 後腦 | 視覺 |
| 顳葉 | 側腦 | 聽覺、記憶 |

口訣：**前迴管「動」（運動）、後迴管「感」（感覺）**。中央前迴位於額葉、負責運動與發聲/表情，但**不負責內臟疼痛**（內臟感覺主要在後迴/島葉）。

**皮質下與其他重要構造（配對題常考，記「功能關鍵字」即可）**

| 構造 | 一句話功能（關鍵字） |
|---|---|
| **海馬體（hippocampus）** | 形成**新的長期記憶**；受損 → 記不住事故後新事、舊記憶仍在 |
| **杏仁核（amygdala）** | **情緒記憶**（尤其恐懼）；見蛇心跳加速冒汗的「情緒」反應中樞 |
| **下視丘（hypothalamus）** | 內臟與內分泌總管：**體溫、飢餓、口渴**、晝夜節律（內含視交叉上核 SCN） |
| **小腦（cerebellum）** | **運動協調與平衡**（不是發起運動，而是讓動作精準） |
| **延腦（medulla）** | 維生中樞：**呼吸、心跳、血壓**（注意：體溫/飢渴是下視丘，不是延腦——常見陷阱） |
| **中腦（midbrain）／網狀活化系統** | **清醒、覺醒（arousal）**的調控中心 |
| **胼胝體（corpus callosum）** | 連接**左右大腦半球**、讓兩側溝通 |
| **邊緣系統（limbic system）** | 情緒、動機與長期記憶的整合（含海馬體、杏仁核等） |

判斷訣竅：把「**維生自動化**（呼吸心跳）」歸**延腦**、「**內在恆定/慾望**（溫度飢渴）」歸**下視丘**、「**動作要不要準**」歸**小腦**、「**記得住/記不住**」歸**海馬體**、「**怕不怕**」歸**杏仁核**。

## 八、感覺器官重點（送分題常考）

| 器官 | 重點 | 易錯 |
|---|---|---|
| **視網膜——錐細胞（cone）** | 人有 **3 種**錐細胞（紅、綠、藍三原色）→ 彩色視覺、需強光；密度最高在**中央凹（fovea）** | 不是 1 種也不是數百種；不是 7 種 |
| **視網膜——桿細胞（rod）** | 1 種，感光敏感、只分明暗，負責暗處視覺 | 不分顏色 |
| **內耳——耳蝸（cochlea）** | 聽覺 | — |
| **內耳——前庭（球狀囊 saccule＋橢圓囊 utricle）** | 偵測**直線**加速度與頭部位置（平衡覺）；內含毛細胞與**耳石（otolith）** | 耳石是**碳酸鈣（CaCO₃）結晶**，不是磷酸鎂 |
| **內耳——半規管** | 偵測**旋轉**加速度 | — |

**光轉導：為什麼「照光反而讓光受體變更負、放更少神經傳遞物」？（最反直覺、最常考）**

關鍵是光受體有一條「**暗電流（dark current）**」——記住一句原理就能推出所有相關題：

> **黑暗中**，細胞內 **cGMP 濃度高** → 撐開細胞膜上的 **cGMP 依賴鈉離子通道** → Na⁺ 持續流入 → 光受體維持**去極化**、不斷釋放神經傳遞物（**麩胺酸**）。

照光後把上面每一步反過來：**光 → 活化視紫質（rhodopsin）→ 把 cGMP 水解掉 → cGMP 變少 → 鈉通道關閉 → Na⁺ 不進來 → 膜超極化（hyperpolarization）→ 神經傳遞物釋放減少**。

所以「照光 = 關掉一個本來開著的電流」，不是「照光去開一個新電流」。一旦記住「暗中是開、是去極化、放很多麩胺酸」，下面三種常見問法都能直接答：照光使膜**超極化**（對）、照光鈉通道**關閉**（對）、**黑暗**中釋放的神經傳遞物**比照光時多**（對）。

**視覺傳遞路徑（順序題）**：光 → **視桿/視錐細胞**（感光）→ **雙極細胞** → **神經節細胞**（其軸突＝視神經，腦神經 II）→ 經視交叉到**視丘外側膝狀核（LGN）** → **枕葉視覺皮質**。記法：先「感光細胞」，再層層往內接到神經節細胞出眼睛，最後進枕葉。（枕葉受損 → 視覺障礙。）

## 九、行為類型

| 類型 | 說明 | 例子 |
|---|---|---|
| **先天行為——本能（Innate）** | 天生固定，不需學習 | 蜘蛛結網、新生兒吸吮反射 |
| **先天行為——固定行為模式（FAP）** | 由特定刺激（釋放子）觸發、一旦啟動就跑完的固定動作序列 | 灰雁滾蛋回巢、雄魚見紅腹就攻擊 |
| **先天行為——印痕（Imprinting）** | 特定敏感期學習，之後固定 | 剛孵化雛鵝跟隨第一個看到的移動物體 |
| **後天行為——習慣化（Habituation）** | 對反覆出現、無意義的刺激逐漸**不再反應** | 鳥對稻草人久了不再害怕 |
| **後天行為——古典制約** | CS（鐘聲）配 UCS（食物）→ CS 單獨可引發反應 | 巴夫洛夫的狗 |
| **後天行為——操作制約** | 行為後的獎懲影響未來行為頻率 | 老鼠按槓桿得食物 |
| **後天行為——洞察學習** | 靠理解與推理解決新問題 | 黑猩猩疊箱子取香蕉 |

**基因 × 環境交互作用（gene–environment interaction）**：許多行為**不是**單純先天或後天，而是基因背景與後天環境**共同**塑造。例：幼鼠若由低互動（少舔舐照顧）的母鼠養大，長大後在新環境較易恐懼焦慮——這既受基因影響、也受早期環境影響，是兩者**交互作用**的結果。看到「先天 + 後天一起影響」就選此項，而非單一的印痕或習慣化。

## 十、睡眠與腦波（EEG）

**腦波的頻率／振幅怎麼變——一條原理全部推出來（不用背四種波的數值）**

腦波量到的是「很多皮質神經元電活動的總和」。決定波形的核心是**同步程度**：

> **清醒、專注**時，神經元各做各的、放電**不同步** → 彼此抵銷 → 波形**頻率快、振幅小**（去同步化）。
> 越進入**深睡**，視丘把大批皮質神經元拉成**一起放電（高度同步）** → 波疊加 → 波形**頻率變慢、振幅變大**（同步化）。

所以「從清醒進入深睡」= **頻率下降、振幅上升**（這正是考點答案）。把這條原理套到四種波，順序就出來了：

| 波 | 狀態 | 頻率 / 振幅 |
|---|---|---|
| **β（Beta）** | 清醒、專注思考 | 最快、最小（最不同步） |
| **α（Alpha）** | 清醒但**閉眼放鬆** | 比 β 慢、稍大 |
| **θ（Theta）** | 淺睡 | 更慢、更大 |
| **δ（Delta）** | **深睡（慢波睡眠）** | 最慢、最大（最同步）；由**視丘–皮質迴路**產生 |

**睡眠的化學開關（藥理題）**：

- **食慾素（orexin）**：由下視丘分泌，作用是**維持清醒**。所以**食慾素受體拮抗劑**＝關掉「保持清醒」的訊號 → **促進睡眠**（一類新型安眠藥）。反推：缺 orexin 會過度想睡（猝睡症）。
- **褪黑激素（melatonin）**：由**松果體**於**夜間（黑暗）**分泌，是「天黑了該睡」的訊號；夜長的季節分泌量高。可助眠。
- **GABA**：中樞主要**抑制性**傳遞物；安眠藥／酒精增強 GABA → 助眠。故 GABA 受體**拮抗劑**反而會**妨礙**睡眠。
