字音字形題考的是辨正：破音字看詞義定讀音，形近字看部首分意義，錯別字把詞還原成本義。本篇整理高頻題型與辨別方法。

## 一、破音字是什麼？

同一個字，因詞義不同而有兩種（甚至更多）讀音，叫做**破音字**（又稱多音字）。
考試最愛出「哪個讀法最正確」，關鍵在**先判斷詞義，再選讀音**。

| 字 | 讀音 A | 詞例 | 讀音 B | 詞例 |
|---|---|---|---|---|
| 行 | ㄏㄤˊ (háng) | 行伍、行列 | ㄒㄧㄥˊ (xíng) | 行走、行動 |
| 調 | ㄉㄧㄠˋ (diào) | 調動、調查 | ㄊㄧㄠˊ (tiáo) | 調和、調味 |
| 難 | ㄋㄢˊ (nán) | 困難、難題 | ㄋㄢˋ (nàn) | 災難、遇難 |
| 重 | ㄓㄨㄥˋ (zhòng) | 重量、重要 | ㄔㄨㄥˊ (chóng) | 重複、重來 |
| 處 | ㄔㄨˋ (chù) | 處所、住處 | ㄔㄨˇ (chǔ) | 處理、處置 |
| 數 | ㄕㄨˋ (shù) | 數字、數量 | ㄕㄨˇ (shǔ) | 數一數二 |
| 好 | ㄏㄠˇ (hǎo) | 好人、好看 | ㄏㄠˋ (hào) | 好學、嗜好 |
| 長 | ㄔㄤˊ (cháng) | 長短、漫長 | ㄓㄤˇ (zhǎng) | 成長、師長 |

## 二、讀音是否相同（考最兇的題型）

考試很愛問「下列各組『』內的字，讀音兩兩相同的是哪一組？」。
做法很簡單：**把每個字的注音默念出來，逐組比對，完全一樣（含聲調）才算相同。**
一字一字念，不要用「感覺很像」判斷——聲調差一聲就不算同音。

| 一組兩字 | 注音 | 是否同音 |
|---|---|---|
| 「踅」身／空谷「跫」音 | ㄒㄩㄝˊ／ㄑㄩㄥˊ | ✗ 不同 |
| 蹧「蹋」糧食／坍「塌」 | ㄊㄚˋ／ㄊㄚ | ✗ 聲調不同 |
| 烘「焙」麵包／「培」育人才 | ㄅㄟˋ／ㄆㄟˊ | ✗ 不同 |
| 「朔」風野大／「塑」像 | ㄕㄨㄛˋ／ㄙㄨˋ | ✗ 不同 |
| 三更畫「舫」／相「仿」 | ㄈㄤˇ／ㄈㄤˇ | ✓ 相同 |

口訣：**先標注音再比，聲、韻、調三者全同才算同音。**

## 三、注音對應到哪個字（字音→字形）

另一種變化題：題目給注音，問「兩個空格寫出來是不是同一個字」。
做法：**先想注音對應哪個常用字，再看兩個詞各該填哪個字，字形一樣才算對。**

| 注音 | 詞例 | 各自的字 | 同字？ |
|---|---|---|---|
| ㄇㄛˊ | 「ㄇㄛˊ」刀霍霍／「ㄇㄛˊ」頂放踵 | 磨刀／摩頂 | ✗（磨 vs 摩） |
| ㄅㄧˋ | 金「ㄅㄧˋ」輝煌／小家「ㄅㄧˋ」玉 | 金碧／碧玉 | ✓ 都是「碧」 |
| ㄒㄧㄚˊ | 名聞「ㄒㄧㄚˊ」邇／「ㄒㄧㄚˊ」不掩瑜 | 遐邇／瑕不掩瑜 | ✗（遐 vs 瑕） |

提醒：同一個注音常對應好幾個字（磨/摩、碧/壁/璧、遐/瑕/暇），**要靠詞義決定到底是哪個字**。

## 四、形近字辨正

字形相近、極易混淆，靠**部首意義**來辨別：

| 易混組 | 辨別訣竅 | 例詞 |
|---|---|---|
| 己／已／巳 | 己開口朝左、已半閉、巳全閉 | 知己；已經；巳時 |
| 戊／戌／戍／戎 | 「戊」中間空；「戌」中間一橫；「戍」中間一點（戍守）；「戎」十字交叉（軍事） | 戊辰年；戌時；戍守；戎馬 |
| 刺／剌 | 「刺」左旁是「朿」、「剌」左旁是「束」，右邊都是「刂」 | 刺激；乖剌 |
| 贏／嬴 | 「贏」中下作「貝」（與輸贏、財利有關）；「嬴」中下作「女」（姓氏，如嬴政） | 贏得；嬴政 |
| 侯／候 | 「候」比「侯」多一短豎 | 王侯；等候 |
| 即／既 | 「即」是人就食；「既」是人食已離 | 即將；既然 |

## 五、常見錯別字辨正

**為什麼會寫錯？** 錯別字幾乎都是把正確字換成一個**同音或近音字**——正因為唸起來一樣，手才會寫錯（迫不「及」待誤成「急」、再接再「厲」誤成「勵」，兩兩都同音）。
所以辨正的通法只有一條：**別管它唸什麼（反正同音），改問「這個字的意思放進詞裡通不通」**，用字義去淘汰那個音對、義不對的冒牌字。

下面是考古題中最高頻的易錯字，請花幾分鐘記一遍：

<TypoSpotter client:visible />

| 錯誤寫法（✗） | 正確寫法（✓） | 記憶線索 |
|---|---|---|
| 迫不**急**待 | 迫不**及**待 | 「及」是來得及，不是心情「急」 |
| 義不容**詞** | 義不容**辭** | 「辭」是推辭，不是言詞的「詞」 |
| 再接再**勵** | 再接再**厲** | 「厲」是磨礪、磨刀，不是勉勵的「勵」 |
| 察**顏**觀色 | 察**言**觀色 | 察的是「言語」，不是臉色的「顏」 |
| 出**奇**不意 | 出**其**不意 | 「其」才是出乎意料的「其」 |
| 動輒得**救** | 動輒得**咎** | 「咎」是責怪、過失，不是「救」 |
| 無濟於**是** | 無濟於**事** | 對「事情」沒有幫助，用「事」 |
| **嘻**皮笑臉 | **嬉**皮笑臉 | 「嬉」從「女」、表嬉戲，不是狀聲的「嘻」 |

## 六、整句挑錯別字（考最多的題型）

最常見的問法是「下列文句中，**沒有**錯別字（或**有**錯別字）的是哪一項」——把錯字藏進一整句白話文裡，比單看成語更難掃。與其從頭硬讀，不如用**鎖定可疑點**的策略，把注意力放在最容易藏錯的地方：

- **先抓成語與固定詞**：句子裡的四字成語、慣用語是出題者最愛動手腳的地方（如「鞠躬盡瘁」「迫不及待」），一句先圈出這些片語逐字檢查，命中率最高。
- **再疑同音／近音字**：錯字一定和正字**同音或音近**（這是它能被混進來的原因）。看到一個字，心裡默念它的音，想「同這個音、但意思更貼切的字是不是另一個？」。
- **用字義收網**：把可疑字的**本義**放回詞裡，意思不通的就是錯字（前面第五節的通法，整句題照用）。
- **善用「聲旁」回推**：多數漢字是形聲字（形旁表義、聲旁表音）。若拿不準某字，先看它的**聲旁**約略推音、再看**形旁**是否切合詞義——但聲旁只是「提示」，古今音常有變化，**不能只憑聲旁就斷定**，仍要回到字義確認。

口訣：**先圈成語、再疑同音、用義定奪。** 找「沒有錯字」的選項時，反過來逐一刪掉「有錯字」的三項即可。
