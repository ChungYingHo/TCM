植物體由三大組織系統構成，靠維管束（木質部、韌皮部）運輸水分與養分，靠分生組織不斷長大。本篇從組織分類談起，帶到運輸、生長與氣孔調節。

## 一、植物體三大組織系統

維管束植物（蕨類、裸子、被子植物）的所有組織，依功能可分成三大系統：

| 系統 | 主要組織 | 位置 | 核心功能 |
|---|---|---|---|
| **表皮組織系統** | 表皮、氣孔保衛細胞、根毛 | 最外層 | 保護、防水、氣體交換 |
| **基本組織系統** | 薄壁組織、厚角組織、厚壁組織 | 皮層、髓 | 光合、儲存、支撐 |
| **維管束組織系統** | 木質部、韌皮部 | 莖/根中央附近 | 水分與養分運輸 |

## 二、基本組織的三種細胞與「次生細胞壁」

基本組織系統由三種細胞組成，差別在**細胞壁**：

| 細胞 | 細胞壁 | 死活 | 功能 |
|---|---|---|---|
| **薄壁組織**（parenchyma） | 只有薄的初生壁 | 活 | 光合、儲存（最常見、最不特化） |
| **厚角組織**（collenchyma） | 初生壁不均勻加厚（**無次生壁**） | 活 | 幼嫩部位的柔軟支撐 |
| **厚壁組織**（sclerenchyma） | **有厚的次生壁（木質化）** | 多死 | 強力支撐；含**纖維細胞、石細胞** |

- **初生細胞壁**：所有植物細胞剛形成時都有，較薄、可延展。
- **次生細胞壁**：在初生壁內側加厚、常木質化（lignin），形成後細胞多停止生長甚至死亡。
- 有次生壁者：**厚壁組織（纖維、石細胞）、木質部（導管、管胞）**。
- **沒有**次生壁者：薄壁組織、厚角組織（這是考點！）。

> 易錯：厚「角」組織只是初生壁加厚，**沒有次生壁**；厚「壁」組織才有次生壁。

## 三、木質部 vs 韌皮部

這是考試最愛考的對比，請用表格記死：

| 比較項目 | 木質部（Xylem） | 韌皮部（Phloem） |
|---|---|---|
| 運輸物質 | **水分與礦物質**（往上） | **有機物（蔗糖）**（雙向） |
| 主要細胞 | 管胞、導管（死細胞） | 篩管細胞＋伴細胞（活細胞） |
| 細胞壁 | 木質化（厚、強） | 未木質化 |
| 動力來源 | 蒸散拉力（被動） | 主動裝載（ATP消耗） |

> 口訣：**木質部運「水往上」，韌皮部運「糖上下」。**

**為什麼方向是這樣？用「水往低水勢流」一條原理就能推：**

- **木質部＝內聚-張力學說（cohesion-tension）**：葉片氣孔蒸散把水「拉」走，葉肉細胞水勢變很負，於是水從水勢高的根被吸往水勢低的葉。水分子靠氫鍵彼此**內聚**成一條不斷的水柱，被拉而不斷裂。**動力在頂端（葉），是「拉」不是「推」**，所以只能**向上、單向**，且全程被動、不耗 ATP。推論：蒸散愈旺（葉肉愈負壓）→ 拉力愈大 → 運速愈快。
- **韌皮部＝壓力流學說（pressure-flow）**：在**供源（source，如行光合的葉）**，伴細胞**主動**把蔗糖裝進篩管（耗 ATP），篩管內溶質濃度升高、水勢下降，水便從旁邊木質部滲入 → 篩管內產生**高膨壓**；在**積貯（sink，如根、果實）**糖被卸下，膨壓低。糖水就從高壓的 source 被「推」向低壓的 sink。**哪裡是 source／sink 會隨季節改變**（春天根是 source 供芽生長），所以韌皮部能**雙向**。
- 由壓力流可直接推出考點：運速由 **sink 卸糖速率** 決定（卸得慢→壓力梯度不再增加→運速趨於穩定）；只要把糖**裝載/卸載**的主動步驟一擋，整條運輸就停。

## 四、分生組織（Meristem）

分生組織是持續保有分裂能力的細胞群，是植物「長大」的關鍵：

| 類型 | 位置 | 功能 |
|---|---|---|
| 頂端分生組織 | 根尖、莖尖 | **初生生長**（伸長） |
| 側生分生組織（形成層） | 木質部與韌皮部之間 | **次生生長**（加粗） |
| 居間分生組織 | 禾本科莖節基部 | 節間延伸 |

## 五、次生生長與年輪

- 維管形成層往外生出新韌皮部，往內生出新木質部。
- **早材淺、晚材深，是「水多細胞就長得大」推出來的**：春天水分溫度充足 → 導管細胞長得**大、壁薄、排得疏** → 整體顏色**淺**＝**早材（春材）**；夏末秋初轉乾冷 → 細胞**小、壁厚、緻密** → 顏色**深**＝**晚材（秋材）**。深色晚材是「一年結束」的記號。
- 每一道**深色環（晚材）+ 淺色環（早材）＝ 一年一輪**，年輪數 = 樹齡。
- 由「加粗靠側生形成層、加高只靠莖頂端」可推：**樹幹上刻的記號高度永遠不變**（記號以下的莖只會變粗、不會把記號往上頂；新增高度都發生在頂芽）。同理乾燥年年輪窄、潮濕年輪寬。

## 六、根尖的分區（由尖端往上）

考題會問「成熟區緊鄰誰」「根毛在哪」，順序記死：

| 分區 | 位置 | 特徵 |
|---|---|---|
| **根冠**（root cap） | 最尖端 | 保護分生組織、感受重力 |
| **分生區**（meristem） | 根尖內側 | 細胞快速分裂 |
| **延長區**（elongation） | 分生區上方 | 細胞拉長，根因此往前推進 |
| **成熟區**（maturation） | 延長區上方 | 細胞分化完成；**根毛在此**（增加吸收面積） |

> 易錯：成熟區**緊鄰延長區**，不是緊鄰根尖分生組織（中間還隔著延長區）。根毛分布於**成熟區**。

## 七、單子葉 vs 雙子葉植物

| 比較 | 單子葉（玉米、稻） | 雙子葉（豆、向日葵） |
|---|---|---|
| 子葉數 | **1 枚** | 2 枚 |
| 葉脈 | 平行脈 | 網狀脈 |
| 維管束排列 | 散生 | 環狀排列 |
| 根系 | 鬚根 | 軸根（主根明顯） |
| 花瓣數 | 3 的倍數 | 4 或 5 的倍數 |

> 細胞延展方向由**細胞壁中纖維素微纖維（microfibril）的排列**決定（垂直於微纖維方向延長）。

## 八、氣孔與保衛細胞

- 氣孔（stoma）由兩個**腎形保衛細胞**圍成。
- **核心機制就是「K⁺ 帶水進出」一條鏈，方向自己推**：保衛細胞用質子泵（耗 ATP）把 H⁺ 打出去，**K⁺ 順電位流入** → 細胞內溶質變多、水勢下降 → **水滲透跟著進來** → 保衛細胞膨脹。保衛細胞**內側（靠氣孔）壁厚、外側壁薄**，膨脹時只能往外彎，開口因而**張開**。反過來 K⁺ 流出 → 水跟著出 → 縮小 → **關閉**。所以「水」永遠是被動跟著 K⁺ 走，不是被泵的。
- 由此可推開關因子：**光照**（促 K⁺ 入）開；**缺水、黑暗、高 CO₂** 使 K⁺ 流出 → 關。**Na⁺ 不是調控離子**（主角是 K⁺）。
- 離層酸（ABA）是乾旱時的「關閉訊號」：促進 K⁺ **流出**保衛細胞，循上述機制使氣孔關。ABA 由缺水葉肉細胞合成。

## 九、根的橫切構造與內皮（卡氏帶）

考題愛問「根橫切由內到外順序」「卡氏帶在哪、做什麼」。先記住**由中心往外**的層次，再用「內皮是把關卡」一條原理串起來：

**（雙子葉/多數根）中心 → 外：木質部（常呈星狀居中）→ 韌皮部 → 周鞘（pericycle）→ 內皮（endodermis）→ 皮層（cortex）→ 表皮（epidermis）。** 單子葉根中央**多一個髓**，順序為**髓 → 木質部 → 韌皮部 → 周鞘 → 內皮 → 皮層 → 表皮**。

- 水與礦物質從土壤進入根，有兩條路：沿細胞壁與細胞間隙走的**質外體路徑（apoplast）**，和穿過細胞質、經胞間連絲的**共質體路徑（symplast）**。
- **內皮**細胞的徑向壁／橫向壁有一圈木栓化、木質化的**卡氏帶（Casparian strip）**，像門框的防水膠條，**把質外體路徑封死**。水要進維管束**只能改走共質體**，被迫穿過內皮細胞膜。
- **這就是內皮的意義**：細胞膜上有選擇性運輸蛋白，可**篩選**讓哪些離子進入、擋掉有害物 → 根能「管制」礦物吸收，而非照單全收。
- **周鞘**保有分裂力，是**側根**的發源處。

> 易錯：卡氏帶位在**內皮**（不在表皮、不在皮層）；它逼水從質外體**轉**共質體，所以一條根可**同時**有質外體與共質體運輸。

## 十、根毛吸收、根壓與泌液（guttation）

- **根毛**是**根表皮細胞向外突出的「單細胞」構造**（不是多細胞、也不是周鞘長的），位在成熟區，大幅增加吸收表面積。要不要長根毛，取決於該表皮細胞**相對於皮層細胞的位置**。
- 根毛細胞膜上的**質子泵（proton pump）**把 H⁺ 打出去，建立質子梯度，再用**共運輸**把土壤中的礦物離子「順帶」拉進來——所以質子泵的生理意義是**幫助吸收礦物元素**（不是合成 ATP）。礦物鹽、胺基酸進入都屬**主動運輸**，需要 ATP、轉運蛋白與質子梯度。
- **根壓與泌液**：夜間蒸散停止、但根仍主動把離子打進中柱，**離子拉著水**滲入木質部，在根部累積出**正的根壓**，把水**從下往上推**、由葉緣的水孔擠出成水珠——這就是清晨葉尖的**泌液／泌溢（guttation）**。**動力是根壓（推），與白天的蒸散拉力剛好相反**，所以泌液發生在蒸散最小的夜裡。

> 為何泌液≠露水：露水是空氣中的水凝結在葉表；泌液是植物**自己把體內的水（含少量溶質）從水孔排出**，由根壓驅動。

## 十一、植物登陸陸地的演化與分類階層

這類題不必硬背年代，抓住「**愈晚演化的構造，是為了解決上陸後愈進階的問題**」就能排序：

- **登陸四大適應，出現順序＝解決問題的先後**：**①角質層（cuticle，先防乾死）→ ②維管束組織（長高、長距離運水）→ ③種子（不靠水受精、可休眠）→ ④花（更高效的授粉）。** 記法：先別死（角質）→ 再長大（維管束）→ 再獨立繁殖（種子）→ 再求偶（花）。
- **植株能長高，關鍵在維管束**：苔蘚（如蘚類 liverworts）**缺維管束**，不能有效運水、也沒木質部支撐，所以**體型矮小、高度受限**；早期化石植物（如頂囊蕨 Cooksonia）**只有行光合的莖、缺真正的根與葉**，同樣長不高。
- **包含關係（由大到小）**：有胚植物 ⊃ 維管束植物 ⊃ 無種子維管束植物（如蕨、木賊、石松）⊃ 個別類群。**無種子維管束植物是「並系群（paraphyletic）」**——因為它含了共同祖先，卻**不含該祖先演化出的「種子植物」後裔**，被切掉一支，所以不是單系群。
- **世代交替的演化趨勢**：愈高等的植物，**孢子體（2n）愈發達、配子體（n）愈退化**。苔蘚是配子體佔優勢（孢子體寄生在配子體上）；蕨類起，孢子體（我們看到的本體）才成為主要世代。**裸子植物（如銀杏）、被子植物**孢子體最發達。
- **小應用**：石炭紀煤層是大量**蕨類、木賊、石松**（當時的高大無種子維管束植物）埋藏碳化而成 → 那時最適合當建材的就是這群高大維管束植物。
