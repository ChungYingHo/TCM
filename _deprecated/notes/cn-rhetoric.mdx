修辭題考的是辨識：抓住每種修辭的關鍵特徵，就能分辨譬喻與借代、擬人與轉品、排比與對偶。本篇整理十大修辭格與最易混淆的幾組。

## 一、十大修辭格定義速查

| 修辭格 | 定義（一句話） | 辨識關鍵 | 例句 |
|---|---|---|---|
| **譬喻** | 用「像、如、是」等連結本體與喻體 | 有喻詞（像/如/是/彷彿）；或暗喻（直接說是） | 「瓶身描繪的牡丹一如你初妝」 |
| **轉化（擬人）** | 把無生命事物當作人來描寫 | 無生物出現人的動作/感情 | 「簾外芭蕉惹驟雨」（芭蕉「惹」事） |
| **轉化（擬物）** | 把人比作物來描寫 | 人出現物的特徵 | 「我變成一棵樹，靜靜地在風中等你」 |
| **轉品（活用）** | 把某詞性的字臨時用作另一詞性 | 名詞→動詞；形容詞→動詞 | 「春風風人」（第二個「風」由名詞轉動詞） |
| **借代** | 不直說本體，用相關事物代替 | 找不到喻詞；能問「代替的是什麼？」 | 「杜康」代酒；「絲竹」代音樂；「帆」代船 |
| **誇飾** | 故意誇大或縮小事實以加強語氣 | 現實上不可能、極度誇張 | 「炊煙嫋嫋升起，隔江千萬里」 |
| **映襯（對比）** | 兩種相反或相對的事物並列，互相映照 | 前後形成強烈對比 | 「朱門酒肉臭，路有凍死骨」 |
| **排比** | 三個以上結構相似、意義相關的句子或詞語並列 | 至少三組，結構平行 | 「簾外芭蕉惹驟雨，門環惹銅綠，而我路過那江南小鎮惹了你」 |
| **對偶（對仗）** | 上下兩句字數相等、結構相對、詞性對應 | 只有兩句，且一一對應 | 「無邊落木蕭蕭下，不盡長江滾滾來」 |
| **設問** | 自問自答（提問）或無疑而問（激問/反問） | 問句形式，引起注意 | 「何以解憂？惟有杜康」（提問·自問自答） |
| **類疊（疊字）** | 重複使用同一字詞以加強語氣或節奏 | 連續重複同字 | 「蕭蕭」「滾滾」「嫋嫋」 |

## 二、最易混淆的三組

<RhetoricConfusion client:visible />

**A. 譬喻 vs 借代**

| | 譬喻 | 借代 |
|---|---|---|
| 本體 | 存在（明說或暗示） | 不出現，完全被替換 |
| 喻詞 | 有（像、如、彷彿、是） | 無 |
| 例 | 「她的笑容像陽光」 | 「六宮粉黛無顏色」（粉黛代美女） |

**B. 轉化（擬人）vs 轉品（活用）**

| | 擬人 | 轉品 |
|---|---|---|
| 核心 | 無生物「有了人的感情/動作」 | 字的詞性在句中臨時改變 |
| 例 | 「芭蕉惹驟雨」（芭蕉有人的行為「惹」） | 「春風風人」（第二「風」從名詞變動詞） |

**C. 排比 vs 對偶**

| | 排比 | 對偶 |
|---|---|---|
| 組數 | 三組以上 | 恰好兩組 |
| 字數 | 不一定相等 | 上下句字數相等 |
| 例 | 「芭蕉惹驟雨，門環惹銅綠，惹了你」（三組） | 「蕭蕭下，滾滾來」（上下兩句對應） |

## 三、怎麼判斷「是不是對偶（對仗）」

考試很常問「下列<b>不是</b>對句的選項是？」或「<b>沒有</b>對仗的選項是？」。
判斷對偶，上下兩句要同時滿足三個條件，**缺一就不算對仗**：

| 條件 | 說明 | 反例（不對仗） |
|---|---|---|
| ① 字數相等 | 上下句字數一樣 | 句子長短不一 |
| ② 詞性相對 | 名詞對名詞、動詞對動詞、數量詞對數量詞 | 「珠有淚」對「玉生煙」——「有」與「生」對得上，但若一句是動詞一句是名詞就破格 |
| ③ 結構相對 | 句法結構（主謂、動賓…）一一對應 | 上句「主＋動＋賓」下句卻是「主＋形＋名」 |

判斷步驟：**把上下句拆成一個字（或一個詞）對一個字，逐一比詞性與結構；只要有一處對不上，就不是對仗。**

範例（標準對仗）：「窗含<b>西嶺</b>千秋雪，門泊<b>東吳</b>萬里船」——窗對門（名）、含對泊（動）、西嶺對東吳（地名）、千秋對萬里（數量）、雪對船（名），字字工整。

容易誤判：句子有「對偶感」但**詞性或結構對不上**，就是答案（不是對句）。例如「春潮帶雨晚來急，野渡無人舟自橫」雖意境相配，但結構不全對應，屬非工對。

## 四、借代常考範例

| 代詞 | 代替的本體 | 出處 |
|---|---|---|
| 杜康 | 酒（以人名代物） | 「何以解憂？惟有杜康」 |
| 絲竹 | 音樂（以樂器：絲弦＋竹管代音樂） | 「終歲不聞絲竹聲」 |
| 帆 | 船（以部分代整體） | 「過盡千帆皆不是」 |
| 粉黛 | 美女（以妝飾代人） | 「六宮粉黛無顏色」 |
| 巾幗 | 女性（以服飾代人） | 「巾幗不讓鬚眉」 |
| 鬚眉 | 男性（以外貌代人） | 「鬚眉」 |
| 朱門 | 富貴人家（以門色代人） | 「朱門酒肉臭」 |
| 東市 | 刑場（以地名代事）| 「直到東市方知」 |

## 五、其他高頻修辭與「判別原理」

前四類最常考，但考卷也常出下面這幾種。**與其背定義，不如記住每種的「判別動作」與它最容易被誤認成哪一格**——抓住差異點就能秒判。

| 修辭格 | 判別原理（怎麼一眼認出） | 最易混淆者・怎麼分 |
|---|---|---|
| **層遞** | 各項依「程度／數量／範圍／時間」由小到大（或由大到小）**層層遞進**，前後有「累進」關係 | vs **排比**：排比只是平行並列、可任意對調；層遞**抽掉中間一級語意就斷**（身修→家齊→國治→天下平，順序不可換） |
| **摹寫** | 用文字摹擬**感官知覺**：視（色彩光影）、聽（聲響）、嗅、味、觸。判斷時先問「這句訴諸哪一種感官」 | vs 一般敘述：摹寫**訴諸感官、可被感覺到**；單純說理／敘事不算 |
| **移覺（通感）** | 摹寫的進階：把**甲感官**的感受，用**乙感官**的詞語去形容（感官「挪移」） | 判別動作：先標出「主體屬於哪一感官」，再看「拿哪一感官的字去寫它」。如「**音樂**（聽）裊裊**如煙**（視）」＝聽→視 |
| **雙關** | 一個詞**同時表裡兩義**：諧音雙關（音同義異，如「蓮」諧「憐」、「絲」諧「思」）、詞義雙關（一詞兼指本義與另一義） | vs 借代：借代是「換一個詞代替本體」（只剩一義）；雙關是「同一個詞**兩義並存**」 |
| **錯綜（交蹉語次）** | 本該整齊對應並列的兩組詞，**故意打散次序、交錯排列**。還原法：把對應項重新配對，若能還原成「A→A′；B→B′」就是錯綜 | vs 對偶：對偶是**順序工整**地兩兩相對；錯綜反而是**刻意把對應次序錯開** |
| **析數（拆數相乘）** | 不直接寫數字，而把它**拆成兩數相乘**：二八＝16、三五＝15、八九＝72；多用於詩詞湊節奏 | 陷阱：「十一」常被誤認，其實多是**分數「十分之一」**（不能相乘），不是析數 |

判斷小訣竅：**層遞看「順序能不能換」**（不能換＝層遞）；**移覺看「兩種感官」**（一句裡橫跨兩感官＝移覺）；**錯綜看「對應有沒有被打散」**（還原得回對句＝錯綜）。

## 六、設問的三種：提問・激問・懸問

「設問」是大類，考試常要你**再細分**是哪一種。判別關鍵只有一個問題：**「下文有沒有作答？答案是正面還是反面？」**

| 種類 | 判別原理 | 特徵一句話 |
|---|---|---|
| **提問**（自問自答） | 先問、**下文馬上給答案** | 有問有答 |
| **激問**（反問／詰問） | **無疑而問**，作者心中早有定見；**答案在問句的反面**，且**不明寫** | 「難道…嗎？」「豈能…？」——意思其實是相反那一面 |
| **懸問**（疑問） | 真有疑惑、**問而不答**，把問題懸在那裡 | 純提問、不解答，留給讀者想 |

判別動作：看到問句先找下文——**有答案就是提問**；**沒答案、且用「難道／豈／焉得」這類語氣、答案明顯是反面**，就是激問；**沒答案、也只是單純發問**，是懸問。**激問**最常考，記住它＝「明知故問、要你會意相反的意思」。
