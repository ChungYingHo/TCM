片語動詞與慣用語的意思常和字面無關，要<b>整組記</b>，並靠上下文的動作推義。本篇整理高頻片語動詞與慣用語的分類記憶。

## 一、什麼是片語動詞（Phrasal Verb）？

片語動詞 = 動詞 + 介副詞（介系詞 or 副詞），組合後意思**往往和字面完全不同**。

| 片語動詞 | 字面拆解 | 真正意思 |
|---|---|---|
| carry out | 帶出去 | **執行**（任務） |
| look up | 向上看 | **查詢**（字典） |
| look after | 向後看 | **照顧** |
| look for | 向前看 | **尋找** |
| look into | 往裡看 | **調查** |
| give up | 向上給 | **放棄** |
| come across | 穿越過來 | **偶然遇到** |
| put off | 放到外面 | **推遲、拖延** |
| break down | 往下打碎 | **故障；崩潰** |
| turn down | 向下轉 | **拒絕；調低音量** |
| rule out | 往外畫線 | **排除**（可能性） |
| point out | 往外指 | **指出** |
| set up | 向上放置 | **建立、設置** |
| take over | 拿過來 | **接管** |
| work out | 往外工作 | **計算出；解決；運動** |
| stand for | 代表旗下 | **代表**（縮寫意思） |
| run out of | 往外跑光 | **耗盡** |
| call off | 喊出外面 | **取消** |
| bring about | 帶到周圍 | **導致、引起** |
| figure out | 找出形狀 | **弄清楚、想出** |

### 不要硬背整張表——用「介副詞的方向／語意」推義

上表看似要逐條死記，其實**介副詞（particle）本身帶固定的方向感與引申義**。抓住 particle 的核心意象，多數片語動詞就能「望文生義、自己推出來」：

| 介副詞 | 核心意象 | 引申語意 | 例 |
|---|---|---|---|
| **up** | 向上、到頂 | **完成／徹底／增加／浮現** | speed up（加快）、eat up（吃光）、set up（建起）、well up（湧上來） |
| **out** | 由內向外、到盡頭 | **產出／徹底完成／排除／用盡** | carry out（執行）、work out（算出）、rule out（排除）、run out（用光） |
| **off** | 分離、脫離 | **中斷／取消／出發／除去** | call off（取消）、put off（推遲＝把事推離現在）、set off（出發） |
| **down** | 向下 | **減少／壓制／記下／故障** | turn down（調低／拒絕）、cut down（減少）、break down（故障）、write down（記下） |
| **over** | 翻越、覆蓋 | **翻轉／移交／重來** | take over（接管）、think over（仔細想）、turn over（翻面） |
| **in** | 向內、進入 | **加入／進入某狀態／呈現** | come in（以…形式出現）、fill in（填入）、take in（吸收） |

**推義示範**：不認得 `well up`？well 作動詞是「湧出」，加 **up**（向上、浮現）→ **（淚水/情緒）湧上來**。不認得 `crank out`？crank 是「轉動曲柄」，加 **out**（大量產出）→ **大量快速地製造**。先想 particle 給的方向，再配動詞本義，答案常呼之欲出。

### 可分 vs. 不可分：受詞放哪裡？

片語動詞分兩類，規則來自「particle 是副詞還是介系詞」：

- **及物＋副詞 → 可分**：受詞可放中間或後面；但**代名詞一定夾在中間**。turn the radio down ✓ ／ turn it down ✓ ／ ~~turn down it~~ ✗。（其他：look up the word／look it up、call off the trip／call it off。）
- **動詞＋介系詞 → 不可分**：介系詞後面非接受詞不可，**永遠不能拆**。look after the baby ✓ ／ ~~look the baby after~~ ✗ ／ look after it ✓。（其他：look into、deal with、come across、run out of。）
- 一句話判斷：**代名詞能塞進中間（turn it down）就是可分；不能（~~look it after~~ 要說 look after it）就是不可分。**

## 二、常考慣用語分類記憶

依情境分類，一次記一組比較有效：

<IdiomCategories client:visible />

**時間類**
- on time（準時）/ in time（及時，還來得及）
- at the moment（此刻）/ for the time being（目前、暫時）
- sooner or later（遲早）

**讓步 / 不管如何**
- in spite of / despite（儘管）
- regardless of（不管）
- after all（畢竟）

**動作 / 名詞片語（後中醫實際考過，常配 take / come）**
- take center stage（成為焦點、登場主角）
- take ... by storm（席捲、轟動）
- come in (different forms)（以…形式存在；有不同種類）
- pass up（錯過、放過機會）
- speed up（加快）/ speed along（疾行、迅速前進）

**因果 / 結果**
- as a result（因此）
- lead to / result in（導致）
- owing to / due to（由於）

**程度**
- to some extent（某種程度上）
- by no means（絕非）
- to a large degree（在很大程度上）

## 三、形容詞／分詞 + 介系詞（高頻必考，最常被忽略）

後中考古題每年都大量考「**形容詞或過去分詞要搭哪個介系詞**」，且常把同字根的形容詞當陷阱（resistant / persistent / insistent / consistent 各配不同介系詞）。這類**介系詞是「綁定」在該形容詞上的固定搭配**，但仍有可循的語意邏輯，不必純背：

| 介系詞 | 語意線索 | 高頻搭配 |
|---|---|---|
| **to**（朝向、面對） | 對某對象的傾向／易受性 | resistant **to**（對…有抗性）、susceptible / prone / vulnerable **to**（易受…）、adjacent **to**（鄰接） |
| **of**（從屬、構成） | 沒有／構成／剝奪 | free **of**（無…的）、devoid **of**（缺乏）、comprised **of**（由…構成）、deprived **of**（被剝奪） |
| **from**（來源、分離） | 源自／有別於 | derived **from**（源自）、distinguished **from**（有別於）、abstained **from**（戒除） |
| **in**（內含、本質） | 內在固有 | inherent **in**（內在固有於）、interested **in**、involved **in** |
| **with**（伴隨、賦予） | 帶有／被歸予 | credited **with**（被歸功於…）、laced **with**（摻有）、consistent **with**（與…一致） |
| **on**（依靠、堅持） | 依賴／堅持 | dependent / reliant **on**（依賴）、insistent **on**（堅持）、keen **on**（熱衷） |

**推義要訣**：介系詞的方向感能幫你刪去錯項——表「易受影響、有抗性」的形容詞幾乎都配 **to**（susceptible / prone / resistant / vulnerable to），所以看到 `insistent **on**`、`consistent **with**` 就知道是另一語意群。**遇到不確定的，先用句意鎖定形容詞，再回想該形容詞慣用的介系詞，並用上面的方向感反推驗證。**

<Memorize>
形容詞/分詞 + 介系詞是固定搭配，但有方向感：<br />
「易受…/有抗性/傾向」→ <b>to</b>（susceptible / prone / resistant / vulnerable to）。<br />
「無…/由…構成/被剝奪」→ <b>of</b>（free / devoid / comprised / deprived of）。<br />
「源自/有別」→ <b>from</b>；「內在固有」→ <b>in</b>（inherent in）；「被歸功」→ <b>with</b>（credited with）。
</Memorize>

## 四、考試遇到不認識的片語動詞怎麼辦？

1. 讀上下文，找「**句子裡在做什麼動作**」
2. 看動詞本身的基本意思（look = 看/查；give = 給）；再看 **particle 的方向感**（up = 完成、out = 產出/排除……，見第一節）
3. 對照選項，選最能填入句子邏輯的

<Memorize>
片語動詞<b>不能照字面拆</b>——carry out 不是「帶出去」，是「執行」。<br />
遇到不認識的：看上下文動作 → 猜整體語意 → 從選項刪去邏輯不符的。<br />
look 家族高頻：look <b>after</b>（照顧）/ <b>for</b>（尋找）/ <b>into</b>（調查）/ <b>up</b>（查詢）。
</Memorize>
