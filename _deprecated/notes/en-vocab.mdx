字彙題不是考「有沒有背過這個字」，而是考**在句子中選最貼切的字**。三個核心技巧：判語氣、拆字根、用刪去法。

## 一、語氣判斷（正面 / 負面 / 中性）

先讀整句，判斷空格需要正面、負面還是中性的字。  
例：*"The doctor gave us _____ evidence that the treatment was safe."*  
→ 句意正面（安全的治療），空格需要「有力的、令人信服的」之類的**正面**形容詞。

## 二、字根字首拆解推義

認識常見字首字根，陌生單字也能縮小範圍：

| 字首 / 字根 | 意義 | 例字 |
|---|---|---|
| un- / in- / im- / ir- | 否定 | unhappy, incomplete, impossible |
| re- | 再次 / 往回 | review, rebuild, reverse |
| pre- | 之前 | predict, prevent, precaution |
| mis- | 錯誤 | misunderstand, misjudge |
| over- | 過度 | overestimate, overload |
| sub- | 在下 / 次要 / 順從 | submarine, substandard, subservient |
| trans- | 橫越 / 轉移 | transfer, transport, transcend |
| geo- | 地、土地 | geography, geopolitical |
| -tion / -sion | 名詞化 | action, decision, invasion |
| -ous / -ful / -ive | 形容詞化 | dangerous, careful, effective |
| -ize / -ify | 動詞化 | realize, simplify |
| bene- | 好的 | benefit, beneficial |
| mal- | 壞的 | malfunction, malnutrition |
| -cide | 殺 | homicide, pesticide |
| -port | 攜帶 | transport, import, export |
| -dict | 說 | predict, contradict, dictate |
| -vis / -vid | 看 | visible, evidence, supervise |
| -mit / -miss | 送 | transmit, mission, submit |
| -archy / -cracy | 統治、政體 | monarchy, hierarchy, democracy |

### 同字首／同字根題：比的是「第二段」

近年最常見的陷阱是**四個選項共用同一個字首或字根**，例如 patriarchy／anarchy／monarchy／**hierarchy**、appeal／**appropriation**／appreciation／apparition、transferring／transporting／transplanting／transcending。  
這時共用的部分（-archy、appro-、trans-）對答案毫無鑑別力，**真正在比的是「另一段語素」**。原則：**先把共同部分劃掉，只看相異的字根，再回句子核對**。

- patri-（父）／an-（無）／mono-（單一）／hier-（神聖→層級）+ -archy（統治）→ 句意要「位階高低的界線」就選 **hierarchy（階層）**。
- appeal（吸引）／appropri-（據為己有）／appreci-（珍視）／appari-（顯現）→ 句意是「多數族群『挪用』少數文化」就選 **appropriation（挪用）**。
- 同理 geo- 系列差在 -physical／-nealogy（家系）／-metric（測量）／-politic：談國界與和平就選 **geopolitical**。

也用在**詞性區分**：四個選項同字根、字尾不同（如 -ate 動詞／-tion 名詞／-ous 形容詞），先看空格需要什麼詞性，字尾不對直接刪。

### 拆不出來時：用上下文與搭配詞推

字根拆不動、選項又都眼生時，**句子本身會給線索**——別空等想起字義：

- **搭配詞（collocation）**：某些字幾乎只跟特定名詞一起出現。amass 後面常接 **fortune／wealth**（聚斂財富）；virulent 多形容 **disease**（劇毒、傳染力強的病）；exert 後面常接 **pressure／influence**（施加壓力）。看到熟悉的搭配名詞，就能反推空格字。
- **定義式線索**：空格後常用 such as、which means、亦即…把答案「解釋」給你。如 *"Proper ___ facilities (such as toilets)"*，括號裡的 toilets 直接定義了 **sanitation（衛生設施）**。
- **對比／轉折詞**：but、however、while、unlike 後面語意常**相反**；therefore、thus、so 則語意**順承**。題幹 "controversial… therefore both ___ and opponents"，therefore 順承且與 opponents（反對者）對舉，空格就是**支持者 proponents**。

口訣：**拆得動就拆字根，拆不動就讀上下文**——兩條路都通往刪去法。

## 三、刪去法

選項四個，先刪掉詞性不對、語氣相反的，通常能縮到一兩個再決定。

<Memorize>
遇到不會的字：<b>①判語氣正負 → ②拆字根字首推義 → ③刪去詞性/語氣不符的選項</b>。<br />
四個選項<b>同字首／同字根</b>時，劃掉共同部分、<b>只比相異那段語素</b>。<br />
字根拆不動就<b>讀上下文與搭配詞</b>（such as 定義、therefore 順承、but 轉折）回推。<br />
時間不夠時，光靠語氣（正/負）刪去法就能把勝率拉到 50% 以上。
</Memorize>

<ExampleQuestion client:visible
  n={1}
  q="The new medication was found to _____ the symptoms of the disease, providing much-needed relief to patients."
  options={["aggravate", "alleviate", "eliminate", "provoke"]}
  answer="(B) alleviate"
  steps={[
    "讀句意：新藥讓症狀「___」，提供了急需的緩解（relief）。→ 需要<b>正面、減輕症狀</b>的字。",
    "刪去法：A. aggravate（惡化）負面❌；D. provoke（激起）負面❌；C. eliminate（完全消除）語氣過強——relief 是『減輕』非根除，故不如 alleviate 貼切。",
    "B. alleviate（緩解）＝正面、程度適中，與 relief 語意一致。答案 (B)。",
    "字根提示：al-levi-ate → levi 來自拉丁 levis（輕），使變輕 = 緩解。"
  ]}
/>

<ExampleQuestion client:visible
  n={2}
  q="It is quite clear that the electric car is technically _____."
  options={["negotiable", "feasible", "impassible", "bearable"]}
  answer="(B) feasible"
  steps={[
    "句意：電動車在技術上是「___」的。→ 描述技術上「做得到、可行」的<b>中性偏正面</b>形容詞。",
    "A. negotiable（可協商的）、C. impassible（無法通行的）、D. bearable（可忍受的）語意都不符。",
    "B. <b>feasible</b>（可行的、行得通的）完全符合。答案 (B)。字源 facere（拉丁：做、造，經古法語 faisible）→ 做得到的、可行的（字根 fac-/fais-，非 fea-）。"
  ]}
/>

<ExampleQuestion client:visible
  n={3}
  q="Peter presented us with _____ evidence that convinced us he was right."
  options={["indecisive", "feeble", "telling", "dreary"]}
  answer="(C) telling"
  steps={[
    "句意：Peter 提出「___」的證據讓我們信服。→ 需要「有力、令人信服」的<b>正面形容詞</b>。",

    "注意：telling 常見意思是「說」（動詞），但作形容詞時意思完全不同——遇到熟字意思卻不對，考慮它的另一詞性或詞義。"
  ]}

<ExampleQuestion client:visible
  n={4}
  q="The doctor warned that ignoring the early signs could _____ the patient's condition significantly."
  options={["mitigate", "exacerbate", "stabilize", "alleviate"]}
  answer="(B) exacerbate"
  steps={[
    "句意：忽視早期徵兆會「___」病況。→ 忽視症狀的後果是負面的，需要<b>負面、使惡化</b>的字。",
    "A. mitigate（減輕）正面❌；C. stabilize（穩定）中性但與忽視後果不符❌；D. alleviate（緩解）正面❌。",
    "B. exacerbate（使惡化）語氣負面，符合「忽視→惡化」的邏輯。答案 (B)。",
    "字首提示：ex- 往外加強 + acer（尖、苦）→ 使情況更尖銳/苦 = 惡化。"
  ]}

  n={5}
