應用文考的是「**場合配對**」——不是考你背定義，而是考你在哪個場合用哪個詞、哪個格式。先把書信結構看一遍，再把各種場合的詞彙對應記起來。

## 一、書信格式五大部分

```
① 稱謂（對方的稱呼）      如：父親大人、老師尊鑒
② 提稱語（接在稱謂後）    如：膝下、函丈、台鑒
③ 開頭寒暄語
④ 正文
⑤ 結尾敬辭 + 署名
   結尾敬辭：如：敬祝 鈞安、謹頌 時祺
   署名：自稱（謙稱）+ 姓名 + 敬上
```

## 二、提稱語與書信用語對照

提稱語接在稱謂後，表示「呈上此信」。**依對象不同，用語也不同**，這是考試最常問的地方。下面的工具一次列出各對象的提稱語、自稱、結尾敬辭與啟封詞：

<LetterSalutations client:visible />

提稱語整理如下：

| 對象 | 提稱語 | 例 |
|---|---|---|
| 父母、長輩（至親） | **膝下** | 父親大人膝下 |
| 師長、老師 | **函丈**（尊師）、**道席**、**講席** | 恩師函丈 |
| 一般長輩、上司 | **尊鑒**、**賜鑒**（鈞鑒限上司／官方） | 伯父尊鑒 |
| 平輩、朋友 | **台鑒**、**惠鑒**、**大鑒** | 同學台鑒 |
| 晚輩（寫給學生） | **知悉**、**覽** | 學生 某某 知悉 |
| 政府機關 | **鈞鑒** | 局長鈞鑒 |

## 二之二、書信的雅稱／借代（古詩文常考）

考題很愛在古詩文裡挖一個詞，問「下列何者**與書信無關**／何者**指書信**」。這些詞清一色是**古人傳信方式的借代**，先懂典故就不用硬背：

- **魚（魚書、雙鯉、雙鯉魚、尺素）**：古人把信紙（一尺長的素絹＝「**尺素**」）裝在刻成鯉魚形的木盒裡寄送，所以「**雙鯉**」「烹鯉魚」其實是拆信盒，魚就成了信的代稱。
- **雁（雁書、雁足、雁帛、魚雁）**：用蘇武「**鴻雁傳書**」的典故——鴻雁南北遷徙、被想像成能帶信，於是「雁」也代指書信。
- **其他**：**錦書**（織錦寄字）、**八行書**（信紙一頁約八行，故稱「八行」）、**尺牘／尺翰**（一尺長的書寫木片）。

> 判斷訣竅：句中的「魚／雁／鯉／素／錦／牘」若**搭配「寄、傳、來、烹、中有……書」等「傳遞或藏字」的動作**，多半就是借指書信；若只是寫**真的動物或動作**（如「信馬」是放鬆韁繩騎馬、「雁行」是兄弟並行、「落雁沉魚」是形容美貌），就**與書信無關**。

## 三、稱人／稱己：家族與親屬稱謂對照表

「稱呼別人的家人」用敬辭，「稱呼自己的家人」用謙辭——這組最容易考錯：

| 關係 | 稱「別人的」（敬，多用「令／尊／賢」） | 稱「自己的」（謙，多用「家／舍／小／先」） |
|---|---|---|
| 父親 | **令尊**、尊翁 | **家父**、家嚴 |
| 母親 | **令堂**、令慈 | **家母**、家慈 |
| 兒子 | **令郎**、令公子 | **小兒**、犬子 |
| 女兒 | **令媛**（令嬡） | **小女** |
| 兄弟 | **賢昆仲**、令兄／令弟 | **家兄**、舍弟 |
| 已故的長輩 | — | **先父**、先母（「先」＝已過世的尊長） |

> 三字口訣：**長輩用「家」**（家父家母）、**平輩晚輩用「舍／小」**（舍弟小女）、**已故用「先」**（先父）。稱對方一律用敬辭（令／尊／賢），絕不能用謙辭。
>
> 陷阱：「賢昆仲」是**敬稱對方的兄弟**，不能拿來稱自己的兄弟。

## 四、自稱（謙稱）對照表

寫信時對不同對象的自稱：

| 對象 | 自稱 | 說明 |
|---|---|---|
| 父母 | **男（女）**、不孝兒 | 子女對父母 |
| 師長 | **受業**、門生、學生 | 學生對老師 |
| 長輩 | **晚**、後學 | 晚輩對長輩 |
| 平輩 | **弟**（男）、**妹**（女）| 同輩之間 |
| 晚輩（對方） | 余、愚 | 長輩寫給晚輩 |

## 五、結尾敬辭（祝頌語）

書信末尾的祝福，依**對象身份**選用：

| 對象 | 結尾敬辭 |
|---|---|
| 長輩 | 敬請 **福安**、謹頌 **崇安**、叩請 **金安** |
| 師長 | 敬請 **道安**、敬頌 **誨安** |
| 平輩 | 敬請 **台安**、即請 **大安** |
| 晚輩 | 即詢 **近安**、順詢 **近好** |

## 六、信封啟封詞（別跟「提稱語」搞混）

**提稱語**寫在「信紙裡」稱謂後（膝下、函丈…）；**啟封詞**寫在「信封上」收信人名字後，請對方拆信。兩者位置與用詞都不同：

| 對象 | 信封啟封詞（請對方開啟） |
|---|---|
| 長輩 | **安啟**、福啟（恭敬請長輩拆） |
| 平輩 | **大啟**、台啟 |
| 晚輩 | **啟**、收 |

> **大陷阱**：「**敬啟**」是「**恭敬地（替您）開啟**」，主詞是收信人——叫長輩「恭敬地拆信」於理不合，所以**信封上對長輩不可寫「敬啟」**，要用「安啟／福啟」。「敬啟」只能用在署名後表「敬告」（如公告「○○謹啟」）。

## 七、抬頭（書信中的敬意符號）

信中**提到對方或對方尊長**時，要表示尊敬：

- **挪抬**：在該詞前空一格（最常用），如「敬請　鈞安」。
- **平抬**：另起一行頂格書寫，更隆重。
- 反之，**提到自己或自己的尊長**時，字體要**略小、偏右**書寫，以示自謙。

> 一句話：抬高別人（空格／另行），縮小自己（略小偏右）。

## 八、便條／柬帖常見類型（看內容判用途）

便條是簡短的應酬文字，考題給一段便條問「這是做什麼用的」，看關鍵動詞就懂：

| 便條類型 | 關鍵字／情境 |
|---|---|
| **謝饋贈** | 對方送東西來（佳茗、禮物），回「拜領、申謝忱」 |
| **謝邀宴** | 對方請吃飯，回「敬謝盛宴」 |
| **謝來訪** | 對方來拜訪，回「謝枉駕」 |
| **謝慰問** | 自己生病／有事，對方來問候 |
| **借物／還物** | 「謹借」「奉還」 |

| 題辭 | 說明 |

**開業（喬遷、開店）**：

| 題辭 | 說明 |
|---|---|

| **生意興隆** | 商業祝賀 |
| **鴻圖大展** | 事業開展 |
| **業紹陶朱**（陶朱＝范蠡，古之富商）| 賀**商店**開張、生財 |

| 題辭 | 典故／所指 |
|---|---|
| **杏林春暖／杏林之光** | 董奉行醫不收錢、只要病患種杏樹，後以「**杏林**」代稱醫界 |
| **橘井流香（泉香）** | 蘇耽以井水加橘葉治瘟疫，「**橘井**」遂代指良醫良藥 |
| **術精岐黃／妙手回春** | 岐伯、黃帝（《黃帝內經》）＝醫術之祖，「**岐黃**」即醫道 |
| **功同良相／功侔相業** | 「**良醫良相**」——醫者濟世之功可比賢相 |
| **望隆盧扁／扁鵲復生** | 盧醫、扁鵲＝古代神醫，喻醫術高超 |
| **祕傳金匱／方列千金** | 《金匱要略》《千金方》＝醫書經典，喻醫術有本 |

> **辨偽陷阱**：題辭若用的是**「教育、文教」典故就不是賀醫**——如「**杏壇**」（孔子講學處，賀**教育界**，別跟醫界的「杏**林**」混）、「德業長昭／儀型足式」（泛頌德行，非專賀開業）。看到「杏壇春暖」配診所即為錯誤配對。

## 九之二、對聯判讀：上下聯怎麼分？行業怎麼配？

對聯題有兩種問法，各有一個「能自己推」的訣竅，不必背每副對聯：

**（甲）判斷上聯／下聯（看末字平仄）**：對聯規矩是「**仄起平收**」——

- **上聯末字收「仄聲」**（三、四聲，或入聲字如「福、節、月、業」），念起來「短促、往下壓」。
- **下聯末字收「平聲」**（一、二聲，如「春、家、天、來」），念起來「平長、可收尾」。
- 所以看兩句的**最後一個字**：尾字是仄聲的擺上聯、平聲的擺下聯；若題目把平聲句放在上聯，就是「上下聯顛倒」。
- 張貼時：**上聯在右、下聯在左**（直式由右讀到左）。

**（乙）判斷對聯配哪個行業／對象（抓關鍵意象）**：行業聯一定把該行的「**招牌字眼**」藏在句裡，對到字眼就對到行業——

- 中醫藥店 → 「**君臣佐使**（藥性配伍）、岐黃、橘井、囊中延年藥」；
- 理髮 → 用快刀名將典故（翼德、公瑾「再現／重生」暗喻**刀法俐落**）；
- 照相館 → 「**鏡頭、神韻、留影**」；電信 → 「**談心有捷徑、不握手言歡**（遠距通話）」；
- 餐飲 → 「**烹、味、珍饈**」；保險 → 「風雨水火**無情／不測**」。
- 訣竅：**先找名詞意象 → 反推它屬於哪一行**，再檢查有沒有張冠李戴（把照相館的「神韻相紙」配到服飾店就錯）。

## 十一、公文常識（類別、稱謂、期望／准駁語）

公文題的核心是**「行文方向」**——分清楚是**上行**（下級對上級）、**平行**（對等機關）、**下行**（上級對下級），用語就能推出來，不必死背：

**① 公文程式類別**：

| 類別 | 用途 |
|---|---|
| **令** | 公布法規、人事任免，或**上級對下級**有所指示 |
| **呈** | 對**總統**有所呈請或報告（專用於對總統） |
| **函** | 最常用：**各機關公文往復**（上行、平行、下行都可用） |
| **書函** | 性質較不正式的洽辦、答覆 |
| **公告** | 向**公眾或特定對象**宣布周知 |
| **手令／手諭** | 機關長官對所屬有所指示交辦 |

**② 稱謂語**（看「誰對誰」）：

- 對等或不相隸屬機關互稱「**貴**」（貴部、貴府）；自稱「**本**」（本院、本部）。
- **有隸屬關係**的下級對上級用「**鈞**」（鈞部、鈞府）；**無隸屬關係**而表尊敬用「**大**」（大部、大院）——「鈞」對應隸屬、「大」對應不相隸屬，別記反。
- 機關／首長對人民或屬員，可稱「**台端**」。

**③ 期望語與准駁語**（順著行文方向走）：

- **上行**（求人核可）→ 期望語用「**請鑒核**」「**請核備**」「請鑒察」。
- **下行**（上級裁示）→ 准駁語如「**應予照准**」「**未便照准**」「**應從緩議**」。
- **平行**（對等商洽）→ 表態用「**敬表同意**」「**礙難同意**」，不會對平行機關說「照准／不准」（那是上對下的口氣）。

> 一句話：**上行客氣求人（鑒核）、下行裁決准駁（照准）、平行商量同意（敬表同意）**；用錯方向就是考點。

稱對方家人用敬辭（<b>令尊、賢昆仲</b>），稱自己家人用謙辭（<b>家父、舍弟</b>）。<br />
信封對長輩用「<b>安啟</b>」，<b>不可用「敬啟」</b>（敬啟＝恭敬地拆，不能叫長輩做）。<br />
生男用<b>夢熊／弄璋</b>，生女用<b>夢蘭／弄瓦</b>；<b>瓊花並蒂</b>是婚慶，不是生子。<br />
<b>魚雁、雙鯉、尺素、錦書、八行</b>都借指「<b>書信</b>」（鴻雁傳書／魚腹藏書）。<br />
對聯<b>仄起平收</b>：上聯末字<b>仄</b>、下聯末字<b>平</b>；賀醫用<b>杏林／橘井／岐黃</b>（杏「壇」是教育，別混）。
</Memorize>

  "<b>生男</b>用弄璋之喜、夢熊之兆；<b>生女</b>用弄瓦之喜、夢蘭之兆；綿綿瓜瓞祝子孫繁衍。",
  "<b>節日對聯</b>：春節＝宜春、歲月增壽；元宵＝燈火笙歌；端午＝艾旗蒲劍（驅邪）。",
  "<b>稱人稱己</b>：稱對方家人用敬辭（令尊、令堂、賢昆仲）；稱自己家人用謙辭（家父、家母、舍弟）；已故尊長用「先」（先父）。",
  "<b>啟封詞 vs 提稱語</b>：提稱語在信紙內（膝下、函丈）；啟封詞在信封上（長輩安啟、平輩台啟）。對長輩信封<b>不可寫「敬啟」</b>。",
  "<b>抬頭</b>：提到對方／對方尊長要挪抬（空一格）或平抬（另起一行）；提到自己尊長則字體略小偏右以示自謙。",
  "<b>便條看動詞判用途</b>：拜領→謝饋贈、謝盛宴→謝邀宴、謝枉駕→謝來訪。",
