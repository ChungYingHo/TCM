演化講的是族群的基因組成隨世代改變。本篇從天擇的三個條件談起，帶到哈溫平衡的計算、改變基因頻率的各種力量，再到物種如何形成與生命如何起源。

## 一、天擇（Natural Selection）三要素

天擇不是「強者生存」那麼簡單，考試最愛考「缺少哪一要素就不成立」：

| 要素 | 白話說明 | 考試關鍵字 |
|---|---|---|
| **變異（Variation）** | 同種個體間有性狀差異 | 隨機突變、重組 |
| **可遺傳（Heredity）** | 變異能傳給後代 | 遺傳物質改變 |
| **環境篩選（Selection）** | 某些表現型在環境中存活/繁殖較佳 | 適應度（fitness）|

三者缺一，天擇就停止運作。**後天獲得的性狀（如練出的肌肉）不可遺傳，不算演化材料。**

### 天擇的三種模式：看「篩掉分布的哪一端」就能推

天擇怎麼塑造一個性狀的分布（如體型大小），不必硬背三個名字——**只要問「環境淘汰掉鐘形曲線的哪部分」**就推得出來：

| 模式 | 淘汰誰、留下誰 | 分布變化 | 典型情境 |
|---|---|---|---|
| **方向性（Directional）** | 淘汰**某一端**極端 | 平均值往另一端移 | 環境往單一方向變（乾旱→留大喙） |
| **穩定性（Stabilizing）** | 淘汰**兩端**極端 | 變異變小、向中間集中 | 環境穩定，中庸最適（新生兒體重） |
| **分歧性／歧化（Disruptive）** | 淘汰**中間**、留兩端 | 分裂成兩個高峰 | 兩種極端策略都吃香，中間最差 |

推導訣竅：題目描述「**中等型最吃虧、兩種極端各有優勢**」→ 中間被淘汰 → **分歧性**。描述「**極端都被淘汰、只剩中庸**」→ **穩定性**（注意：穩定性把變異往中間收，**最不可能**製造新種）。描述「**平均值整代往一個方向跑**」→ **方向性**。

## 二、哈溫平衡（Hardy–Weinberg Equilibrium）

哈溫平衡是「族群遺傳不變」的基線。設一個體等位基因頻率為 **p（顯性 A）** 和 **q（隱性 a）**，則：

$$
p + q = 1
$$

$$
\text{基因型頻率：} p^2 (\text{AA}) + 2pq (\text{Aa}) + q^2 (\text{aa}) = 1
$$

**哈溫平衡成立條件**（違反任一 → 族群演化中）：

| 條件 | 違反後造成 |
|---|---|
| 族群夠大（無遺傳漂變） | 遺傳漂變（genetic drift） |
| 隨機交配（panmixia） | 非隨機交配，改變基因型頻率 |
| 無突變 | 改變等位基因頻率 |
| 無自然選擇 | 某基因型存活率差異 |
| 無基因流（gene flow） | 外來基因改變頻率 |

**計算流程（兩等位基因）**：題目通常給「某隱性表現型比例」= q²，則：

$$
q = \sqrt{q^2}, \quad p = 1 - q, \quad 2pq = \text{雜合子頻率}
$$

<HardyWeinberg client:visible />

**三等位基因（ABO 血型常考！）**：若一個基因有三個等位基因，頻率設為 p、q、r，仍然「全部加起來＝1」，平方展開即得所有基因型頻率：

$$
p + q + r = 1
$$

$$
(p+q+r)^2 = p^2 + q^2 + r^2 + 2pq + 2pr + 2qr = 1
$$

- **同型合子（homozygote）**＝平方項：p²、q²、r²。
- **異型合子（heterozygote）**＝交叉項：2pq、2pr、2qr。
- 「同型合子頻率總和」就是把三個平方項加起來：**p² + q² + r²**。

> ABO 血型：IA、IB、i 三個等位基因。同型合子＝IAIA、IBIB、ii，頻率＝(IA)²+(IB)²+(i)²。

## 三、基因頻率改變的原因

| 機制 | 說明 |
|---|---|
| **天擇** | 有方向性地改變頻率 |
| **遺傳漂變** | 小族群中頻率隨機波動（奠基者效應、瓶頸效應） |
| **突變** | 新等位基因的來源 |
| **基因流** | 個體或配子在族群間移動 |
| **非隨機交配** | 改變基因型頻率，但不一定改變等位基因頻率 |

## 四、物種形成與生殖隔離

**異域物種形成（Allopatric）**：地理屏障 → 族群分隔 → 各自演化 → 出現生殖隔離。

**同域物種形成（Sympatric）**：無地理隔離（如多倍體化、生態棲位分化）。

**生殖隔離**分兩大類：

| 種類 | 範例 |
|---|---|
| **合子前隔離（Prezygotic）** | 開花時間不同、行為隔離、機械隔離、配子不相容 |
| **合子後隔離（Postzygotic）** | 雜交後代不育（如馬×驢→騾，不育）、雜交致死 |

## 五、演化證據

| 證據類型 | 舉例 |
|---|---|
| **化石記錄** | 顯示生物隨時間改變；過渡化石（如始祖鳥） |
| **同源構造（Homologous）** | 人手/鳥翼/海豚鰭同源，由共同祖先演化而來 |
| **同功構造（Analogous）** | 鳥翼/蝴蝶翅膀功能相同但來源不同（趨同演化） |
| **退化器官（Vestigial）** | 人類尾椎骨、鯨魚骨盆殘跡（為陸生祖先遺留的無功能後肢骨） |
| **分子證據** | DNA/蛋白質/rRNA 序列越相近 → 親緣越近 |
| **生物地理** | 島嶼物種與最近大陸相似（達爾文雀） |

**為什麼建親緣樹只能信「同源」、不能信「同功」？** 演化證據的核心原理是：**相似性要來自共同祖先（同源），才反映親緣**。同功構造是不同祖先在相似選擇壓力下各自演化出的「**趨同（convergent）**」相似，叫**同塑性（homoplasy）**——它讓無關物種看起來很像，是建樹的**最大陷阱**（如恐狼 vs 灰狼、地中海/南非/澳洲都演化出耐旱耐火的植物，皆為趨同而非近親）。所以：**rRNA／DNA／胺基酸序列、同源構造、胚胎發育、生物地理都能定親緣；唯獨「同功構造」不能**，反而會誤導。

> **擴展適應（exaptation／前適應）**：一個構造**最初為某功能演化、後來被借用於新功能**。例：羽毛原本是爬行類祖先的**保溫**裝置，後來才被用於飛行——此時飛行羽毛就是 exaptation。別和「退化器官（失去功能的殘跡）」混淆：exaptation 是**換了新用途**，不是退化。

## 六、植物登陸的演化：用「離水程度遞增」一路推

植物從水生到征服陸地，每一個新構造都是為了**解決一個離水後的新問題**。把握「**愈晚出現的構造，愈能擺脫對水的依賴**」，登陸適應的**先後順序就能自己排**，不必死背：

| 出現順序 | 構造 | 解決的問題（離水困境） |
|---|---|---|
| ① 最早 | **角質層（cuticle）** | 防止體表水分散失——上陸第一關 |
| ② | **維管束組織（vascular tissue）** | 木質部運水、韌皮部運養，使植物能長高、運輸 |
| ③ | **種子（seed）** | 保護並攜帶胚，受精**不再需要水**，可擴散到乾地 |
| ④ 最晚 | **花朵（flower）** | 被子植物高效繁殖（吸引授粉者） |

- **推導**：先要能「**待在陸地不乾死**」（角質層）→ 再「**長高長大、把水運上去**」（維管束）→ 再「**繁殖不靠水**」（種子）→ 最後「**繁殖更有效率**」（花）。即 **角質層 → 維管束 → 種子 → 花**。
- **苔蘚（蘚苔）與蕨類為何離不開潮濕？** 牠們的精子**有鞭毛、要靠水游到卵**才能受精（且配子體世代裸露）；種子植物（裸子+被子）演化出**花粉管**送精，受精**脫離水**，才真正征服乾地。
- **過渡證據**：有些**裸子植物的精子仍帶鞭毛**（如蘇鐵、銀杏），正是「從無種子→種子植物」的過渡痕跡。
- **無種子維管束植物（蕨類、石松）是並系群（paraphyletic）**：因為這群「有維管束、無種子」的成員，其共同祖先的後代裡**還包含了後來長出種子的種子植物**，卻把種子植物排除在外——只要一個類群「**含共同祖先卻不含其全部後裔**」，就是並系群。

### 地質年代：記住「古→中→新生代」大框架就能排序

考題常給幾個「紀」要你選最早/最晚。不必背絕對年代，記住**大代的順序與代表事件**即可粗排：

| 大代 | 代表「紀」（早→晚） | 標誌事件 |
|---|---|---|
| **古生代（Paleozoic）** | 寒武→**奧陶**→志留→**泥盆**→**石炭**→二疊 | 寒武大爆發；泥盆「魚類時代」→四足類登陸；石炭巨大蕨類森林成煤 |
| **中生代（Mesozoic）** | **三疊**→侏羅→**白堊** | 恐龍時代；末期恐龍滅絕 |
| **新生代（Cenozoic）** | 第三紀→第四紀 | 哺乳類與人類興起 |

- 所以「**奧陶紀**（古生代早期）」比「泥盆、三疊、白堊」都早。
- **泥盆紀晚期（約 3.6–3.8 億年前）**出現第一批**四足類**：判定四足類的關鍵不是「肺能呼吸空氣」（肉鰭魚就有原始肺），而是**椎骨之間、椎骨與骨盆之間發育出完整關節**——能支撐身體在陸上活動。
- **石炭紀**的大量**蕨類、木賊、石松**巨木堆積成煤，是當時「最適合做建材/燃料」的植物來源。

## 七、生命起源

| 里程碑 | 說明 |
|---|---|
| 化學演化 | 有機小分子（胺基酸、核苷酸）在原始大氣/海洋中自發形成（米勒–尤里實驗） |
| 原始細胞 | 脂質泡囊（protobionts）具選擇性滲透 |
| RNA 世界假說 | 最早的自我複製分子可能是 RNA（ribozyme），而非 DNA |
| 最早細胞 | 原核細胞先出現（≈35 億年前）；真核細胞後出現（≈20 億年前），由內共生演化 |

**內共生理論（Endosymbiosis）**：粒線體的祖先是被吞噬的好氧性細菌；葉綠體祖先是被吞噬的光合作用細菌（藍綠菌）。

生殖隔離 = 物種形成的最後一步；合子前／合子後兩大類別必考。<br />
<b>天擇三模式</b>：淘汰兩端→穩定（不易種化）、淘汰一端→方向、淘汰中間→分歧。<br />
<b>建樹陷阱</b>：同功＝趨同（homoplasy）不可信；rRNA/DNA/同源才定親緣。<br />
<b>植物登陸序</b>（離水遞增）：角質層 → 維管束 → 種子 → 花。
</Memorize>
