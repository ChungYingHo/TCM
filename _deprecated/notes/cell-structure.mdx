細胞分原核與真核兩大類，真核細胞裡有各種分工的胞器。本篇用「工廠部門」的比喻認識胞器，再比較動植物細胞與細胞骨架。

## 一、原核細胞 vs 真核細胞

| 特徵 | 原核細胞（Prokaryote） | 真核細胞（Eukaryote） |
|---|---|---|
| **核膜** | **無**（DNA 裸露在細胞質中） | **有**（DNA 包在細胞核內） |
| 膜狀胞器 | **無**（粒線體、葉綠體等皆無） | **有** |
| 核糖體 | 有（70S，較小） | 有（80S，較大；粒線體/葉綠體內也是 70S） |
| 細胞壁 | 通常有（細菌：肽聚糖；古菌：不含肽聚糖） | 植物有（纖維素）；動物無 |
| DNA | 環狀，單一條染色體；可有質粒（plasmid） | 線狀，多條染色體，在細胞核 |
| 代表 | 細菌、古菌、藍綠菌（藍綠藻） | 動物、植物、真菌、原生生物 |

> **考試陷阱**：藍綠菌（Cyanobacteria）能行光合作用，但它是**原核生物**，沒有葉綠體！光合色素位於細胞質內的類囊體膜上（藍綠菌有獨立類囊體膜系統，但無葉綠體），而非細胞膜上。

> **藍綠菌的固氮**：某些絲狀藍綠菌會分化出一種厚壁、不行光合的特化細胞，叫**異形細胞（heterocyst）**，專門進行**固氮作用**（把 N₂ 變成可用氮）。厚壁是為了隔絕氧氣，因為固氮酶怕氧。

## 二、真核細胞胞器（工廠部門對照）

把細胞想成一間工廠，各胞器就是不同部門。動手探索：

<Organelle client:visible />

| 胞器（工廠部門） | 構造特點 | 主要功能 |
|---|---|---|
| **細胞核（Nucleus）** | 雙層核膜，核孔控制進出 | 儲存 DNA，主宰基因表現（CEO 辦公室） |
| **核糖體（Ribosome）** | 無膜，rRNA + 蛋白質組成；附著內質網或游離 | **蛋白質合成**（生產線） |
| **粗糙內質網（RER）** | 表面有核糖體 | 蛋白質合成後的初步折疊、送往高基氏體 |
| **滑面內質網（SER）** | 無核糖體 | 脂質合成、解毒（肝細胞多）、鈣離子儲存 |
| **高基氏體（Golgi）** | 扁平囊狀堆疊 | 蛋白質**修飾、分類、包裝、運輸**（郵局） |
| **粒線體（Mitochondria）** | 雙層膜，內膜有嵴（cristae） | **有氧呼吸（ATP 生產）**（發電廠） |
| **葉綠體（Chloroplast）** | 雙層膜＋類囊體（thylakoid）＋基質（stroma） | **光合作用**（太陽能面板） |
| **溶體（Lysosome）** | 單層膜，內含水解酶（pH≈5） | **分解老舊胞器、異物**（廢物處理廠） |
| **液胞（Vacuole）** | 單層膜（tonoplast） | 植物：大液胞儲水維持膨壓；動物：小食泡/水泡 |
| **中心體（Centrosome）** | 含 2 根中心粒，無膜 | 形成紡錘絲，動物細胞分裂必備；植物通常無 |
| **過氧化體（Peroxisome）** | 單層膜 | 分解脂肪酸、解毒（2 H₂O₂ → 2 H₂O + O₂，由 catalase 催化） |

> **溶體 vs 過氧化體（都會「解毒」但方式不同）**：溶體用**水解酶**（酸性 pH≈5）消化大分子與老舊胞器；過氧化體用**氧化酶**處理脂肪酸並把有毒的 H₂O₂ 用**過氧化氫酶（catalase）**分解成 H₂O。兩者都參與細胞內有害物質的處理。

## 三、細胞骨架（Cytoskeleton）：鋼筋與軌道

細胞質裡有三種蛋白質纖維，撐起形狀、固定胞器、當運輸軌道：

| 纖維（由粗到細想） | 主成分 | 主要功能 | 搭配的運動蛋白 |
|---|---|---|---|
| **微管（microtubule）** | 微管蛋白（tubulin） | 最粗；紡錘絲、鞭毛/纖毛的軸絲、胞器運輸軌道 | 動力蛋白（dynein）、運動蛋白（kinesin） |
| **中間絲（intermediate filament）** | 角蛋白等 | 機械支撐、維持細胞與核的形狀（最耐拉） | 無（不負責主動運動） |
| **微絲（microfilament）** | 肌動蛋白（actin） | 最細；肌肉收縮、胞器移動、變形蟲運動、縊縮環 | **肌凝蛋白（myosin）沿微絲移動** |

> 高頻陷阱：**肌凝蛋白（myosin）是沿著「微絲（actin）」走，不是沿著中間絲**；負責沿微管走的是 dynein / kinesin。

> **直徑順序用「名字」就能推**：「微<b>管</b>」是中空小管→最粗（約 25 nm）；「微<b>絲</b>」是細絲→最細（約 7 nm）；中間絲居中（約 10 nm）——所以**微管是三者中直徑最大**（陷阱題常說「微管最小」，是錯的）。

**鞭毛與纖毛**：真核細胞的鞭毛/纖毛內部軸絲是 **9＋2 排列**（9 對周邊微管 + 中央 2 根），不是 9＋1。靠微管滑動產生擺動。

> **離心分離（細胞分餾）的原理**：把細胞打破後離心，**越重、越大、密度越高的構造越早沉澱**。所以隨轉速升高，沉澱物依序是：**細胞核（最大最重）→ 粒線體/葉綠體 → 核糖體（最小最輕）**——記住「先沉重的、後沉輕的」就能排序，不必死背。

## 五、粒線體與葉綠體：內共生起源

兩者都有**雙層膜**、自己的環狀 DNA（像細菌）、自己的 70S 核糖體——支持「內共生學說（Endosymbiotic Theory）」：粒線體源自好氧細菌、葉綠體源自藍綠菌，被早期真核細胞吞入後共生至今。

> **雙層膜 = 內共生的指紋**：要判斷哪個胞器「源自被吞的細菌」，看**有沒有雙層膜**就好——外層是當年宿主把它吞進來的食泡膜，內層才是細菌本來的膜。所以雙層膜（粒線體、葉綠體、細胞核）＋環狀 DNA ＋ 70S 核糖體三者同時出現，幾乎就是內共生來源的標記；單層膜胞器（內質網、高基氏體、溶體…）則是真核細胞自己長出來的。

> **母系遺傳**：粒線體（及葉綠體）有自己的 DNA，受精時精子幾乎只貢獻細胞核、不帶胞器，受精卵的粒線體**全來自卵（母方）**。所以粒線體基因病（如 LHON 視神經病變）**一律由母親遺傳給子女**，不分性別都可能得，但只由母系往下傳——這是它和體染色體／性聯遺傳最好用的判別點。

## 六、細胞的「品管與資源回收」：自噬、泛素－蛋白酶體、細胞凋亡

細胞要主動清掉壞掉的零件，靠三套系統。先抓一個原則：**「小東西（單個壞蛋白）走蛋白酶體，大東西（整個壞胞器、入侵病毒）走溶體（自噬）」**，就能推出大部分考點。

- **泛素－蛋白酶體（ubiquitin–proteasome）**：細胞替**錯誤折疊的單個蛋白質**貼上**泛素（ubiquitin）**標籤當「垃圾標記」，被標記的蛋白被送進**蛋白酶體（proteasome）**這台「碎紙機」分解。關鍵是先「貼標」再「銷毀」，標籤就是泛素。
- **自噬作用（autophagy）**：用一層膜把**大型目標**（老舊／受損的胞器、入侵的病毒、甚至錯折疊蛋白聚集體）包起來，送進**溶體（lysosome）**用酸性水解酶消化。飢餓時細胞還會自噬自己的胞器，把分解產物拿來產生能量續命。**注意**：自噬能清蛋白質、壞粒線體、病毒，但**不能修 DNA 點突變**（DNA 錯誤是 DNA 修復系統的事，不是消化系統）。
- **細胞凋亡（apoptosis，計畫性細胞死亡）**：細胞「按程式自殺」，用來雕塑器官（如胚胎時**手指間的蹼細胞凋亡**才分出五指）與清除危險細胞。
  - **內在（粒線體）途徑**：由細胞**內部**壓力（如嚴重 DNA 損傷）觸發 → 粒線體釋出 **細胞色素 c（cytochrome c）** 到細胞質 → 與 Apaf-1、procaspase-9 組成**凋亡小體（apoptosome）** → 啟動 caspase 連鎖把細胞拆解。
  - **外在途徑**：由**外部**訊號分子結合細胞膜上的**死亡受體（death receptor）**觸發（陷阱：死亡受體屬「外在」，別歸到內在途徑）。
  - **Bcl-2 家族是總開關**：Bcl-2／Bcl-xL **抑制**凋亡（擋住細胞色素 c 外漏），Bax／Bak **促進**凋亡——同一家族裡有踩煞車也有踩油門的成員。

## 七、內膜系統（Endomembrane System）：誰算、誰不算

**內膜系統**＝一群靠**囊泡（vesicle）互相往來、彼此相連**的膜狀構造，分泌蛋白就在這套系統裡接力加工。成員：**核膜、內質網、高基氏體、溶體、液胞、運輸囊泡、細胞膜**。

判斷訣竅：**「會用囊泡和別人交換內容物的，才算內膜系統。」**

- **粒線體、葉綠體不算**——它們是內共生來的雙層膜胞器，自成一格、不靠囊泡和這套系統交流（這正是高頻陷阱題的答案）。
- **溶體算**——因為它是「內質網合成 → 高基氏體加工 → 出芽成囊泡」生出來的，符合囊泡往來的定義。

由此可推**分泌蛋白的接力路線**：細胞核（基因 → mRNA） → 核糖體（轉譯） → 粗糙內質網（折疊） → 高基氏體（修飾、加多醣、分類包裝） → 運輸囊泡 → 胞外。**溶體不在分泌路線上**（它是消化部門，不參與「合成並送出」分泌蛋白）。

> **信號胜肽決定去向**：蛋白質要被送進內膜系統／粒線體／要插到膜上，胺基酸鏈上得帶一段**信號胜肽（signal peptide）**當「地址標籤」；唯獨**留在細胞質作用的蛋白質不需要**地址標籤（哪都不去，就地工作）。所以「最不需要信號肽」的就是細胞質蛋白。

## 八、細胞外結構與細胞連接

### 細胞壁／細胞外基質的成分（依生物分類記）

膜外支持結構**因界而異**，但有一條共通原則可推：**這些細胞外成分都是在細胞質裡合成、再被分泌（運出）到膜外組裝的聚合物**（所以「在細胞外卻由細胞內製造後送出」是它們的共同點）。

| 生物 | 膜外結構 | 主成分 |
|---|---|---|
| 細菌 | 細胞壁 | **肽聚糖（peptidoglycan）** |
| 古菌 | 細胞壁 | 不含肽聚糖 |
| 真菌 | 細胞壁 | **幾丁質（chitin）** |
| 植物 | 細胞壁 | **纖維素（cellulose）**；木質部另含木質素（lignin）強化 |
| 動物 | 細胞外基質（ECM） | **膠原蛋白（collagen）**、醣胺聚糖如硫酸軟骨素（chondroitin sulfate）等 |

> **陷阱**：**鈣黏蛋白（cadherins）不是 ECM 成分**——它是嵌在細胞膜上、負責**細胞與細胞相黏**的連接蛋白，不是分泌到細胞外的基質纖維。看到「下列何者不屬於 ECM」，答案常是 cadherin。

### 動物細胞的三種細胞連接（用「功能」推，不用硬背）

| 連接 | 功能（一句話） | 怎麼推 |
|---|---|---|
| **緊密連接（tight junction）** | **封口**：把相鄰細胞膜縫死，**擋住物質（連水、葡萄糖）從細胞間隙滲漏** | 上皮要當防漏屏障（如腸道內襯不讓腸液漏進體內），就需要把縫封死 |
| **胞橋小體（desmosome）** | **鉚釘**：把細胞牢牢鉚在一起抗拉扯 | 名字像「小體」，是點狀的強力黏合 |
| **間隙連接（gap junction）** | **通道**：相鄰細胞間開小孔，讓離子/小分子直接互通 | 「gap＝開孔」，要細胞間溝通就走它 |

> 植物沒有上述動物連接，改用**胞間連絲（plasmodesmata）**——穿過細胞壁的細胞質通道，讓相鄰植物細胞互通（如篩管與伴細胞間運蔗糖）。
