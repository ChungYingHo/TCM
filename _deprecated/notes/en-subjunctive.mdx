「假設語氣」是**時態與語態**大類裡最常被單獨拿出來考的一塊：講「與事實相反、不太可能、或要求別人做」的特殊動詞變化。掌握「條件句三型 + 倒裝 + that 子句原形」就能拿下絕大多數題目。

## 一、條件句三型（最核心）

| 類型 | if 子句（條件） | 主句（結果） | 用在 |
|---|---|---|---|
| **真實條件**（可能發生） | if + 現在式 | will / can + 原形 V | 講通則或未來可能 |
| **與現在相反** | if + **過去式**（be 一律用 were） | **would / could** + 原形 V | 現在不可能的假設 |
| **與過去相反** | if + **had + p.p.** | **would / could have** + p.p. | 對過去的懊悔／假設 |

<ConditionalTypePicker client:visible />

- 真實：If it **rains**, we **will stay** home.（可能下雨）
- 與現在相反：If I **were** you, I **would see** a doctor.（我不是你）
- 與過去相反：If she **had taken** the medicine, she **would have recovered**.（她當初沒吃）

> 口訣：if 子句「**往前推一個時態**」就是與事實相反——現在事用過去式、過去事用過去完成。

**為什麼這樣設計（推導法，不必硬背三排）**：英文用「**時態退一格**」這個動作來標記「這不是真的」。現在的事退一格 → 過去式（所以是 `if + 過去式`）；過去的事已經沒得退，就退到「過去的過去」→ 過去完成（所以是 `if + had p.p.`）。主句的 **would** 就是 will 的過去式，跟著一起退格。**先判斷在講哪個時間、再各退一格**，三型就能自己推出來，不用背表。

> **真實條件的時態**：兩邊用「現在簡單式 → will + 原形」，不要兩邊都用 will。科學/必然的因果也算真實條件——*If water **is heated** to 212°F, it **will boil***（is heated 不是 will be heated；CMU-112）。

## 二、省略 if 的倒裝（高頻陷阱）

把 if 省略，再把 **were / had / should** 提到主詞前面，意思不變：

| 原句 | 倒裝後 |
|---|---|
| If I **were** rich… | **Were** I rich… |
| If he **had** known… | **Had** he known… |
| If you **should** need help… | **Should** you need help… |

所以看到句首是 **Were / Had / Should + 主詞**，立刻判斷它是「省略 if 的假設句」，再回推完整意思。

> **為什麼只有這三個字能倒裝**：能提到主詞前的只有**助動詞**。were、had、should 本身就是助動詞，省掉 if 後直接把它們搬到句首即可；一般動詞（如 know）沒有這個身分，所以 *Knew I…* 不成立——要倒裝得先變成 had known，寫成 **Had I known…**（CMU-114）。**還原法**：把句首助動詞搬回主詞後、補一個 if，就是完整句。

### 否定副詞開頭也要倒裝（另一條規則，別搞混）

把 **No sooner / Not until / Hardly / Seldom / Never / Little** 等否定／半否定詞放句首時，主句也要**助動詞提前**（疑問句語序），但這跟假設語氣**無關**——純粹是「否定詞開頭 → 倒裝」：

- **No sooner had** they heard the news **than** they burst into tears.（No sooner 配 than；had p.p. 配後面 past）
- **Not until** I lay in bed **did I think of** the quiz.（did + 主詞 + 原形）

> 判斷法：句首是否定／限定副詞 → 後面**立刻接助動詞 + 主詞**；不要寫成正常語序（*Not until… I thought* 是錯的）。No sooner 永遠搭 **than**、Hardly/Scarcely 搭 **when**。

## 三、that 子句用原形（建議、要求、命令、重要）

當主句出現 **suggest / recommend / demand / insist / propose / require / order**，或 **It is essential / necessary / important / imperative that …**，後面 that 子句的動詞一律用**原形（base form）**，主詞單複數都不變：

- The doctor recommended that he **take** the pills.（不是 takes）
- It is essential that the form **be** submitted today.（被動就是 **be + p.p.**）

> 記法：這些子句前其實藏了一個省略的 **should**，所以永遠用原形。

## 四、wish 與 as if（與事實相反）

| 句型 | 接 | 例 |
|---|---|---|
| wish + 與現在相反 | 過去式 | I wish I **were** taller. |
| wish + 與過去相反 | had + p.p. | I wish I **had studied** harder. |
| as if / as though | 過去式（與現在相反） | He talks as if he **knew** everything. |

## 五、不用 if 也能下條件（同義引導詞）

條件不一定靠 if。**先把這些詞在心裡換回 if 句，再套三型的時態規則**就好：

| 引導詞 | 等於 | 例 |
|---|---|---|
| **unless** | if … not（除非） | **Unless** she had argued well, the board **would have rejected** it.（= If she had not argued…，與過去相反）|
| **but for / without** + 名詞 | if it were not for / if it had not been for | **But for** your help, I **would have failed**.（要不是你幫忙）|
| **Had it not been for** + 名詞 | = But for（倒裝寫法） | The impact **might not have been** so great **had it not been for** her.（CMU-109）|
| **otherwise / or** | 「否則」＝把前句反過來當條件 | He **must have** finished; **otherwise** he **wouldn't be** relaxing.（要是沒做完，他就不會在放鬆）|

- **unless** 本身已含 not，子句**不要再加一個 not**（unless = if…not）。
- 看到 **otherwise**，它後面那句就是「與前句相反的假設結果」，所以照樣用 would / wouldn't；前句常搭 **must have p.p.**（對過去的合理推斷：一定是…）。

> **推斷型 must / might + have p.p.**：講「**對過去的推測**」而非條件本身——*He **must have** completed it*（一定做完了，ISU-111）、*None **might ever have survived***（大概沒人活下來，TCU-109）。判斷法：句子在「猜過去發生了什麼」就用 **modal + have + p.p.**。

<Memorize>
與現在相反：<b>if + 過去式 … would + 原形</b>（be 用 were）。<br />
與過去相反：<b>if + had p.p. … would have p.p.</b>。<br />
句首 <b>Were / Had / Should + 主詞</b> = 省略 if 的倒裝假設句。<br />
<b>unless</b> = if…not（別再加 not）；<b>but for / had it not been for</b> = 要不是。<br />
suggest / recommend / essential that … 子句動詞用<b>原形</b>（被動 = be + p.p.）。<br />
wish、as if 後接<b>與事實相反</b>的過去式。<br />
否定詞開頭（<b>No sooner / Not until / Hardly</b>）→ 主句<b>助動詞提前</b>倒裝（No sooner…than）。<br />
推測過去用 <b>must / might + have + p.p.</b>（一定／大概…了）。
</Memorize>
