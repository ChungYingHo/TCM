植物沒有神經系統，靠激素與光感受器協調生長、開花與防禦。本篇從五大激素談起，帶到礦物質、光週期、蒸散與生殖。

## 一、五大植物激素

植物沒有神經系統，靠**化學信號（激素）**協調生長。五大激素請先熟記：

| 激素 | 縮寫 | 主要合成部位 | 代表功能 |
|---|---|---|---|
| **生長素** | IAA（Auxin） | 莖頂端、嫩葉 | 促細胞伸長、**頂端優勢**、向光性/向地性 |
| **吉貝素** | GA | 種子、嫩葉 | 促莖伸長、**打破休眠**、誘導開花（長日植物） |
| **細胞分裂素** | CK（Cytokinin） | 根尖 | 促**細胞分裂**、延緩葉片老化（抑制黃化） |
| **離層酸** | ABA | 葉片、種子 | 促**休眠**、乾旱時**關閉氣孔**、促落葉 |
| **乙烯** | Ethylene | 熟果、受傷組織 | 促**果實成熟**、促落葉落果、「三重反應」 |

> 記憶口訣：**生（長素）吉（貝素）細（胞分裂素）離（層酸）乙（烯）**

<PlantHormones client:visible />

> 為什麼這五個要放一起？它們其實是**兩股拮抗力量**：促生長/促代謝的（IAA、GA、CK）對上促休眠/促老化逆境的（ABA、乙烯）。同一件事常由一對激素「一推一拉」決定，例如種子萌發是 **GA（打破休眠）vs ABA（維持休眠）** 的拉鋸。記功能時用「這激素站哪一邊」來推，比逐條背更穩。

### 乙烯的三重反應與催熟、落葉

乙烯是**氣態**激素，可在空氣中擴散，這解釋了幾個經典現象：

- **三重反應（triple response）**：幼苗碰到障礙物（機械壓迫）時釋放乙烯 → ①**莖伸長受抑制**（長不高）、②**莖加粗**、③**莖橫向偏轉**繞過障礙。三項合起來是「遇阻就變矮胖、轉個方向」的避障策略，也是偵測乙烯的指標反應。
- **催熟與落葉**：成熟果實放出乙烯，會**催熟鄰近果實**（「一顆爛蘋果壞一籃」）；乙烯也促進葉柄**離層**形成 → 落葉落果。十八世紀街燈燃煤氣，煤氣含**乙烯**，使路樹提早落葉，正是同一機制。

### 向性（Tropism）

- **向光性**：單側光照 → 生長素從受光側移往背光側 → 背光側細胞伸長較多 → 莖彎向光源。
- **向地性（重力性）**：根尖感受重力 → 生長素積聚在下方 → **根細胞對高濃度生長素敏感（抑制）**，下方不伸長 → 根向下彎；莖相反，下方受促進 → 莖向上彎。

### 其他防禦／訊號物質：茉莉酸（Jasmonic acid, JA）

除了五大激素，植物受傷或被蟲咬時會用**茉莉酸**啟動防禦：

- JA 不是直接毒死昆蟲，而是**調控植物抗蟲基因的表現**（例如誘導合成蛋白酶抑制劑，干擾昆蟲消化）。
- 受傷部位釋放 JA → 啟動防禦基因 → 全株提高抗蟲性。

> 考點口訣：**茉莉酸 = 抗蟲基因的「開關」**（調控基因表現），不是接觸性毒劑。

植物防禦不只 JA 一招，常一起考的還有兩類分子，差別在「對誰」：

| 分子 | 對付對象 | 機制（記「在地 vs 廣播」） |
|---|---|---|
| **茉莉酸（JA）** | 草食昆蟲 | 受傷誘導 → 調控抗蟲基因 |
| **植物防禦素（phytoalexin）** | **病原真菌／細菌** | 被感染細胞**現場合成的抗菌小分子**，局部殺菌 |
| **揮發性訊號（如甲基茉莉酸）** | 預警**鄰株** | 受害株放出**氣態訊號** → 飄到鄰株 → 鄰株提前啟動防禦 |

> 推導：受傷找 **JA**、真菌入侵找 **phytoalexin**、「整片植物一起變抗蟲」一定是靠**會飄的揮發性分子**廣播，而不是靠基因親緣辨識。

### 共生招募：獨腳金內酯（strigolactone）與菌根

- 植物根會分泌**獨腳金內酯**到土中，吸引**菌根真菌（mycorrhizal fungi）**靠近、形成菌根；菌根幫植物吸收**水分與礦物質（尤其磷）**，植物回報醣類——典型互利共生。獨腳金內酯同時也與生長素互動、抑制側芽（參與頂端優勢）。
- 推論：噴**殺真菌劑**會連根表的菌根真菌一起殺死 → 失去吸收幫手 → 植株出現**礦物質缺乏**（不是受體或運輸蛋白壞掉）。

## 二、礦物質營養（無機營養元素）

植物除了 C、H、O，還需從土壤吸收礦物質。依需求量分兩類：

| 類別 | 需求量 | 例子 |
|---|---|---|
| **巨量營養素**（macronutrient） | 多（佔乾重較大比例） | N、P、K、**Ca**、Mg、S |
| **微量營養素**（micronutrient） | 極少 | Fe、Mn、Zn、Cu、B、Mo、Cl |

幾個高頻考的元素角色：

| 元素 | 主要角色 |
|---|---|
| **氮 N** | 蛋白質、核酸、葉綠素的成分 |
| **鎂 Mg** | **葉綠素的中心原子**（缺鎂 → 黃化） |
| **鈣 Ca** | **巨量元素**；細胞壁中膠層成分；**做為細胞內訊號**調控對刺激的反應 |
| **鉀 K** | 滲透調節（保衛細胞開關氣孔） |

> 易錯：鈣是**巨量**元素（非微量）；缺鎂（不是缺鈣）才造成葉片黃化；核酸主要成分是 N、P（不是 Ca）。

**缺乏症出現在老葉還是新葉？看「韌皮部移動性」就能推：**

- **可移動元素（N、P、K、Mg）**：缺乏時植物會把這些養分從**老葉拆解、回收**送往生長中的新葉 → 所以**缺乏症狀先出現在老葉**。
- **不可移動元素（Ca、Fe、B 等）**：固定在原處無法回收 → 新長出的組織缺料 → **症狀先出現在新葉（頂芽）**。

> 推導原則：**能搬的先犧牲老葉、不能搬的先餓死新葉**。看「症狀從哪片葉開始」就能反推該元素是否可移動，不必死背每個元素。

## 三、光週期與光敏素（Phytochrome）

**光週期（Photoperiodism）**：植物用**黑暗期長度（臨界夜長）**，而非光照長度，來判斷季節。

| 植物類型 | 開花條件 | 例子 |
|---|---|---|
| **短日植物（長夜植物）** | 連續黑暗 **超過** 臨界夜長 | 菊花、稻子、蒼耳（草莓多為一季結果短日品種） |
| **長日植物（短夜植物）** | 連續黑暗 **短於** 臨界夜長 | 菠菜、小麥、萵苣 |
| **中性植物** | 不依賴光週期 | 番茄、玉米 |

**光敏素（Phytochrome）** 是感光色素：
- **Pr（紅光吸收型）** ⇌ **Pfr（遠紅光吸收型）**
- 白天（陽光含紅光多）→ Pr 轉換成 Pfr（活性型）。
- 夜晚 → Pfr 緩慢轉回 Pr；若夜間插入一次紅光照射 → Pr→Pfr → 相當於「打斷夜長」 → 短日植物不開花。
- 若短暫遠紅光（far-red）照射緊接在紅光後 → 效果被逆轉（Pfr→Pr）→ 短日植物恢復開花。

> **「最後一道光說了算」**：紅光把光敏素推成 Pfr、遠紅光推回 Pr，而且後一次照射會覆蓋前一次。所以連續閃「紅→遠紅→紅」時，看**最後一閃**是紅光 → 結尾停在 Pfr（等於「夜被打斷」）；若最後一閃是遠紅光 → 停在 Pr（等於「夜未被打斷」）。記住這條，任何長串紅/遠紅交替題都能直接推結論，不必背每種組合。
>
> 反過來用：**Pfr 是「白天/有光」訊號**。短日（長夜）植物要開花就怕看到 Pfr；長日（短夜）植物則靠夜間補紅光（製造 Pfr、假裝短夜）來**提早**開花。

## 四、蒸散作用（Transpiration）

水分從葉片氣孔散失的過程，靠**內聚-附著-張力學說（Cohesion-Tension Theory）**解釋水如何「被拉上去」：

1. **蒸散**：葉肉細胞水分蒸發，造成**負壓（張力）**。
2. **內聚力（Cohesion）**：水分子間 H-bond 互相拉住，形成連續水柱。
3. **附著力（Adhesion）**：水分子與導管細胞壁親水基黏附，防止水柱斷裂。
4. 張力由葉片向下傳導 → 根部水分被「拉」上來。

> 驅動力是**蒸散**（不是幫浦），能量來源是**太陽能**使水蒸發。

**用水勢（water potential, Ψ）一條規則判斷水往哪流：水永遠從 Ψ 高流向 Ψ 低（更負）。**

- 白天蒸散旺 → **葉片 Ψ 最低（最負）** → 把水從根（Ψ 較高）一路往上拉到葉。看水勢表時，**最負的部位就是當下的「抽水點」**。
- 因此白天的水勢梯度是「根 > 莖 > 葉」（越往上越負），這正是蒸散拉力在運作的指紋。

**根壓與泌液（guttation）——蒸散停止時的另一套機制：**

- 夜間氣孔關閉、蒸散停 → 沒有蒸散拉力。但根部仍**主動把礦物質打進導管**，使導管 Ψ 下降、水滲入 → 由下往上產生**正壓（根壓）**。
- 根壓把水從**葉緣的水孔**擠出成水珠，就是**泌液（guttation）**——注意這是**根壓「推」**的，不是蒸散「拉」的，也不是露水（露是空氣凝結）。

> 一句話分辨：**白天靠蒸散「拉」（張力、負壓），夜間靠根壓「推」（正壓、泌液）。**

## 五、花的構造與性別

一朵完整花有四輪：**萼片、花瓣、雄蕊（含花藥）、雌蕊（含子房）**。依雄雌蕊是否齊全分：

| 類型 | 定義 | 例子 |
|---|---|---|
| **兩性花**（完全花） | 同一朵花兼具雄蕊與雌蕊 | 百合、水稻、豌豆、朱槿 |
| **單性花** | 一朵花只有雄蕊或只有雌蕊 | **玉米**（雄花序在頂、雌花序在葉腋） |

> 高頻考點：**玉米是單性花**（雌雄花分開），常被拿來和兩性花（百合、水稻、豌豆）對比。

## 六、植物生殖——雙重受精（Double Fertilization）

被子植物（開花植物）特有：

- 一個花粉管送入**兩個精核**。
- **精核₁ + 卵細胞（n）→ 合子（2n）→ 胚**。
- **精核₂ + 兩個極核（n+n = 2n）→ 胚乳（3n）**。
- 胚乳（3n）提供種子萌發的養分。

### 受精後才結果：果實發育與「種子有沒有料」

- **果實發育由受精觸發**：受精成功 → 胚珠發育成種子、同時誘發**激素變化（GA、auxin）** → 子房壁膨大成果實。沒受精通常不結果（少數單性結實例外）。
- **養分存哪裡？** 種子萌發要靠儲存養分，可能放在**胚乳**（如禾本科）或被胚吸收進**子葉**（如豆類；雙子葉常以子葉儲糧）。**種皮（種被）只是保護外殼，不存養分**——這是常見陷阱選項。

## 七、配子體發育、授粉與自交辨識

### 花粉與胚珠怎麼來：大小孢子 → 配子體

被子植物的配子不是直接由減數分裂產生，而是**先減數分裂成孢子、孢子再有絲分裂成配子體**，配子體裡才有配子：

- **雄方**：花藥小孢子囊內，一個**小孢子母細胞**減數分裂 → **4 個小孢子** → 各自有絲分裂 → **花粉粒（雄配子體）**，內含 **2 個精核 + 1 個管細胞**。
- **雌方**：胚珠內一個**大孢子母細胞**減數分裂 → 大孢子 → 再經**多次有絲分裂**形成胚囊（雌配子體，含卵、極核等）。
- 推導：成熟胚珠的形成需要「**減數分裂＋有絲分裂兩者都有**」，只說「一次減數分裂就完成」是錯的。

### 自交不親合（self-incompatibility）

- 很多植物會**辨識並排斥自己的花粉**，避免自交、維持遺傳多樣性。
- 排斥發生在**雌蕊的柱頭或花柱**（花粉一落上就被擋下或花粉管中途停長），不是在花藥、也不是等到精卵結合才擋。

### 花的長相＝給授粉者的廣告

花的形態其實是**對應傳粉者**演化出來的訊號，可反推授粉方式：

| 花的特徵 | 主要授粉者 |
|---|---|
| 鮮紅／橙黃、無香味、花蜜多 | **鳥**（鳥類嗅覺差、對紅色敏感） |
| 芳香、鮮豔、有蜜源標記 | 蜂、蝶 |
| 夜間開、白色、濃香 | 蛾 |
| 小而不顯眼、無蜜無香、花粉量大 | **風**（不需吸引動物） |

> 推導：花把資源投在哪種訊號（顏色／氣味／花蜜／花粉量），就是在「打廣告」給對應的授粉者；看廣告就能猜顧客。

## 八、逆境生理：植物怎麼撐過環境壓力

植物不能跑，只能靠生理調節硬撐。多數逆境反應都可由「**先止損、再改造構造**」這個邏輯推出來：

| 逆境 | 反應 | 為什麼（機制） |
|---|---|---|
| **乾旱** | ABA 累積 → **氣孔關閉** | 先止住最大宗的失水（蒸散） |
| **淹水** | 根缺氧 → 產生**乙烯** → 根皮層細胞死亡形成**通氣組織（aerenchyma）** | 在根內挖出氣道，把地上部空氣導向缺氧根部 |
| **低溫** | 提高細胞質**溶質濃度**、改變細胞膜**脂質組成** | 溶質降冰點防結冰；膜脂改組維持低溫流動性 |
| **高溫** | 合成**熱休克蛋白（HSP）** | 當「分子伴護」防止蛋白變性 |
| **鹽分** | 把根細胞 Ψ 調得**比土壤更低（更負）** | 唯有根 Ψ 比土壤低，水才進得來（順 Ψ 梯度） |

> 高溫題常見陷阱：植物**沒有**用木質部／韌皮部「循環液體把熱導到地下」這種散熱系統——這是杜撰選項，直接刪。

### 黃化現象（etiolation）≠ 缺鎂黃化

- **黃化（etiolation）**指種子在**黑暗（土中）**萌發時的形態策略：**莖優先快速伸長**、節間拉長、不展葉也不合成葉綠素，目的是**盡快鑽出地面見光**；一見光就轉為正常綠色生長。
- 千萬別和「**缺鎂造成葉綠素不足的黃化**」搞混：前者是黑暗中的**正常發育策略**，後者是**礦物質缺乏症**。考點專愛把這兩個「黃」放在一起混淆。

## 九、世代交替與登陸演化

### 世代交替（alternation of generations）

植物（與多數藻類）一生在兩個世代間輪替：**孢子體（2n，行減數分裂產孢子）** ⇌ **配子體（n，行有絲分裂產配子）**。判斷一個植物「以哪一代為主」是高頻考點，趨勢很清楚：

- **演化越往後，孢子體越佔優勢、配子體越退化**。蘚苔類以**配子體**為主體（最原始）；**蕨類起，孢子體已成為主要植株**，配子體縮成小小的原葉體；種子植物的配子體更退化到包在花粉／胚珠裡。
- 所以「蕨類以配子體為主要生長形式」是**錯的**（蕨類已是孢子體為主）。
- 不論生活史怎麼變，所有有性生殖都一定包含三件事：**減數分裂、受精、配子**（世代交替與孢子則非人人皆有）。

### 登陸四大適應與「為什麼長不高」

植物從水生到陸生，依序演化出對應乾燥與重力的構造，**出現順序＝解決問題的先後**：

> **角質層 → 維管束組織 → 種子 → 花**

- 先要**角質層**防止離水後乾死；再要**維管束（木質部／韌皮部）**輸水撐高、把水送上陸地植株；接著**種子**保護並供養胚、擺脫對水受精的依賴；最後**花**提升授粉效率。
- 由此可推：**蘚苔類沒有維管束**，水分只能靠擴散短距離傳遞、又缺乏木質部的支撐 → **體型與高度因此受限**（這正是它們矮小的關鍵）。
