分子生物學的工具大多圍繞一件事：複製、切接、分離或編輯 DNA。本篇從 PCR 出發，依序講重組 DNA、電泳、定序、轉殖與 CRISPR，並整理幾個常考的辨析陷阱。

## 一、PCR（聚合酶鏈鎖反應）

PCR 目的：在**體外**大量複製指定的 DNA 片段，只要有微量模板就能擴增。

**三步驟循環（每輪約 1–3 分鐘）：**

| 步驟 | 溫度（約） | 發生什麼 |
|---|---|---|
| **1. 變性（denaturation）** | 94–96°C | 高溫使 DNA 雙股氫鍵斷裂，分離成單股 |
| **2. 黏合（annealing）** | 50–65°C | **引子（primer）**與模板互補配對，決定擴增區域 |
| **3. 延長（extension）** | 72°C | **Taq 聚合酶**（耐熱）沿 5'→3' 合成新股 |

- 每輪理論上將 DNA 量加倍：n 輪後 → 2ⁿ 份。
- **引子**：人工合成的短單股 DNA，左右各一個（正向/反向），夾住目標區段。
- **Taq 聚合酶**來自嗜熱菌（*Thermus aquaticus*），在 94°C 不變性。

## 二、重組 DNA 技術（Recombinant DNA）

**目標**：把某基因（如胰島素基因）插入細菌，讓細菌大量生產該蛋白質。

**主要工具：**

| 工具 | 功能 |
|---|---|
| **限制酶（restriction enzyme）** | 辨認特定 DNA 序列並切割，產生**黏性末端（sticky ends）** |
| **連接酶（DNA ligase）** | 將目標 DNA 片段與載體 DNA 以磷酸二酯鍵連接（封口） |
| **質體（plasmid）** | 細菌染色體外的小型環狀 DNA，作為**載體（vector）** |

**重組 DNA 製作流程：**
1. 用**同一種限制酶**切目標基因 ＆ 質體（確保末端互補）。
2. 混合，讓黏性末端互補配對。
3. 加連接酶，封閉切口 → **重組質體**完成。
4. 轉形（transformation，又稱轉化）進入宿主細菌。
5. 篩選含重組質體的菌落（例如抗生素抗性篩選）。

## 三、凝膠電泳（Gel Electrophoresis）

**原理：**
- DNA 帶**負電**（磷酸基），施加電場後往正極（+）移動。
- 凝膠（瓊脂糖）像篩網，**小片段跑得快（跑得遠）、大片段跑得慢（靠近起點）**。

**常見應用：**

| 應用 | 說明 |
|---|---|
| PCR 產物確認 | 跑電泳確認擴增片段大小是否正確 |
| 限制酶圖譜（RFLP）| 比較不同個體 DNA 片段大小差異 |
| DNA 指紋鑑定 | 刑事鑑識、親子鑑定 |

**判讀技巧：**
- 同排跑越遠 = 分子量越**小**。
- 與**分子量標準（ladder）**對照，估計片段大小。

## 四、DNA 定序

**Sanger 定序（鏈終止法）：**
- 加入**ddNTP（雙脫氧核苷酸）**，ddNTP 沒有 3'-OH，插入後鏈終止。
- 產生各種長度的片段，電泳後按長度排列，讀出序列。
- 為什麼是「雙」去氧？正常 dNTP 已在核糖 **2' 缺氧**（DNA 的特徵），ddNTP 再把 **3'-OH 也換成 -H**，所以是 **2' 和 3' 兩處皆無 -OH**。延長靠的是 3'-OH 接上下一個核苷酸的磷酸；3' 一旦沒了 -OH，鏈就接不下去而終止——這就是「鏈終止」的機制。

**次世代定序（NGS）：**
- 大量平行定序，速度快、成本低，用於全基因體、轉錄體、總體（環境）基因體分析。
- **能力邊界（高頻陷阱）**：NGS 讀的是**核酸序列（DNA/RNA）**，所以可做個人化醫療、找新的 RNA 剪接產物、鑑定難培養的微生物；但**測不到「蛋白質層次」的事**——例如蛋白質的轉譯後修飾、蛋白質活性，那要靠質譜等蛋白質體工具。看到「定序技術 + 蛋白質修飾/活性」配在一起，幾乎都是要選的錯誤項。

**即時定量 PCR（real-time qPCR / qRT-PCR）：邊擴增邊測量**
- 一般 PCR 跑完才用電泳看「有沒有」；qPCR 在每一輪用**螢光訊號**即時反映產物量，可**定量**起始模板多寡，**不必再跑膠**（這點常考：說 qPCR「仍須依賴 DNA 凝膠電泳」是錯的）。
- **Ct 值（cycle threshold）**＝螢光越過門檻所需的循環數。**模板越多 → 越早達標 → Ct 越小**（Ct 與起始量成反比）。
- 倍數換算（會考計算）：PCR 每輪加倍，所以每差 1 個 Ct ≈ 量差 2 倍 → 兩樣本量差 = **2^(ΔCt 差)**。例：ΔCt 相差 3 → 2³ = **8 倍**。
- 要測 **RNA**（如新冠檢測、mRNA 表現量）須先用**反轉錄酶**把 RNA → cDNA 再做 qPCR，稱 **qRT-PCR**（聚合酶只認 DNA 模板，無法直接擴增 RNA）。

**「-omics」分析工具配對：先定位你要測哪一層分子（高頻應用題）**

考題愛問「研究 X 該用什麼技術」。**不必死背，對準中心法則的層次想：你要測的是 DNA、RNA、蛋白質還是代謝物？** 同一層才配得起來。

| 想分析的層次 | 對應工具 |
|---|---|
| **DNA / 基因體** | PCR、定序（Sanger、NGS）、南方墨點法 |
| **RNA / 轉錄體** | RT-PCR、qRT-PCR、RNA-seq、北方墨點法、微陣列 |
| **蛋白質 / 蛋白質體** | 西方墨點法、**質譜（mass spectrometry）**、二維電泳、ELISA |
| **代謝物 / 代謝體** | **質譜** |

- **質譜**是蛋白質體與代謝體學的主力工具（如癌症標靶藥開發找蛋白質生物標記）；**RNA-seq** 是轉錄體學主力。
- 想測**特定蛋白的修飾狀態（如磷酸化）**：用對該修飾有專一抗體的**西方墨點法（Western blot）**最直接。
- 想測**蛋白質–蛋白質交互作用**：免疫共沉澱、酵母雙雜交、螢光共振能量轉移（FRET）皆可；**次世代定序測的是核酸，無法測蛋白交互作用**（常見「何者不能」陷阱）。

## 五、基因轉殖（Transgenic Technology）

- 將外源基因插入生物基因體，使其穩定遺傳與表現。
- 例：轉基因大豆（抗除草劑）、基因剔除小鼠（knock-out mouse，研究基因功能）。

**植物轉殖主角：農桿菌（Agrobacterium）＋ Ti 質體**
- 農桿菌天生會把自己 Ti 質體上的一段 **T-DNA** 送進植物細胞並嵌入植物染色體——基因工程就是「搭便車」：把目標基因接到 T-DNA 區，讓農桿菌幫忙運送。
- 因此流程順序要記對：**目標基因 → 接入 Ti 質體 → 把 Ti 質體送回農桿菌 → 農桿菌感染植物 → 基因嵌入植物染色體**。（常考：基因插入 Ti 質體後，「下一步」是送進**農桿菌**，不是直接打進植物。）
- 其他直接把 DNA 送進植物細胞的物理/化學法：**基因槍、電穿孔、脂質體**。
- **陷阱**：以 **CaCl₂ 處理使勝任** 是把質體送進**細菌（大腸桿菌）**的轉形法，不是植物轉殖常用法。

## 六、CRISPR-Cas9 基因編輯

| 元件 | 角色 |
|---|---|
| **sgRNA（guide RNA）** | 與目標 DNA 互補，引導 Cas9 到正確位置 |
| **Cas9 蛋白** | 核酸酶，負責切割雙股 DNA |

**CRISPR 優勢（相較傳統轉殖）：**
- 位點精確，可定點修改特定基因。
- 效率高、成本低，應用廣泛（基礎研究、醫學基因治療）。

**CRISPR 流程：**
1. 設計 sgRNA，使其與目標 DNA 互補。
2. sgRNA-Cas9 複合物切割目標 DNA 雙股。
3. 細胞自行修復 → 可能引入缺失（基因剔除）或插入目標序列（精確編輯）。

**Cas9 只負責「切」，真正改寫序列的是細胞自己的 DNA 修復——選哪條路決定 knock-out 還是 knock-in：**

| 修復路徑 | 特性 | 結果 |
|---|---|---|
| **NHEJ（非同源末端接合）** | 直接把斷端接回，常出小錯（插入/刪除幾個鹼基）→ 框移 | 把基因弄壞 → **基因剔除（knock-out）** |
| **HDR（同源重組修復）** | 以一段「模板 DNA」為樣板精準修補 | 可照模板**插入特定序列 → 基因敲入（knock-in）** |

> 推導要點：想**精準植入**序列就必須提供模板、走 **HDR**；只想**破壞**基因功能則靠 **NHEJ** 的隨機錯誤即可。這也解釋了「為何 CRISPR 能編輯真核細胞」——正是因為真核細胞本身具備 DNA 修復機制。
>
> 易錯澄清：CRISPR/Cas9 的本質是**切割 DNA** 後交給修復，**不是「讓基因過量表現」**；說它「透過 Cas9 誘發基因過量表現」是錯的。另外，CRISPR 源自細菌對抗病毒的**後天/適應性免疫**（記錄過往入侵者序列），不是先天免疫。

## 七、其他常考工具與觀念辨析

**細菌的水平基因轉移（抗藥質體怎麼傳開）——三條路用「DNA 從哪來」分辨**

抗藥基因常坐在質體上，在細菌間橫向擴散。三種方式的差別只在 **DNA 的來源/媒介**：

| 方式 | DNA 怎麼進來 | 關鍵字 |
|---|---|---|
| **轉化／轉形（transformation）** | 直接從環境**裸 DNA** 攝入 | 沒有性線毛、沒有噬菌體時，靠它傳 |
| **轉導（transduction）** | 由**噬菌體（病毒）**夾帶傳遞 | 需要噬菌體 |
| **接合（conjugation）** | 兩菌經**性線毛/F 因子**直接接觸傳質體 | 需要 F 因子、性線毛 |

> 推導法：題目把條件抽掉就知道答案——「**缺 F 因子又無噬菌體**」→ 接合與轉導都做不到，只剩**轉化**；反之質體要在菌間移轉、且有性線毛，多半是**接合**。
>
> 補充：**轉座子（跳躍基因）**能在質體與染色體之間「跳」，自帶轉位所需的酵素，但它是基因在**同一細胞內**換位置，不是把基因送到另一隻細菌——別跟上面三種菌間轉移混淆。

**基因沉默機制（RNAi）：siRNA／miRNA 怎麼關掉基因**
- 雙股 RNA 被切成短的 **siRNA**，與蛋白質組成複合體（RISC），靠**序列互補**找到標的 **mRNA** 並使其降解 → 抑制表現。
- **常考陷阱**：siRNA 發揮作用的成熟形式是**短雙股 RNA**（之後解開由其中一股導引），說「siRNA 是**單股**」是錯的；而 **miRNA** 是細胞本來就有的短**非編碼** RNA（如線蟲體內調控發育），同樣靠互補抑制轉譯/促降解。
- 對照記憶：**反義 RNA（antisense RNA）**是與 mRNA 互補的單股 RNA，直接黏上 mRNA 擋住轉譯。要點是——這些都是**調控基因表現**的工具，不是基因標記、也不是基因編輯。

**基因標記（genetic marker）：用來區分個體 DNA 的「記號」**

| 是基因標記 | 為什麼 |
|---|---|
| **RFLP**（限制片段長度多型性）| 限制酶切點差異 → 片段長短不同 |
| **VNTR**（變異重複序列）/ **微衛星** | 短序列重複次數因人而異 |
| **SNP**（單核苷酸多型性）| 單一鹼基差異 |

> **RNAi（RNA 干擾）不是基因標記**——它是「調控/抑制基因表現」的機制（降解 mRNA），不是用來標定 DNA 身分的記號。

**把外源基因送進細胞的方法（注意動物 vs 植物）**

| 方法 | 主要對象 |
|---|---|
| 原核顯微注射、胚幹細胞載體、精子載體、反轉錄病毒感染 | **動物** |
| **農桿菌（Agrobacterium）感染**、基因槍 | **植物** |

> 考點：**農桿菌感染法是植物轉殖**，不是把基因送進動物的方法。

**哪些蛋白質「不適合」用大腸桿菌生產？**
- 大腸桿菌是原核生物，**不會做真核式的轉譯後修飾（如糖基化）**，也無法折疊某些複雜蛋白。
- 需要醣化或複雜折疊的蛋白（如某些人類醣蛋白）要改用**酵母菌或哺乳類細胞**生產。
- **陷阱**：紫杉醇（Taxol）是植物產生的**小分子代謝物，不是蛋白質**，根本無法靠「表現基因」用細菌生產。

**細胞工程：原生質體融合（protoplast fusion）**
- 去除細胞壁後，把**兩個不同物種的細胞融合**，可直接產生**新的雜交（雜種）物種**。
- 這是少數能「直接造出新雜交種」的技術；PCR、組織培養、微陣列都做不到這件事。

**iPS（誘導式多能幹細胞）的風險**
- 重新編程可能殘留致癌風險（如導入的轉錄因子使細胞**癌化**）。
- 用病人自己的細胞誘導 → **不會被自體免疫排斥**（這是 iPS 相對胚胎幹細胞的優點）。

qPCR：<b>Ct 越小＝模板越多</b>，兩樣本量差 = <b>2^(ΔCt 差)</b>；CRISPR 修復 <b>NHEJ→剔除、HDR→敲入</b>。<br />
選工具先定位分子層次：<b>DNA→PCR/定序、RNA→RNA-seq/qRT-PCR、蛋白質/代謝物→質譜</b>。
</Memorize>

<KeyPoints items={[
  "<b>PCR 引子</b>決定擴增區域，必須與兩端互補；引子被併入新生股、提供 3'-OH 供延長（不是被以模板合成，其序列成為產物的一部分）。",
  "<b>Taq 聚合酶耐熱</b>，可在 PCR 高溫變性步驟後仍保有活性，是 PCR 技術的關鍵突破。",
  "<b>限制酶</b>辨認特定迴文序列（palindrome），切出黏性末端或平滑末端；同一種限制酶切出的末端才能互補配對。",
  "<b>電泳跑越遠 = 片段越小</b>——這點常考反向思考題，要特別注意。",
  "<b>CRISPR-Cas9</b>：sgRNA 決定定向（特異性），Cas9 執行切割——兩者缺一不可。",
  "基因剔除（knock-out）移除基因功能、基因敲入（knock-in）插入特定序列，都可用 CRISPR 實現。",
  "<b>Sanger 定序</b>利用 ddNTP 終止鏈延長，電泳後依長度排列讀出序列；現代已被 NGS 取代但仍是考試重點。",
  "<b>基因標記</b>：RFLP、VNTR、微衛星、SNP 都是；<b>RNAi 不是標記</b>（它是抑制基因表現的機制）。",
  "<b>原生質體融合</b>可直接造出新雜交物種；PCR/組織培養/微陣列做不到。",
  "<b>農桿菌感染法是植物轉殖</b>；動物轉殖用顯微注射、胚幹細胞/精子載體、反轉錄病毒。",
  "<b>大腸桿菌不會糖基化</b>，需醣化的蛋白要用酵母/哺乳類細胞；紫杉醇是小分子代謝物不是蛋白質，無法用細菌「表現」。",

  "<b>植物轉殖：農桿菌 + Ti 質體</b>，順序為「基因→Ti 質體→送回農桿菌→感染植物」；CaCl₂ 轉形是用在<b>細菌</b>不是植物。",
