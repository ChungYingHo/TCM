訓詁就是解釋字義。文言字詞會因引申、假借或時代而變義，虛詞更是一字多用。本篇整理詞義類型、古今異義、虛詞用法與辨析方法。

## 一、詞義的四種類型

訓詁就是「解釋字義」。文言字詞的意義分四類：

| 類型 | 說明 | 例 |
|---|---|---|
| **本義** | 造字時最初的意義 | 「道」本指道路 |
| **引申義** | 由本義延伸出去 | 「道」引申為道理、方法 |
| **假借義** | 借同音字記錄不同意思 | 「莫」本指傍晚，借作否定詞「沒有人」 |
| **古今異義** | 古代與現代意思不同 | 「走」古指奔跑，今指步行 |

## 二、常見古今異義對照

| 字／詞 | 古義 | 今義 |
|---|---|---|
| 走 | 奔跑（走馬） | 步行 |
| 妻子 | 妻與子女 | 配偶 |
| 犧牲 | 祭祀用的牲畜 | 為理想放棄生命 |
| 交通 | 互相往來溝通 | 道路運輸 |
| 可以 | 可以（憑藉）此；能夠 | 允許、辦得到 |
| 不過 | 不超過 | 表轉折「但是」 |
| 感激 | 感動激盪 | 感謝 |
| 小生 | 年輕讀書人（謙稱） | 戲曲角色 |

## 三、文言虛詞速查表（最常考六字）

| 虛詞 | 主要用法 | 例句簡析 |
|---|---|---|
| **之** | ①助詞（無義，取獨/補足音節）②代詞（他/它）③動詞（到/往）④結構助詞（的） | 「師道之不傳」①取獨；「愛之」②代詞；「吾欲之南海」③動詞 |
| **乎** | ①語氣詞（疑問/感嘆/反問）②介詞（相當於「於」「在」「比」） | 「學而時習之，不亦說乎？」①感嘆；「生乎吾前」②介詞 |
| **者** | ①助詞，附在動詞/形容詞後表人或事②句末停頓語氣 | 「仁者愛人」①指仁的人；「陳勝者，陽城人也」②停頓 |
| **也** | ①句末判斷語氣（是/為）②感嘆③句中停頓 | 「師者，所以傳道受業解惑也」①判斷 |
| **而** | ①並列（且）②遞進（而且、又）③轉折（但是）④修飾（地）⑤承接（然後） | 「人而無信」③轉折；「博學而篤志」②遞進 |
| **以** | ①介詞（用、拿、憑）②連詞（因為、從而）③動詞（認為） | 「以石投水」①用；「以其境過清」②因為；「我以日始出時去人近」③認為 |

## 四、典故詞語（雅稱／別稱）釋義

考試也會問「下列對詞語的解釋，錯誤的選項是？」，考的是古典文學裡的**雅稱、別稱、借代詞**。這類只能靠背，先記最高頻的：

| 詞語 | 正確解釋 | 易誤 |
|---|---|---|
| 柔荑（ㄊㄧˊ） | 女子細嫩的手 | 非植物本身 |
| 桂魄 | 月亮的別稱（月中有桂） | 非桂花 |
| 桃符 | 春聯（古代門上避邪桃木板） | 非符咒 |
| 桑梓（ㄗˇ） | 故鄉 | 非桑樹田 |
| 桑戶 | 用桑枝編的門，指**貧者居所**（非「農婦所居」） | 易被改寫成農婦之處 |
| 梵宇 | 佛寺 | 正確要記得 |
| 軒冕 | 官位爵祿（高官的車與冠） | 非車子 |
| 廟堂 | 朝廷 | 非寺廟 |
| 桑榆 | 晚年（日落時餘光照桑榆） | 非樹木 |
| 須眉／鬚眉 | 男子 | 巾幗才是女子 |

解法：**逐項把詞語的解釋代回，找出那個「被偷換」的錯誤解釋**（通常把雅稱硬解成字面意思）。

## 五、一字多義辨析法

**步驟：把字代回句子，看它在句中扮演什麼角色（名詞/動詞/形容詞），再看語境。**

例：「信」
- 動詞：相信（「信而見疑」）
- 名詞：書信（「家書抵萬金」的「書」同理）
- 形容詞：誠信（「信義」）
- 副詞：果真（「信如君不君，臣不臣」）→ 此處是「果真如果」

    "C：「不以物喜」——不因外物而喜悅，「以」也是「因為」，似乎也對。但整體比較，B 更貼近「是以（因此）」的連詞邏輯。補充：C 選項中「以」也作「因」，如試題偏重此分類，亦可視情況討論。",
