## 觀念速複習（先把忘掉的補回來）

應用文考的是「**場合配對**」——不是考你背定義，而是考你在哪個場合用哪個詞、哪個格式。先把書信結構看一遍，再把各種場合的詞彙對應記起來。

### 書信格式五大部分

```
① 稱謂（對方的稱呼）      如：父親大人、老師尊鑒
② 提稱語（接在稱謂後）    如：膝下、函丈、台鑒
③ 開頭寒暄語
④ 正文
⑤ 結尾敬辭 + 署名
   結尾敬辭：如：敬祝 鈞安、謹頌 時祺
   署名：自稱（謙稱）+ 姓名 + 敬上
```

### 提稱語對照表

提稱語接在稱謂後，表示「呈上此信」。**依對象不同，用語也不同**，這是考試最常問的地方：

| 對象 | 提稱語 | 例 |
|---|---|---|
| 父母、長輩（至親） | **膝下** | 父親大人膝下 |
| 師長、老師 | **函丈**（尊師）、**道席**、**講席** | 恩師函丈 |
| 一般長輩、上司 | **尊鑒**、**鈞鑒** | 伯父尊鑒 |
| 平輩、朋友 | **台鑒**、**惠鑒**、**大鑒** | 同學台鑒 |
| 晚輩（寫給學生） | **知悉**、**覽** | 學生 某某 知悉 |
| 政府機關 | **鈞鑒** | 局長鈞鑒 |

### 稱人／稱己：家族與親屬稱謂對照表

「稱呼別人的家人」用敬辭，「稱呼自己的家人」用謙辭——這組最容易考錯：

| 關係 | 稱「別人的」（敬，多用「令／尊／賢」） | 稱「自己的」（謙，多用「家／舍／小／先」） |
|---|---|---|
| 父親 | **令尊**、尊翁 | **家父**、家嚴 |
| 母親 | **令堂**、令慈 | **家母**、家慈 |
| 兒子 | **令郎**、令公子 | **小兒**、犬子 |
| 女兒 | **令媛**（令嬡） | **小女** |
| 兄弟 | **賢昆仲**、令兄／令弟 | **家兄**、舍弟 |
| 已故的長輩 | — | **先父**、先母（「先」＝已過世的尊長） |

> 三字口訣：**長輩用「家」**（家父家母）、**平輩晚輩用「舍／小」**（舍弟小女）、**已故用「先」**（先父）。稱對方一律用敬辭（令／尊／賢），絕不能用謙辭。
>
> 陷阱：「賢昆仲」是**敬稱對方的兄弟**，不能拿來稱自己的兄弟。

### 自稱（謙稱）對照表

寫信時對不同對象的自稱：

| 對象 | 自稱 | 說明 |
|---|---|---|
| 父母 | **男（女）**、不孝兒 | 子女對父母 |
| 師長 | **受業**、門生、學生 | 學生對老師 |
| 長輩 | **晚**、後學 | 晚輩對長輩 |
| 平輩 | **弟**（男）、**妹**（女）| 同輩之間 |
| 晚輩（對方） | 餘、愚 | 長輩寫給晚輩 |

### 結尾敬辭（祝頌語）

書信末尾的祝福，依**對象身份**選用：

| 對象 | 結尾敬辭 |
|---|---|
| 長輩 | 敬請 **福安**、謹頌 **崇安**、叩請 **金安** |
| 師長 | 敬請 **道安**、敬頌 **誨安** |
| 平輩 | 敬請 **台安**、即請 **大安** |
| 晚輩 | 即詢 **近安**、順詢 **近好** |

### 信封啟封詞（別跟「提稱語」搞混）

**提稱語**寫在「信紙裡」稱謂後（膝下、函丈…）；**啟封詞**寫在「信封上」收信人名字後，請對方拆信。兩者位置與用詞都不同：

| 對象 | 信封啟封詞（請對方開啟） |
|---|---|
| 長輩 | **安啟**、福啟（恭敬請長輩拆） |
| 平輩 | **大啟**、台啟 |
| 晚輩 | **啟**、收 |

> **大陷阱**：「**敬啟**」是「**恭敬地（替您）開啟**」，主詞是收信人——叫長輩「恭敬地拆信」於理不合，所以**信封上對長輩不可寫「敬啟」**，要用「安啟／福啟」。「敬啟」只能用在署名後表「敬告」（如公告「○○謹啟」）。

### 抬頭（書信中的敬意符號）

信中**提到對方或對方尊長**時，要表示尊敬：

- **挪抬**：在該詞前空一格（最常用），如「敬請　鈞安」。
- **平抬**：另起一行頂格書寫，更隆重。
- 反之，**提到自己或自己的尊長**時，字體要**略小、偏右**書寫，以示自謙。

> 一句話：抬高別人（空格／另行），縮小自己（略小偏右）。

### 便條／柬帖常見類型（看內容判用途）

便條是簡短的應酬文字，考題給一段便條問「這是做什麼用的」，看關鍵動詞就懂：

| 便條類型 | 關鍵字／情境 |
|---|---|
| **謝饋贈** | 對方送東西來（佳茗、禮物），回「拜領、申謝忱」 |
| **謝邀宴** | 對方請吃飯，回「敬謝盛宴」 |
| **謝來訪** | 對方來拜訪，回「謝枉駕」 |
| **謝慰問** | 自己生病／有事，對方來問候 |
| **借物／還物** | 「謹借」「奉還」 |

### 題辭（賀辭）場合對照表

題辭依**場合**選用，選錯就鬧笑話——這是考試很愛考的坑：

**壽誕（祝壽）用語**：

| 題辭 | 場合說明 |
|---|---|
| **南山獻壽** | 泛用祝壽 |
| **福如東海，壽比南山** | 泛用祝壽 |
| **耄耋之慶**（八、九十歲）| 高齡祝壽 |
| **松鶴延年** | 老人長壽 |
| **壽域宏開** | 壽宴題辭 |

**婚慶用語**：

| 題辭 | 場合說明 |
|---|---|
| **瓊花並蒂** | 婚慶（這是雙人喜事） |
| **鸞鳳和鳴** | 婚慶 |
| **百年好合** | 婚慶 |
| **宜室宜家** | 婚慶（新人新居） |

**生育（喜獲麟兒）用語**：

| 題辭 | 場合說明 |
|---|---|
| **夢熊之兆** | 生男孩（熊→男） |
| **夢蘭之兆** | 生女孩（蘭→女） |
| **弄璋之喜** | 生男孩（璋是玉器） |
| **弄瓦之喜** | 生女孩（瓦是紡錘） |
| **綿綿瓜瓞** | 祝子孫繁衍（詩經句） |
| **麟趾呈祥** | 祝子孫賢德（不特指男女） |
| **慶衍螽斯** | 祝多子多孫（螽斯多子） |

> **考試陷阱**：「瓊花並蒂」是**婚慶**，不是生子；生了小孩要用「夢熊之兆」「弄璋之喜」等，不能送「瓊花並蒂」。

**喪葬輓聯**：

| 題辭 | 說明 |
|---|---|
| **音容宛在** | 悼念死者 |
| **駕鶴西歸** | 死者（高齡） |
| **千古流芳** | 悼念（有功德者） |

**開業（喬遷、開店）**：

| 題辭 | 說明 |
|---|---|
| **開張大吉** | 店家開業 |
| **生意興隆** | 商業祝賀 |
| **鴻圖大展** | 事業開展 |

|---|---|
