免疫系統分兩層：先天免疫快速但無記憶，後天免疫慢但專一且有記憶。本篇從兩道防線談起，帶到抗原呈現、體液與細胞免疫、抗體分類與疫苗原理。

## 一、免疫系統的兩道防線

| | 先天免疫（Innate Immunity） | 後天免疫（Adaptive Immunity） |
|---|---|---|
| 別名 | 非專一性免疫 | 專一性免疫 |
| 反應速度 | **快**（立即） | 慢（數天至數週） |
| 專一性 | 無（對所有病原體） | **有**（針對特定抗原） |
| 記憶性 | **無** | **有**（免疫記憶細胞） |
| 主要成員 | 皮膚、黏膜、發炎反應、自然殺手細胞（NK）、吞噬細胞 | T 細胞、B 細胞 |

**白血球與吞噬細胞的來源（小但常考）：**

- **巨噬細胞（macrophage）**由血液中的**單核細胞（monocyte）**離開血管、進入組織後分化而成 → 單核細胞是巨噬細胞的**先驅細胞**。
- 巨噬細胞、嗜中性球（neutrophil）是主要的**吞噬細胞**，屬先天免疫；同時巨噬細胞也能當 APC 連接後天免疫。

## 二、抗原（Antigen）是什麼？

- 抗原（Antigen）= 能引發免疫反應的分子（通常是外來蛋白質或多醣；蛋白質免疫原性最強，脂質、核酸本身免疫原性弱）。
- 抗原上的特定結構叫**抗原決定位（Epitope）**，是抗體或淋巴細胞辨識的「指紋」。
- 自身細胞通常不引發免疫（有**自我耐受性 self-tolerance**）；若失控 → 自體免疫疾病。

## 三、後天免疫兩大分支

**體液免疫（Humoral Immunity）**——靠抗體：

```
抗原進入體內
     ↓
B 細胞辨識抗原 → 活化
     ↓
分化成「漿細胞（Plasma cell）」→ 大量分泌抗體（Antibody/Immunoglobulin）
+ 部分 B 細胞成為「記憶細胞（Memory B cell）」留存
```

**細胞免疫（Cell-mediated Immunity）**——靠 T 細胞：

```
抗原由抗原呈現細胞（APC，如樹突細胞）呈現
     ↓
輔助 T 細胞（Helper T cell, Th, CD4⁺）活化 → 分泌細胞激素
     ↓
活化 B 細胞（體液分支）+ 活化殺手 T 細胞（Cytotoxic T cell, Tc, CD8⁺）
                                         ↓
                           直接殺死被感染的細胞（釋放穿孔素）
```

**重點**：輔助 T 細胞（CD4⁺）是整個後天免疫的「總指揮」——HIV 攻擊 CD4⁺，導致免疫崩潰（AIDS）。

**抗原呈現（APC + MHC）——把「敵人特徵」秀給 T 細胞看：**

```
病原體入侵 → 巨噬細胞/樹突細胞（APC）吞噬 → 把抗原碎片
       裝在細胞表面的 MHC 分子上 → 「呈現」給輔助 T 細胞
                    ↓
   輔助 T 細胞與 APC 互相作用、分泌白血球介白素（IL-1、IL-2）
                    ↓
   活化 B 細胞（→ 抗體＋記憶 B 細胞）＋ 增生更多胞殺 T 細胞
```

注意：這條「APC + MHC → 活化 T/B 細胞」的**後天免疫**級聯，主角是巨噬細胞、輔助 T 細胞、IL、記憶 B 細胞、胞殺 T 細胞。**發炎反應（inflammation）屬於先天免疫**的非專一性反應，不算在這條特異性級聯裡。

## 四、抗體（Antibody）結構與功能

- 抗體是 Y 形糖蛋白（免疫球蛋白 Immunoglobulin, Ig）。
- Y 形頂端 = **可變區（Variable region）**，辨識並結合特定抗原。
- Y 形底端 = **恆定區（Constant region）**，決定抗體類別（IgG、IgM、IgA、IgE、IgD）。

| 類別 | 主要功能 | 記憶關鍵字 |
|---|---|---|
| **IgG** | 血清中**含量最多**；**唯一能通過胎盤**給新生兒；長效保護；促進凝集 | 「最多、過胎盤」 |
| **IgM** | **初次免疫反應最先合成**的抗體；促進細菌凝集、溶解 | 「最早、最先」 |
| **IgA** | 存在於**體外分泌物**（唾液、母乳、淚液、腸道）；新生兒可從母乳獲得 | 「分泌液、母乳」 |
| **IgE** | 引起**第 I 型過敏反應**；促進組織胺等釋放（與肥大細胞結合） | 「過敏」 |
| **IgD** | 主要在 B 細胞表面當受體；**沒有明確的獨立效應功能**（常是考題中「對不上描述」的那一個） | 「功能最模糊」 |

抗體功能：**中和（Neutralization）**、**調理素化（Opsonization，幫助吞噬）**、**活化補體系統**、**凝集（agglutination）**。

**做「抗體配功能」題的訣竅**：先把有特徵的四個（IgG 最多/過胎盤、IgM 最早、IgA 分泌液、IgE 過敏）對上，剩下「對不上任何描述」的那個通常就是 **IgD**。

## 五、初次 vs. 二次免疫反應

| | 初次反應（Primary response） | 二次反應（Secondary response） |
|---|---|---|
| 觸發條件 | 第一次接觸抗原 | 再次接觸同一抗原 |
| 潛伏期 | 長（5–10 天） | **短**（1–3 天） |
| 抗體濃度 | 低 | **高**（大幅提升） |
| 抗體持續 | 短 | **長** |
| 原因 | 需時活化淋巴細胞 | **記憶細胞**快速大量增殖 |

**疫苗（Vaccine）**的原理：用減毒/死的病原體或抗原片段刺激初次免疫反應 → 產生記憶細胞 → 真正感染時觸發強烈二次反應。

## 六、過敏與自體免疫

| 狀況 | 原因 | 例子 |
|---|---|---|
| **過敏（Allergy）** | 對無害抗原（過敏原）產生 IgE 過度反應 → 肥大細胞釋放組織胺 | 花粉症、氣喘 |
| **自體免疫疾病** | 免疫系統錯誤攻擊自身組織 | 類風濕性關節炎、紅斑性狼瘡、第一型糖尿病 |

## 七、病毒與免疫（HIV 常考其病毒特性）

| 病毒 | 遺傳物質 | 有無套膜（envelope） | 重點 |
|---|---|---|---|
| **HIV（人類免疫缺失病毒）** | **RNA**（反轉錄病毒 retrovirus） | **有套膜** | 攻擊 CD4⁺ 輔助 T 細胞 → AIDS |
| HPV（人類乳突瘤病毒） | DNA | 無套膜 | 與子宮頸癌相關 |

記法：**HIV ＝ 有套膜的 RNA 病毒**（套膜來自宿主細胞膜；靠反轉錄酶把 RNA 變成 DNA 插入宿主基因體）。
