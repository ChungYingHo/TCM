介系詞題多半考固定搭配，靠「整組記」而非中文硬推。本篇整理 at／on／in 的時間地點用法，以及動詞、形容詞、名詞的常考搭配。

## 一、時間介系詞：at / on / in 的範圍大小

越具體的時間點用 at，越大的時間單位用 in：

| 介系詞 | 用於 | 例子 |
|---|---|---|
| **at** | 精確時刻、節日（特定點） | at 8 a.m., at noon, at midnight |
| **on** | 特定日期、星期幾 | on Monday, on January 1st, on my birthday |
| **in** | 月份、年份、季節、世紀、一天的時段 | in June, in 2024, in the morning, in winter |

> 例外：at night（固定說法）；in the morning/afternoon/evening 但 at noon/midnight。

## 二、地點介系詞：at / on / in 的概念

| 介系詞 | 概念 | 例子 |
|---|---|---|
| **at** | 視為一個「點」 | at the hospital, at the corner, at the bus stop |
| **on** | 表面接觸；道路 | on the table, on the wall, on Fifth Avenue |
| **in** | 三維空間內部；城市/國家 | in the room, in Taipei, in the box |

## 三、常考動詞 + 介系詞搭配（Verb + Preposition Collocations）

<CollocationQuiz client:visible />

| 搭配 | 中文意思 |
|---|---|
| depend **on** / rely **on** | 依賴、取決於 |
| result **in** | 導致（結果） |
| result **from** | 起因於 |
| consist **of** | 由……組成 |
| refer **to** | 指的是；參考 |
| contribute **to** | 貢獻；有助於 |
| base sth **on** | 把……建立在……之上 |
| be responsible **for** | 負責；應歸咎於 |
| be categorized **as** | 被歸類為 |
| be described **as** | 被描述為 |
| be impressed **by/with** | 對……印象深刻 |
| agree **with** | 同意某人 |
| agree **on** | 就某事達成共識 |

> 兩個常考的「as」搭配：be **categorized as**（歸類為）、be **described as**（描述為），as 後面可接名詞或 V-ing（described **as having** difficulty…）。base A **on** B＝把 A 建立在 B 上（base theories **on** evidence）。

## 四、常考形容詞 + 介系詞搭配（Adjective + Preposition）

| 搭配 | 例句 |
|---|---|
| interested **in** | She is interested in herbal medicine. |
| familiar **with** | Are you familiar with this procedure? |
| capable **of** | He is capable of handling the case. |
| dependent **on** | The outcome is dependent on the dosage. |
| similar **to** | This symptom is similar to influenza. |
| aware **of** | Be aware of the side effects. |

## 五、常考名詞 + 介系詞搭配（Noun + Preposition）

有些名詞後面固定接特定介系詞，空格常考這個：

| 搭配 | 中文 / 例句 |
|---|---|
| a frontier / market / demand **for** | 對……的新領域／市場／需求（the next frontier **for** terrorists） |
| room / need **for** | 有……的空間／需要（room **for** improvement） |
| an increase / a rise **in** | ……的增加（an increase **in** cases） |
| the cause / reason **of/for** | ……的原因 |
| an effect / impact **on** | 對……的影響 |
| access **to** | 取得……的管道（access to care） |

> 「frontier / market / demand / need / room **for** + 對象」是高頻：表示「為了某對象而存在的領域/需求」。

時間介系詞：<b>at（精確時刻）→ on（特定日/星期）→ in（月/年/季）</b>，範圍越大用 in。<br />
常考搭配：result <b>in</b>（導致）vs result <b>from</b>（起因於）；depend / rely <b>on</b>；consist <b>of</b>。<br />
be categorized <b>as</b>（被歸類為）、be impressed <b>by/with</b>——介系詞和形容詞是固定搭配，要一起背。

## 例題（先自己做，再看步驟）

<ExampleQuestion client:visible
  n={1}
  q="Attempts to define reading are usually categorized ____ falling into one of the following three categories: the bottom-up, the top-down, or the interactive model."
  options={["of", "as", "at", "for"]}
  answer="(B) as"
  steps={[
    "空格前 categorized，後面跟著分類的說明 → 固定搭配 <b>categorized as</b>（被歸類為）。",
    "of/at/for 都不是 categorize 的固定介系詞搭配。",
    "答案：<b>as</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={2}
  q="The judges felt that Judy's performance had been the most impressive ____ the nine finalists."
  options={["of", "at", "for", "in"]}
  answer="(A) of"
  steps={[
    "most impressive 是最高級，後面接「比較範圍」。",
    "「在某群人/物之中」用 <b>of</b>（of the nine finalists），表示從這九人中挑出最好的。",
    "in 接地點或大範圍（in the class）；at/for 不接比較群體。答案：<b>of</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={3}
  q="Whether I go to university or not is ____ on what exam grades I get."
  options={["depended", "dependent", "dependence", "dependable"]}
  answer="(B) dependent"
  steps={[
    "空格前 is，後面接 on → 需要「形容詞」充當主詞補語，且能搭配 on。",
    "<b>dependent on</b> = 取決於，是固定搭配的形容詞。",
    "depended 是動詞過去式；dependence 是名詞（雖有 dependence on 搭配，但此處 is 後需形容詞作補語、且名詞還需冠詞，故不選）；dependable 意思是「可信賴的」，不接 on。答案：<b>dependent</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={4}
  q="The disease outbreak resulted ____ poor sanitation, which in turn resulted ____ a public health crisis."
  options={["from / in", "in / from", "from / from", "in / in"]}
  answer="(A) from / in"
  steps={[
    "第一空：爆發的<b>原因</b>是衛生差 → result <b>from</b>（起因於）。",
    "第二空：這個事件<b>導致</b>公衛危機 → result <b>in</b>（導致）。",
    "記憶法：result from（追溯來源）/ result in（指向結果）。答案：<b>from / in</b>。"
  ]}
/>
