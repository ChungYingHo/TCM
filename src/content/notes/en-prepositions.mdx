介系詞題多半考固定搭配，靠「整組記」而非中文硬推。本篇整理 at／on／in 的時間地點用法，以及動詞、形容詞、名詞的常考搭配。

## 一、時間介系詞：at / on / in 的範圍大小

越具體的時間點用 at，越大的時間單位用 in：

| 介系詞 | 用於 | 例子 |
|---|---|---|
| **at** | 精確時刻、節日（特定點） | at 8 a.m., at noon, at midnight |
| **on** | 特定日期、星期幾 | on Monday, on January 1st, on my birthday |
| **in** | 月份、年份、季節、世紀、一天的時段 | in June, in 2024, in the morning, in winter |

> **不必硬背——用「點 → 面 → 容器」的空間邏輯推**：at 把時間當成一個沒有大小的「點」（一個時刻）；on 把它當成一條「線／一格」（日曆上的一天）；in 把它當成一個「容器」，你被包在裡面（一個月、一年、一個季節都大到可以「住進去」）。時間單位越大、越像個包住你的空間，就越往 in 移。地點介系詞（下一段）用的是**同一條規則**，學會一個就會兩個。
>
> 例外：at night（固定說法）；in the morning/afternoon/evening 但 at noon/midnight（noon/midnight 是精確的「點」，故回到 at）。

## 二、地點介系詞：at / on / in 的概念

和時間完全是**同一套「點 → 面 → 容器」維度邏輯**，只是換成真實空間——你怎麼想像那個地方的形狀，就決定用哪個介系詞：

| 介系詞 | 維度 | 概念 | 例子 |
|---|---|---|---|
| **at** | 0 維（點） | 視為地圖上一個「點」、一個定位 | at the hospital, at the corner, at the bus stop |
| **on** | 1–2 維（線／面） | 貼在表面或沿著一條線 | on the table, on the wall, on Fifth Avenue |
| **in** | 3 維（容器） | 被包在一個立體空間／範圍**內部** | in the room, in Taipei, in the box |

> 同一個地點，**你想成什麼形狀就配什麼介系詞**：把醫院當作會合的一個點 → at the hospital；強調人在建築物**裡面** → in the hospital。這就是為什麼 at/on/in 沒有「唯一正解」，要看語意把它當點、當面、還是當容器。

## 三、常考動詞 + 介系詞搭配（Verb + Preposition Collocations）

<CollocationQuiz client:visible />

| 搭配 | 中文意思 |
|---|---|
| depend **on** / rely **on** | 依賴、取決於 |
| result **in** | 導致（結果） |
| result **from** | 起因於 |
| consist **of** | 由……組成 |
| refer **to** | 指的是；參考 |
| contribute **to** | 貢獻；有助於 |
| base sth **on** | 把……建立在……之上 |
| be responsible **for** | 負責；應歸咎於 |
| be categorized **as** | 被歸類為 |
| be described **as** | 被描述為 |
| be impressed **by/with** | 對……印象深刻 |
| agree **with** | 同意某人 |
| agree **on** | 就某事達成共識 |

> 兩個常考的「as」搭配：be **categorized as**（歸類為）、be **described as**（描述為），as 後面可接名詞或 V-ing（described **as having** difficulty…）。base A **on** B＝把 A 建立在 B 上（base theories **on** evidence）。

## 四、常考形容詞 + 介系詞搭配（Adjective + Preposition）

| 搭配 | 例句 |
|---|---|
| interested **in** | She is interested in herbal medicine. |
| familiar **with** | Are you familiar with this procedure? |
| capable **of** | He is capable of handling the case. |
| dependent **on** | The outcome is dependent on the dosage. |
| similar **to** | This symptom is similar to influenza. |
| aware **of** | Be aware of the side effects. |
| grateful / thankful **for** | They are grateful **for** the support.（感謝某事） |
| responsible **for** | The doctor is responsible **for** the ward. |
| afraid / anxious / worried **about** | She is worried **about** the diagnosis. |

> **情緒形容詞 + for/about，不必硬背——分工有邏輯**：要接「**引發情緒的原因**」用 **for**（grateful / thankful / sorry / famous **for** + 那件事）；要接「**心裡掛念、放不下的對象**」用 **about**（worried / anxious / nervous **about** + 那件事）。例如 grateful **for** their disease＝感謝的「理由」是這場病。

## 五、常考名詞 + 介系詞搭配（Noun + Preposition）

有些名詞後面固定接特定介系詞，空格常考這個：

| 搭配 | 中文 / 例句 |
|---|---|
| a frontier / market / demand **for** | 對……的新領域／市場／需求（the next frontier **for** terrorists） |
| room / need **for** | 有……的空間／需要（room **for** improvement） |
| an increase / a rise **in** | ……的增加（an increase **in** cases） |
| the cause / reason **of/for** | ……的原因 |
| an effect / impact **on** | 對……的影響 |
| access **to** | 取得……的管道（access to care） |

> 「frontier / market / demand / need / room **for** + 對象」是高頻：表示「為了某對象而存在的領域/需求」。

## 六、衝突／爭議情境：over 與 against

考題很愛把「爭論、指控、對抗」的情境挖空，這兩個介系詞各有畫面，記住畫面就不用背搭配：

| 介系詞 | 畫面與用法 | 例子 |
|---|---|---|
| **over** | 雙方「**隔著**一個爭議主題拉鋸」→ 爭論/分歧**關於**什麼 | a debate / argument / dispute / disagreement / concern / conflict **over** + 議題 |
| **against** | 力量「**對著**目標推過去」→ 反對、控訴、防範 | accusation / charge / evidence / protest **against**；fight / protect / guard **against** |

> **推導法**：over 的本義是「在……上方／跨越」，兩方就像隔著桌上的議題對峙，所以「爭論 **over** 某主題」；against 的本義是「抵著、逆著」，矛頭指向對象，所以「指控 / 對抗 **against** 某人事」。看到 debate / argument / dispute 後面接主題就選 **over**；看到 accusation / charge / fight / protect 後面接矛頭對象就選 **against**。
