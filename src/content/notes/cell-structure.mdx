細胞分原核與真核兩大類，真核細胞裡有各種分工的胞器。本篇用「工廠部門」的比喻認識胞器，再比較動植物細胞與細胞骨架。

## 一、原核細胞 vs 真核細胞

| 特徵 | 原核細胞（Prokaryote） | 真核細胞（Eukaryote） |
|---|---|---|
| **核膜** | **無**（DNA 裸露在細胞質中） | **有**（DNA 包在細胞核內） |
| 膜狀胞器 | **無**（粒線體、葉綠體等皆無） | **有** |
| 核糖體 | 有（70S，較小） | 有（80S，較大；粒線體/葉綠體內也是 70S） |
| 細胞壁 | 通常有（細菌：肽聚糖；古菌：不含肽聚糖） | 植物有（纖維素）；動物無 |
| DNA | 環狀，單一條染色體；可有質粒（plasmid） | 線狀，多條染色體，在細胞核 |
| 代表 | 細菌、古菌、藍綠菌（藍綠藻） | 動物、植物、真菌、原生生物 |

> **考試陷阱**：藍綠菌（Cyanobacteria）能行光合作用，但它是**原核生物**，沒有葉綠體！光合色素直接在細胞膜（類囊體膜）上。

> **藍綠菌的固氮**：某些絲狀藍綠菌會分化出一種厚壁、不行光合的特化細胞，叫**異型細胞（異形細胞，heterocyst）**，專門進行**固氮作用**（把 N₂ 變成可用氮）。厚壁是為了隔絕氧氣，因為固氮酶怕氧。

## 二、真核細胞胞器（工廠部門對照）

把細胞想成一間工廠，各胞器就是不同部門。動手探索：

<Organelle client:visible />

| 胞器（工廠部門） | 構造特點 | 主要功能 |
|---|---|---|
| **細胞核（Nucleus）** | 雙層核膜，核孔控制進出 | 儲存 DNA，主宰基因表現（CEO 辦公室） |
| **核糖體（Ribosome）** | 無膜，rRNA + 蛋白質組成；附著內質網或游離 | **蛋白質合成**（生產線） |
| **粗糙內質網（RER）** | 表面有核糖體 | 蛋白質合成後的初步折疊、送往高基氏體 |
| **滑面內質網（SER）** | 無核糖體 | 脂質合成、解毒（肝細胞多）、鈣離子儲存 |
| **高基氏體（Golgi）** | 扁平囊狀堆疊 | 蛋白質**修飾、分類、包裝、運輸**（郵局） |
| **粒線體（Mitochondria）** | 雙層膜，內膜有嵴（cristae） | **有氧呼吸（ATP 生產）**（發電廠） |
| **葉綠體（Chloroplast）** | 雙層膜＋類囊體（thylakoid）＋基質（stroma） | **光合作用**（太陽能面板） |
| **溶體（Lysosome）** | 單層膜，內含水解酶（pH≈5） | **分解老舊胞器、異物**（廢物處理廠） |
| **液胞（Vacuole）** | 單層膜（tonoplast） | 植物：大液胞儲水維持膨壓；動物：小食泡/水泡 |
| **中心體（Centrosome）** | 含 2 根中心粒，無膜 | 形成紡錘絲，動物細胞分裂必備；植物通常無 |
| **過氧化體（Peroxisome）** | 單層膜 | 分解脂肪酸、解毒（H₂O₂→H₂O） |

> **溶體 vs 過氧化體（都會「解毒」但方式不同）**：溶體用**水解酶**（酸性 pH≈5）消化大分子與老舊胞器；過氧化體用**氧化酶**處理脂肪酸並把有毒的 H₂O₂ 用**過氧化氫酶（catalase）**分解成 H₂O。兩者都參與細胞內有害物質的處理。

## 三、細胞骨架（Cytoskeleton）：鋼筋與軌道

細胞質裡有三種蛋白質纖維，撐起形狀、固定胞器、當運輸軌道：

| 纖維（由粗到細想） | 主成分 | 主要功能 | 搭配的運動蛋白 |
|---|---|---|---|
| **微管（microtubule）** | 微管蛋白（tubulin） | 最粗；紡錘絲、鞭毛/纖毛的軸絲、胞器運輸軌道 | 動力蛋白（dynein）、運動蛋白（kinesin） |
| **中間絲（intermediate filament）** | 角蛋白等 | 機械支撐、維持細胞與核的形狀（最耐拉） | 無（不負責主動運動） |
| **微絲（microfilament）** | 肌動蛋白（actin） | 最細；肌肉收縮、胞器移動、變形蟲運動、縊縮環 | **肌凝蛋白（myosin）沿微絲移動** |

> 高頻陷阱：**肌凝蛋白（myosin）是沿著「微絲（actin）」走，不是沿著中間絲**；負責沿微管走的是 dynein / kinesin。

**鞭毛與纖毛**：真核細胞的鞭毛/纖毛內部軸絲是 **9＋2 排列**（9 對周邊微管 + 中央 2 根），不是 9＋1。靠微管滑動產生擺動。

## 四、動物細胞 vs 植物細胞差異

| 構造 | 動物細胞 | 植物細胞 |
|---|---|---|
| 細胞壁 | **無** | **有**（纖維素） |
| 葉綠體 | **無** | **有**（綠色部位） |
| 大液胞 | 無（只有小食泡） | **有**（佔細胞大部分體積） |
| 中心體 | **有** | 通常**無**（高等植物） |
| 溶體 | 常見 | 較少（液胞有類似功能） |

## 五、粒線體與葉綠體：內共生起源

兩者都有**雙層膜**、自己的環狀 DNA（像細菌）、自己的 70S 核糖體——支持「內共生學說（Endosymbiotic Theory）」：粒線體源自好氧細菌、葉綠體源自藍綠菌，被早期真核細胞吞入後共生至今。
