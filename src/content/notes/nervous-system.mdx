## 觀念速複習（先把忘掉的補回來）

### 神經元的基本結構

神經元（neuron）是神經系統的功能單位：

| 部位 | 功能 |
|---|---|
| **樹突（dendrite）** | 接收來自其他神經元的訊號 |
| **細胞體（soma）** | 含核，整合訊號 |
| **軸突（axon）** | 傳導動作電位（電訊號）往下傳 |
| **髓鞘（myelin sheath）** | 絕緣層，由許旺細胞（PNS）或寡樹突細胞（CNS）包覆 |
| **蘭氏節（Nodes of Ranvier）** | 髓鞘間的裸露節點，動作電位在此「跳」 |

### 靜止電位（Resting Membrane Potential）

靜止電位大約 **−70 mV**（細胞內相對細胞外為負）。

**形成原因：鈉鉀幫浦（Na⁺-K⁺ ATPase）**

| 方向 | 離子 | 數量 |
|---|---|---|
| 幫浦「泵出」（主動） | Na⁺ | 3 個 Na⁺ 出 |
| 幫浦「泵入」（主動） | K⁺ | 2 個 K⁺ 入 |

- 淨效果：持續把正電荷（Na⁺ 多出 1）泵出 → 維持細胞內負電位。
- 靜止時 K⁺ 通道部分開放，K⁺ 沿濃度梯度外漏，使內部更負。

**平衡電位（Equilibrium Potential）—— 這個觀念常出題**

每種離子都有自己的「平衡電位」：當這個離子的「濃度梯度想往外推」與「電位梯度想往內拉」剛好抵銷時的膜電位。

- K⁺ 平衡電位（E_K）約 **−90 mV**；Na⁺ 平衡電位（E_Na）約 **+60 mV**。
- 靜止時膜對 **K⁺ 通透性最高**，所以靜止電位（−70 mV）**最靠近 K⁺ 的平衡電位**（但因為仍有一點 Na⁺ 漏入，比 E_K（−90）稍微偏正一點）。
- 一句話：靜止膜電位 ≈ K⁺ 平衡電位（接近但不完全相等，且比 E_K 偏正）。動作電位高峰則趨近 Na⁺ 平衡電位。

### 動作電位（Action Potential）

動作電位是「全或無（all-or-none）」反應：達到閾值（−55 mV）才觸發，一觸發就走完完整波形，無法「半觸發」。

**四個階段：**

| 階段 | 離子動作 | 膜電位變化 |
|---|---|---|
| ① 靜止 | Na⁺ 通道關 | −70 mV |
| ② **去極化（Depolarization）** | 電位依存性 Na⁺ 通道大量**開啟**，Na⁺ 湧入 | −70 → +30 mV |
| ③ **再極化（Repolarization）** | Na⁺ 通道關閉，K⁺ 通道**開啟**，K⁺ 外流 | +30 → −70 mV |
| ④ **不反應期（Refractory period）** | Na⁺ 通道暫時無法再開（絕對不反應期） | 確保訊號單向傳導 |

### 跳躍傳導（Saltatory Conduction）

- 有髓鞘的軸突：動作電位只在**蘭氏節**（髓鞘間的裸露段）發生，從節跳到節。
- 優點：**速度快**（可達 120 m/s）、**耗能少**。
- 無髓鞘神經：依序連續去極化，速度較慢（約 0.5–2 m/s）。

### 突觸（Synapse）與神經傳遞物

突觸是神經元之間的訊號傳遞接合點，多數為**化學突觸**：

1. 動作電位到達**突觸前神經末梢** → Ca²⁺ 通道開啟 → Ca²⁺ 內流。
2. 突觸小泡（vesicle）與細胞膜融合 → **神經傳遞物（neurotransmitter）** 釋放進突觸間隙。
3. 神經傳遞物結合突觸後膜受體 → 引發**興奮性（EPSP）**或**抑制性（IPSP）**後電位。

| 神經傳遞物 | 主要效果 | 例子 |
|---|---|---|
| **乙醯膽鹼（ACh）** | 興奮（神經肌肉接合處）；在心臟為抑制 | 骨骼肌收縮、自律神經 |
| **多巴胺（Dopamine）** | 獎賞、動作控制 | 帕金森症（多巴胺神經元退化） |
| **血清素（Serotonin）** | 情緒調節、睡眠 | 抗憂鬱藥（SSRI）阻止回收 |
| **GABA** | 主要<b>抑制性</b>傳遞物 | 安眠藥/酒精增強 GABA 作用 |
| **麩胺酸（Glutamate）** | 主要<b>興奮性</b>傳遞物 | 學習與記憶 |
| **正腎上腺素（NE）** | 「戰或逃」反應 | 交感神經末梢釋放 |

### 中樞與周邊神經系統

| 系統 | 組成 | 功能 |
|---|---|---|
| **中樞神經系統（CNS）** | 腦 ＋ 脊髓 | 整合、決策、反應 |
| **周邊神經系統（PNS）** | 腦神經（12 對）＋ 脊神經（31 對）| 傳入（感覺）/傳出（運動） |

PNS 傳出分兩支：
- **軀體神經**：隨意控制骨骼肌。
- **自律神經**：不隨意控制內臟，分交感（「戰或逃」）與副交感（「休息消化」）。

### 大腦皮質的功能分區（會考「某迴管什麼」）

大腦皮質分四葉。考試最常考**中央溝兩側的兩條迴**：

| 構造 | 位置 | 功能 |
|---|---|---|
| **中央前迴（precentral gyrus）** | 額葉，中央溝**前** | **主要運動皮質**：發出隨意運動指令到骨骼肌 |
| **中央後迴（postcentral gyrus）** | 頂葉，中央溝**後** | **主要體感皮質**：接收皮膚觸覺、痛覺等 |
| 額葉其他區 | 額葉 | 思考、決策、語言發聲（布洛卡區）、面部表情控制 |
| 枕葉 | 後腦 | 視覺 |
| 顳葉 | 側腦 | 聽覺、記憶 |

口訣：**前迴管「動」（運動）、後迴管「感」（感覺）**。中央前迴位於額葉、負責運動與發聲/表情，但**不負責內臟疼痛**（內臟感覺主要在後迴/島葉）。

### 感覺器官重點（送分題常考）

| 器官 | 重點 | 易錯 |
|---|---|---|
| **視網膜——錐細胞（cone）** | 人有 **3 種**錐細胞（紅、綠、藍三原色）→ 彩色視覺、需強光 | 不是 1 種也不是數百種 |
| **視網膜——桿細胞（rod）** | 1 種，感光敏感、只分明暗，負責暗處視覺 | 不分顏色 |
| **內耳——耳蝸（cochlea）** | 聽覺 | — |
| **內耳——前庭（球狀囊 saccule＋橢圓囊 utricle）** | 偵測**直線**加速度與頭部位置（平衡覺）；內含毛細胞與**耳石（otolith）** | 耳石是**碳酸鈣（CaCO₃）結晶**，不是磷酸鎂 |
| **內耳——半規管** | 偵測**旋轉**加速度 | — |

### 行為類型

| 類型 | 說明 | 例子 |
|---|---|---|
| **先天行為——本能（Innate）** | 天生固定，不需學習 | 蜘蛛結網、新生兒吸吮反射 |
| **先天行為——固定行為模式（FAP）** | 由特定刺激（釋放子）觸發、一旦啟動就跑完的固定動作序列 | 灰雁滾蛋回巢、雄魚見紅腹就攻擊 |
| **先天行為——印痕（Imprinting）** | 特定敏感期學習，之後固定 | 剛孵化雛鵝跟隨第一個看到的移動物體 |
| **後天行為——習慣化（Habituation）** | 對反覆出現、無意義的刺激逐漸**不再反應** | 鳥對稻草人久了不再害怕 |
| **後天行為——古典制約** | CS（鐘聲）配 UCS（食物）→ CS 單獨可引發反應 | 巴夫洛夫的狗 |
| **後天行為——操作制約** | 行為後的獎懲影響未來行為頻率 | 老鼠按槓桿得食物 |
| **後天行為——洞察學習** | 靠理解與推理解決新問題 | 黑猩猩疊箱子取香蕉 |

**基因 × 環境交互作用（gene–environment interaction）**：許多行為**不是**單純先天或後天，而是基因背景與後天環境**共同**塑造。例：幼鼠若由低互動（少舔舐照顧）的母鼠養大，長大後在新環境較易恐懼焦慮——這既受基因影響、也受早期環境影響，是兩者**交互作用**的結果。看到「先天 + 後天一起影響」就選此項，而非單一的印痕或習慣化。
