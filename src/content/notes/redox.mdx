氧化還原就是電子的轉移。本篇講氧化數怎麼判定、半反應法怎麼配平方程式、以及用標準電位比較氧化還原劑的強弱。

## 一、氧化與還原的定義

| 概念 | 氧化 | 還原 |
|---|---|---|
| 電子 | 失去電子（e⁻↑） | 得到電子（e⁻↓） |
| 氧化數 | 升高 | 降低 |
| 記憶口訣 | OIL（Oxidation Is Loss） | RIG（Reduction Is Gain） |

**氧化劑**：使別人氧化（自己被還原，氧化數降低）。  
**還原劑**：使別人還原（自己被氧化，氧化數升高）。

## 二、氧化數判定（7 條規則）

**氧化數（oxidation number）**是假設化合物中的共用電子都歸給電負度較大的原子後，每個原子「帳面上」帶的電荷。判定規則（依優先序）：

| 規則 | 說明 | 例子 |
|---|---|---|
| 1 | 單質（元素態）氧化數 = 0 | Fe(s)、O₂(g) → 0 |
| 2 | 單原子離子 = 其電荷 | Ca²⁺ → +2；Cl⁻ → −1 |
| 3 | 化合物中 F 恆為 −1 | HF → F 是 −1 |
| 4 | 化合物中 O 通常 −2（過氧化物 −1） | H₂O → O 是 −2；H₂O₂ → O 是 −1 |
| 5 | 化合物中 H 通常 +1（與金屬形成氫化物 −1） | HCl → H 是 +1；NaH → H 是 −1 |
| 6 | 分子中各原子氧化數之和 = 0 | H₂SO₄：+1×2 + S + (−2)×4 = 0 → S = +6 |
| 7 | 多原子離子各原子之和 = 離子電荷 | SO₄²⁻：S + (−2)×4 = −2 → S = +6 |

**為什麼是這個優先序（不用硬背）**：氧化數的定義是「把每根鍵的共用電子整份判給電負度大的那一方」。所以**電負度越大的元素，越優先拿到固定的負氧化數**：F 電負度全表最大 → 永遠 −1（規則 3 最優先）；O 次之 → 通常 −2，但遇到更兇的 F 就得讓出（OF₂ 中 O ＝ +2）；H 電負度比一般非金屬小 → 對非金屬時當 +1，碰到電負度更小的金屬反而拿負電（金屬氫化物 −1）。記住「電負度大者先占負值」就能推出整張表，連特例方向都對。

**⚠️ 氧的特例（常考陷阱）**：O 不是永遠 −2！

| 化合物 | O 的氧化數 | 怎麼算 |
|---|---|---|
| 一般氧化物（H₂O、CO₂） | −2 | 規則 4 |
| 過氧化物 peroxide（H₂O₂、Na₂O₂） | **−1** | O–O 單鍵，兩個 O 共擔 |
| 超氧化物 superoxide（KO₂、NaO₂） | **−½** | 整個 O₂⁻ 帶 −1，2 個 O 平分 |
| 與 F 結合（OF₂） | **+2** | F 更負（規則 3 凌駕規則 4）|

**為什麼過氧化物變 −1**：O–O 是**同種原子的鍵**，電負度一樣大、共用電子對半分，這根鍵對每個 O 的氧化數貢獻是 0。於是每個 O 只「靠它連到別的元素的那一根鍵」拿電子——過氧 O₂²⁻ 整團帶 −2、兩個 O 平分各 −1；超氧 O₂⁻ 整團帶 −1、平分各 −½。判定訣竅：先看「這個氧有沒有接到另一個氧」。

## 三、半反應法配平步驟（酸性）

1. 分為氧化半反應和還原半反應
2. 先平衡氧、氫以外的原子（把被氧化／還原的主元素先配平係數，如 Cr₂O₇²⁻ → 2Cr³⁺、I₂ → 2IO₃⁻）
3. 用 H₂O 補 O 原子
4. 用 H⁺ 補 H 原子
5. 用 e⁻ 補電荷（讓兩側電荷平衡）
6. 乘以係數使兩個半反應電子數相同
7. 相加、消去重複項

**為什麼補 H₂O→H⁺→e⁻（不用死記順序）**：在酸性水溶液裡，現場唯一能任意取用的就是水分子、H⁺ 與電子這三樣。先用 H₂O 補氧、再用 H⁺ 補氫，是因為「**先把每種原子數配平（質量守恆），最後才用電子收尾電荷（電荷守恆）**」——電子只改變電荷、不增減原子，所以一定擺在最後。順序的邏輯就是「原子先、電荷後」。

> **照步驟走一次（MnO₄⁻ → Mn²⁺，酸性）**：
> 1. 主原子 Mn 兩側各 1，已平衡。
> 2. 補 O：左邊有 4 個 O → 右邊加 4 H₂O：MnO₄⁻ → Mn²⁺ + 4H₂O
> 3. 補 H：右邊多了 8 個 H → 左邊加 8 H⁺：MnO₄⁻ + 8H⁺ → Mn²⁺ + 4H₂O
> 4. 補電荷：左邊 (−1)＋(+8) ＝ +7、右邊 +2 → 左邊加 5 e⁻：
>    　**MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O**（兩側電荷都 +2 ✓）
>
> Mn 從 +7 降到 +2、得 5 個電子，正是還原半反應。把另一個氧化半反應也配好後，用步驟 6–7 讓電子數相同再相加即可。

## 四、鹼性條件的額外步驟

配平好酸性方程式後：  
→ 兩側各加等量 OH⁻（抵消 H⁺），使 H⁺ + OH⁻ → H₂O  
→ 化簡重複的 H₂O

> **接續上面那條轉成鹼性**：兩側各加 8 OH⁻ → 左邊 8H⁺＋8OH⁻ 併成 8H₂O，右邊變 4H₂O＋8OH⁻；把兩邊都有的 4H₂O 消掉 →
> 　**MnO₄⁻ + 4H₂O + 5e⁻ → Mn²⁺ + 8OH⁻**。

## 五、用標準還原電位 E° 比較強弱

**標準還原電位（E°）**衡量一個半反應「往還原方向（得電子）」的傾向，數值越正、越想得電子。考題常給一張 E° 表問誰最強。動手切換看：

**為什麼 E° 大就是強氧化劑（背後是熱力學）**：E° 直接連到自發性，ΔG° ＝ −nFE°。E° 越正 → 該還原（得電子）方向的 ΔG° 越負 → 越自發 → 這個左側物種「搶電子」的本事越強，就是越強的氧化劑。所以你比的不是死規則，是「哪個反應更想往得電子方向走」。

**共軛強弱反向（最常考的推理）**：每個半反應的氧化態（左）與還原態（右）是一對。**氧化態越強的氧化劑 ⇒ 它對應的還原態就越弱的還原劑**（電子被它抓得越牢，當然越不肯再放出來），反之亦然。這把「金屬 X 比 Y 強的還原劑 → X⁺ 比 Y⁺ 弱的氧化劑」一句話講通：還原力強的金屬，它的陽離子搶電子的慾望就弱。

一招判斷：

$$
\text{E° 越大（越正）} \Rightarrow \text{越想搶電子} \Rightarrow \text{越強的氧化劑}
$$

$$
\text{E° 越小（越負）} \Rightarrow \text{越想丟電子} \Rightarrow \text{越強的還原劑}
$$

- 找「**最強氧化劑**」→ 挑 E° **最大**那條，反應物（左側那個）就是答案。
- 找「**最強還原劑**」→ 挑 E° **最小（最負）**那條，生成物（右側那個被氧化的還原態）就是答案。
- 例：Mg²⁺ + 2e⁻ → Mg，E° = −2.37 V 最負 → **Mg 金屬是最強還原劑**。

## 六、一個反應轉移幾個電子

配平後，看氧化半反應與還原半反應乘上的係數後，**任一半反應放出（或得到）的電子總數**即為轉移電子數＝兩半反應電子數的**最小公倍數**。

- 例：S（+4→+6，失 2e⁻）與 Mn（+7→+2，得 5e⁻），LCM(2,5)=**10** → 轉移 10 個電子。

## 七、標準電池電位 E°cell ＝ E°陰 − E°陽

很多題給你一堆半反應 E°、要你算「整個反應」的標準電池電位（standard cell potential，E°cell）。公式只有一條：

$$
E°_{\text{cell}} = E°_{\text{陰極（還原）}} - E°_{\text{陽極（被氧化者的還原電位）}}
$$

- 兩個數**都用「還原電位」**代入，不要因為陽極在氧化就把它的 E° 變號再相加——變號的事「減法」已經幫你做了。
- E° 較大的半反應當**陰極**（被還原）；E° 較小的當**陽極**（被氧化）。
- E°cell 是**強度性質（intensive）**：乘係數平衡方程式時 E° **不乘**（不像 ΔG 會乘 n）。為什麼？因為電位是「**每單位電荷**的能量」（E° ＝ −ΔG°⁄nF）：你把方程式乘 2，ΔG° 與 n 同時加倍、相除後每庫侖的能量不變——就像把整桶水加倍、水溫不變一樣，所以 E° 與係數無關。

> **以 Cu/Zn 電池示範**：給 Cu²⁺ + 2e⁻ → Cu（E° ＝ +0.34 V）、Zn²⁺ + 2e⁻ → Zn（E° ＝ −0.76 V）。
> Cu²⁺/Cu 的 E° 較大 → 當陰極；Zn²⁺/Zn 較小 → 當陽極。
> E°cell ＝ E°陰 − E°陽 ＝ 0.34 − (−0.76) ＝ **+1.10 V** > 0 → 自發（就是鋅銅電池）。

注意有些題目把陽極直接寫成**氧化方向**並標出「氧化電位」（例如「Ag → Ag⁺ + e⁻，E° ＝ −0.799 V」）。這個 −0.799 已經是把還原電位 +0.799 變號後的氧化電位，這時用 **E°cell ＝ E°陰(還原) ＋ E°陽(氧化)** 直接相加即可，與「陰減陽」結果相同，別重複變號兩次。

## 八、配位化合物的中心金屬氧化數

判斷錯合物（coordination compound）中心金屬的氧化數，原則和規則 6、7 一樣（總和 ＝ 電荷），只是要先知道**各配體（ligand）帶幾價**，再扣掉外圈離子（counter-ion）。常見配體電荷：

| 配體 | 電荷 | 配體 | 電荷 |
|---|---|---|---|
| NH₃（ammine） | 0 | Cl⁻、Br⁻、I⁻（halido） | −1 |
| H₂O（aqua） | 0 | CN⁻（cyano） | −1 |
| en 乙二胺（雙牙） | 0 | OH⁻（hydroxido） | −1 |
| CO（carbonyl） | 0 | F⁻（fluoro） | −1 |

**做法**：①整個錯離子的電荷 ＝ 中心金屬 ＋ 各配體電荷之和；②錯離子的電荷由外圈相反離子推回（如 [⋯]Br₂ → 錯離子帶 +2、[⋯]Cl₂ → +2、K₃[⋯] → 錯離子帶 −3）。

> **示範 K₃[Fe(CN)₆]**：外圈 3 個 K⁺ → 錯離子 [Fe(CN)₆] 帶 −3；CN⁻ 各 −1、共 6 個 → −6。
> Fe ＋ (−6) ＝ −3 → **Fe ＝ +3**。
>
> **示範 [Cr(NH₃)₄Br₂]Br**：外圈 1 個 Br⁻ → 錯離子帶 +1；裡面 NH₃ ＝ 0、Br⁻ 各 −1 共 2 個 → −2。
> Cr ＋ 0 ＋ (−2) ＝ +1 → **Cr ＝ +3**。

## 九、氧化還原如何改變鍵級（bond order）

用分子軌域（molecular orbital）看，O₂、N₂ 這類雙原子分子**得或失電子**時，電子是進出**反鍵結軌域（antibonding，π\* / σ\*）**，所以鍵級會變。鍵級公式：

$$
\text{鍵級（BO）} = \frac{\text{鍵結電子數} - \text{反鍵結電子數}}{2}
$$

- **O₂**：BO ＝ 2（兩個電子在 π\* 反鍵）。
  - **失去**一個反鍵電子 → O₂⁺（價數 +1）→ BO ＝ **2.5**（反鍵少 1 個，鍵更強）。
  - **得到**電子 → O₂⁻（過氧離子端，價數 −1）BO ＝ 1.5；O₂²⁻（過氧化物）BO ＝ **1**。
- **N₂**：BO ＝ 3（π\*、σ\* 都空）。
  - **得到**一個反鍵電子 → N₂⁻（價數 −1）→ BO ＝ **2.5**。

口訣：**反鍵電子變多 → 鍵級下降**；反鍵電子變少 → 鍵級上升。所以「題目給你新的鍵級、反推帶幾價」時，先和中性分子（O₂＝2、N₂＝3）比，鍵級升代表失了反鍵電子（帶正）、鍵級降代表得了反鍵電子（帶負）。

## 十、用 E° 換算平衡常數 K（含 Ksp）

把電位和平衡常數連起來的橋樑是 ΔG°：

$$
\Delta G° = -nFE°_{\text{cell}} = -RT\ln K \;\Rightarrow\; \ln K = \frac{nFE°_{\text{cell}}}{RT}
$$

25 °C 時整理成常用對數（好代入）：

$$
\log K = \frac{n\,E°_{\text{cell}}}{0.0592}
$$

**0.0592 不是魔術數字**：把上式的 ln K 換成 2.303 log K，係數就是 (RT⁄F)·ln10 在 298 K 的值：

$$
\frac{2.303\,RT}{F} = \frac{2.303 \times 8.314 \times 298}{96485} \approx 0.0592\ \text{V}
$$

所以這個常數**只在 25 °C 成立**，換溫度要重算；記得它的來歷就不會把它用錯場合。

連兩個只差一個沉澱/錯合平衡的半反應，就能求那個平衡的 K（例如難溶鹽的 **Ksp**）：把「含沉澱的半反應」當陰極、「游離金屬離子的半反應」相減，得到對應「沉澱溶解」那條淨反應的 E°cell，再代上式即得 Ksp。
