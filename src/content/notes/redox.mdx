氧化還原就是電子的轉移。本篇講氧化數怎麼判定、半反應法怎麼配平方程式、以及用標準電位比較氧化還原劑的強弱。

## 一、氧化與還原的定義

| 概念 | 氧化 | 還原 |
|---|---|---|
| 電子 | 失去電子（e⁻↑） | 得到電子（e⁻↓） |
| 氧化數 | 升高 | 降低 |
| 記憶口訣 | OIL（Oxidation Is Loss） | RIG（Reduction Is Gain） |

**氧化劑**：使別人氧化（自己被還原，氧化數降低）。  
**還原劑**：使別人還原（自己被氧化，氧化數升高）。

## 二、氧化數判定（7 條規則）

**氧化數（oxidation number）**是假設化合物中的共用電子都歸給電負度較大的原子後，每個原子「帳面上」帶的電荷。判定規則（依優先序）：

| 規則 | 說明 | 例子 |
|---|---|---|
| 1 | 單質（元素態）氧化數 = 0 | Fe(s)、O₂(g) → 0 |
| 2 | 單原子離子 = 其電荷 | Ca²⁺ → +2；Cl⁻ → −1 |
| 3 | 化合物中 F 恆為 −1 | HF → F 是 −1 |
| 4 | 化合物中 O 通常 −2（過氧化物 −1） | H₂O → O 是 −2；H₂O₂ → O 是 −1 |
| 5 | 化合物中 H 通常 +1（與金屬形成氫化物 −1） | HCl → H 是 +1；NaH → H 是 −1 |
| 6 | 分子中各原子氧化數之和 = 0 | H₂SO₄：+1×2 + S + (−2)×4 = 0 → S = +6 |
| 7 | 多原子離子各原子之和 = 離子電荷 | SO₄²⁻：S + (−2)×4 = −2 → S = +6 |

**⚠️ 氧的特例（常考陷阱）**：O 不是永遠 −2！

| 化合物 | O 的氧化數 | 怎麼算 |
|---|---|---|
| 一般氧化物（H₂O、CO₂） | −2 | 規則 4 |
| 過氧化物 peroxide（H₂O₂、Na₂O₂） | **−1** | O–O 單鍵，兩個 O 共擔 |
| 超氧化物 superoxide（KO₂、NaO₂） | **−½** | 整個 O₂⁻ 帶 −1，2 個 O 平分 |
| 與 F 結合（OF₂） | **+2** | F 更負（規則 3 凌駕規則 4）|

## 三、半反應法配平步驟（酸性）

1. 分為氧化半反應和還原半反應
2. 用 H₂O 補 O 原子
3. 用 H⁺ 補 H 原子
4. 用 e⁻ 補電荷（讓兩側電荷平衡）
5. 乘以係數使兩個半反應電子數相同
6. 相加、消去重複項

## 四、鹼性條件的額外步驟

配平好酸性方程式後：  
→ 兩側各加等量 OH⁻（抵消 H⁺），使 H⁺ + OH⁻ → H₂O  
→ 化簡重複的 H₂O

## 五、用標準還原電位 E° 比較強弱

**標準還原電位（E°）**衡量一個半反應「往還原方向（得電子）」的傾向，數值越正、越想得電子。考題常給一張 E° 表問誰最強。動手切換看：

<RedoxLadder client:visible />

一招判斷：

$$
\text{E° 越大（越正）} \Rightarrow \text{越想搶電子} \Rightarrow \text{越強的氧化劑}
$$

$$
\text{E° 越小（越負）} \Rightarrow \text{越想丟電子} \Rightarrow \text{越強的還原劑}
$$

- 找「**最強氧化劑**」→ 挑 E° **最大**那條，反應物（左側那個）就是答案。
- 找「**最強還原劑**」→ 挑 E° **最小（最負）**那條，生成物（右側那個被氧化的還原態）就是答案。
- 例：Mg²⁺ + 2e⁻ → Mg，E° = −2.37 V 最負 → **Mg 金屬是最強還原劑**。

## 六、一個反應轉移幾個電子

配平後，看氧化半反應與還原半反應乘上的係數後，**任一半反應放出（或得到）的電子總數**即為轉移電子數＝兩半反應電子數的**最小公倍數**。

- 例：S（+4→+6，失 2e⁻）與 Mn（+7→+2，得 5e⁻），LCM(2,5)=**10** → 轉移 10 個電子。

<Memorize>
氧化 = 失電子 = 氧化數升高；還原 = 得電子 = 氧化數降低。<br />
<b>OIL RIG</b>：Oxidation Is Loss，Reduction Is Gain。<br />
氧化劑自己被還原；還原劑自己被氧化。
</Memorize>
