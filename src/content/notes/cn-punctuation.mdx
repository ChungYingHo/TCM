標點符號題考的是「**這個停頓處該用哪一個符號**」。關鍵是先讀懂句意層次，再對應各符號的功能。以下依**台灣**標準用法整理。

## 一、常用標點與功能

| 符號 | 名稱 | 功能 |
|---|---|---|
| 。 | 句號 | 一個語意完整的句子結束 |
| ， | 逗號 | 句中較大的停頓、分隔分句 |
| 、 | 頓號 | **並列的詞語**之間（停頓最小） |
| ； | 分號 | 分隔**並列的分句**（長句之間） |
| ： | 冒號 | **總起下文**、引出說明、引語或列舉 |
| 「」『』 | 引號 | 引文、對話、特定稱謂或反諷（雙引號中再引用用單引號） |
| 《》〈〉 | 書名號／篇名號 | 書名用《》、篇章用〈〉 |
| —— | 破折號 | 解釋說明、語意轉折、聲音延續 |
| …… | 刪節號 | 省略、語氣未完（台灣標準為六點） |
| （） | 夾注號 | 注釋、補充說明 |
| ？ | 問號 | 真正的疑問語氣 |
| ！ | 驚嘆號 | 感嘆、命令、強烈情緒 |

## 二、最常考的辨析

**1. 頓號 vs 逗號**：並列的**詞或短語**用頓號；並列的**分句**或較大停頓用逗號。
- 我買了筆、墨、紙、硯。（並列詞→頓號）
- 他喜歡讀書，我喜歡運動。（並列分句→逗號）

**2. 分號的用法**：分隔**結構相近、意義並列的分句**（常已含逗號）。
- 內舉不避親，外舉不避仇；前事不忘，後事之師。

**3. 冒號**：用於**總起下文**、引出說明或引語。
- 他只有一個願望：考上理想的學校。
- 子曰：「學而時習之……」

**4. 引號內的標點**：完整引用一句話時，**句末標點放引號內**。
- 他說：「我明天會到。」

**5. 破折號 vs 刪節號**：破折號表**解釋、轉折或聲音延長**；刪節號表**省略或語氣未完**。
- 這就是答案——其實大家早就知道。（轉折／解釋）
- 我想說的是……算了。（語氣未完）

## 三、問號的陷阱：有「疑問詞」不一定是問句

句子裡有「誰、什麼、是否、嗎」未必是疑問句。要看**整句是不是真的在發問**：

- 你明天會來**嗎**？（真疑問→問號）
- 我不知道他**會不會**來。（直述句，陳述「我不知道」→ 用句號，不用問號）
- 請問你叫**什麼**名字？（仍是發問→問號）

## 四、書名號與篇名號

- 書、報、刊：《史記》《聯合報》——用**雙書名號**。
- 篇章、單篇詩文：〈出師表〉〈岳陽樓記〉——用**單篇名號**。
- 書中的篇：《古文觀止》〈赤壁賦〉。

<Memorize>
<b>頓號、</b>用於並列<b>詞語</b>；<b>逗號，</b>用於並列<b>分句</b>或較大停頓。<br />
<b>分號；</b>分隔並列的長分句；<b>冒號：</b>總起下文／引出說明、引語。<br />
完整引語的<b>句末標點放引號內</b>（他說：「我會到。」）。<br />
<b>破折號——</b>解釋／轉折／聲音延續；<b>刪節號……</b>省略／語氣未完。<br />
有疑問詞不一定是問句：「我不知道他來不來」是<b>直述句</b>，用句號。
