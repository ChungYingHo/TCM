文學史題多半是**配對題**（作者 vs 作品、作品 vs 時代）或是「下列何者不屬於同一時代/流派？」的排除題。只要把「作者—作品—時代—流派」四欄串起來，就能快速作答。

## 一、各時代文學一覽

**先秦（西元前）**

| 類型 | 代表人物 | 代表作 | 特色 |
|------|---------|--------|------|
| 儒家 | 孔子 | 《論語》（弟子記）| 仁、禮、君子之道 |
| 道家 | 老子 | 《老子》（道德經） | 無為、自然、道 |
| 道家 | 莊子 | 《莊子》 | 寓言、逍遙、相對 |
| 墨家 | 墨子 | 《墨子》 | 兼愛、非攻 |
| 法家 | 韓非子 | 《韓非子》 | 法術勢、富國強兵 |
| 詩歌 | 屈原 | 《楚辭》〈離騷〉 | 楚文化、抒情長詩 |

**兩漢**

| 類型 | 代表人物 | 代表作 | 特色 |
|------|---------|--------|------|

| 詩人 | 流派/風格 | 代表作 | 特色 |
|------|----------|--------|------|
| **李白** | 浪漫主義 | 〈靜夜思〉〈將進酒〉 | 想像豐富、豪放飄逸；「詩仙」 |
| **杜甫** | 現實主義 | 〈春望〉〈茅屋為秋風所破歌〉 | 憂國憂民、沉鬱頓挫；「詩聖」 |
| **王維** | 山水田園詩 | 〈山居秋暝〉 | 詩中有畫、靜謐禪意 |
| **白居易** | 新樂府運動 | 〈琵琶行〉〈長恨歌〉 | 平易近人、反映社會現實 |
| **韓愈** | 古文運動（散文） | 〈師說〉〈進學解〉 | 倡復古文、反對駢文 |
| **柳宗元** | 古文運動（散文） | 〈永州八記〉〈捕蛇者說〉 | 散文寫景抒情見長 |

| 詞人 | 流派 | 代表作 | 特色 |

| **蘇軾** | 豪放派 | 〈念奴嬌·赤壁懷古〉〈水調歌頭〉 | 開豪放詞風、「詞聖」 |
| **李清照** | 婉約派 | 〈如夢令〉〈聲聲慢〉 | 女性詞人、細膩婉轉 |
| **辛棄疾** | 豪放派 | 〈青玉案·元夕〉〈摸魚兒〉 | 最多詞作（620 首）、愛國豪情 |
| **歐陽修** | 散文宗師 | 〈醉翁亭記〉 | 宋古文八大家領袖 |
| **范仲淹** | — | 〈岳陽樓記〉 | 「先天下之憂而憂」 |

| 作者 | 代表作 | 特色 |
|------|--------|------|
| 關漢卿 | 《竇娥冤》 | 雜劇四大家之首；反映社會不公 |

| 馬致遠 | 〈天淨沙·秋思〉 | 散曲小令；「元曲四大家」之一 |

**元曲四大家：關（關漢卿）白（白樸）馬（馬致遠）鄭（鄭光祖）**

| 作者 | 作品 | 類型 | 特色 |
|------|------|------|------|
| 施耐庵 | 《水滸傳》 | 英雄傳奇小說 | 一百單八將 |
| 羅貫中 | 《三國演義》 | 歷史演義小說 | 第一部章回小說 |
| 吳承恩 | 《西遊記》 | 神魔小說 | 取經、浪漫奇想 |
| 蘭陵笑笑生 | 《金瓶梅》 | 世情小說 | 晚明社會寫實 |
| 曹雪芹 | 《紅樓夢》 | 世情小說 | 四大名著之冠；人物最多、最深刻 |

**「四大名著」：《三國演義》《水滸傳》《西遊記》《紅樓夢》**

**現當代與台灣文學（後中常考，別漏！）**

題目常考日治到戰後的台灣作家，以及現代文學的「流派／題材」分類。

| 作家 | 身分／題材 | 備註 |
|------|-----------|------|
| 楊逵 | 日治時期、寫實 | 〈送報伕〉，描寫殖民下勞工 |
| 吳濁流 | 日治到戰後 | 《亞細亞的孤兒》，台灣人認同 |
| 鍾肇政 | 戰後、大河小說 | 《台灣人三部曲》 |
| 陳千武 | 日治、戰爭經驗 | 詩人，寫台籍日本兵 |
| 鍾理和 | 戰後鄉土 | 《笠山農場》 |

**現代文學題材／流派分類（填空題常見）：**

| 流派／題材 | 關鍵字 | 代表作家 |
|-----------|--------|----------|
| 原住民文學 | 部落、被遺忘的族群 | 瓦歷斯·諾幹、夏曼·藍波安 |
| 女性文學 | 身體、性別、被囚禁的處境 | 李昂、廖輝英 |
| 同志小說 | 邊緣、禁忌、認同 | 白先勇、邱妙津 |
| 鄉土／本土文學 | 土地、農村、台灣歷史 | 黃春明、鍾肇政 |

> 提醒：朱西甯是「軍中／外省作家」，**不以日治台灣人生活**為主要題材，這類「誰不屬於同一群」的排除題常拿他當答案。

## 二、字號與別稱對照（填空、稱呼題常考）

古人除本名外有「字」與「號」，詩文常以字號稱人。填空題愛用別稱（如「少陵詩、右軍帖」）。

<PenNameQuiz client:visible />

| 別稱／字號 | 本人 | 由來 |
|-----------|------|------|
| 少陵（少陵野老） | 杜甫 | 自號 |
| 青蓮（青蓮居士） | 李白 | 自號 |
| 摩詰 | 王維 | 字摩詰 |
| 右軍 | 王羲之 | 曾任右軍將軍 |
| 相如 | 司馬相如 | 名相如（漢賦大家） |
| 子瞻／東坡 | 蘇軾 | 字子瞻、號東坡居士 |
| 易安（居士） | 李清照 | 自號 |
| 五柳先生／靖節 | 陶淵明 | 自號／諡號 |

> 解題：把別稱換回本名，再判斷該人擅長的領域是否與句中搭配（「少陵詩、摩詰畫、右軍帖、相如賦」＝杜甫的詩、王維的畫、王羲之的字、司馬相如的賦，各得其所）。

## 三、配對題技巧

1. **從熟悉的作品反推作者**：題目常給作品問作者，或給作者問作品。
2. **用時代排除**：詞人是宋代的，不可能是元代的。
3. **注意同姓名誤導**：蘇軾≠蘇洵≠蘇轍（三蘇：父子三人）。
