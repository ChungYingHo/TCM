  實驗/數據題：先找自變項、應變項、對照組，再看數據趨勢推結論；對照組是用來排除其他變因。

  例：神經元等於外胚層，得到 角膜、表皮也是外胚層。
  配對題（甲乙丙丁配症狀/構造）：先確定你最有把握的一兩組，用刪去法收斂。
  看到專有名詞別慌：很多是熟悉概念換英文名（如 apoptosis等於細胞凋亡）。

## 這一類是什麼？

有些題目<b>跨好幾個章節</b>、考<b>實驗設計與數據判讀</b>、或結合<b>時事與在地生態</b>（如台灣濕地、保育、疾病新聞），還有大量「下列敘述何者正確／錯誤」的綜合題。它們沒有單一所屬章節，就收在這裡。要做的不是學新觀念，而是**先辨認它在考哪個主題**，再回該章用對應方法。

**跨章常用速查表（綜合題常一次混好幾章）**

| 主題 | 一句話必記 |
|---|---|
| 四大組織 | 上皮、結締、肌肉、神經（沒有「內分泌組織」這一類） |
| 三胚層代表 | 外＝神經/表皮/角膜；中＝肌肉/骨/血/腎；內＝消化道/肝/胰/肺 |
| 細胞凋亡 vs 壞死 | 凋亡＝基因調控的程序性死亡；壞死＝意外受傷死亡 |
| 酵素 | 催化劑，反應後<b>不被消耗</b>、可重複使用 |
| DNA 複製 | <b>半保留</b>：每子代雙股＝1 母股＋1 新股 |
| 演化對象 | 作用在<b>族群</b>的基因頻率；變異隨機產生再被環境篩選（非個體主動改變） |
| 相關 vs 因果 | 數據只顯示「一起變化」時，不能直接斷定誰造成誰 |

<ExampleQuestion client:visible
  n={1}
  q="科學家想驗證「某肥料能促進植物生長」，下列實驗設計何者最恰當？"
  options={[
    "只種一盆加肥料的植物，長高就證明有效",
    "兩組植物除了『有無加肥料』外，其他條件（光、水、土）都相同",
    "一組多澆水加肥料，另一組少澆水不加肥料",
    "比較不同種類的植物加肥料後的高度"
  ]}
  answer="(B)"
  steps={[
    "好的實驗只能有<b>一個變因</b>（自變項＝有無肥料）。",
    "(A) 沒有對照組，無法比較。",
    "(C) 同時改了澆水與肥料兩個變因，無法判斷是誰的效果。",
    "(D) 連植物種類都不同，變因太多。",
    "(B) 只差『有無肥料』、其餘條件相同 → 正確的<b>控制變因</b>設計。"
  ]}

<ExampleQuestion client:visible
  n={2}
  q="下列有關生物學概念的敘述，何者正確？"
  options={[
    "細胞凋亡（apoptosis）是細胞受傷後的意外死亡",
    "酵素在反應後會被消耗掉",
    "DNA 複製為半保留複製，新股各保留一條母股",
    "演化的對象是個體，個體會為了適應而主動改變基因"
  ]}
  answer="(C)"
  steps={[
    "逐項找反例。",
    "(A) 錯：細胞凋亡是<b>受基因調控的程序性死亡</b>，非意外（意外死亡是壞死 necrosis）。",
    "(B) 錯：酵素是催化劑，<b>反應後可重複使用</b>、不被消耗。",
    "(C) 對：半保留複製，每個子代雙股 = 一條母股 + 一條新股。",
    "(D) 錯：演化作用在<b>族群</b>的基因頻率上；變異是隨機產生、再被環境篩選，不是個體主動改變。"
  ]}
/>

<ExampleQuestion client:visible
  n={5}
  q="某切片以高爾基染色法（Golgi stain）染出人體的「神經元」。下列細胞中，何者與神經元<b>源自相同胚層</b>？"

    "肝細胞、小腸上皮＝內胚層；心肌＝中胚層，皆不同源。答案選 (C)。"
  ]}
/>
