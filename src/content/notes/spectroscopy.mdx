光譜題的邏輯：給光譜資料推結構、或給結構預測光譜。關鍵是熟悉每種工具各管什麼：

| 光譜工具 | 問的問題 | 核心資訊 |
|---|---|---|
| **IR**（紅外光譜） | 有哪些**官能基**？ | 吸收峰位置（波數 cm⁻¹） |
| **¹H NMR**（質子核磁共振） | 氫在哪些**化學環境**？ | 訊號數、積分比、裂分（splitting） |
| **MS**（質譜） | **分子量**（分子式）？ | 分子離子峰 m/z |
| **UV-Vis**（紫外-可見） | 有無**共軛**？呈什麼**顏色**？ | 最大吸收波長 λmax；顏色＝吸收色的互補色 |

**先記電磁波譜的順序**（能量由大到小、波長由短到長，常直接考排序）：

$$\gamma\text{射線} > \text{X射線} > \text{UV} > \text{可見光} > \text{IR} > \text{微波} > \text{無線電波}$$

能量 $E = h\nu = hc/\lambda$：**頻率 ν 越高、波長 λ 越短 → 能量越大**。各光譜技術用到的波段不同：

| 光譜技術 | 用到的電磁波段 | 激發的對象 |
|---|---|---|
| UV-Vis | 紫外-可見光 | 價電子躍遷（共軛） |
| IR | 紅外光 | 鍵的振動 |
| NMR | **無線電波**（能量最低） | 核自旋翻轉 |

> 注意陷阱：NMR 用的是**能量最低的無線電波**（不是 UV、也不是 IR）；UV-Vis 能量比 IR 高。

> 哪種光譜最能「區別兩個很像的異構物」？看它們差在哪：差在**氫的環境/個數**用 **NMR**（最常考、最有力）；差在**官能基**用 **IR**；只差**分子量**用 **MS**。

## 一、IR 紅外光譜

IR 照射分子，不同鍵的振動頻率不同，會在特定波數吸收能量，留下「吸收峰」。

**高頻考官能基吸收波數**（熟記這幾個就夠）：

| 波數（cm⁻¹） | 對應官能基 | 特徵 |
|---|---|---|
| **3300–3500** | **O–H（醇）** | 寬、強烈的吸收峰 |
| **2500–3300**（較寬） | O–H（羧酸） | 非常寬，蓋住 C–H 峰 |
| **3300 附近** | N–H（胺、醯胺） | 尖峰，可能有兩個（一級胺） |
| **2850–2960** | C–H（sp³） | 普遍存在，不特別診斷 |
| **≈1710–1715** | **C=O（醛、酮）** | 強、尖，非常可靠 |
| **≈1735** | C=O（酯） | 比酮稍高波數 |
| **≈1710** | C=O（羧酸） | 配合 2500–3300 寬 O–H 確認 |
| **1620–1680** | C=C（烯） | 中等強度 |
| **≈2100–2260** | C≡C 或 C≡N | 出現在「空曠區」，很特別 |

> 考場口訣：**3300 寬峰 = 有 O–H 或 N–H；1700 附近強峰 = 有 C=O**。

**C=O 吸收頻率的規律（高頻考、用來分辨羰基種類）**

C=O 的吸收波數不是固定 1715，會隨「電子效應」與「環張力」上下移動。記兩條主軸：

1. **共軛 → 降頻**：羰基若與 C=C 或苯環共軛（α,β-不飽和酮、芳香醛酮），π 電子離域使 C=O 鍵略帶單鍵性、鍵變弱 → 波數**下降**約 20–40 cm⁻¹。醯胺（amide）因 N 的孤對電子向 C=O 共軛，降得最多。
2. **環張力 → 升頻**：環狀酮的環越小、角張力越大，C=O 伸縮波數**上升**。六員環酮 ≈1715、五員環 ≈1745、四員環 ≈1780；**β-內醯胺（β-lactam，四員環醯胺，如青黴素核心）** 因張力，C=O 可升到 ≈1745–1780（比一般醯胺高很多）。

各類 C=O 的大致波數（由低到高排序，務必記順序）：

| C=O 類型 | 大約波數（cm⁻¹） | 備註 |
|---|---|---|
| 醯胺（amide, –CONH–） | **≈1630–1690（最低）** | N 孤對電子共軛，最弱 |
| 共軛/芳香酮、醛 | ≈1680–1700 | 共軛降頻 |
| 一般酮（ketone） | ≈1715 | 基準值 |
| 醛（aldehyde） | ≈1725 | 另有醛 C–H ≈2720、2820 |
| 羧酸（–COOH） | ≈1710（伴 2500–3300 寬 O–H） | — |
| 酯（ester, –COO–） | ≈1735 | 比酮高 |
| 醯氯（acyl chloride, –COCl） | **≈1800（最高）** | Cl 拉電子，鍵最強 |

> 順序口訣：**醯胺 < 共軛酮 < 酮 < 醛 ≈ 酯 < 醯氯**。一句話：「**推電子（共軛）往下、拉電子（鹵素）／環張力往上**」。

**IR 吸收強度與「IR 活性」條件**

- **IR 活性的條件**：振動時**偶極矩必須改變**才會吸收紅外光。完全對稱的伸縮（如 <Chem eq="H_2" />、<Chem eq="N_2" />、乙烷中央 C–C 的對稱伸縮）偶極矩不變 → **IR 無活性、看不到峰**。
- **偶極矩變化越大 → 吸收越強**。常見鍵的吸收強度排序：**C–O ＞ C–N ＞ C–Cl ＞ C–H**（鍵兩端電負度差越大，極性越大，吸收越強）。這也是為何 C=O、C–O 的峰總是又強又顯眼。
- **苯環取代位置**：苯環 Ar–H 的**面外彎曲（out-of-plane, oop bending）** 落在 **700–900 cm⁻¹**，其峰型可區分**鄰位（o-）／間位（m-）／對位（p-）二取代苯**（對位約 800–840 出單峰最乾淨）。

## 二、¹H NMR 氫核磁共振

NMR 偵測**同一個磁場環境下的氫核**。磁場環境不同 → 不同的**化學位移**（chemical shift, δ，單位 ppm）。

**前提：哪些核才有 NMR 訊號？**

只有**自旋量子數 I ≠ 0**（有磁矩）的核才會與磁場作用、產生訊號。判斷小技巧：質量數與原子序**不能同時為偶數**。

| 有訊號（I ≠ 0） | 無訊號（I = 0） |
|---|---|
| ¹H、¹³C、¹⁹F、³¹P | **¹²C、¹⁶O**（質量數、原子序皆偶數） |

> 所以常做的是 ¹H 與 ¹³C NMR；¹²C、¹⁶O **完全沒有訊號**。另外**溶劑要用氘代溶劑**（如 <Chem eq="CDCl_3" />、<Chem eq="D_2O" />、DMSO-d₆）——把會干擾的 ¹H 換成 ²H（氘，訊號落在別處），避免溶劑的氫蓋住樣品訊號。

**三個關鍵資訊：**

**A. 訊號數（peaks）= 不同氫環境的種類數**

相同化學環境的氫叫**等價氫**，只出現一個訊號。

例：乙醇 <Chem eq="CH_3CH_2OH" /> 有三種氫（CH₃、CH₂、OH）→ 3 個訊號。

> **對稱會「併掉」訊號（這才是難點）**：對二甲苯（1,4-二甲基苯）乍看氫很多，但分子左右上下對稱——4 個苯環氫**全部等價**（1 種）、2 個 –CH₃ 也等價（1 種）→ 其實只有 **2 個訊號**。數訊號時先找對稱面／對稱軸，把對稱位置的氫**算成同一種**，別被氫的「數量」騙了。

**B. 積分比（integration）= 各氫環境的氫原子數比**

積分面積比 = 各訊號對應的氫數比。

例：積分比 3:2:1 → 三種氫數分別是 3:2:1。

**C. 裂分（splitting）= (n+1) 規則**

某訊號被鄰碳上 n 個氫裂分成 **(n+1) 條峰**：

| 鄰碳氫數（n） | 裂分 | 峰型名稱 |
|---|---|---|
| 0 | 1 條 | singlet（單峰） |
| 1 | 2 條 | doublet（雙峰） |
| 2 | 3 條 | triplet（三峰） |
| 3 | 4 條 | quartet（四峰） |

例：乙醇的 CH₃（鄰 CH₂ 有 2 個氫）→ 裂分成**三峰（triplet）**；CH₂（鄰 CH₃ 有 3 個氫）→ 裂分成**四峰（quartet）**。

**常見化學位移參考（δ ppm）：**

| 化學位移（δ） | 對應氫環境 |
|---|---|
| 0.5–1.5 | 烷基 C–H（–CH₃、–CH₂–） |
| 2.0–2.5 | 羰基旁的 C–H（–CO–CH₂–） |
| 3.3–3.9 | 連氧的 C–H（–O–CH₂–，醚/醇） |
| 5.0–6.0 | 烯氫（=CH–） |
| 7.0–8.5 | 芳香環氫 |
| 9.5–10.0 | 醛氫（–CHO） |
| 10–12 | 羧酸/酚 –OH |

## 三、MS 質譜

質譜儀將分子電離後加速，依 **m/z**（質荷比）分離。

- **分子離子峰（M⁺）**：m/z 最高的主要峰，**等於分子量**（若帶一個正電荷）。
- **碎片峰（fragment ions）**：分子離子斷裂後的片段，可推官能基。
- **M+1、M+2 峰**：含 ¹³C、³⁵Cl/³⁷Cl 等同位素的峰，可判定是否含氯（M+2 ≈ 1/3 M 峰）。

> 最常考：**分子離子峰的 m/z 值 = 分子量**，不要複雜化。

**碎裂機制（高頻考：解釋為何出現某些特徵碎片峰）**

分子離子（M⁺，是個**陽離子自由基**）會斷在「能生成最穩定碎片」的地方。三個必考機制：

**A. α-裂解（α-cleavage）**

斷的是**官能基旁邊那根 α 鍵**（含雜原子 O、N 的官能基特別常見）。斷裂後正電荷由雜原子的孤對電子穩定，生成**醯基陽離子／亞銨離子**等。

- 例：酮 R–CO–R′ 斷 α 鍵 → 醯基陽離子 <Chem eq="RCO^+" />（被 C≡O⁺ 共振穩定）。
- 例：丙酮 <Chem eq="(CH_3)_2CO" />（M = 58）α-裂解失去一個 •CH₃ → 出現 **m/z = 43** 的乙醯基陽離子 <Chem eq="CH_3CO^+" />（最強的基峰）。

**B. McLafferty 重排（McLafferty rearrangement）**

需要兩個條件：① 分子有 **C=O（或 C=C、苯環等）π 鍵**，② **γ 位置上有氫（γ-H）**。透過**六員環過渡態**把 γ-H 轉移到羰基氧，同時 α–β 鍵斷裂，**中性烯（alkene）脫離**，留下烯醇陽離子自由基。

- 特徵：丟掉一個中性小分子（常是乙烯 C₂H₄＝28），出現比預期低的偶數質量碎片。
- 例：丁醛、2-己酮等含 γ-H 的羰基化合物常見此重排峰。

**C. 苄基／托品鎓離子（benzyl / tropylium, m/z = 91）**

烷基苯（如甲苯、乙苯）斷掉苄位的鍵 → 先成**苄基陽離子 <Chem eq="C_6H_5CH_2^+" />**，立刻重排成**七員環的托品鎓離子（tropylium, <Chem eq="C_7H_7^+" />）**。托品鎓有**芳香性（6 π 電子、平面、電荷均布七個碳）**極穩定 → 在烷基苯質譜中幾乎必出現 **m/z = 91** 的強峰。

> 看到 **m/z = 91 → 想到含苯環的烷基苯**（托品鎓）；看到 **m/z = 43**（C₃H₇⁺ 或 CH₃CO⁺）→ 丙基或乙醯基碎片。

## 四、UV-Vis 與顏色（互補色是關鍵）

有**共軛系統**（交替雙鍵、染料）的分子會吸收可見光，吸收越往長波長 → 共軛越長。看到「染料顏色 → 排吸收波長」的題，用**互補色**規則：

> **你看到的顏色 ＝ 被吸收顏色的「互補色」**（吸收什麼，剩下的補色就是你看到的）。

<ComplementaryColor client:visible />

| 你看到（呈現）的顏色 | 它吸收的顏色 | 吸收波長 λ |
|---|---|---|
| **黃** | 紫/藍（短波） | **短**（≈ 400–450 nm） |
| **藍** | 橙（中波） | 中（≈ 600 nm） |
| **綠** | 紅（長波） | **長**（≈ 650–700 nm） |
| 紅 | 綠 | 中（≈ 500 nm） |

口訣記互補對：**紅↔綠、黃↔紫藍、橙↔藍**。
所以「呈綠色」的染料吸收波長最長、「呈黃色」的最短。

> 共軛越長 → λmax 越長（越往紅移）→ 物質常顯色加深。胡蘿蔔素、葉綠素都是長共軛顯色的例子。

**Beer-Lambert 定律（比爾定律，定量用）**

吸光度與濃度成正比，是 UV-Vis 定量分析的基礎：

$$A = \varepsilon\, l\, c$$

- $A$：吸光度（absorbance，無單位）。
- $\varepsilon$：莫耳吸收係數（molar absorptivity，單位 M⁻¹cm⁻¹），物質固有常數。
- $l$：光程（cuvette 厚度，通常 1 cm）。
- $c$：莫耳濃度（mol/L）。

> 用法：量到 $A$、已知 $l$ 與 $c$ → 反推 $\varepsilon = A/(l\,c)$；或用同一物質的已知 $\varepsilon$ 反推未知濃度。**吸光度與濃度成正比**是考點，吸光度高不代表波長長。
