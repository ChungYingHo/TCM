這個考點要你能「看到句子就知道是誰說的、在講什麼道理」。先把四書與諸子的架構記住，再背代表句子。

## 一、四書是哪四本？

| 書名 | 作者／記錄者 | 核心一句話 |
|---|---|---|
| **論語** | 孔子弟子記錄孔子言行 | 仁、禮、君子之道 |
| **孟子** | 孟子自著 | 性善說、仁政、民貴君輕 |
| **大學** | 曾子作（宋代朱熹考訂） | 三綱八目：明明德、親民、止於至善 |
| **中庸** | 子思著 | 誠、中和、率性之謂道 |

> 「四書」由**朱熹**在宋代選定，成為科舉考試核心，地位高於其他儒家典籍。

## 二、論語高頻章句（看到句子要認得是孔子的話）

考題常給一句《論語》要你判讀涵義，先把這些核心句記熟：

| 章句 | 意思／考點 |
|---|---|
| 子在齊聞韶，三月不知肉味 | 讚美**音樂感人至深**（韶＝舜時的樂曲） |
| 自行束脩以上，吾未嘗無誨焉 | 孔子**有教無類**（束脩＝十條乾肉的見面禮） |
| 君子之於天下也，無適也，無莫也，**義之與比** | 君子待人**不偏執，只看是否合義**；精神相通於「子絕四：毋意、毋必、毋固、毋我」（不主觀臆測、不武斷、不固執、不自我中心） |
| 己所不欲，勿施於人 | **恕**道——推己及人 |
| 富而可求也，雖執鞭之士，吾亦為之；如不可求，從吾所好 | 富貴若不可強求，**寧可做自己喜歡的事**（安貧樂道） |

> 小技巧：判讀《論語》題，先抓句中關鍵字（韶＝樂、束脩＝教、義之與比＝守義不偏），再對到「仁／禮／教／義」哪一個主題。

## 三、大學「三綱八目」

**三綱**：明明德 → 親民（新民）→ 止於至善

**八目**（先後順序很重要）：

格物 → 致知 → **誠意** → **正心** → **修身** → 齊家 → 治國 → 平天下

口訣：**格致誠正修、齊治平**（「格致」是知識，「誠正修」是個人，「齊治平」是社會）

## 四、中庸關鍵語句

| 句子 | 意思 |
|---|---|
| 天命之謂性，**率性之謂道**，修道之謂教 | 順著本性走就是道，「率」= 遵循、依循 |
| 喜怒哀樂之未發謂之**中**，發而皆中節謂之**和** | 「中和」：情緒未動是中，表達恰當是和 |
| 至誠之道，可以前知 | 誠是中庸思想的核心 |

## 五、孟子核心主張

| 主張 | 代表句 |
|---|---|
| **性善說** | 人之初，性本善（衍生說法，孟子原文：惻隱之心，人皆有之） |
| **四端說** | 惻隱（仁之端）、羞惡（義之端）、辭讓（禮之端）、是非（智之端） |
| **仁政** | 與民同樂、推己及人、老吾老以及人之老 |
| **民貴君輕** | 民為貴，社稷次之，君為輕 |
| **浩然之氣** | 我善養吾浩然之氣——集義所生，不可強求 |

## 六、諸子百家對照表

<PhilosophySchools client:visible />

| 學派 | 代表人 | 核心主張 | 代表句 |
|---|---|---|---|
| **儒家** | 孔子、孟子、荀子 | 仁義禮、修身治國、性善（孟）／性惡（荀） | 己所不欲，勿施於人 |
| **道家** | 老子、莊子 | 無為自然、道法自然、逍遙 | 上善若水；相濡以沫，不如相忘於江湖 |
| **墨家** | 墨子 | 兼愛（無差等之愛）、非攻、節用、尚賢 | 兼相愛，交相利 |
| **法家** | 韓非子、商鞅 | 法、術、勢三位一體，依法治國 | 以法治國，不別親疏 |

> **儒墨對比**：儒家「仁愛」有差等（親疏遠近），墨家「兼愛」無差等——這是兩家的根本分歧。

## 七、荀子（也是儒家，但常被當陷阱）

荀子是儒家，卻和孟子唱反調，考題很愛拿來混淆：

| 主張 | 重點 |
|---|---|
| **性惡說** | 人性本惡，善是後天教化來的（與孟子性善正相反） |
| **天行有常** | 「天行有常，不為堯存，不為桀亡」——**自然有其規律，不因人事而改變**（不是孟子說的！這是常見誤植陷阱） |
| **化性起偽** | 用禮義法度改造本性、引導向善 |

## 八、經典名句「一句配一人」速記表

判讀「這句話是誰說的」是最高頻題型。把這張表記熟，看到引文就能對上人：

<QuoteAttribution client:visible />

| 名句 | 出處／作者 | 學派 |
|---|---|---|
| 天行健，君子以**自強不息** | 《易經》 | 群經之首 |
| 天行有常，不為堯存，不為桀亡 | **荀子** | 儒家 |
| 聖人不仁，以百姓為**芻狗** | **老子** | 道家（芻狗＝草紮的狗，喻天道無私、任萬物自生自滅） |
| 人皆知**有用之用**，而莫知**無用之用**也 | **莊子** | 道家（無用方能保全，是逍遙智慧） |
| 君無**術**則弊於上，臣無**法**則亂於下 | **韓非子** | 法家（術＝御臣之術，法＝公開的律令） |
| 民為貴，社稷次之，君為輕 | **孟子** | 儒家 |
| 兼相愛，交相利 | **墨子** | 墨家 |

## 九、老莊核心概念

- **老子**：「道可道，非常道」——道不可言說；水善利萬物而不爭；知足者富
- **莊子**：「天地與我並生，萬物與我為一」；「朝菌不知晦朔，蟪蛄不知春秋」（小知不及大知）；「魚相忘乎江湖，人相忘乎道術」
- 莊子「逍遙遊」三問：鯤鵬之志 vs 小雀之見——批評「小知」的局限
