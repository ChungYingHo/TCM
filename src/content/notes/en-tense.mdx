英文動詞的時態由**時間**（過去／現在／未來）和**樣貌**（簡單／進行／完成）組合出 12 種，考試最常考 6 種。本篇從六大時態談起，帶到被動、非限定動詞、假設語氣與易混淆句型。

## 一、六大核心時態一覽

| 時態 | 結構 | 常見時間副詞 |
|---|---|---|
| **簡單現在** | V / V-s | always, usually, every day |
| **簡單過去** | V-ed | yesterday, last year, ago |
| **簡單未來** | will V / be going to V | tomorrow, next week, soon |
| **現在進行** | am/is/are + V-ing | now, at this moment |
| **現在完成** | have/has + p.p. | already, yet, since, for, just |
| **過去完成** | had + p.p. | before, by the time, after |

> 口訣：**看到副詞，就能定時態**。題目有 "since 2010" → 現在完成；有 "yesterday" → 簡單過去。

## 二、主動 vs 被動（Passive Voice）

被動式公式：**be 動詞 + 過去分詞（p.p.）**

| 時態 | 主動 | 被動 |
|---|---|---|
| 簡單現在 | The doctor examines the patient. | The patient **is examined**. |
| 簡單過去 | They built the hospital. | The hospital **was built**. |
| 現在完成 | She has written the report. | The report **has been written**. |
| 助動詞 | They must follow the rules. | The rules **must be followed**. |

判斷技巧：主詞是「動作的承受者」→ 用被動；主詞是「動作的執行者」→ 用主動。

## 三、非限定動詞（Verbals）：to V、V-ing、p.p.

非限定動詞不當主要動詞，而是扮演**名詞、形容詞或副詞**角色：

| 形式 | 名稱 | 常見用法 |
|---|---|---|
| to V | 不定詞 | 目的（in order to）、名詞（I want **to study**）、形容詞（a chance **to win**） |
| V-ing | 動名詞/現在分詞 | 當主詞（**Studying** is fun）、介系詞後（good at **swimming**） |
| p.p. | 過去分詞 | 被動形容詞（a **broken** window）、完成時態輔助 |

## 四、假設語氣（Subjunctive）——考古題最愛考的兩大型

<Subjunctive client:visible />

「假設語氣」＝講「不是真的／與事實相反／要求別人做」的特殊動詞變化。要分兩類：

*A. 表「要求、建議、命令、重要」的 that 子句 → 動詞用「原形」*

當主句出現 **suggest / recommend / demand / insist / propose / require** 等動詞，或 **It is essential / necessary / important / imperative that …** 句型，後面的 that 子句動詞**一律用原形（base form）**，主詞單複數都不變、也不加 -s：

- The doctor recommended that he **take** the medicine.（不是 takes）
- It is essential that the report **be** submitted today.（被動就是 **be + p.p.**，不是 is）

> 記法：這些「要求別人做某事」的子句，動詞前面其實藏了一個省略的 should，所以永遠用原形。被動就是 should be → **be + p.p.**。

*B. 與事實相反的條件句（If 子句）*

| 假設的時間 | If 子句 | 主句 |
|---|---|---|
| 與「現在」相反 | If + 過去式 | would / could + 原形 V |
| 與「過去」相反 | If + had + p.p. | would / could **have** + p.p. |

**倒裝（Inversion）是高頻陷阱**：把 If 省略，再把助動詞提到主詞前面，意思不變：

- If he **had** studied … → **Had** he studied …
- If I **were** you … → **Were** I you …
- If you **should** need help … → **Should** you need help …

所以看到句首是 **Had / Were / Should + 主詞**，就是「省略 If 的倒裝假設句」。

## 五、used to V vs be used to V-ing（極易混淆）

| 片語 | 意思 | 後面接 |
|---|---|---|
| **used to + 原形 V** | 過去常常（現在不再） | 原形動詞：I **used to smoke**. |
| **be used to + V-ing** | 習慣於（to 是介系詞） | V-ing：I **am used to getting up** early. |

## 六、感官／使役動詞 + 受詞 + 原形 V

see / hear / feel / watch / notice 及 make / let / have 後面，接受詞再接**原形動詞（bare infinitive，無 to）**：

- I felt the floor **shake**.（感覺地板震動，用原形 shake，不是 to shake）
- The teacher made us **rewrite** the essay.

（若強調「正在進行」可改 V-ing：I saw him **crossing** the street；但被動時要還原 to V：He was made **to rewrite**。）

<ExampleQuestion client:visible
  n={1}
  q="By the time the ambulance arrived, the patient ____ unconscious for over an hour."
  options={["was", "has been", "had been", "is"]}
  answer="(C) had been"
  steps={[
    "句中有 <b>by the time + 過去式（arrived）</b>，表示「在救護車抵達之前，病人已經昏迷了一個多小時」——先發生的事。",
    "先發生的過去事件要用<b>過去完成式 had + p.p.</b>，be 的過去分詞是 been。",
    "答案：<b>had been</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={2}
  q="The new medical guidelines ____ announced at last week's conference, and they will take effect next month."
  options={["are", "were", "have been", "will be"]}
  answer="(B) were"
  steps={[
    "時間副詞 <b>last week</b> → 簡單過去時態。",
    "主詞 guidelines 是「被宣布」的對象 → 用<b>被動語態 be + p.p.</b>。",
    "簡單過去被動 = <b>were + p.p.</b>（announced）。答案：<b>were</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={3}
  q="The curriculum committee recommended that this motion ____ immediately."
  options={["is passing", "been passed", "passes", "be passed", "pass"]}
  answer="(D) be passed"
  steps={[
    "主句動詞是 <b>recommended</b>（建議）→ that 子句要用<b>假設語氣，動詞用原形</b>，不管主詞單複數、不加 -s。",
    "motion（動議）是「被通過」的 → 用<b>被動</b>。原形的被動就是 <b>be + p.p.</b>。",
    "pass 的過去分詞是 passed → <b>be passed</b>。(E) pass 是主動（動議自己通過？語意不通）；(C) passes 加了 -s 不是原形。答案：<b>be passed</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={4}
  q="____ the artists and creative thinkers not dared to be different, the history of civilization would have to be rewritten."
  options={["If the artists dared to be different", "Have the artists dared to be different", "Had the artists not dared to be different", "Did the artists not dare to be different"]}
  answer="(C) Had the artists not dared to be different"
  steps={[
    "主句是 <b>would have to be rewritten</b>，搭配的是<b>與過去事實相反</b>的假設句（過去藝術家其實『有』勇於不同）。",
    "與過去相反的 If 子句 = If + had + p.p.；這裡省略 If，改成<b>倒裝</b>：把 had 提到主詞前面 → <b>Had + 主詞 + (not) + p.p.</b>。",
    "語意是「假如他們<b>當初沒有</b>勇於不同」→ 要加 not。答案：<b>Had the artists not dared to be different</b>。"
  ]}
/>

<ExampleQuestion client:visible
  n={5}
  q="When I was young, I ____ think money was important. Now, ____ old, I know it is."
  options={["was used to, was", "used to, being", "used to, was", "was used to, being"]}
  answer="(B) used to, being"
  steps={[
    "第一空：「年輕時<b>曾經</b>認為」→ 過去的習慣/看法用 <b>used to + 原形 V</b>（used to think）；was used to 是「習慣於」語意不合，且後面要接 V-ing。",
    "第二空：「如今年紀大了」→ 用分詞片語 <b>being old</b>（= now that I am old）放句首，作背景說明。",
    "答案：<b>used to, being</b>。"
  ]}
/>
