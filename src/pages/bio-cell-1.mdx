## 一、細胞是生命的基本單位

**細胞學說（cell theory）**：

| # | 主張 | 補充 |
|---|------|------|
| 1 | 細胞是生命體的**基本單位** | 能獨立執行生命活動的最小單元 |
| 2 | 所有細胞都來自**既存的細胞** | _omnis cellula e cellula_，不會憑空產生 |
| 3 | 生物體由一或多個細胞構成 | — |

### 共同特徵：多樣中的統一

- **多樣（外型）**：神經元是細長軸突、紅血球是雙凹圓盤、肌細胞是長纖維、細菌只有幾微米，外型差異極大。
- **統一（本質）**：但只要是細胞，就一定具備下面四樣，缺一就不算活細胞：

| 共同特徵 | 角色 |
|----------|------|
| **細胞膜**（plasma membrane） | 隔開裡／外的屏障，選擇性管制進出 |
| **細胞質液**（cytosol） | 膜內半流動液體，化學反應場所 |
| **DNA**（去氧核糖核酸） | 遺傳指令，組成染色體 |
| **核糖體**（ribosome） | 把胺基酸接成蛋白質的工廠 |

> 原核與真核的**差別不在這四樣**（都有），而在「**DNA 有沒有被膜包成細胞核**」。

## 二、看細胞的工具

### 顯微鏡的三個指標

| 指標 | 意義 |
|------|------|
| **放大率**（magnification） | 影像放大幾倍。再高、解析度不夠也只是放大成糊團 |
| **解析度**（resolution） | 能分辨兩相鄰點的最短距離，**數值越小＝越清晰**（最常考） |
| **對比**（contrast） | 構造與背景的區分度，常靠染色提升 |

### 三種顯微鏡

<div class="overflow-x-auto print:overflow-visible">

| 顯微鏡 | 成像 | 解析度 | 看得到 ＆ 特點 |
|--------|------|--------|----------------|
| **光學 LM**（light） | 可見光穿透 | 約 **0.2 µm** | 細胞、核、粒線體、細菌；**可看活細胞** |
| **電子 SEM**（scanning） | 電子束掃**表面** | 約 2 nm | **表面立體形貌**；只能看死樣本 |
| **電子 TEM**（transmission） | 電子束**穿透**切片 | 約 2 nm | **內部超微剖面**；只能看死樣本 |
| **共軛焦 confocal** | 雷射＋**針孔** | 光學等級 | 針孔擋掉焦外散光 → **光學切片**疊成 3D |

</div>

電子顯微鏡（EM）解析度比 LM 好約 **100 倍**，但只能看死樣本（須真空）。

**油鏡 vs 水鏡（常考）**：解析度 **油鏡 ＞ 水鏡 ＞ 乾鏡**。

### 細胞大小尺度

<Figure src="/notes/bio-cell/cell-sizes.webp" alt="從原子、分子到細菌、細胞、青蛙卵的大小對數尺度，並標示光學顯微鏡與電子顯微鏡的可見範圍" caption="大小對數尺度：右側標出肉眼、光學顯微鏡（到約 0.2 µm）、電子顯微鏡（到約 0.1 nm）各自能看到的範圍。" source="Campbell 生物學・上冊" maxW="30rem" />

| 對象 | 大致尺寸 | | 對象 | 大致尺寸 |
|------|----------|---|------|----------|
| 真核細胞（動植物） | 10–100 µm | | 大多數細菌 | 1–5 µm |
| 人類卵細胞 | ~100 µm（肉眼極限） | | 粒線體 | 1–10 µm |
| 細胞核 | ~5 µm | | 核糖體 | ~25–30 nm |

**LM 下限 0.2 µm 是一條分界線**：

- 線**以上**（細胞、核、粒線體、細菌）→ 光學顯微鏡（LM）可見。
- 線**以下**（核糖體、膜、病毒、分子）→ 要電子顯微鏡（EM）。

<Supplement title="表面積／體積比（限制細胞大小）">

- **為什麼小**：半徑變大時 **體積（∝ r³）長得比表面積（∝ r²）快** → 太大則表面積不夠和外界交換物質。
- **對策**：保持**小體積**，或長**微絨毛（microvilli）** 增大表面積。

</Supplement>

### 細胞分離（cell fractionation）

細胞打碎成勻漿 → **差速離心（慢→快）**，重、大者先沉澱：

| 轉速 | 沉澱出 |
|------|--------|
| 低速 | 細胞核 |
| 中速 | 粒線體／葉綠體 |
| 高速 | 內質網碎片、核糖體 |

## 三、原核細胞（prokaryote） vs 真核細胞（eukaryote）

分界：**DNA 有沒有被膜包成核、有沒有膜性胞器**。

| | **原核 prokaryote** | **真核 eukaryote** |
|---|---|---|
| 物種 | 細菌、古菌 | 原生生物、真菌、植物、動物 |
| 大小 | 小（1–5 µm） | 大（10–100 µm，約為原核 10 倍） |
| 細胞核 | **無**膜性核；DNA 在**類核區**（nucleoid） | **有**膜性細胞核 |
| 膜性胞器 | **無** | **有** |
| DNA 位置 | 類核 ＋ 質體（plasmid） | 細胞核為主，**另在粒線體、葉綠體** |
| DNA 形狀 | **環狀**、裸露 | **線狀**、纏**組蛋白**（histone） |

<Supplement title="質體 plasmid">

細菌**主染色體以外**的**小型環狀 DNA**：

- 可**獨立複製**。
- 攜帶非必需但有用的基因（**抗藥性**、毒力、特殊代謝）。
- 能在細菌間**傳遞**；基因工程拿它當**載體（vector）** 送基因。

</Supplement>

真核基因多在核，但**粒線體、葉綠體各有一套環狀 DNA**。三者源自被吞入卻共生的細菌／藍綠菌：

**雙層膜胞器 ＝ 核、粒線體、葉綠體，都有自己的 DNA → 內共生（endosymbiosis）線索。** 證據：

- 雙層膜。
- 自有**環狀 DNA**。
- 自有 **70S 核糖體**（與細菌同型）。
- 以**二分裂（binary fission）** 增殖。

### 細菌構造（bacteria，微生物學再述）

<Figure src="/notes/bio-cell/prokaryote.webp" alt="桿菌構造示意圖：類核區、細菌染色體、核糖體、細胞膜、細胞壁、莢膜、線毛、鞭毛" caption="原核（細菌）構造：DNA 集中在無膜的類核區、外有細胞壁與莢膜，表面有線毛（附著）與鞭毛（運動）。" source="Campbell 生物學・上冊" />

- **二分裂（binary fission）**：複製環狀 DNA、一分為二，快速增殖。
- **細胞壁 ＝ 肽聚醣（peptidoglycan）**：糖鏈被短胜肽**交聯**成網。
- **線毛（pili）** 附著與接合傳遞質體；**鞭毛（flagella）** 運動。兩者常是**毒力因子（virulence factor）**。

**青黴素（penicillin）為何殺菌又不傷人（常考）**：

- 抑制肽聚醣交聯的酵素（轉肽酶 transpeptidase）→ 生長中的菌做不出完整壁而脹破。
- 人類細胞**無肽聚醣壁** → 不受影響。
- 古菌的壁是**偽肽聚醣（pseudopeptidoglycan）**、用不同的糖 → **青黴素對古菌無效**。
