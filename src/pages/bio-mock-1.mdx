## 三、生命的研究

這一章三校 12 年只考 8 題，不值得單開一篇，內容全部收在這一節。

### 生物階層

生物學把研究對象由大到小排成十個層次。

<div class="overflow-x-auto print:overflow-visible">

| 層次 | 英文 | 一句話 |
|---|---|---|
| 生物圈 | biosphere | 地球上一切有生命存在的區域，含陸地、水體與大氣 |
| 生態系 | ecosystem | 某一區域內所有生物，**加上**該環境的無生命成分（土壤、水、空氣、光線） |
| 群集 | community | 該生態系內的所有生物體，不含無生命成分 |
| 族群 | population | 住在同一區域、屬於同一物種的所有個體 |
| 生物體 | organism | 個別的活生物 |
| 器官與器官系統 | organ、organ system | 器官由多重組織構成，一組器官團隊合作執行特定功能就是器官系統 |
| 組織 | tissue | 一群一起工作、執行同一項特化功能的細胞 |
| 細胞 | cell | 生物體結構與功能的基本單位 |
| 胞器 | organelle | 細胞內具特定功能的構造，例如葉綠體 |
| 分子 | molecule | 由兩個以上原子構成的化學構造，例如葉綠素 |

</div>

把第六層拆開寫，完整順序是生物圈 → 生態系 → 群集 → 族群 → 生物體 → 器官系統 → 器官 → 組織 → 細胞 → 胞器 → 分子。兩個最容易被弄混的分界：生態系含無生命成分而群集不含，族群限定同一物種而群集是所有物種。

### 新生特質

**新生特質（emergent properties，也譯突現性質）**是在複雜度提升時，由各成分的排列方式與彼此的互動所產生、在較低層次並不存在的性質。例如光合作用發生在完整的葉綠體內，把葉綠體拆開、讓葉綠素和其他分子無秩序地混在一起就不會發生，因為光合作用需要這些分子在葉綠體內排成特定位置。兩個配套的研究取徑：

- **化約論（reductionism）**是把複雜的系統簡化為較容易處理與研究的成分。華生與克里克從細胞萃取物裡解出 DNA 分子結構，就是化約論的成果。
- **系統生物學（systems biology）**方向相反，以各部分之間的互動來探討整個系統，補化約論看不見新生特質的不足。

### 生命的共同特徵

生命無法用一句話定義，只能從生物的所作所為來辨識。下面七項是所有生物共有的。

<div class="overflow-x-auto print:overflow-visible">

| 特徵 | 英文 | 例子 |
|---|---|---|
| 秩序 | order | 向日葵花盤的高度秩序化結構 |
| 生殖 | reproduction | 生物體繁衍出它們自身 |
| 生長與發育 | growth and development | 基因攜帶的遺傳資訊控制橡樹苗的生長與發育樣式 |
| 能量處理 | energy processing | 蝴蝶以花蜜為燃料，用其中的化學能飛行 |
| 對環境的回應 | response to the environment | 捕蠅草在昆蟲停上時迅速閉合 |
| 調節 | regulation | 兔耳血管調節血流，藉與周遭空氣的熱交換維持穩定體溫 |
| 演化適應 | evolutionary adaptation | 侏儒海馬的外觀模擬環境，是天擇累積出來的可遺傳表徵 |

</div>

### 分類階層、三域與界

分類學（taxonomy）把物種整理成越來越寬廣的類群。林奈系統的階層由小到大是**種 → 屬 → 科 → 目 → 綱 → 門 → 界 → 域**，例如美洲黑熊 *Ursus americanus* 屬於熊屬、熊科、食肉目、哺乳綱、脊索動物門、動物界、真核生物域。二名法有三條規則：學名由屬名加種小名兩個字組成，屬名首字母大寫而種小名全部小寫，兩個字合起來用斜體書寫。亞種在後面再加第三個字，例如家犬 *Canis lupus familiaris*。

1977 年 Woese 與 Fox 依據分子證據，把原本擠在一起的原核生物拆成細菌與古菌兩群，形成三域系統。

<div class="overflow-x-auto print:overflow-visible">

| 域 | 中文 | 內容 |
|---|---|---|
| Bacteria | 細菌域 | 最多樣且分佈最廣的原核生物，如今再分為許多界 |
| Archaea | 古菌域 | 原核生物，許多種住在鹽湖、滾燙溫泉這類極端環境，也包括許多界 |
| Eukarya | 真核生物域 | 所有具真核細胞的生物，包含植物界、真菌界、動物界與原生生物 |

</div>

界的數目有三套算法，題目問「幾界」時要先看它站在哪一套上：

- **五界系統**：原核生物界、原生生物界、真菌界、植物界、動物界。所有原核生物擠在同一界。
- **六界系統**：把原核生物界拆成古細菌界與真細菌界，其餘四界不變。
- **三域系統**：原核生物升格成細菌域與古菌域兩個域，真核生物全部收在真核生物域。原生生物近年被切割成好幾個界，界的總數因此沒有定論，目前已有六界或更多界的方案被提出。

真核生物域裡三個多細胞界靠營養模式區分：植物界行光合作用自製食物，真菌界自環境吸收溶解的養分，動物界攝食並消化其他生物體。原生生物大多是單細胞真核生物，其中有些在親緣上比較接近植物、動物或真菌，反而不像其他原生生物，所以不再被當成單一的界。真菌界在演化樹上最接近的是動物界，不是植物界。

### 細菌、古菌與真核的差別

三域在下面這幾項特徵上互有異同，逐列比對。

<div class="overflow-x-auto print:overflow-visible">

| 特徵 | 細菌域 | 古菌域 | 真核域 |
|---|---|---|---|
| 核套膜 | 無 | 無 | 有 |
| 膜包覆的胞器 | 無 | 無 | 有 |
| 細胞壁含肽聚醣 | 有（革蘭氏陰性菌外面再加脂多醣） | 無真正的肽聚醣，部分種類是偽肽聚醣 | 無（植物是纖維素、真菌是幾丁質、動物無細胞壁） |
| 膜脂質 | 甘油與不分支的烴鏈以**酯鍵**相連 | 甘油與有分支的烴鏈以**醚鍵**相連，嗜熱種可形成四醚單層膜 | 甘油與不分支的烴鏈以酯鍵相連 |
| RNA 聚合酶 | 一種 | 數種 | 數種 |
| 蛋白質合成的起始胺基酸 | 甲醯甲硫胺酸（fMet） | 甲硫胺酸（Met） | 甲硫胺酸（Met） |
| 基因含內含子 | 非常稀少 | 有些基因有 | 許多基因有 |
| 對鏈黴素與氯黴素的反應 | 通常生長受抑制 | 生長不受抑制 | 生長不受抑制 |
| 伴隨 DNA 的組蛋白 | 無 | 有些物種有 | 有 |
| 環狀染色體 | 有 | 有 | 無 |
| 高於 100 °C 仍能生長 | 不會 | 有些物種有 | 不會 |

</div>

這張表可以直接推出兩件事。第一，盤尼西林抑制肽聚醣的合成，所以它只對細菌有效、對古菌無效，其中又以細胞壁厚的革蘭氏陽性菌最敏感。第二，古菌在組蛋白、RNA 聚合酶、內含子這幾格都靠向真核域，這就是「古菌與真核親緣較近」的分子證據。另外大多數的嗜極端生物屬於古菌而不是細菌。

### 科學方法

**科學（science）**是求知的方式，核心是**探索（inquiry）**，也就是對自然現象之資訊與解釋的搜尋。理想化的流程如下，真正的研究很少完整照這個順序走。

<div class="overflow-x-auto print:overflow-visible">

| 步驟 | 內容 | 手電筒範例 |
|---|---|---|
| 觀察（observation） | 直接運用感官或工具蒐集資訊，記錄下來的觀察結果稱為**數據（data）** | 手電筒不亮了 |
| 疑問 | 由觀察引出的問題 | 手電筒為什麼不亮 |
| 假說（hypothesis） | 對疑問的試驗性解答，一個觀察要能生出多個候選假說 | 一號假說電池沒電，二號假說燈泡燒壞 |
| 預測（prediction） | 由假說**演繹**出來的「若…則」結果 | 若電池沒電，則換電池就能解決問題 |
| 測試 | 在受調控的條件下執行的科學測試就是**實驗（experiment）** | 換電池、換燈泡 |
| 結果 | 支持或否定假說 | 換了電池仍然不亮，一號假說被否定 |

</div>

數據分兩類。**定性數據（qualitative）**是敘述形式的紀錄，例如珍古德的黑猩猩行為筆記與素描。**定量數據（quantitative）**是數量上的測量，通常整理成圖表，再用**統計學**判斷結果是否具**顯著性**，而不是只肇因於隨機波動。

<div class="overflow-x-auto print:overflow-visible">

| | 歸納式推理（inductive reasoning） | 演繹式推理（deductive reasoning） |
|---|---|---|
| 方向 | 由許多特定的觀察綜合出通則 | 由概括性推到特殊性 |
| 形式 | 從一堆個案看出共通點 | 「若…則」 |
| 例子 | 所有的生物體都是由細胞所構成 | 若某一特定假說正確，則應該出現預期的結果 |
| 用在哪 | 假說多半在歸納引導下形成 | 從假說導出可以拿去測試的預測 |

</div>

### 對照組與變因

**實驗**是操縱系統中的某項因素，以看出改變它之後的效應。受操縱的因素與所測量的效應都是實驗的**變數（variables）**。

<div class="overflow-x-auto print:overflow-visible">

| 名詞 | 定義 | 小鼠毛色實驗裡是什麼 |
|---|---|---|
| 獨立變數（independent variable） | 由研究人員操縱的因子 | 小鼠模型的顏色 |
| 相依變數（dependent variable） | 實驗中所測量的因子 | 模型被掠食的次數 |
| 對照組（control） | 拿來比較、用以刪除其他因子效應的一組 | 與棲地相配的擬態模型 |
| 實驗組（experimental） | 被操縱的那一組 | 與棲地不相配的非擬態模型 |

</div>

一個常見的誤解是「對照性實驗就是把待測變數以外的所有條件都固定不變」。田野研究做不到這件事。研究人員確實會控制不想要的變數，但不是靠環境調節把它們排除，而是靠對照組把它們的效應刪掉。缺了對照組，就無法排除其他因子造成同樣結果的可能。

科學假說必須**可測試（testable）**，也就是要有觀察或實驗能揭露它可能的真偽，超自然的解釋因為無法測試而落在科學的範疇之外。實驗只能否定假說或支持假說，永遠無法證實一項假說為真。**學說（theory）**與假說的差別有三點：學說涵蓋的層面寬廣得多，學說普及到足以生出許多可供測試的新假說，學說受到的證據支持也大得多。以小鼠為例，「毛色和棲地相配是免遭掠食的適應現象」是假說，「演化適應來自天擇」是學說。
