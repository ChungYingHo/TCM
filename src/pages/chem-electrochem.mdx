## 一、伽凡尼電池的構造與電池符號

**伽凡尼電池（galvanic cell）**又叫**伏打電池（voltaic cell）**或原電池，是把一個**自發**的氧化還原反應拆成兩半（各一條**半反應，half-reaction**，只寫氧化那一半或只寫還原那一半的式子），讓電子被迫走外部導線，藉此把化學能轉成電能的裝置。把鋅片直接丟進硫酸銅溶液，鋅上的電子當場交給貼在表面的 $\ce{Cu^2+}$，能量全變成熱、拿不到電流。伽凡尼電池的做法是把氧化與還原分裝在兩個容器（各稱一個**半電池，half-cell**），電子唯一的通路就是外面那條導線。

**兩個電極的名字由反應決定，不由正負決定**：

- **陽極（anode）**：發生**氧化**的那一極，電子從這裡流出。
- **陰極（cathode）**：發生**還原**的那一極，電子從這裡流入。

這條定義在伽凡尼電池與電解池都成立，是後面所有判斷的地基。電子在外電路的方向永遠是**陽極 → 導線 → 陰極**，因為電子只由「丟電子的那一邊」流向「搶電子的那一邊」。伽凡尼電池的陽極因此是電子的出發點、對外是**負極**，陰極是**正極**。

**電極的質量變化**跟著半反應走：陽極金屬被氧化成離子溶進水裡，電極**變輕**，陰極的金屬離子得電子鍍上去，電極**變重**。半反應的物種全在溶液裡時（例如 $\ce{MnO4^-}$ 變 $\ce{Mn^2+}$），就插一根不參與反應的**惰性電極（inert electrode）**如白金 $\ce{Pt}$ 或石墨，只當導電板用。反應本身只發生在**電極與溶液的界面**上，反應物要先移動到電極表面才能得失電子，不會在遠離電極的液層中自己發生。

**鹽橋（salt bridge）**是裝著惰性電解質（如 $\ce{KNO3}$、$\ce{KCl}$）的通道，接在兩個半電池之間。沒有它，陽極槽因為不斷生成陽離子而積正電、陰極槽因為陽離子被消耗而積負電，電荷一失衡電子就走不動，電流幾秒內停掉。鹽橋讓離子補位維持兩槽電中性：**陰離子往陽極槽移動、陽離子往陰極槽移動**。記法是「陰離子去陽極」，兩個字剛好相反。

**電池符號（cell notation）**用一行字記完整個電池，讀法固定：

- **左邊寫陽極、右邊寫陰極**，順序是「陽極固體、陽極溶液、鹽橋、陰極溶液、陰極固體」。
- 單直線 ∣ 代表**相界**，也就是固體與溶液這種不同相接觸的界面。雙直線 ‖ 代表**鹽橋**。
- 同一相裡的多個物種用逗號隔開，不用直線。

鋅銅電池寫成 **Zn(s) ∣ Zn²⁺(aq) ‖ Cu²⁺(aq) ∣ Cu(s)**，讀出來就是：鋅是陽極、被氧化成 $\ce{Zn^2+}$，$\ce{Cu^2+}$ 在陰極被還原成銅，鋅電極變輕、銅電極變重。惰性電極的例子是 **Fe(s) ∣ Fe²⁺(aq) ‖ MnO₄⁻(aq), H⁺(aq), Mn²⁺(aq) ∣ Pt(s)**，右半電池三個物種同在水相、用逗號並列，最右邊的 $\ce{Pt}$ 只負責導電。

<RelatedNote title="氧化數怎麼算、半反應怎麼配平" href="/chem-solution-reactions" to="溶液中的化學反應">

氧化數的判定規則、酸性與鹼性介質的半反應配平六步驟、金屬活性序列，都寫在溶液中的化學反應那一篇。這裡假設半反應已經配平好，直接拿它的電子數 $n$ 來用。

</RelatedNote>

## 二、標準還原電位表怎麼讀

單一個電極的電位量不到，只能量兩極之間的電位差，所以要先挑一個當基準。**標準氫電極（standard hydrogen electrode，SHE）**就是這個基準，它的半反應 $\ce{2H+(aq) + 2e^- -> H2(g)}$ 在標準狀態下的電位被**人為定義為 $0.00$ V**。其他電極都拿去跟它配對量電壓，量到的數字就是那個電極的**標準還原電位（standard reduction potential，$E^\circ$，單位伏特 V）**。

**標準狀態**指所有溶液濃度 $1$ M、所有氣體分壓 $1$ atm、溫度 $25\ ^\circ\text{C}$。符號右上角的 $^\circ$ 就是在標記這件事，沒有 $^\circ$ 的 $E$ 指的是當下實際條件下的電位。表上每一條都寫成**還原方向**（左邊氧化態、右邊還原態），**$E^\circ$ 越正代表這條半反應越想往右跑、越想搶電子**。

<div class="overflow-x-auto print:overflow-visible">

| 半反應（還原方向） | $E^\circ$（V） |
|---|---|
| $\ce{F2 + 2e^- -> 2F^-}$ | $+2.87$ |
| $\ce{MnO4^- + 8H+ + 5e^- -> Mn^2+ + 4H2O}$ | $+1.51$ |
| $\ce{Cl2 + 2e^- -> 2Cl^-}$ | $+1.36$ |
| $\ce{O2 + 4H+ + 4e^- -> 2H2O}$ | $+1.23$ |
| $\ce{Ag+ + e^- -> Ag}$ | $+0.80$ |
| $\ce{Fe^3+ + e^- -> Fe^2+}$ | $+0.77$ |
| $\ce{Cu^2+ + 2e^- -> Cu}$ | $+0.34$ |
| $\ce{2H+ + 2e^- -> H2}$ | $0.00$（SHE 基準） |
| $\ce{Fe^2+ + 2e^- -> Fe}$ | $-0.44$ |
| $\ce{Zn^2+ + 2e^- -> Zn}$ | $-0.76$ |
| $\ce{2H2O + 2e^- -> H2 + 2OH^-}$ | $-0.83$ |
| $\ce{Al^3+ + 3e^- -> Al}$ | $-1.66$ |
| $\ce{Mg^2+ + 2e^- -> Mg}$ | $-2.37$ |
| $\ce{Na+ + e^- -> Na}$ | $-2.71$ |
| $\ce{Li+ + e^- -> Li}$ | $-3.04$ |

</div>

**兩個查表動作**：

- 找**最強氧化劑**：挑 $E^\circ$ **最大**那條，取它**左邊**的物種。$E^\circ$ 大代表最愛搶電子，搶別人電子就是把別人氧化。
- 找**最強還原劑**：挑 $E^\circ$ **最負**那條，取它**右邊**的物種。$E^\circ$ 最負代表這條半反應最不想往右跑、最想逆著走（丟電子）。選項裡**不能被氧化的物種要先排除**，只有處於還原態（表上右邊那一欄）的物種有資格，已經在最高氧化態的粒子沒有電子可以再丟。
- **氧化劑側是鏡像**：只有處於氧化態（表上左邊那一欄）的物種有資格當氧化劑，已經在最低氧化態的粒子（如 $\ce{S^2-}$、$\ce{Cl^-}$）沒有空位再收電子，只能當還原劑。題目沒給 $E^\circ$ 時就看電荷：同一種物種帶的正電越多越想搶電子，$\ce{O2+}$ 比 $\ce{O2}$ 是更強的氧化劑，帶的負電越多越想丟電子，$\ce{S^2-}$ 是比 $\ce{HS^-}$ 更強的還原劑。

**共軛強弱相反**是同一件事的另一面：一個金屬越強的還原劑，它的陽離子就越弱的氧化劑。電子被抓得越鬆，反過來搶電子的本事就越差。所以「金屬 X 比 Y 更強的還原劑」立刻可以翻成「$\ce{Y+}$ 比 $\ce{X+}$ 更強的氧化劑」。

## 三、標準電池電位 E°cell

把兩個半反應湊成一個電池，整個電池的標準電位是

$$E^\circ_{\text{cell}} = E^\circ_{\text{陰極}} - E^\circ_{\text{陽極}}$$

這個量也叫**電動勢（electromotive force，emf）**，就是電池兩極之間的電位差，題目兩種說法都會出現。**兩個數都直接用查表的還原電位代入**。陽極跑的是氧化、電位要變號，但那個負號已經包在減法裡了，不可以再變一次號。**誰當陰極不必猜**：$E^\circ$ 較大的那條比較想得電子，讓它當陰極，剩下那條被迫氧化當陽極，這樣相減才會是正值、電池才放得出電。所以判極與判自發是同一個動作。

<CellPotential client:visible />

三個必須分清的陷阱：

**陷阱一：$E^\circ$ 不隨係數放大。** 電位是「每單位電荷的能量」，屬於**內涵性質（intensive property，數值與物質的量無關的性質，像溫度與密度）**。把方程式全部乘以 $2$，反應放出的總能量與轉移的電子數 $n$ 同時加倍，兩者相除後每庫侖分到的能量不變，所以 $E^\circ$ **維持原值**。能量本身則會跟著係數放大，兩者行為完全不同。

**陷阱二：題目直接給氧化電位時改成相加。** 有些題目把陽極寫成氧化方向並標出**氧化電位**（還原電位變號後的值），例如「$\ce{Ag(s) -> Ag+(aq) + e^-}$，$E^\circ = -0.799$ V」。這個 $-0.799$ 已經變過號，這時用 $E^\circ_{\text{cell}} = E^\circ_{\text{陰極（還原）}} + E^\circ_{\text{陽極（氧化）}}$ 直接相加，結果與「陰減陽」相同。看到半反應箭頭往氧化方向寫，就要警覺不能再減一次。

**陷阱三：兩個半反應相加時，$E^\circ$ 不能直接相加減。** 要合成一條新的半反應（例如由 $\ce{Fe^2+/Fe}$ 與 $\ce{Fe^3+/Fe^2+}$ 湊出 $\ce{Fe^3+/Fe}$），必須繞道能量：能量可以直接相加，$E^\circ$ 是「每個電子分到的能量」、電子數不同時不可加。做法是把每條乘上自己的 $n$ 變成 $nE^\circ$（正比於該條的總能量）、相加後再除以新的總電子數。這條規則只在合成半反應時需要，兩個完整半電池組成電池時仍然用「陰減陽」。

<WorkedExample source="慈濟 108・化學 1" answer="(B) 0.38 V" tags={["半反應合成", "E°cell"]}>

**題目**　已知 $\ce{Fe^2+ + 2e^- -> Fe}$ 的 $E^\circ=-0.44$ V、$\ce{Fe^3+ + e^- -> Fe^2+}$ 的 $E^\circ=0.76$ V、$\ce{Cu^2+ + 2e^- -> Cu}$ 的 $E^\circ=0.34$ V，求 $\ce{3Cu^2+ + 2Fe -> 3Cu + 2Fe^3+}$ 的標準電壓。

(A) 0.02 V　(B) 0.38 V　(C) 0.45 V　(D) 0.64 V

**解**　鐵在總反應中由 $0$ 直接升到 $+3$，但表上沒有 $\ce{Fe^3+/Fe}$ 這一條，要自己合成。**不可以**寫成 $0.76-0.44$，那是陷阱三。改把兩條各乘自己的 $n$ 再相加：

$$
\begin{aligned}
&\ce{Fe^2+ + 2e^- -> Fe} &\quad nE^\circ &= 2(-0.44) = -0.88\\[4pt]
&\ce{Fe^3+ + e^- -> Fe^2+} &\quad nE^\circ &= 1(+0.76) = +0.76\\[4pt]
&\ce{Fe^3+ + 3e^- -> Fe} &\quad nE^\circ &= -0.12
\end{aligned}
$$

$$E^\circ(\ce{Fe^3+/Fe}) = \dfrac{-0.12\ \text{V}}{3} = -0.04\ \text{V}$$

$\ce{Cu^2+}$ 被還原是陰極（$+0.34$ V），$\ce{Fe}$ 被氧化是陽極（$-0.04$ V），故 $E^\circ_{\text{cell}} = 0.34-(-0.04) = +0.38$ V → (B)。若誤用 $0.76-0.44=0.32$ 當陽極電位，會得到 $0.02$ V（選項 A）。係數 $3$ 與 $2$ 完全不影響 $E^\circ$，這是陷阱一。

</WorkedExample>

## 四、E°cell、ΔG° 與平衡常數 K

**電位與自由能只差一個係數**。電池對外能做的最大電功等於「通過的電量 × 電位差」，而**吉布斯自由能變化（Gibbs free energy change，$\Delta G$）**的定義就是系統能對外做的最大非膨脹功取負號，於是

$$\Delta G^\circ = -\,n F E^\circ_{\text{cell}}$$

- $n$：整個反應轉移的**電子莫耳數**，等於兩個半反應各自得失電子數的最小公倍數。
- $F$：**法拉第常數（Faraday constant）**，一莫耳電子帶的電量，$F = 96485$ C/mol，考試取 $96500$ C/mol。
- 單位橋樑是 **$1$ V $=1$ J/C**，所以 mol $\times$ (C/mol) $\times$ (J/C) 相消後剩下 J。

$n$ 與 $F$ 都是正數，所以 $\Delta G^\circ$ 與 $E^\circ_{\text{cell}}$ **必定反號**。這鎖死了三件套的等價關係：

<div class="overflow-x-auto print:overflow-visible">

| $E^\circ_{\text{cell}}$ | $\Delta G^\circ$ | $K$ | 標準狀態下的反應 |
|---|---|---|---|
| $\gt 0$ | $\lt 0$ | $\gt 1$ | 自發，可做成伽凡尼電池 |
| $=0$ | $=0$ | $=1$ | 恰在平衡 |
| $\lt 0$ | $\gt 0$ | $\lt 1$ | 非自發，要外加電源才跑得動 |

</div>

<WorkedExample source="中國醫 108・化學 16" answer="(C) −394 kJ" tags={["ΔG° = −nFE°", "unit factor"]}>

**題目**　鉛蓄電池的反應為 $\ce{Pb + PbO2 + 2HSO4^- + 2H+ -> 2PbSO4 + 2H2O}$，$E^\circ=+2.04$ V，求 $25\ ^\circ\text{C}$ 時的 $\Delta G^\circ$。

(A) −98 kJ　(B) −197 kJ　(C) −394 kJ　(D) −591 kJ　(E) −787 kJ

**解**　先定 $n$：$\ce{Pb}$ 由 $0$ 升到 $+2$ 失 $2$ 個電子，$\ce{PbO2}$ 中的鉛由 $+4$ 降到 $+2$ 得 $2$ 個電子，所以 $n=2$。把常數連乘到底，讓 mol e⁻ 與 C 逐段相消：

$$
\Delta G^\circ = -\,2\ \text{mol e}^- \times \dfrac{96500\ \text{C}}{1\ \text{mol e}^-} \times \dfrac{2.04\ \text{J}}{1\ \text{C}} \times \dfrac{1\ \text{kJ}}{1000\ \text{J}} = -394\ \text{kJ}
$$

→ (C)。把 $n$ 誤當成 $1$ 會得到 $-197$ kJ（選項 B）、誤當成 $4$ 會得到 $-787$ kJ（選項 E），忘記換算 kJ 則會得到 $-3.94\times10^5$ 這種不在選項裡的數。

</WorkedExample>

**帶 $^\circ$ 與不帶 $^\circ$ 是兩個量**，這是最常設陷阱的地方。$\Delta G^\circ = -nFE^\circ_{\text{cell}}$ 只描述**標準狀態**這個假想條件，$\Delta G = -nFE$ 則描述**當下**的實際狀態。電池「完全放電」就是反應**達到平衡**：此時實際電位 $E=0$、反應商 $Q=K$（$Q$ 是把當下濃度代進平衡常數算式得到的值，第五節會正式定義）、$\Delta G=0$。但 $E^\circ$ 是固定的標準值、**不會變成 $0$**，$\Delta G^\circ$ 也**不一定是 $0$**（除非 $K$ 剛好等於 $1$）。另外平衡時是 $Q=K$，不是 $Q=1$，$Q=1$ 對應的是標準狀態。反過來說，**正在供電的電池**是 $E \gt 0$ 且 $\Delta G \lt 0$。

**電位換平衡常數**。$\Delta G^\circ$ 同時等於 $-RT\ln K$，把兩條式子接起來並在 $25\ ^\circ\text{C}$ 換成常用對數：

$$\log K = \dfrac{n\,E^\circ_{\text{cell}}}{0.0592}$$

那個 $0.0592$ 不是魔術數字，而是 $\dfrac{2.303\,RT}{F}$ 在 $298$ K 的值（$R=8.314$ J/(mol·K)），**只在 $25\ ^\circ\text{C}$ 成立**，換溫度要重算。

<WorkedExample source="中國醫 108・化學 9" answer="(D) 9.0 × 10⁻¹⁷" tags={["E° 換 Ksp", "半反應相減"]}>

**題目**　由 $\ce{AgI(s) + e^- -> Ag(s) + I^-(aq)}$（$E^\circ=-0.15$ V）與 $\ce{Ag+(aq) + e^- -> Ag(s)}$（$E^\circ=+0.80$ V），求 $25\ ^\circ\text{C}$ 下 $\ce{AgI}$ 的溶解度積 $K_{sp}$。

(A) $2.9\times10^{-3}$　(B) $1.9\times10^{-4}$　(C) $2.1\times10^{-12}$　(D) $9.0\times10^{-17}$　(E) $2.4\times10^{-20}$

**解**　目標反應是 $\ce{AgI(s) -> Ag+(aq) + I^-(aq)}$，它等於「第一條」減「第二條」。兩條的 $n$ 都是 $1$，這次可以直接相減：

$$E^\circ_{\text{cell}} = -0.15 - 0.80 = -0.95\ \text{V}$$

$$\log K_{sp} = \dfrac{1 \times (-0.95\ \text{V})}{0.0592\ \text{V}} = -16.0 \quad\Rightarrow\quad K_{sp} = 10^{-16.0} \approx 9.0\times10^{-17}$$

→ (D)。$E^\circ_{\text{cell}}$ 為負代表溶解在標準狀態下非自發，$K$ 遠小於 $1$，與 $\ce{AgI}$ 是難溶鹽相符。

</WorkedExample>

**電池最多能做多少功**就是 $|\Delta G|$。例如乙醇燃料電池 $\ce{C2H5OH(l) + 3O2(g) -> 2CO2(g) + 3H2O(l)}$，$E^\circ=1.14$ V，$n$ 由氧氣算最快（每個 $\ce{O2}$ 得 $4$ 個電子，三個共 $12$ 個）：

$$
12\ \text{mol e}^- \times \dfrac{96500\ \text{C}}{1\ \text{mol e}^-} \times \dfrac{1.14\ \text{J}}{1\ \text{C}} \times \dfrac{1\ \text{kJ}}{1000\ \text{J}} = 1.3\times10^{3}\ \text{kJ}
$$

<RelatedNote title="自由能 ΔG 的定義與自發性判準" href="/chem-thermo" to="熱力學">

$\Delta G = \Delta H - T\Delta S$ 的來源、$\Delta G$ 的正負如何判自發，寫在熱力學那一篇。

</RelatedNote>

<RelatedNote title="ΔG° 與 K 為什麼是對數關係" href="/chem-equilibrium" to="化學平衡">

$\Delta G^\circ = -RT\ln K$ 的推導、反應商 $Q$ 與 $K$ 比大小判方向，寫在化學平衡那一篇。本節只把它當橋樑，用來把電位換成 $K$。

</RelatedNote>

## 五、能斯特方程式與濃差電池

濃度離開 $1$ M 時，實際電位由**能斯特方程式（Nernst equation）**給出，$25\ ^\circ\text{C}$ 換成常用對數後就是考試在用的形式：

$$E = E^\circ - \dfrac{RT}{nF}\ln Q = E^\circ - \dfrac{0.0592}{n}\log Q$$

$Q$ 是**反應商（reaction quotient）**，算式與平衡常數 $K$ 長得一模一樣（生成物濃度冪次的乘積除以反應物濃度冪次的乘積），差別只在代入的是**當下**濃度而非平衡濃度。純固體與純液體不列入 $Q$。

**方向不用背**，用**勒沙特列原理（Le Chatelier's principle，平衡受到擾動時會往抵銷該擾動的方向移動）**想：$Q$ 小代表生成物還少、反應更想往右衝，推動力比標準態大，所以 $E$ 升高。$Q$ 大則 $E$ 下降。平衡時 $Q=K$、$E=0$，電池沒電。

<div class="overflow-x-auto print:overflow-visible">

| 操作 | 對 $Q$ 的影響 | 對 $E$ 的影響 |
|---|---|---|
| 提高反應物濃度（含半反應中的 $\ce{H+}$） | 變小 | 升高 |
| 提高生成物濃度 | 變大 | 降低 |
| 讓生成物離子沉澱或形成錯離子 | 生成物濃度驟降，變小 | 升高 |

</div>

第一列解釋了為什麼在 Fe(s) ∣ Fe²⁺(aq) ‖ MnO₄⁻(aq), H⁺(aq), Mn²⁺(aq) ∣ Pt(s) 這種電池中**加酸會提高電位**：$\ce{H+}$ 出現在陰極半反應的反應物側，而且係數高達 $8$，濃度一提高 $Q$ 就大幅變小。第三列則是「往銅半電池通 $\ce{H2S}$ 使 $\ce{Cu^2+}$ 沉澱成 $\ce{CuS}$，電動勢升高」這類題的原理。

**濃差電池（concentration cell）**是兩個半電池用**同一種**電極與同一種離子、只有濃度不同的電池。兩邊材料相同所以 $E^\circ = 0$，電位完全由濃度差撐起來：

$$E = \dfrac{0.0592}{n}\log \dfrac{[\text{濃}]}{[\text{稀}]}$$

**濃的那一邊當陰極**（離子多、比較容易被還原掉），稀的那一邊當陽極（金屬溶解補離子）。電池運作的方向就是把兩邊濃度拉平，一旦相等 $E$ 立刻歸零，所以濃差電池的 $E$ 恆為正。題目只給 $\log 2$ 時，要把濃度比拆成 $2$ 與 $10$ 的次方再拆對數，例如 $\log(1.25\times10^{3}) = \log\dfrac{10^4}{8} = 4-3\log 2 = 3.097$。

**能斯特方程式也可以用在單一半反應**。半反應寫成還原方向時，還原態是生成物、氧化態是反應物，所以

$$E = E^\circ - \dfrac{0.0592}{n}\log \dfrac{[\text{還原態}]}{[\text{氧化態}]} = E^\circ + \dfrac{0.0592}{n}\log \dfrac{[\text{氧化態}]}{[\text{還原態}]}$$

氧化還原滴定到達當量點之前，溶液電位由被滴定的那一對決定，只要算出反應掉多少、剩下多少，代進比值即可。以 $\ce{Ce^4+}$ 滴定 $\ce{Fe^2+}$ 為例，$10$ mmol $\ce{Fe^2+}$ 加入 $2.5$ mmol $\ce{Ce^4+}$ 後生成 $2.5$ mmol $\ce{Fe^3+}$、剩 $7.5$ mmol $\ce{Fe^2+}$，兩者同在一個容器裡、體積相同，可直接用毫莫耳數相除：

$$E = 0.771 + \dfrac{0.0592}{1}\log \dfrac{2.5}{7.5} = 0.771 - 0.028 = 0.743\ \text{V}$$

## 六、電解池與法拉第定律

**電解池（electrolytic cell）**接上外部電源，強迫一個**非自發**的氧化還原反應發生，把電能轉成化學能。它與伽凡尼電池的差別只在能量流向與極性：

<div class="overflow-x-auto print:overflow-visible">

| 項目 | 伽凡尼電池 | 電解池 |
|---|---|---|
| 能量轉換 | 化學能 → 電能 | 電能 → 化學能 |
| 自發性 | 自發（$E^\circ_{\text{cell}} \gt 0$） | 非自發（$E^\circ_{\text{cell}} \lt 0$，需外加電壓） |
| 陽極 | 氧化，是**負極** | 氧化，是**正極**（接電源正端） |
| 陰極 | 還原，是**正極** | 還原，是**負極**（接電源負端） |
| 用途 | 各式電池 | 電鍍、精煉金屬、電解水、製鋁與氯 |

</div>

**「陽極氧化、陰極還原」兩種電池都不變**，會換邊的只有正負極。理由在第一節已經講過：極名由反應定義，正負則看電子是自己流出（伽凡尼陽極為負）還是被電源逼進去（電解陽極接正端）。**電解熔融鹽**沒有水參與競爭，離子直接放電，熔融 $\ce{NaCl}$ 的陰極得到金屬鈉（$\ce{Na+ + e^- -> Na(l)}$）、陽極得到氯氣（$\ce{2Cl^- -> Cl2(g) + 2e^-}$）。**電解水溶液**則要先判斷誰放電，判準仍是電位：每一極都是「最容易反應的那一位先來」。

<div class="overflow-x-auto print:overflow-visible">

| 電極 | 先放電的是 | 條件 |
|---|---|---|
| 陰極（還原） | 金屬離子 | $E^\circ$ 明顯高於水的 $-0.83$ V，如 $\ce{Cu^2+}$、$\ce{Ag+}$ |
| 陰極（還原） | 水，放出 $\ce{H2}$ | 溶液是活性金屬離子（$\ce{Na+}$、$\ce{K+}$、$\ce{Ca^2+}$、$\ce{Mg^2+}$、$\ce{Al^3+}$），$E^\circ$ 太低 |
| 陽極（氧化） | 鹵離子，放出 $\ce{X2}$ | $\ce{Cl^-}$、$\ce{Br^-}$、$\ce{I^-}$ |
| 陽極（氧化） | 水，放出 $\ce{O2}$ | 溶液是含氧酸根（$\ce{SO4^2-}$、$\ce{NO3^-}$、$\ce{PO4^3-}$）或 $\ce{F^-}$ |
| 陽極（氧化） | 電極自己溶解 | 電極是活性金屬（如電鍍用的銅陽極） |

</div>

$\ce{SO4^2-}$ 不放電的原因是其中的硫已經是最高氧化態 $+6$，再氧化極為困難。兩極都由水放電時，兩邊會出現明顯的酸鹼差異：

$$
\begin{aligned}
\text{陰極}&: \ce{2H2O + 2e^- -> H2(g) + 2OH^-} \qquad \text{累積 }\ce{OH^-}\text{，變鹼}\\[4pt]
\text{陽極}&: \ce{2H2O -> O2(g) + 4H+ + 4e^-} \qquad \text{累積 }\ce{H+}\text{，變酸}
\end{aligned}
$$

所以電解 $\ce{Na2SO4}$ 水溶液並滴入**酚酞（phenolphthalein，在鹼性中呈粉紅、酸性與中性無色）**時，**陰極附近轉粉紅、陽極附近維持無色**。兩極產氣的體積比是 $\ce{H2}:\ce{O2}=2:1$，因為每莫耳 $\ce{O2}$ 要 $4$ 個電子、每莫耳 $\ce{H2}$ 只要 $2$ 個。電解**濃食鹽水**是唯一要小心的例外：標準電位預測水先被氧化（$+1.23$ V 低於 $+1.36$ V），實際卻主要放出 $\ce{Cl2}$，因為生成 $\ce{O2}$ 需要額外的**過電位（overpotential，實際反應所需電壓超出理論值的部分）**。

**法拉第定律（Faraday's laws of electrolysis）**把電量與析出量接起來，本質是「電流計帳的是電子」。四段連乘一路把單位換到底：

$$
t\ (\text{s}) \times \dfrac{I\ \text{C}}{1\ \text{s}} \times \dfrac{1\ \text{mol e}^-}{96500\ \text{C}} \times \dfrac{1\ \text{mol 金屬}}{n\ \text{mol e}^-} \times \dfrac{M\ \text{g}}{1\ \text{mol 金屬}} = \text{質量 (g)}
$$

這裡的 $n$ 是**該半反應中每個原子需要的電子數**（$\ce{Cu^2+}$ 是 $2$、$\ce{Ag+}$ 是 $1$、$\ce{Al^3+}$ 是 $3$），與第四節「整個反應轉移電子莫耳數」的 $n$ 在多電子反應時可能不同。最常見的錯誤就是漏掉這一段除法，其次是忘記把分鐘換成秒。

<WorkedExample source="義守 106・化學 19" answer="(C) K（原子量 39.10 g/mol）" tags={["法拉第定律", "unit factor"]}>

**題目**　以 $4.0$ A 電流電解熔融鹽 $\ce{MCl}$，通電 $16.0$ 分鐘產生 $1.56$ g 金屬，此金屬 M 為何？（$F=96500$ C/mol）

(A) Li（$6.94$）　(B) Na（$22.99$）　(C) K（$39.10$）　(D) Rb（$85.47$）

**解**　鹽的化學式是 $\ce{MCl}$，代表 $\ce{M+}$ 帶一價，每個原子只要 $1$ 個電子，$n=1$。先把電量換成金屬莫耳數：

$$
16.0\ \text{min} \times \dfrac{60\ \text{s}}{1\ \text{min}} \times \dfrac{4.0\ \text{C}}{1\ \text{s}} \times \dfrac{1\ \text{mol e}^-}{96500\ \text{C}} \times \dfrac{1\ \text{mol M}}{1\ \text{mol e}^-} = 0.0398\ \text{mol}
$$

再用「質量除以莫耳數」反推莫耳質量：$\dfrac{1.56\ \text{g}}{0.0398\ \text{mol}} = 39.2\ \dfrac{\text{g}}{\text{mol}}$，最接近鉀的 $39.10$ → (C)。若把 $16.0$ 分鐘直接當成 $16.0$ 秒代入，會算出六十倍大的莫耳質量。

## 七、常見電池、腐蝕與電鍍

**一次電池（primary cell）**放完就報廢，反應不可逆。**二次電池（secondary cell）**可以外加電源逆推反應、充電再用。

<div class="overflow-x-auto print:overflow-visible">

| 電池 | 陽極（放電時） | 陰極（放電時） | 電壓 | 可否充電 |
|---|---|---|---|---|
| 乾電池（鋅碳） | $\ce{Zn}$ | $\ce{MnO2}$，生成 $\ce{Mn2O3}$ | 約 $1.5$ V | 否 |
| 鹼性電池 | $\ce{Zn}$（鹼性介質） | $\ce{MnO2}$ | 約 $1.4$ V | 否 |
| 鉛蓄電池 | $\ce{Pb}$ | $\ce{PbO2}$ | 約 $2$ V | 可 |
| 鋰離子電池 | 嵌在石墨層間的鋰 | 鋰鈷氧化物 $\ce{LiCoO2}$ | 約 $3.7$ V | 可 |
| 氫氧燃料電池 | $\ce{H2}$ | $\ce{O2}$ | 約 $1.2$ V | 持續供料 |

</div>

**鉛蓄電池**的兩極反應要能直接寫出來，放電時兩極都生成硫酸鉛：

$$
\begin{aligned}
\text{陽極}&: \ce{Pb(s) + HSO4^-(aq) -> PbSO4(s) + H+(aq) + 2e^-}\\[4pt]
\text{陰極}&: \ce{PbO2(s) + HSO4^-(aq) + 3H+(aq) + 2e^- -> PbSO4(s) + 2H2O(l)}
\end{aligned}
$$

三個容易混的點：放電時陽極是**金屬鉛**（不是 $\ce{PbO2}$），放電是自發的**化學能轉電能**（不是電能轉化學能），以及它**可以充電**（充電時整條反應逆向跑，電池變成電解池）。

**燃料電池（fuel cell）**與一般電池的差別在於反應物由外部持續供應、電極本身不消耗。氫氧燃料電池的**陽極通氫氣**被氧化（$\ce{2H2 -> 4H+ + 4e^-}$）、**陰極通氧氣**被還原（$\ce{O2 + 4H+ + 4e^- -> 2H2O}$）。

**腐蝕（corrosion）**就是金屬自己在表面組成的微型伽凡尼電池。鐵生鏽需要**水與氧氣同時存在**：鐵的某一塊當陽極被氧化（$\ce{Fe -> Fe^2+ + 2e^-}$，$E^\circ=-0.44$ V），另一塊當陰極把氧氣還原（$\ce{O2 + 4H+ + 4e^- -> 2H2O}$，$E^\circ=+1.23$ V）。$E^\circ_{\text{cell}} = 1.23-(-0.44) = +1.67$ V 為正，所以生鏽是自發的。溶液偏酸或含鹽（提高導電度）都會加速腐蝕。

**犧牲陽極（sacrificial anode）**的防蝕原理就是 $E^\circ$ 比大小：接上一塊**更活潑**（$E^\circ$ 更負）的金屬如 $\ce{Zn}$ 或 $\ce{Mg}$，讓它當陽極先被氧化，被保護的鐵整塊變成陰極、不再溶解，也叫**陰極保護（cathodic protection）**。

**鍍鋅鐵與鍍錫鐵刮傷後的命運完全相反**：鋅的 $E^\circ$ 是 $-0.76$ V、比鐵的 $-0.44$ V 更活潑，鍍層刮破後鋅**繼續當陽極被犧牲**，鐵仍受保護。錫的 $E^\circ$ 是 $-0.14$ V、比鐵不活潑，鍍層刮破後錫變陰極、鐵變陽極，鐵反而**加速**鏽蝕。

**電鍍（electroplating）**是電解池的應用：**待鍍物當陰極、鍍層金屬當陽極**，鍍層質量直接用法拉第定律算。

<WorkedExample source="中國醫 104・化學 6" answer="(C) 全反應為 Pb + PbO₂ + 2H⁺ + 2HSO₄⁻ → 2PbSO₄ + 2H₂O" tags={["鉛蓄電池", "放電方向"]}>

**題目**　關於鉛蓄電池放電的過程，下列敘述何者正確？

(A) 陰極反應為 $\ce{Pb(s) + HSO4^-(aq) -> PbSO4(s) + H+(aq) + 2e^-}$　(B) 陽極反應為 $\ce{PbO2(s) + 3H+(aq) + HSO4^-(aq) + 2e^- -> PbSO4(s) + 2H2O(l)}$　(C) 全反應為 $\ce{Pb(s) + PbO2(s) + 2H+(aq) + 2HSO4^-(aq) -> 2PbSO4(s) + 2H2O(l)}$　(D) 此反應為自發反應，是電能轉變成化學能的過程　(E) 鉛蓄電池無法充電再生

**解**　先看箭頭方向再判極名，不必記哪一極是哪個物質。(A) 的式子**放出**電子、是氧化，屬於**陽極**，標成陰極就錯了。(B) 的式子**吸收**電子、是還原，屬於**陰極**，同樣標反，兩者恰好互換。

(C) 把 (A) 與 (B) 相加、消去兩邊的電子，正是總反應 → (C)。(D) 前半句對（放電確實自發），後半句反了，放電是**化學能轉電能**。(E) 錯，鉛蓄電池是二次電池，充電時反應逆向跑。

</WorkedExample>
