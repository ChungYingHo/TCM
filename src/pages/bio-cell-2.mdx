## 四、細胞核與核糖體

### 細胞核（nucleus）

<Figure src="/notes/bio-cell/nucleus.webp" alt="細胞核構造：雙層核膜、核孔與孔複合體、核仁、染色質，以及核膜與內質網相連" caption="核套膜雙層、佈滿核孔、與粗糙內質網相連。核內有核仁與染色質。" source="Campbell 生物學・上冊" />

| 構造 | 重點 |
|------|------|
| **核套膜**（nuclear envelope） | **雙層膜**、與**粗糙 ER 相連**（核套膜與 ER **都是內膜系統成員**） |
| **核孔**（nuclear pore）＋孔複合體 | 管大分子進出：**出** mRNA、核糖體次單位、**進**蛋白質。小分子自由通過 |
| **核纖層／核蛋白片層**（nuclear lamina） | 核膜內襯的**中間絲（lamin）** 網，撐核形、固定核 |
| **染色質／染色體**（chromatin / chromosome） | 平時鬆散為染色質、分裂時凝聚成染色體。每物種染色體數固定（人類體細胞 46、生殖細胞 23） |
| **核仁**（nucleolus） | 合成 **rRNA**、組裝核糖體大、小次單位 |

真核基因多在核，少數在**粒線體、葉綠體、色質體（plastid）**。

<Supplement title="色質體 plastid">

植物的**雙層膜胞器家族**，都源自原色質體、有自己的 DNA：

- **葉綠體（chloroplast）**：光合作用。
- **有色體（chromoplast）**：花、果的紅黃色素。
- **白色體（leucoplast）**：儲澱粉／油。

</Supplement>

<Supplement title="染色體的組成（組蛋白約一半 ＋ DNA 約一半）">

DNA 纏**組蛋白（histone）** 成「**核小體（nucleosome）**」串珠，再層層摺疊，2 公尺長的 DNA 才塞得進 5 µm 的核。

</Supplement>

<Supplement title="真染色質 vs 異染色質（轉錄與否）">

- **真染色質（euchromatin）**：鬆散、淡染、**正在轉錄**。
- **異染色質（heterochromatin）**：緻密、深染、**不轉錄**。

轉錄旺盛的核，淡染區多。

</Supplement>

<Supplement title="核糖體：大小次單位與 70S／80S">

- **所有細胞都有核糖體**。**原核 70S** ＝ 大 **50S** ＋ 小 **30S**。**真核 80S** ＝ 大 **60S** ＋ 小 **40S**。
- **60S＋40S＝80S 而非 100S 的原因**：S（Svedberg）是**沉降係數**，量離心時沉降的快慢，同時受**質量與形狀**影響、不是純質量，所以**不能直接相加**（兩次單位合體後形狀更緊實）。
- 小次單位**讀 mRNA**、大次單位**催化胜肽鍵**。兩次單位在核仁做好 → 經核孔出核 → 在細胞質才合體。

</Supplement>

### 核糖體（ribosome）

成分 ＝ **rRNA ＋ 蛋白質**（rRNA 由核仁做。**核糖體蛋白、組蛋白都在細胞質做好、再運進核**）。依位置分兩種：

| | **游離核糖體**（free） | **黏附核糖體**（bound） |
|---|---|---|
| 位置 | 懸在細胞質 | 黏在粗糙 ER／核膜 |
| 做的蛋白 | **用在細胞質內**（多數代謝酶） | **送出細胞、入膜、入胞器**（分泌蛋白、膜蛋白、溶體酶） |

分泌旺盛的細胞 → 核糖體多、核仁明顯。

<Supplement title="內分泌 vs 外分泌（胰臟兼具）">

- **內分泌（endocrine）**：分泌物**入血**、送遠處（如胰島素 insulin）。
- **外分泌（exocrine）**：經**導管**送到管腔（如唾液澱粉酶 amylase）。
- **胰臟兩者都有**：外分泌（腺泡細胞做消化酶、入小腸）＋ 內分泌（胰島做胰島素／升糖素 glucagon、入血）。

</Supplement>

## 五、內膜系統（endomembrane system）：七大成員

膜彼此相連、或靠運輸小泡互通的一組構造，分工「合成 → 加工 → 分類 → 運送 → 分解」。

- **七大成員**：核套膜（nuclear envelope）、內質網（ER）、高基氏體（Golgi）、溶體（lysosome）、液泡（vacuole）、運輸小泡（transport vesicle）、細胞膜（plasma membrane）。
- **任務**：①合成蛋白質 ②送蛋白到胞器或胞外 ③脂質運送與代謝 ④分解有毒物質。

<Figure src="/notes/bio-cell/bonus-endomembrane.webp" alt="內膜系統總覽：細胞核、內質網、高基氏體、運輸小泡與細胞膜如何透過膜與小泡彼此相連、依序傳遞物質" caption="流向：核膜／內質網 → 運輸小泡 → 高基氏體 → 分泌小泡 → 細胞膜。" source="Campbell 生物學・上冊" />

<Supplement title="瘦瘦針的原理">

- **是什麼**：**GLP-1 受體致效劑**（如 semaglutide），是腸泌素 **GLP-1** 的長效類似物（胜肽激素）。
- **怎麼控糖減重**：促**胰島素**、抑**升糖素（glucagon）** → 肝臟多把血糖合成**肝糖（glycogen）儲存**、少分解肝糖 → 血糖降。再加抑食慾、延緩胃排空。
- **跟內膜系統的關係**：GLP-1、胰島素這類**分泌型胜肽激素**都走「核糖體 → 粗糙 ER → Golgi → 分泌小泡 → 胞吐（exocytosis）」這條分泌路徑。

</Supplement>

### 內質網（endoplasmic reticulum，ER）：平滑 vs 粗糙

<Figure src="/notes/bio-cell/er.webp" alt="內質網構造：粗糙內質網表面有核糖體、平滑內質網無核糖體、過渡區掐出運輸小泡" caption="ER 由核膜延伸。有核糖體者為粗糙 ER、無者為平滑 ER。" source="Campbell 生物學・上冊" maxW="32rem" />

**ER 占真核細胞「總膜量」的一半以上**（不只是內膜系統，是全細胞的膜，由核套膜延伸而來）：

- **構造**：膜圍成**扁囊（cisternae，扁平囊狀）** 與內腔（ER 內腔 lumen）。
- **動態**：可擴張、**掐出運輸小泡**，或延伸**變成其他內膜系統構造**（ER 是內膜系統的膜來源）。

依表面有無核糖體**分兩種**：

| | **平滑 ER（smooth ER，SER）** | **粗糙 ER（rough ER，RER）** |
|---|---|---|
| 表面核糖體 | **無** | **有** |
| 主責 | **代謝** | **合成蛋白質** |
| 代表功能 | 合成脂質／固醇、代謝肝醣、解毒、儲鈣 | 做分泌／膜／溶體蛋白、醣基化、製膜 |

**SER 四件事**：

- **合成脂質**：油脂、磷脂質、**固醇類（sterol，含膽固醇 cholesterol）**。
- **代謝肝醣（glycogen）**：肝細胞 SER 分解肝醣、釋出葡萄糖入血。
- **解毒**：肝細胞 SER（**細胞色素 P450**）代謝藥物／毒物。常吃藥 → SER 增生 → **耐藥性**。
- **儲鈣（Ca²⁺）**：肌肉細胞特化成「肌漿網（sarcoplasmic reticulum）」，釋 Ca²⁺ 觸發**肌肉收縮**與訊號。

<Supplement title="膽固醇、固醇與性激素／皮質激素">

- **膽固醇（cholesterol）** 是固醇（sterol）、屬於**類固醇（steroid）**，更是**性激素、皮質激素的合成原料**：做這些激素的細胞（性腺、腎上腺皮質）SER 特別發達。
- **性激素（sex hormone）**：管生殖與第二性徵（雌激素、睪固酮）。
- **皮質激素（corticosteroid）**：如皮質醇（調代謝、抗壓）、醛固酮（調鈉鉀水）。

</Supplement>

<Supplement title="鈣離子的功能">

肌肉收縮、神經傳遞、細胞訊號、凝血，細胞最常用的「訊號離子」之一。

</Supplement>

**RER 重點**：

- **合成蛋白質 ＝ 合成胜肽鍵（peptide bond）**：核糖體在轉譯時把胺基酸接成胜肽鍵。
- **醣基化（glycosylation）→ 糖蛋白（glycoprotein）**：多胜肽在 RER 內腔加**醣鏈**。**修飾順序「ER 先、Golgi 後」**。
- **包裝送出**：分泌蛋白裝進運輸小泡送往 Golgi。
- **製膜工廠**：自己合成磷脂質（磷脂質主要由 ER 做）、把新膜加上身再分送。

<Supplement title="補充：從基因到蛋白質（轉錄 vs 轉譯）">

- **轉錄（transcription）**：在**細胞核**，把 DNA 抄成 mRNA。
- mRNA 經**核孔**出核 → 到細胞質。
- **轉譯（translation）**：在**核糖體**，依 mRNA 的密碼把胺基酸接成蛋白質（即下面三種 RNA 的分工）。

</Supplement>

**三種 RNA 分工**（轉譯）：

- **mRNA**（messenger）：模板，帶基因密碼。
- **tRNA**（transfer）：搬胺基酸。
- **rRNA**（ribosomal）：催化核心，核糖體是核酶（ribozyme），真正催化胜肽鍵的是 rRNA。

<Supplement title="ER 摺疊出錯：ER 壓力與 UPR">

- **錯誤蛋白堆積**：摺疊錯誤的蛋白在 ER 內**大量累積** → 引發 **ER 壓力（ER stress）**。
- **未摺疊蛋白反應（unfolded protein response，UPR）**：細胞踩煞車，減少蛋白合成、加強摺疊與清除。
- **清除**：ER 有品管，摺錯的蛋白送去**蛋白酶體（proteasome）** 降解。
- **後果**：清不掉、壓力太大 → 細胞凋亡。與多種疾病（神經退化、糖尿病…）有關。

</Supplement>

### 小泡的外被、回收與融合

小泡在胞器間送貨，靠幾組蛋白決定「怎麼成形、往哪送、怎麼靠岸融合」。

- **外被蛋白（coat protein）**：小泡從膜上掐出來時，外面先包一層蛋白外鞘，負責挑貨、把膜彎成泡。分成方向相反的兩型：
  - **COPII**：包在由**內質網（ER）掐出、送往高基氏體**的小泡上（順向 anterograde，ER → Golgi）。
  - **COPI**：包在由**高基氏體送回內質網**的小泡上（逆向 retrograde，Golgi → ER）。

> **記法**：COP**II** 往前送去 Golgi、COP**I** 送回（retrieve）ER。

- **KDEL 訊號**：內質網常駐蛋白（如摺疊酵素）尾端帶的一段胺基酸序列 **KDEL（Lys-Asp-Glu-Leu）**，等於回郵地址。它若被小泡誤帶到高基氏體，Golgi 上的 **KDEL 受體（KDEL receptor）** 會認出這段地址，用 **COPI 逆向小泡把它退回 ER**，確保 ER 該有的酵素不流失。

- **SNARE 蛋白**：讓小泡與目標膜**融合**的關鍵。小泡上的 **v-SNARE** 與目標膜上的 **t-SNARE** 像拉鍊互扣成束，把兩層膜拉到貼緊而融合，內容物才倒得出去。

- **synaptotagmin（突觸結合蛋白）**：突觸小泡膜上的**鈣離子（Ca²⁺）感應器**。神經訊號讓 Ca²⁺ 衝進神經末梢時，它一抓到 Ca²⁺ 就催 SNARE 完成融合，把神經傳遞物質在毫秒內胞吐釋出，是「電訊號 → 化學訊號」的瞬間開關。

### 高基氏體（Golgi apparatus）

<Figure src="/notes/bio-cell/golgi.webp" alt="高基氏體：一疊扁囊，順面接收來自內質網的小泡、反面送出分泌小泡" caption="一疊扁囊。順面 cis 收貨、反面 trans 出貨。" source="Campbell 生物學・上冊" />

- **由誰產生**：ER 來的運輸小泡**融合堆疊**。
- **構造**：一疊扁囊，**順面（cis face）**（朝 ER、收貨）↔ **反面（trans face）**（朝細胞膜、出貨），動態。
- **功能**：修飾糖蛋白醣鏈、**分類、包裝、貼地址、出貨**。

<Supplement title="醣基化：糖蛋白與 ER／Golgi 分工">

- **醣基化（glycosylation）**：蛋白在 RER 內腔合成、摺疊時被接上一段**醣鏈** → 變成**糖蛋白（glycoprotein）**。
- **ER 先、Golgi 後**：RER 先接「核心醣鏈」，送到 Golgi 再**修剪掉部分單糖、改接**特定醣。
- **Golgi 修剪／改接醣的目的**：做出不同「醣鏈標籤」＝不同的**郵遞地址**，決定這蛋白送去溶體、嵌進膜、還是分泌出去。
- **不一定都經兩者**：**N-連結（N-linked）** 是「ER 起頭、Golgi 修整」、**O-連結（O-linked）只在 Golgi**、不進 ER 的胞質蛋白完全不走這條。

</Supplement>

### 溶體（lysosome）

<Figure src="/notes/bio-cell/lysosome.webp" alt="溶體進行吞噬作用與自噬作用：與食泡或自噬體融合並消化內容物" caption="溶體與食泡融合消化外來顆粒（吞噬），或包住老舊胞器形成自噬體再分解（自噬）。" source="Campbell 生物學・上冊" />

- **由誰產生**：由**高基氏體反面（trans face）** 掐出的小泡而來，水解酶在 RER 合成、Golgi 修飾打包成小泡。小泡再與內體（endosome）／食泡融合，**成熟為溶體**。
- **內容**：**酸性水解酶（hydrolase）**。
- **酸性水解酶在 pH≈5 最活躍**：膜上質子泵打 H⁺ 維持酸性，使溶體成為**細胞內最酸的隔間之一**。這也是保險：萬一酶漏到接近中性的細胞質就**失活**、不會自我消化。

**兩種「把東西送進溶體消化」的方式**，差在消化「外來物」還是「自己」：

<div class="overflow-x-auto print:overflow-visible">

| | **吞噬作用 phagocytosis** | **自噬作用 autophagy** |
|---|---|---|
| 消化對象 | **外來**的大顆粒、細菌、食物 | **自身**的老舊胞器、壞蛋白（也清病毒） |
| 先形成 | **食泡（phagosome）** | **自噬體（autophagosome）** |
| 接著 | 食泡與溶體融合 → 消化 | 自噬體與溶體融合 → 分解、回收材料 |
| 例 | 白血球吞病原 | 細胞更新、飢餓時回收供能 |

</div>

**溶體儲積症（lysosomal storage disease）**：酶缺 → 受質堆積。

<div class="overflow-x-auto print:overflow-visible">

| 疾病 | 缺的酶 | 堆積物 | 影響 |
|------|--------|--------|------|
| **龐貝氏症 Pompe** | 酸性 α-葡萄糖苷酶（GAA） | 肝醣 glycogen | 心肌、骨骼肌無力 |
| **泰薩二氏症 Tay-Sachs** | 己醣胺酶 A（Hex-A） | GM2 神經節苷脂 | 神經退化 |

</div>

<Supplement title="白血球、巨噬細胞、APC、TH">

- **白血球（white blood cell，WBC）、巨噬細胞（macrophage）**：就是**執行吞噬作用（phagocytosis）的細胞**，靠吞噬清除病原。
- **APC（抗原呈現細胞）、TH（輔助 T 細胞）**：巨噬細胞吞病原後把碎片「呈現」給 TH 啟動免疫（屬免疫學，之後細講）。

</Supplement>

### 液泡（vacuole）

由 **ER 與高基氏體（Golgi）** 衍生的膜囊，依功能分：

| 種類 | 功能 | 哪裡 |
|------|------|------|
| **食泡**（food vacuole） | 吞噬形成、與溶體融合消化 | 白血球、變形蟲 |
| **伸縮泡**（contractile vacuole） | 排多餘的水、調滲透壓 | 淡水原生生物 |
| **中央液胞**（central vacuole） | 儲水／離子／色素／廢物、撐**膨壓（turgor）** | 成熟植物細胞 |

> **核套膜 ＝ 起點、細胞膜 ＝ 終點與邊界**（細胞膜的構造與運輸下一章講）。

## 六、能量胞器與其他（非內膜系統）

粒線體、葉綠體**不由內膜系統長出、彼此不互通**，是**內共生（endosymbiosis）** 來的（自有 DNA／核糖體、雙層膜、二分裂）。**非內膜系統的其他成員還有過氧化體（peroxisome）、蛋白酶體（proteasome／UPS）**，本節一併講。

### 粒線體（mitochondrion）

<Figure src="/notes/bio-cell/mitochondrion.webp" alt="粒線體構造：平滑外膜、向內摺成皺褶的內膜、基質、膜間隙" caption="雙層膜：內膜摺成皺褶（cristae）放電子傳遞鏈。基質含 DNA、核糖體與酵素。" source="Campbell 生物學・上冊" />

- 把食物化學能轉成 **ATP**（細胞呼吸 cellular respiration）。幾乎所有真核細胞都有。
- **數量看需氧量／代謝率**（心肌、肝特別多）、**不是年齡**。可移動、變形、融合、分裂。

<Supplement title="肌肉、粒線體與失智的關聯">

肌肉是**粒線體大戶、耗能高**。肌肉量下降與代謝、認知退化在流行病學上**有相關**（屬關聯、非單一因果）。

</Supplement>

| 構造（雙層膜） | 重點 |
|----------------|------|
| **外膜**（outer membrane） | 平滑 |
| **內膜＋皺褶**（inner membrane / cristae） | **電子傳遞鏈＋ATP 合成酶**在此（＝**氧化磷酸化 oxidative phosphorylation**，產生大部分 ATP）。皺褶增大面積 |
| **基質**（matrix） | 含 **DNA、核糖體、酵素**（檸檬酸循環） |
| **膜間隙**（intermembrane space） | 內外膜之間，質子堆積 |

<Supplement title="細胞呼吸／氰化物中毒">

- **細胞呼吸（cellular respiration）**：大致 $\ce{C6H12O6 + 6O2 -> 6CO2 + 6H2O}$ 並放能（合成 ATP）。
- **氰化物中毒（cyanide poisoning）**：氰化物**結合並抑制複合體 IV（細胞色素 c 氧化酶 cytochrome c oxidase）** → 電子無法傳給 O₂ → 電子傳遞鏈停擺、**氧化磷酸化與 ATP 合成全卡住**。關鍵是**抑制複合體 IV**（不是「累積」）。細胞「有氧卻不能用」＝組織缺氧（histotoxic hypoxia）。

</Supplement>

### 葉綠體（chloroplast）

<Figure src="/notes/bio-cell/chloroplast.webp" alt="葉綠體構造：外膜、內膜、基質、類囊體堆疊成基粒" caption="雙層膜外另有類囊體（thylakoid）疊成基粒（granum）行光反應。基質（stroma）行卡爾文循環。" source="Campbell 生物學・上冊" />

行**光合作用（photosynthesis）**（光能→醣），植物與藻類特有，屬**色質體（plastid）** 家族。

| 構造 | 功能 |
|------|------|
| 外膜、內膜 | 包被 |
| **類囊體**（thylakoid，疊成**基粒 granum**） | **光反應** |
| **基質**（stroma） | DNA、酵素，行**卡爾文循環（Calvin cycle）** |

<Supplement title="光反應 vs 卡爾文循環（光合細節下章再講）">

- **包被**：外膜＋內膜把葉綠體與細胞質隔開。
- **光反應（light reactions）**：在**類囊體膜**，光能 → 分解水放 O₂、產生 ATP 與 NADPH。
- **卡爾文循環（Calvin cycle）**：在**基質**，用 ATP／NADPH 把 CO₂ 固定成醣。

</Supplement>

### 過氧化體與蛋白酶體（都不屬內膜系統）

- **過氧化體（peroxisome）**：**單層膜**、含**過氧化氫酶（catalase）** 分解 **H₂O₂**、做脂肪酸代謝與肝腎解毒。
- **蛋白酶體（proteasome）**：**非膜性**的桶狀蛋白。降解**被泛素（ubiquitin）標記**的壞蛋白（＝**泛素-蛋白酶體系統 UPS**）。

<Supplement title="溶體 vs 蛋白酶體（都分解，分工不同）">

| | **溶體 lysosome** | **蛋白酶體 proteasome** |
|---|---|---|
| 膜 | 膜囊，**屬內膜系統** | 桶狀蛋白，**非膜、非胞器** |
| 分解對象 | 膜包的大塊／吞進來的胞外物 | 單一、被**泛素**標記的蛋白 |

</Supplement>
