## 三種「能階」模型別搞混

三篇各給一條能階公式，長得像但**方向相反**，混用是最常見的失分點：

| 模型 | 公式 | 隨 n 變化 | 出處 |
|---|---|---|---|
| 一維盒中質點 | $E_n = \dfrac{n^2h^2}{8mL^2}$ | $\propto n^2$，**往上越開** | [軌域](/chem-orbitals) |
| 氫原子（波耳） | $E_n = -13.6\dfrac{Z^2}{n^2}\ \text{eV}$ | $\propto -1/n^2$，**往 0 收斂** | [原子光譜](/chem-atomic-spectra) |
| 多電子原子 | 無單一公式，用 **n+l 規則** | n+l 大則高；相同則 n 大者高 | [電子組態](/chem-electron-config) |

> 判斷用哪個：問「箱子／井」用盒中質點；問**氫或類氫離子**（單電子）用波耳；問**多電子原子填電子順序**用 n+l。

## 量子論五式同源

[光電效應](/chem-quantum) 與 [原子光譜](/chem-atomic-spectra) 的公式其實是同一件事換單位，核心只有 $(1/m^2 - 1/n^2)\cdot Z^2$：

| 要算什麼 | 公式 | 單位 |
|---|---|---|
| 一個光子的能量 | $E = h\nu = \dfrac{hc}{\lambda}$ | J |
| 考場速算 | $E(\text{eV}) = \dfrac{1240}{\lambda(\text{nm})}$ | eV |
| 躍遷能量差 | $\Delta E = 13.6\,Z^2\left(\dfrac{1}{m^2}-\dfrac{1}{n^2}\right)$ | eV |
| 躍遷頻率 | $\nu = 3.3\times10^{15}\,Z^2\left(\dfrac{1}{m^2}-\dfrac{1}{n^2}\right)$ | Hz |
| 躍遷波長 | $\lambda = \dfrac{90}{Z^2\left(\frac{1}{m^2}-\frac{1}{n^2}\right)}$ | nm |
| 物質波 | $\lambda = \dfrac{h}{mv} = \dfrac{h}{p}$ | m |

**常數**：$h = 6.626\times10^{-34}$ J·s｜$c = 3.00\times10^8$ m/s｜$1\ \text{eV} = 1.602\times10^{-19}$ J｜$a_0 = 0.529$ Å｜$N_A = 6.022\times10^{23}$ /mol

## Zeff 一個量帶動四個趨勢

[週期表與週期性](/chem-periodicity) 定義有效核電荷 $Z_{\text{eff}} = Z - \sigma$，[週期性趨勢](/chem-periodic-trends) 的四個量全部由它決定——**背一條就好，不必背四張趨勢圖**：

| 量 | 與 Zeff 的關係 | 同週期往右 | 同族往下 |
|---|---|---|---|
| 原子半徑 | Zeff 大 → 拉得緊 → **小** | 變小 | 變大 |
| 游離能 IE | Zeff 大 → 難拔 → **大** | 變大 | 變小 |
| 電子親和力 EA | Zeff 大 → 愛收 → **大** | 變大 | 變小 |
| 電負度 EN | Zeff 大 → 搶得贏 → **大** | 變大 | 變小 |

> 一句話：**Zeff 大、半徑小 → 其餘三個都大。** 例外只有四個要單獨記：Be→B、N→O（[週期性](/chem-periodicity)）、EA 的 F＜Cl、N 半滿難加（[週期趨勢](/chem-periodic-trends)）。

## 計量與單位骨架

任何計算題都走同一條路（[化學計量](/chem-stoichiometry)），每個箭頭是一個 unit factor（[單位](/chem-units)）：

$$
\underbrace{\text{已知量}}_{\text{g／個／L}}
\xrightarrow[\div M,\ \div N_A,\ \div 22.4]{}
\text{mol}
\xrightarrow[\times \frac{\text{目標係數}}{\text{已知係數}}]{}
\text{mol}
\xrightarrow[\times M,\ \times N_A]{}
\text{目標量}
$$

| 常用換算 | 關係 |
|---|---|
| 質量 ↔ mol | $\div M$（g/mol） |
| 粒子數 ↔ mol | $\div N_A$ |
| 氣體體積 ↔ mol | STP $\div 22.4$ L/mol |
| 濃度 ↔ mol | $\times V(\text{L})$ |
| 溫度 | $K = ^\circ C + 273.15$（**加法偏移，不可當乘法因子**） |
| 壓力 | $1\ \text{atm} = 760\ \text{mmHg} = 101325\ \text{Pa}$ |
| 能量 | $1\ \text{cal} = 4.184\ \text{J}$ |

## 結構判斷的三層順序

[分子表達](/chem-molecules) 與 [化學鍵](/chem-chemical-bonding) 講的是同一套流程的前後段：

1. **算電子**：$E = \dfrac{(V_{\text{總}} \pm q) - 8\cdot\#X}{2}$（外圍是 H 改扣 2）→ 得孤對數 E。
2. **判幾何**：立體數 $\text{SN} = X + E$ → 電子幾何；扣掉孤對 → 分子幾何（VSEPR）。
3. **判性質**：形狀對稱且外圍原子全同 → 非極性；否則極性 → 決定分子間作用力 → 決定沸點。

| SN | 電子幾何 | 混成 |
|---:|---|---|
| 2 | 直線 | sp |
| 3 | 三角平面 | sp² |
| 4 | 四面體 | sp³ |
| 5 | 三角雙錐 | sp³d |
| 6 | 八面體 | sp³d² |
