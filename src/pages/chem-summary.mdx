## 三種「能階」不要混用

三條能階公式長得像，但隨 n 的走向**完全相反**，這是最常見的失分點：

| 模型 | 公式 | 隨 n 變化 | 什麼時候用 |
|---|---|---|---|
| 一維盒中質點 | $E_n = \dfrac{n^2h^2}{8mL^2}$ | $\propto n^2$，往上**越開** | 題目講「箱子、井、被關住的粒子」 |
| 氫原子（波耳） | $E_n = -13.6\dfrac{Z^2}{n^2}\ \text{eV}$ | $\propto -\dfrac{1}{n^2}$，往 0 **收斂** | 氫或類氫離子（只有 1 個電子） |
| 多電子原子 | 無單一公式，用 **n+l 規則** | n+l 大則高，相同則 n 大者高 | 填電子順序、比某兩個軌域誰低 |

盒中質點的能階越往上越疏，因為它被硬邊界關住。氫原子的能階越往上越密並收斂到 0，因為電子終究會脫離原子核。**看到負號就是波耳。**

## 量子論公式同源

下面每一條都在算同一件事，只是換單位或換問法，核心只有 $\left(\dfrac{1}{m^2} - \dfrac{1}{n^2}\right)Z^2$ 這一塊：

| 要算什麼 | 公式 | 單位 |
|---|---|---|
| 一個光子的能量 | $E = h\nu = \dfrac{hc}{\lambda}$ | J |
| 考場速算 | $E(\text{eV}) = \dfrac{1240}{\lambda(\text{nm})}$ | eV |
| 躍遷能量差 | $\Delta E = 13.6\,Z^2\left(\dfrac{1}{m^2}-\dfrac{1}{n^2}\right)$ | eV |
| 躍遷頻率 | $\nu = 3.3\times10^{15}\,Z^2\left(\dfrac{1}{m^2}-\dfrac{1}{n^2}\right)$ | Hz |
| 躍遷波長 | $\lambda = \dfrac{90}{Z^2\left(\frac{1}{m^2}-\frac{1}{n^2}\right)}$ | nm |
| 光電效應 | $h\nu = \Phi + E_K$，低限頻率 $\nu_0 = \dfrac{\Phi}{h}$ | J 或 eV |
| 物質波 | $\lambda = \dfrac{h}{mv} = \dfrac{h}{p}$ | m |

**常數**：$h = 6.626\times10^{-34}$ J·s｜$c = 3.00\times10^8$ m/s｜$1\ \text{eV} = 1.602\times10^{-19}$ J｜$a_0 = 0.529$ Å｜$N_A = 6.022\times10^{23}$ /mol

## Zeff 一個量帶動四個趨勢

有效核電荷 $Z_{\text{eff}} = Z - \sigma$（Z 是核電荷、$\sigma$ 是內層電子的遮蔽）。四個週期性的量全部由它決定，**背這一條就好，不必背四張趨勢圖**：

| 量 | 與 Zeff 的關係 | 同週期往右 | 同族往下 |
|---|---|---|---|
| 原子半徑 | Zeff 大 → 拉得緊 → **小** | 變小 | 變大 |
| 游離能 IE | Zeff 大 → 難拔 → **大** | 變大 | 變小 |
| 電子親和力 EA | Zeff 大 → 愛收 → **大** | 變大 | 變小 |
| 電負度 EN | Zeff 大 → 搶得贏 → **大** | 變大 | 變小 |

一句話：**Zeff 大、半徑小 → 其餘三個都大。** 需要單獨記的例外只有四個：

- **Be→B** 游離能下降：2s 穿透深、遮蔽了 2p。
- **N→O** 游離能下降：O 有一個軌域塞了 2 個電子，斥力大反而好拔。
- **EA 最大是氯不是氟**：F 半徑太小、2p 太擠，加電子放熱反而少。
- **N 的 EA 特別小**：2p³ 半滿已穩，不想再收。

## 計量與單位骨架

任何計算題都走同一條路，三步各乘一個 unit factor：

1. **已知量（g／個／L）→ mol**：乘 $\dfrac{1}{M}$、$\dfrac{1}{N_A}$ 或 $\dfrac{1}{22.4}$。
2. **mol → mol**：乘 $\dfrac{\text{目標係數}}{\text{已知係數}}$，這一步才跨到目標物。
3. **mol → 目標量**：乘 $M$、$N_A$ 或 $22.4$，換回題目要的單位。

| 常用換算 | 乘上這個因子 |
|---|---|
| 質量 → mol | $\dfrac{1\ \text{mol}}{M\ \text{g}}$ |
| 粒子數 → mol | $\dfrac{1\ \text{mol}}{N_A\ 個}$ |
| 氣體體積 → mol（STP） | $\dfrac{1\ \text{mol}}{22.4\ \text{L}}$ |
| 濃度 → mol | $\times V(\text{L})$ |
| 壓力 | $1\ \text{atm} = 760\ \text{mmHg} = 101325\ \text{Pa}$ |
| 能量 | $1\ \text{cal} = 4.184\ \text{J}$ |
| 溫度 | $K = ^\circ\text{C} + 273.15$（**加法偏移，不能當乘法因子**） |

反向就把因子倒過來寫。溫度是唯一不能用乘法因子處理的，因為它有偏移量。

## 結構判斷的三層順序

從分子式判到沸點，固定走這三步：

1. **算電子**：$E = \dfrac{(V_{\text{總}} \pm q) - 8\cdot\#X}{2}$（外圍是 H 改扣 2）→ 得孤對數 E。陰離子加電荷、陽離子減。
2. **判幾何**：立體數 $\text{SN} = X + E$ → 電子幾何，扣掉孤對 → 分子幾何。
3. **判性質**：形狀對稱且外圍原子全同 → 非極性，否則極性 → 決定分子間作用力 → 決定沸點。

| SN | 電子幾何 | 混成 | 未混成 p |
|---:|---|---|---:|
| 2 | 直線 | sp | 2 |
| 3 | 三角平面 | sp² | 1 |
| 4 | 四面體 | sp³ | 0 |
| 5 | 三角雙錐 | sp³d | 0 |
| 6 | 八面體 | sp³d² | 0 |

分子間作用力由弱到強：**London 色散力 ＜ 偶極－偶極力 ＜ 氫鍵 ＜ 離子－離子力**。比沸點時先比作用力種類，再比分子量，最後比接觸面積。
