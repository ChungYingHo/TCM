## 一、腦神經與脊神經

周邊神經系統（peripheral nervous system，PNS）由**腦神經**、**脊神經**與**神經節**構成，負責把訊息帶進中樞、把指令帶出中樞。

<div class="overflow-x-auto print:overflow-visible">

| | 腦神經（cranial nerve） | 脊神經（spinal nerve） |
|---|---|---|
| 對數 | **12 對** | **31 對** |
| 從哪裡出來 | 腦，主要是腦幹 | 脊髓 |
| 分佈範圍 | 主要在頭頸部，迷走神經是唯一的例外 | 頸部以下的軀幹與四肢 |
| 成分 | 純感覺、純運動、混合三種都有 | 全部是混合神經 |

</div>

腦神經的編號**由頭側往尾側排**，本篇一律寫成 CN1 到 CN12。課本與考卷常用**羅馬數字**印同一組編號，換算規則只有三個字母加一條方向：

- **I＝1、V＝5、X＝10**。
- 小的寫在大的**左邊**是**減**：IV＝5−1＝4、IX＝10−1＝9。
- 小的寫在大的**右邊**是**加**：VI＝5＋1＝6、VIII＝5＋3＝8、XII＝10＋2＝12。

所以 I、II、III、IV、V、VI、VII、VIII、IX、X、XI、XII 就是 CN1 到 CN12。

31 對脊神經的分節：**頸 8、胸 12、腰 5、薦 5、尾 1**。每一對都由背根（感覺）與腹根（運動）合併而成，所以全部是混合神經。

| CN2 | 視神經 | optic | 感覺 | 視覺 |
| CN3 | 動眼神經 | oculomotor | 運動＋副交感 | 四條眼外肌、提上眼瞼肌、縮瞳、水晶體調節 |

| CN7 | 顏面神經 | facial | 混合＋副交感 | 表情肌、舌前三分之二味覺、淚腺與唾液腺 |

</div>

**三叉神經的三個分支**是它名字的由來，由上而下分別是**眼支（V1，ophthalmic）**、**上頜支（V2，maxillary）**、**下頜支（V3，mandibular）**。三支都管感覺，**只有下頜支同時帶運動纖維**去支配咀嚼肌。角膜反射的傳入走的是眼支。

## 三、按性質分三類

| 類 | 哪幾對 | 怎麼記 |
|---|---|---|
| **純感覺** | **CN1、CN2、CN8** | 嗅、視、聽（含平衡），三個特殊感覺 |
| **純運動** | CN3、CN4、CN6、CN11、CN12 | 三對管眼球，兩對管頸與舌 |
| **混合** | CN5、CN7、CN9、CN10 | 臉、舌、咽喉這些既要動也要感覺的地方 |

純感覺的三對正好是「有專屬感覺器官」的那三種感覺：鼻子、眼睛、耳朵。其餘的感覺（觸壓痛溫、味覺）都夾在混合神經裡送。

## 四、腦幹起源：一、一、二、四、四

由上往下數，每個區域出幾對是固定的。

| 起源 | 幾對 | 哪幾對 |
|---|---|---|
| 大腦（端腦） | **1** | CN1 嗅神經 |
| 間腦 | **1** | CN2 視神經 |
| 中腦 | **2** | CN3、CN4 |
| 橋腦 | **4** | CN5、CN6、CN7、CN8 |
| 延腦 | **4** | CN9、CN10、CN11、CN12 |

**1、1、2、4、4**，加起來剛好 12。

<Supplement>

**CN1 與 CN2 嚴格說不是真正的周邊神經。** 嗅神經是嗅球伸出來的，視神經是視網膜伸出來的，而嗅球與視網膜在發育上都是腦的一部分。兩者都包著**腦膜**（包在腦與脊髓外面的三層保護膜），髓鞘則由**寡突膠細胞**製造，而周邊神經的髓鞘是由許旺氏細胞製造的。這正是視神經受傷之後不像一般周邊神經那樣能再生的原因。

另外，CN6、CN7、CN8 實際上是從**橋腦與延腦的交界**冒出來的，習慣上仍歸在橋腦，記 1、1、2、4、4 就好。

</Supplement>

<RelatedNote title="腦幹三段各自管什麼" href="/bio-brain-1" to="腦的構造與功能">

- **中腦**：喚醒中樞、Edinger-Westphal 核、上丘管跳視、下丘管聽覺中繼。
- **橋腦**：睡眠中樞、呼吸調節中樞（限制吸氣）與長吸中樞（延長吸氣）。
- **延腦**：生命中樞（血管運動、心跳、呼吸）、化學敏感區、吞嚥中樞。

</RelatedNote>

## 五、四對副交感腦神經：CN3、CN7、CN9、CN10

副交感神經的節前纖維只從兩個地方離開中樞：**腦幹**與**薦部脊髓（S2 到 S4）**，因此副交感又稱**顱薦系統（craniosacral）**。從腦幹出去的就是這四對。

| 腦神經 | 副交感支配什麼 | 效果 |
|---|---|---|
| CN3 動眼 | 瞳孔括約肌、睫狀肌 | 縮瞳、水晶體變凸看近 |
| CN7 顏面 | 淚腺、頷下腺、舌下腺 | 流淚、分泌唾液 |
| CN9 舌咽 | 腮腺 | 分泌唾液 |
| CN10 迷走 | 心臟、肺、大部分消化道 | 心跳變慢、支氣管收縮、促進消化 |

編號記成 **3、7、9、10**。四對之中**迷走神經一條就包辦絕大部分內臟的副交感**，它也是唯一離開頭頸部、一路走到胸腔與腹腔的腦神經，名字裡的「迷走」講的正是這件事。

自主神經從中樞走到目標器官不是一條神經元到底，而是**兩段接力**：第一段叫**節前神經元**，細胞本體在中樞，軸突走到半路的神經節換手。第二段叫**節後神經元**，細胞本體就在那個神經節裡，軸突再接到器官上。交感與副交感都是這個兩段結構，差別在神經節擺的位置與節後釋放的傳遞物：

| | 副交感 | 交感 |
|---|---|---|
| 從哪裡離開中樞 | 腦幹與薦部脊髓 | 脊髓的胸腰段 |
| 神經節在哪 | 靠近目標器官，甚至埋在器官裡 | 靠近脊髓旁 |
| 節前傳遞物 | 乙醯膽鹼 | 乙醯膽鹼 |
| 節後傳遞物 | **乙醯膽鹼** | **正腎上腺素** |

## 六、三對控制眼球的腦神經：CN3、CN4、CN6

| 腦神經 | 支配的眼外肌 | 記法 |
|---|---|---|
| CN6 外旋神經 | 外直肌 | **LR₆** |
| CN4 滑車神經 | 上斜肌 | **SO₄** |
| CN3 動眼神經 | 內直肌、上直肌、下直肌、下斜肌 | **其餘四條全歸 3** |

CN3 另外還帶提上眼瞼肌（睜眼）與兩條眼內平滑肌的副交感纖維（縮瞳、看近）。

## 七、常見的腦神經損傷

下表用到兩個名詞。**複視（diplopia）**是兩眼看同一個東西時影像對不齊，變成看到兩個。**雙顳側偏盲**是兩眼各缺自己外側那半的視野。

<div class="overflow-x-auto print:overflow-visible">

| 神經 | 受損後的表現 |
|---|---|
| CN2 視神經 | 該眼失明。視交叉受壓則為雙顳側偏盲 |
| CN3 動眼 | 眼皮下垂、眼球偏向外下方、瞳孔放大且對光無反應 |
| CN4 滑車 | 往下看時複視，患者常把頭歪向健側 |
| CN5 三叉 | 三叉神經痛、臉部感覺喪失、咀嚼無力 |
| CN6 外旋 | 患側眼球無法外展，看向患側時複視 |
| CN7 顏面 | 貝爾氏麻痺，同側整張臉的表情肌癱瘓、眼睛閉不起來 |
| CN8 前庭耳蝸 | 聽力喪失、耳鳴、眩暈 |
| CN10 迷走 | 聲音沙啞、吞嚥困難、心跳加速 |
| CN12 舌下 | 伸舌時舌尖偏向患側 |

</div>

### 兩個容易混在一起的反射

| 反射 | 傳入 | 傳出 | 效果 |
|---|---|---|---|
| 瞳孔光反射 | **CN2** | **CN3** | 光照時縮瞳，兩眼同時 |
| 角膜反射 | **CN5** | **CN7** | 角膜被碰到時眨眼 |

一個是「看到光就縮瞳」，一個是「碰到就閉眼」，進去與出來的神經完全不同。

### 舌頭由四條腦神經分工

同一條舌頭，感覺、味覺、運動分屬不同神經，很容易混：

| 管什麼 | 哪一條 |
|---|---|
| 舌**前三分之二的味覺** | CN7 顏面 |
| 舌**前三分之二的一般感覺**（觸痛溫） | CN5 三叉（下頜支） |
| 舌**後三分之一的味覺與一般感覺** | CN9 舌咽 |
| **舌肌的運動** | CN12 舌下 |

味覺的完整內容見[嗅覺與味覺](/bio-sense-4)。

### 中樞性與周邊性顏面神經麻痺

| | 周邊性（貝爾氏麻痺） | 中樞性（如中風） |
|---|---|---|
| 受損位置 | CN7 這條神經本身 | 大腦皮質下行到腦幹裡顏面神經核的那段路徑 |
| 額頭 | **皺不起來** | **仍能皺** |
| 為什麼 | 整條神經都斷了 | 額部肌肉同時接受左右兩側大腦的輸入，單側受損還有另一側頂著 |
