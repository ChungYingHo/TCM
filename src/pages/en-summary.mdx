## 遇到生字，四步拆解

1. **切字首**——定方向或否定。
2. **切字根**——扛核心語意，通常在中間。
3. **切字尾**——多半只決定**詞性**，不改語意。
4. **回語境驗證**——拆出來的字面義在句子裡講得通嗎？

第 4 步不能省。字首字根給的是**線索不是答案**，考題常考的正是字面義與現行語意已經分家的字。例如 `exhaust` 的字面是「向外抽光」（`ex-` 出＋`haurire` 汲取），現在的「精疲力盡」是從「抽光」引申來的，不是字首本身帶有「盡」的意思。

## 常考字首

| 字首 | 意思 | 例 |
|---|---|---|
| `ex-`、`e-` | 出、向外 | exit、export、emit、exhaust |
| `in-`、`im-` | 進入 | inject、import、invade |
| `in-`、`im-`、`un-`、`dis-` | 否定 | incorrect、impossible、unable、disagree |
| `re-` | 回、再一次 | return、reject、revise |
| `de-` | 向下、相反、去除 | descend、decrease、defrost |
| `sub-` | 在下、次級 | submarine、subway、substitute |
| `pre-`、`pro-` | 之前、向前 | predict、preview、progress |
| `trans-` | 越過、轉換 | transport、translate、transform |
| `con-`、`com-` | 一起 | connect、compose、combine |
| `ad-` | 朝向 | adapt、adhere、advance |

> `in-`／`im-` 同時有「進入」與「否定」兩義，只能靠語境分：`import`（進口）是進入，`impossible`（不可能）是否定。

## 常考字根

| 字根 | 意思 | 例 |
|---|---|---|
| `-duc-`、`-duct-` | 引導 | conduct、reduce、introduce |
| `-spect-`、`-spic-` | 看 | inspect、respect、conspicuous |
| `-port-` | 搬運 | transport、export、portable |
| `-scrib-`、`-script-` | 寫 | describe、prescribe、manuscript |
| `-dict-` | 說 | predict、dictate、contradict |
| `-ject-` | 丟 | inject、reject、project |
| `-mit-`、`-miss-` | 送 | transmit、emit、mission |
| `-fer-` | 帶、承載 | transfer、refer、infer |
| `-tract-` | 拉 | attract、extract、contract |
| `-vert-`、`-vers-` | 轉 | convert、reverse、diverse |

## 字尾只改詞性

| 字尾 | 詞性 | 例 |
|---|---|---|
| `-tion`、`-sion`、`-ment`、`-ness`、`-ity` | 名詞 | action、decision、movement、kindness |
| `-ous`、`-al`、`-ive`、`-able`、`-ful` | 形容詞 | famous、national、active、readable |
| `-ize`、`-ify`、`-en` | 動詞 | realize、simplify、strengthen |
| `-ly` | 副詞（少數為形容詞） | quickly、friendly（形容詞） |

> 看到不認識的長字，先把字尾切掉再拆，剩下的部分才是語意主體。

## 讀文章時的取捨

| 情況 | 怎麼做 |
|---|---|
| 生字**不影響**句子主旨 | 跳過，繼續讀完整段 |
| 生字在**主詞或主要動詞** | 停下來拆，這個字錯整句就錯 |
| 生字重複出現 2 次以上 | 一定是關鍵字，查清楚並記下來 |
| 整段看不懂 | 先找連接詞定邏輯方向，再回頭補細節 |

**連接詞就是文章的路標**：

- 轉折：however、nevertheless、although、despite → 後面才是重點。
- 因果：therefore、thus、consequently、because → 前後是推論關係。
- 並列或遞進：moreover、furthermore、in addition → 同方向加強。
- 舉例：for instance、such as → 前面那句才是主張。
