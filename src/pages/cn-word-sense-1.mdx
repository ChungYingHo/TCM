## 一、「思」在《詩經》裡多半沒有意思

「思」平常的意思是思考、想念，但在《詩經》裡它經常只是**湊足音節用的語助詞，本身沒有意義**，讀音仍然是 ㄙ。

判準只有一條：**把「思」拿掉，句意完全不變，它就是語助詞。**

教育部《重編國語辭典修訂本》在「思」的助詞義項下正好給了三條書證，句首、句中、句末各一條。

<div class="overflow-x-auto print:overflow-visible">

| 位置 | 例句 | 出處 | 怎麼解 |
|---|---|---|---|
| 句首 | **思**樂泮水，薄采其芹 | 詩經・魯頌・泮水 | 發語詞，不翻譯。「泮水令人快樂啊，去採些水芹」 |
| 句中 | 無**思**不服，皇王烝哉 | 詩經・大雅・文王有聲 | 夾在句中湊音節。「沒有不歸服的」 |
| 句末 | 漢有游女，不可求**思** | 詩經・周南・漢廣 | 相當於「啊」。「漢水邊有出遊的女子，卻追求不到啊」 |

</div>

拿「無思不服」試一次就知道差別：把「思」當「思念」，會變成「沒有思念就不服從」，句子講不通。當語助詞刪掉，「無不服」＝沒有不歸服的，才通順。

「皇王烝哉」的**烝**是讚嘆語，《爾雅》訓「君」，《韓詩》訓「美」。整句是對君王的讚美，〈文王有聲〉八章每章都以「烝哉」收尾。

### 采芹與入泮

「思樂泮水，薄采其芹」後來變成**入學**的典故，這條線索要記完整：

| 名詞 | 意思 |
|---|---|
| 泮宮 | 西周諸侯設的學校，前面有半圓形的水池 |
| 泮水 | 泮宮前那個半圓形水池。明清的府學縣學也照著建 |
| 入泮 | 考中秀才、成為生員時要行入學禮，稱為入泮 |
| 采芹 | 因〈泮水〉有「薄采其芹」，考中秀才又稱采芹，秀才也稱采芹人 |

所以「采芹之喜」「泮宮采芹」都是賀人考取秀才的話，與吃芹菜無關。

## 二、「適」只有兩個讀音，卻通到三個字

「適」的難點不在讀音多，而在它**借去當三個不同的字用**。先把兩個讀音分開：

<div class="overflow-x-auto print:overflow-visible">

| 讀音 | 詞性 | 意思 | 書證 |
|---|---|---|---|
| ㄕˋ | 形 | 舒服、自得 | 舒適、安適 |
| ㄕˋ | 動 | 往、到 | 《論語・子路》：子**適**衛，冉有僕 |
| ㄕˋ | 動 | 女子出嫁 | 潘岳〈寡婦賦〉：**適**人而所天又殞 |
| ㄕˋ | 動 | 相合、相配 | 《後漢書・荀爽傳》：截趾**適**履 |
| ㄕˋ | 動 | 順從 | 《樂府詩集》：處分**適**兄意 |
| ㄕˋ | 副 | 僅、只 | 《戰國策・秦策》：疑臣者不**適**三人 |
| ㄕˋ | 副 | 剛才、方才 | 《韓非子》：王**適**有言（適才） |
| ㄕˋ | 副 | 恰巧 | 《史記・灌夫傳》：**適**有萬金良藥 |
| ㄕˋ | 動 | **通「謫」**，放逐 | 《漢書・儒林傳》：敺**適**戍以立號 |
| **ㄉㄧˊ** | 名 | **通「嫡」**，正妻所生的兒子 | 《左傳・文公十八年》：殺**適**立庶 |
| **ㄉㄧˊ** | 名 | **通「敵」** | 《史記・田單列傳》：**適**不及距 |
| **ㄉㄧˊ** | 動 | **專主、作主** | 《詩經・衛風・伯兮》：誰**適**為容 |

</div>

三個通假字一起記：**謫（放逐）、嫡（正妻的兒子）、敵（敵人）**，加上「專主」一個本義，就是「適」的全部難點。

「誰適為容」出自〈伯兮〉，前一句是「豈無膏沐」。丈夫從軍去了，妻子說：難道沒有潤髮的油膏嗎？只是**要為誰打扮呢**。這裡的「適」是專主、作主，讀 ㄉㄧˊ。

「適戍」是把人放逐去戍守邊疆。重編本把這個義項收在 ㄕˋ 底下，但傳統反切作「陟革切」，讀同「謫」。題目問的多半是**字義（通謫、放逐）**，遇到問讀音的題目兩種標法都見過，看清楚題目要的是哪一本的標準。

## 三、《論語・里仁》：無適也，無莫也

> 子曰：「君子之於天下也，無適也，無莫也，義之與比。」

三個字都不能用今義讀：

| 字 | 這裡的意思 | 白話 |
|---|---|---|
| 適 | 專主、一定要這樣 | 絕對如此 |
| 莫 | 不肯、一定不這樣 | 絕不如此 |
| 比 | 親近、依從 | 依照、跟隨 |

整句是：**君子面對天下的事，沒有非得如此的成見，也沒有絕不如此的堅持，只依照「義」來衡量。**

這裡的「適」正是第二節那個「專主」義，與〈伯兮〉的「誰適為容」同一個用法，只是這裡當態度講。孔子反對的是固執拘泥，主張通權達變，判斷的唯一標準是事情合不合宜。

## 四、「差」有六個讀音

「差」是讀音最多的常見字之一，六個讀音各管一組意思。

<div class="overflow-x-auto print:overflow-visible">

| 讀音 | 詞性 | 意思 | 例 |
|---|---|---|---|
| ㄔㄚ | 名 | 缺失、錯誤 | 差錯 |
| ㄔㄚ | 名 | 區別、不同 | 《荀子》：長幼之**差** |
| ㄔㄚ | 名 | 兩數相減的結果 | 差數、公差 |
| ㄔㄚ | 動 | 失誤、不當 | 曆久必**差** |
| ㄔㄚ | 副 | 尚、略、還 | 差強人意 |
| ㄔㄚˋ | 形 | 不好 | 成績很差 |
| ㄔㄚˋ | 動 | 欠缺、短少 | 還差三個 |
| **ㄔㄞ** | 動 | 派遣 | **差**遣、**差**人前往 |
| **ㄔㄞ** | 名 | 受派遣的人、被派的事 | 欽差、出差 |
| **ㄔㄞˋ** | 動 | **病癒（通「瘥」）** | 《三國志》：操積苦頭風眩，佗針，隨手而**差** |
| **ㄘ** | 形 | 不整齊 | 參**差**不齊 |
| **ㄘ** | 動 | 分別、區分 | **差**等 |
| **ㄘㄨㄛ** | 動 | 搓磨、搓洗 | **差**去泥沙 |

</div>

最容易失分的是 **ㄔㄞˋ「病癒」**與 **ㄘㄨㄛ「搓磨」**這兩個，因為現代口語完全用不到。「差強人意」的「差」讀 ㄔㄚ、意思是「還算」，不是「差勁」，這句成語是稱讚不是批評。

## 五、遇到破音字的固定判法

三個步驟，順序不能顛倒：

1. **先看詞性。** 破音多半跟著詞性換。「差」當名詞是 ㄔㄚ（差別），當動詞派遣是 ㄔㄞ。
2. **再看是不是通假。** 古文裡的字讀不通，先想它有沒有借去當別的字用。「適」不通就試「謫、嫡、敵」。
3. **最後看它是不是根本沒有意思。** 《詩經》《楚辭》裡的「思、其、之、彼、言、薄」常常只是湊音節的虛詞。刪掉句意不變就是虛詞。

順序反過來會出事：先猜字義、再回頭湊讀音，容易把「無思不服」讀成「沒有思念就不服從」。
