## 三篇「膜」怎麼串起來

膜的三篇是同一個故事的三段，考題常把它們混在一題裡問：

1. **[bio-cell-4](/bio-cell-4) 建構造**——磷脂雙層是屏障，膜蛋白是穿過屏障的裝置。
2. **[bio-cell-5](/bio-cell-5) 讓東西過去**——同樣那些膜蛋白，當通道就是促進性擴散，當幫浦就是主動運輸。
3. **[bio-cell-6](/bio-cell-6) 讓訊息過去**——訊息不必讓分子本身過膜，受體在膜上接、把訊號轉成胞內的第二傳訊者。

| 分子要進細胞 | 走哪條 | 出處 |
|---|---|---|
| 小的非極性（O₂、CO₂） | 直接穿磷脂雙層 | [4](/bio-cell-4) |
| 小的極性、離子 | 通道／載體蛋白（順濃度） | [5](/bio-cell-5) |
| 逆濃度梯度 | 幫浦（耗 ATP）或共同運輸（借梯度） | [5](/bio-cell-5) |
| 大分子、顆粒 | 胞吞／胞吐（囊泡，膜本身變形） | [5](/bio-cell-5) |
| **訊息**（親水訊號分子） | **分子本身不進去**，膜受體轉手 | [6](/bio-cell-6) |

> 唯一會「自己進去」的訊號分子是**脂溶性**的（類固醇、甲狀腺素、NO），它們穿膜找**細胞內受體**——這正是 4 的「非極性小分子可直接穿膜」在 6 的應用。

## 內膜系統接得上訊號傳遞

[bio-cell-2](/bio-cell-2) 的分泌路徑與 [bio-cell-6](/bio-cell-6) 的訊號傳遞是同一條產線的前後段，分開背會漏掉銜接處：

| 段 | 發生什麼 | 出處 |
|---|---|---|
| 製造 | 核糖體 → 粗糙 ER → 高基氏體 → 分泌小泡 → 胞吐 | [2](/bio-cell-2) |
| 上崗 | 膜受體（GPCR、RTK）就是走這條路線送到細胞膜的膜蛋白 | [2](/bio-cell-2)＋[4](/bio-cell-4) |
| 接訊號 | 受體在膜上被配體活化，訊號轉進胞內 | [6](/bio-cell-6) |
| 下崗 | 受體被胞吞收回，送溶體分解或回收再用 | [5](/bio-cell-5)＋[6](/bio-cell-6) |

> **鈣離子是三篇的交會點**：膜幫浦把 Ca²⁺ 抽出胞外與抽進 ER（[4](/bio-cell-4)、[5](/bio-cell-5)），造出胞外／ER 比胞質高一萬倍以上的梯度；訊號一來 IP₃ 打開 ER 通道，Ca²⁺ 順著這個梯度衝進胞質當第二傳訊者（[6](/bio-cell-6)）。**先有幫浦造梯度，才有訊號能用梯度。**

## 原核 vs 真核

| | **原核 prokaryote** | **真核 eukaryote** |
|---|---|---|
| 物種 | 細菌、古菌 | 原生生物、真菌、植物、動物 |
| 大小 | 1–5 µm | 10–100 µm（約大 10 倍） |
| 細胞核 | 無膜核（DNA 在**類核 nucleoid**） | 有膜核 |
| 膜性胞器 | 無 | 有 |
| DNA | **環狀**裸露 ＋ 質體 | **線狀**纏組蛋白、另在粒線體、葉綠體 |
| 核糖體 | **70S** | **80S** |

## 胞器速查總表

<div class="overflow-x-auto print:overflow-visible">

| 胞器 | 膜 | 功能重點 | 備註（內膜系統／動植物） |
|------|----|----------|------------------------------|
| **細胞核** nucleus | 雙層 | 儲 DNA、核仁做 rRNA／核糖體次單位 | 核套膜與粗糙 ER 相連、**屬內膜系統** |
| **核糖體** ribosome | 無膜 | 讀 mRNA 合成蛋白（轉譯） | 原核 70S／真核 80S、游離 vs 附著 |
| **內質網** ER | 單層 | **SER**：脂質／固醇、解毒、儲鈣、代謝肝醣、**RER**：分泌／膜蛋白、醣基化、製膜 | **內膜系統**、占全細胞總膜量＞50% |
| **高基氏體** Golgi | 單層 | 修飾醣鏈、分類、包裝、出貨 | **內膜系統**、cis 收／trans 出 |
| **溶體** lysosome | 單層 | 酸性水解酶（pH≈5 最活躍）消化、吞噬／自噬 | **內膜系統**、動物為主 |
| **液泡** vacuole | 單層 | 食泡／伸縮泡／中央液胞（撐膨壓） | **內膜系統**、中央液胞＝**植物特有** |
| **粒線體** mitochondrion | 雙層 | 細胞呼吸→ATP（內膜電傳鏈＝氧化磷酸化） | **非**內膜系統、內共生、自有 DNA／70S |
| **葉綠體** chloroplast | 雙層 | 光合（類囊體＝光反應、基質＝卡爾文） | **非**內膜系統、**植物**／藻、內共生 |
| **過氧化體** peroxisome | 單層 | catalase 解 H₂O₂、脂肪酸代謝 | **非**內膜系統 |
| **蛋白酶體** proteasome | 無膜 | 降解被**泛素**標記的壞蛋白（UPS） | 非膜、非胞器 |
| **中心體** centrosome | — | MTOC、長紡錘絲、一對中心粒（9×3） | **動物特有**、真菌／多數植物無 |

</div>

> **雙層膜胞器只有 3 個**：核、粒線體、葉綠體，也只有這 3 個有自己的 DNA（內共生）。

## 內膜系統（endomembrane system）

- **七成員**：核套膜、內質網（ER）、高基氏體（Golgi）、溶體（lysosome）、液泡（vacuole）、運輸小泡、細胞膜。
- **不屬**內膜系統：**粒線體、葉綠體、過氧化體、核糖體、蛋白酶體**。
- **分泌路徑**：核糖體 → 粗糙 ER → 高基氏體 → 分泌小泡 → 胞吐（exocytosis）。

## 中心粒／基體（9×3） vs 纖毛／鞭毛（9+2）

| | **中心粒／基體** centriole / basal body | **纖毛／鞭毛軸絲** axoneme |
|---|---|---|
| 微管排列 | **9×3**（9 組三聯體，無中央） | **9＋2**（9 對雙體＋2 中央） |
| 動力 | — | 動力蛋白 dynein 驅動擺動 |
| 備註 | 基體＝中心粒構造 | 可動 9+2、不動 9+0 |

## 細胞連結（cell junction）

| 連結 | 功能 | 接的骨架／例 |
|------|------|--------------|
| **緊密接合** tight junction | 封住間隙、**防滲漏屏障** | 小腸、膀胱、血腦屏障 |
| **胞橋小體** desmosome | **鉚釘、抗拉扯** | 接中間絲、皮膚、心肌 |
| **裂隙接合** gap junction | 離子／小分子**直接互通** | 心肌同步收縮 |
| **胞間連絲** plasmodesmata | 穿細胞壁、連通細胞質 | **植物**、對標 gap junction |

> **植物無上述三種動物連結**，改用胞間連絲。**心肌**＝胞橋小體（抗拉）＋裂隙接合（同步電訊號）。

## 動物 vs 植物：特有構造

| 動物特有／為主 | 植物特有 |
|----------------|----------|
| 中心體、發達溶體、**ECM**、三種細胞連結 | **細胞壁、葉綠體、中央液胞、胞間連絲** |

## 顯微鏡 ＆ 大小（快速）

| 顯微鏡 | 解析度 | 特點 |
|--------|--------|------|
| 光學 LM | ~0.2 µm | 可看活細胞 |
| 電子 SEM／TEM | ~2 nm（好 100 倍） | SEM 表面／TEM 內部、只能看死樣本 |
| 共軛焦 confocal | 光學級 | 針孔做光學切片 |

**大小量級**：真核細胞 10–100 µm｜細菌 1–5 µm｜粒線體 1–10 µm｜細胞核 ~5 µm｜核糖體 ~25 nm。
