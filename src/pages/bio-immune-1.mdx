## 一、先天免疫的屏障與細胞

**先天免疫（innate immunity）**又稱非專一性免疫，指對任何入侵者都用同一套現成裝備應付、反應立即、事後不留記憶的防禦。**後天免疫（adaptive immunity）**又稱適應性免疫或專一性免疫，指針對某一個特定入侵者量身打造受體與抗體、反應慢但會留下記憶的防禦。

<div class="overflow-x-auto print:overflow-visible">

| 比較項 | 先天免疫 | 後天免疫 |
|---|---|---|
| 專一性 | 無，對所有病原體反應相同 | **有**，只認特定抗原 |
| 反應速度 | **快**，數分鐘到數小時 | 慢，初次需 5 到 10 天 |
| 記憶 | **無**，每次感染反應強度相同 | **有**，記憶細胞使二次反應更快更強 |
| 成員 | 屏障、吞噬細胞、自然殺手細胞、發炎反應、補體、干擾素、類鐸受體 | B 細胞、T 細胞、抗體 |
| 出現在 | 所有動物，包含昆蟲等無脊椎動物 | **只有脊椎動物**，不限於靈長類 |

</div>

第一層是**屏障（barrier defense）**，也就是不讓病原體進來的物理與化學阻擋：皮膚的角質層、消化道與呼吸道的黏液、呼吸道的纖毛、胃酸、皮脂的酸性。化學屏障中的**溶菌酶（lysozyme）**是能分解細菌細胞壁的酵素，存在於眼淚、唾液與鼻腔黏液中，眼睛與呼吸道靠它保護表面。干擾素與補體不是屏障，它們是病原體已經進來以後才動用的分子武器。病原體突破屏障後，由下列細胞接手。

<div class="overflow-x-auto print:overflow-visible">

| 細胞 | 來源與位置 | 做什麼 |
|---|---|---|
| **嗜中性球（neutrophil）** | 血中**數目最多**的白血球 | **最主要的吞噬細胞**。受感染組織釋出的化學訊號吸引，最早大量趕到現場 |
| **巨噬細胞（macrophage）** | 由血中**單核球（monocyte）**離開血管、進入組織後分化而成 | 大型吞噬細胞。有些游移全身，有些長駐脾臟等器官。也能呈現抗原給 T 細胞 |
| **樹突細胞（dendritic cell）** | 聚集在與外界接觸的組織，例如皮膚 | 在周邊組織會吞噬，遷移到淋巴結成熟後轉為專職**呈現抗原**，是啟動後天免疫最主要的一種 |
| **嗜酸性球（eosinophil，又譯嗜伊紅球）** | 黏膜層下方 | 對抗**多細胞寄生蟲**。黏在蟲體外壁後釋出破壞性酵素使其原生質流失，**不是把蟲吞掉** |
| **肥大細胞（mast cell）與嗜鹼性球（basophil）** | 前者在組織中，後者在血中 | 顆粒裡帶**組織胺與肝素**，是發炎與過敏的引爆點 |

</div>

單核球是巨噬細胞的先驅細胞，紅血球與淋巴球都不是。感染中華肝吸蟲、蛔蟲這類多細胞寄生蟲時，血中升高的是嗜酸性球。**自然殺手細胞（natural killer cell，NK 細胞，又譯天然殺手細胞）**是先天免疫中負責殺死壞掉的自體細胞的一群淋巴球。它巡邏全身，檢查細胞表面的**第一類主要組織相容性複合體（major histocompatibility complex class I，簡稱第一類 MHC）**，這是幾乎每個有核細胞表面都有的一種自體標記蛋白，作用是把細胞內部的蛋白質片段展示出來。

- 健康細胞表面第一類 MHC 數量正常，NK 細胞的**抑制型受體**與它結合就收手。
- 被病毒感染或癌變的細胞常把第一類 MHC 壓低，抑制訊號消失，NK 細胞的**活化型受體**又接上病毒誘導出的表面配體，兩相加總就啟動攻擊。
- NK 細胞**不吞噬**標的細胞，而是釋出化學物質使它凋亡。它屬於先天免疫，**沒有記憶功能**，再遇到同一個抗原不會反應更快。它的抑制型受體結合的是**第一類**而不是第二類 MHC。

<RelatedNote title="白血球種類與淋巴系統" href="/bio-circ-1" to="循環與呼吸">

- 五種白血球中**嗜中性球數目最多**，單核球離開血管後分化成巨噬細胞。
- 所有血球都源自骨髓的多潛能幹細胞，**淋巴幹細胞**產生 B 細胞與 T 細胞。
- **初級淋巴器官只有骨髓與胸腺**，淋巴結與脾臟屬次級淋巴器官。

</RelatedNote>

## 二、發炎反應與先天免疫的分子武器

**發炎反應（inflammatory response）**是組織受傷或感染後，局部出現紅、腫、熱、痛的先天免疫反應。

<Figure src="/notes/bio-immune/inflammation.webp" alt="局部發炎反應三個步驟的圖解。第一格為碎片刺入皮膚帶入病原體，肥大細胞釋出訊息分子使微血管擴張，巨噬細胞釋出其他訊息分子，微血管中有紅血球與嗜中性球。第二格為微血管管徑與通透性變大，液體流出，吞噬細胞由血管遷移到組織中。第三格為嗜中性球在受傷處進行吞噬作用消化病原體與細胞碎屑" caption="圖中左下角標籤被裁切的字是紅血球。第一步的關鍵是肥大細胞釋出組織胺使微血管擴張，第二步微血管通透性上升讓抗微生物肽進入組織，第三步由嗜中性球清場。" source="Campbell 生物學・下冊，圖 43.8" />

1. 受傷處的**肥大細胞釋出組織胺（histamine）**，使鄰近**微血管擴張**，巨噬細胞釋出其他訊息分子以增加局部血流。
2. 微血管的**管徑與通透性同時增加**，血漿中的抗微生物肽得以滲進組織，免疫細胞釋出的訊號吸引更多吞噬細胞離開血管。
3. **嗜中性球**在受傷處消化病原體與細胞碎屑。
4. 組織癒合。

紅與熱來自血流增加，腫來自通透性上升使液體滲入組織，痛與**前列腺素（prostaglandin）**等物質有關。發炎早期是微血管**擴張**而不是收縮。組織胺造成的是紅腫癢，它**沒有止痛與消炎的功能**，抗組織胺藥擋的正是組織胺造成的微血管擴張與通透性增加。嗜鹼性球遷移到發炎部位後分泌的是**肝素（heparin）**。免疫細胞到達發炎部位有固定順序，依序是**嗜中性球（數小時內，最早最多）、單核球（一到兩天，進組織後成為巨噬細胞）、淋巴球（最慢，屬後天免疫）**。全身性反應包括發燒（活化的巨噬細胞釋出的物質把下視丘的體溫定點調高）與白血球數目在數小時內增加數倍。細菌感染引起無法控制的全身性發炎，會造成危及生命的**敗血性休克**。

**病原相關分子模式（pathogen-associated molecular pattern，PAMP）**是病原體共有而宿主沒有的分子特徵，例如細菌的細胞壁成分與病毒的核酸。辨識它的受體叫**類鐸受體（Toll-like receptor，TLR）**，接上以後啟動訊息傳導、引發發炎與抗病毒反應。

<div class="overflow-x-auto print:overflow-visible">

| 受體 | 認什麼 | 位置 |
|---|---|---|
| **TLR4** | 革蘭氏陰性菌的**脂多醣（LPS）** | 細胞膜表面 |
| **TLR5** | 細菌的**鞭毛蛋白（flagellin）** | 細胞膜表面 |
| **TLR3** | **雙股 RNA**，病毒複製時的產物 | **囊泡（內涵體）內** |
| **TLR9** | 細菌的 **CpG DNA** | **囊泡（內涵體）內** |

</div>

規律是：認細胞外細菌構造的 TLR 擺在細胞膜上，認核酸的 TLR 擺在囊泡裡，因為核酸要等病原體被吞進來、在囊泡中拆解後才露得出來。革蘭氏陰性菌外膜上的**脂多醣（lipopolysaccharide，LPS）**是**內毒素（endotoxin）**，它是細菌構造的一部分而不是分泌出去的外毒素，加熱到 100 度也破壞不了。它接上 TLR4 後活化 **NF-κB**（一種平時被扣在細胞質、活化後才進細胞核開啟發炎相關基因的轉錄因子）等路徑而引發發炎。

先天免疫還有兩種可溶性的分子武器。

- **抗微生物肽（antimicrobial peptide）**：破壞病原體胞膜完整性的短肽，作用範圍廣。
- **干擾素（interferon，IFN）**：受病毒感染的細胞分泌的蛋白質。它的作法不是救自己，而是**誘導鄰近尚未受感染的細胞**合成可抑制病毒增殖的物質，先把周圍變成抗病毒狀態，藉此限制病毒在體內的散布。抑制病毒複製效果最好的是 **IFN-α**。另有一型由白血球分泌的干擾素負責活化吞噬細胞、加強其吞噬能力。

**補體系統（complement system）**是血漿中約 30 種以不活化狀態循環的蛋白質，編號 C1 到 C9。古典、凝集素、替代三條活化途徑各有起點，但**都匯流到 C3 被切成 C3a 與 C3b**。補體有三個功能：

- **調理（opsonization）**：C3b 共價黏在病原體表面，吞噬細胞上有 C3b 受體，等於幫病原體裝上把手。
- **發炎與趨化**：小片段 C3a 與 C5a 招募並活化吞噬細胞到感染處。
- **溶解**：組成**攻膜複合物（membrane attack complex，MAC）**，也就是 **C5b、C6、C7、C8 再加十幾個 C9** 聚合成的孔道，水和離子湧入使細胞膨脹溶解。**C3 與 C4 都不是攻膜複合物的成員**。

把 C3 切開的酵素稱為 **C3 轉換酶**，把 C5 切開、開啟攻膜複合物那一段的則是 **C5 轉換酶（C5 convertase）**，後者的組成就是在 C3 轉換酶上再加一個 C3b：古典途徑為 **C4b2a3b**，替代途徑為 **C3b₂Bb**。補體威力太強，需要煞車蛋白防止誤傷自身細胞。**DAF（decay-accelerating factor，衰變加速因子）**認的是黏在自身細胞上的 **C3b**，把已經組好的 C3 轉換酶拆散（加速衰變），後面就組不起來。補體是血漿蛋白，**不是自然殺手細胞釋放出來的**。

## 三、抗原、淋巴器官與淋巴球的成熟

**抗原（antigen）**是能被淋巴球受體辨識並引發免疫反應的分子，多為蛋白質或多醣。抗原上真正被受體結合的那一小段構造稱為**抗原決定位（epitope，又稱表位）**。一個蛋白質抗原表面通常帶有**不只一個**抗原決定位，因此一個抗原可以同時挑中好幾株淋巴球。以有感染力的病毒顆粒而言，抗原決定位分布在顆粒的**表面**而非內部，抗體才碰得到。免疫系統不攻擊自身分子的性質稱為**自我耐受（self-tolerance）**。

<div class="overflow-x-auto print:overflow-visible">

| 分類 | 器官 | 角色 |
|---|---|---|
| **初級淋巴器官** | **骨髓、胸腺** | 淋巴球生成與**成熟**的地方。B 細胞在骨髓成熟，T 細胞遷到胸腺成熟 |
| **次級淋巴器官** | 淋巴結、脾臟、扁桃腺、**派爾斑** | 成熟淋巴球**遇到抗原並被活化**的地方 |

</div>

**派爾斑（Peyer's patch，又譯培氏斑塊或貝爾節）**是小腸黏膜下的淋巴濾泡聚集，表面有特化的**微皺褶細胞（M 細胞）**把腸腔中的抗原送進來，屬於腸道黏膜免疫系統，與腸道內蛋白質的分解無關。

T 細胞在胸腺要通過兩道篩選才准出關。

- **正選擇（positive selection）**在胸腺**皮質**：只有受體能與自身 MHC 分子結合的 T 細胞才活下來，確保它日後看得懂自己人的 MHC。
- **負選擇（negative selection）**在胸腺**髓質**：受體與自身抗原結合得太強的 T 細胞被刪除。**避免自體免疫的是這一道。**
- 正選擇留下「看得懂自己 MHC 的」，負選擇刪掉「會攻擊自己的」。B 細胞在骨髓也有類似機制，能與自體抗原作用的 B 細胞在發育過程中就被去活化或剔除。

## 四、抗原受體、MHC 與抗原呈現

B 細胞表面的抗原受體與它日後分泌出去的抗體，是同一個 Y 形分子的兩種版本。

<Figure src="/notes/bio-immune/antibody-structure.webp" alt="B 細胞抗原受體結構圖。左側為 B 細胞表面插著數個 Y 形受體，右側放大顯示一個受體由兩條長的重鏈與兩條短的輕鏈組成，以雙硫鍵相連，Y 的兩個頂端各為一個抗原結合位，上半部標示為多變區，下半部標示為恆定區，重鏈末端有跨膜區穿過細胞膜進入 B 細胞的細胞質" caption="圖中標為多變區的就是本篇說的變異區。抗原結合位由重鏈與輕鏈的變異區共同構成，分泌型的抗體去掉跨膜區，其餘與表面受體相同。" source="Campbell 生物學・下冊，圖 43.9" maxW="30rem" />

- 兩條相同的**重鏈（heavy chain）**與兩條相同的**輕鏈（light chain）**以**雙硫鍵**連成 Y 形。
- Y 的兩個頂端各有一個**抗原結合位（antigen-binding site）**，由重鏈與輕鏈的**變異區（variable region，V 區）**共同構成。變異區中變化最劇烈的幾小段稱為**高度變異區（hypervariable region）**，真正接觸抗原的就是它。
- Y 的下半是**恆定區（constant region，C 區）**，重鏈的恆定區決定這個抗體屬於哪一類。
- 膜結合型多一段**跨膜區**把受體錨在細胞膜上。
- 抗體與抗原之間全靠**非共價**作用力結合：氫鍵、離子鍵、凡得瓦力與疏水作用。**沒有共價鍵參與**，所以結合是可逆的。

**T 細胞受體（T cell receptor，TCR）**由一條 α 鏈與一條 β 鏈以雙硫鍵相連，兩鏈的變異區合起來只構成**一個**抗原結合位。它與 B 細胞受體的決定性差別在於：B 細胞受體可以直接結合游離的或病原體表面的完整抗原，**T 細胞受體只認被展示在 MHC 分子凹槽裡的抗原片段**，看不到游離抗原。**主要組織相容性複合體（major histocompatibility complex，MHC）**就是細胞表面用來展示胜肽片段的那一組自體標記蛋白，它的專一性辨識對象正是 **T 細胞受體**。

T 細胞依工作分成兩種：**輔助 T 細胞（helper T cell）**分泌細胞激素去指揮其他免疫細胞，自己不殺任何東西，**細胞毒性 T 細胞（cytotoxic T cell，又譯毒殺 T 細胞或胞毒型 T 細胞）**則直接殺死壞掉的細胞。兩者表面各帶一個**輔助蛋白（co-receptor）**扣住 MHC 分子、把 T 細胞黏在對的細胞上：輔助 T 細胞帶 **CD4**，細胞毒性 T 細胞帶 **CD8**。專門把吞進來的抗原裝進 MHC 展示給 T 細胞看的細胞，稱為**專業抗原呈現細胞（professional antigen-presenting cell，APC）**。

<div class="overflow-x-auto print:overflow-visible">

| 比較項 | 第一類 MHC | 第二類 MHC |
|---|---|---|
| 展示的抗原來自 | **細胞內部**：被病毒感染時做出的病毒蛋白、癌變的異常蛋白 | **細胞外部**：吞進來的細菌與毒素碎片 |
| 表現在哪些細胞 | **幾乎所有有核細胞** | **只有專業抗原呈現細胞**：樹突細胞、巨噬細胞、**B 細胞** |
| 呈現給誰 | 帶 **CD8** 輔助蛋白的**細胞毒性 T 細胞** | 帶 **CD4** 輔助蛋白的**輔助 T 細胞** |
| 結果 | 直接殺掉這個壞掉的細胞 | 發號施令，活化 B 細胞與細胞毒性 T 細胞 |

</div>

第一類配 CD8、第二類配 CD4，1 乘 8 等於 8、2 乘 4 等於 8。紅血球沒有細胞核，神經細胞與肝細胞不是專業抗原呈現細胞，所以能高量表現第二類 MHC 的是 **B 細胞**。

**抗原呈現（antigen presentation）**的流程是四步：

1. 抗原呈現細胞把病原體吞入，切成胜肽小片段。
2. 片段裝進 MHC 分子的凹槽。
3. MHC 帶著片段移到細胞表面展示。
4. T 細胞受體與 **CD4 或 CD8 輔助蛋白**一起抓住這個複合體。

輔助 T 細胞的 CD4 若失去功能，它就無法與第二類 MHC 抗原複合體交互作用，整條後天免疫就啟動不了。

免疫系統會演化，病原體也會。躲開免疫攻擊的手段中，最單純的是外層包覆，例如肺炎鏈球菌用**莢膜（capsule）**這層包在細胞壁外的黏多醣擋住吞噬細胞的分子辨識與吞噬，其餘五類如下。

- **壓低抗原呈現**：讓被感染的細胞不要「自首」。腺病毒表現 **E19 蛋白**阻止第一類 MHC 上到細胞表面，有些病毒則抑制負責把胞內抗原片段送進內質網的 **TAP 蛋白**。代價是壓低第一類 MHC 會讓自然殺手細胞找上門，兩套機制互為補位。
- **抗原變異（antigenic variation）**：週期性換掉表面抗原，記憶細胞就認不得。**布魯氏錐蟲（Trypanosoma，引起睡眠病）**能輪流表現上千種版本的表面醣蛋白，流感病毒則靠表面蛋白突變與不同病毒株之間的基因交換，所以疫苗要年年重配。
- **潛伏（latency）**：病毒把基因體留在宿主細胞核內、幾乎不做病毒蛋白，免疫系統就看不到它。**單純疱疹病毒（herpes simplex virus，HSV）**潛伏在感覺神經元裡，那裡第一類 MHC 本來就表現得少，發燒或壓力時病毒才重新活化。
- **在吞噬細胞內存活**：**結核分枝桿菌**與**沙門氏菌**被吞進巨噬細胞後，能抵抗溶酶體的分解，反而在裡面生長繁殖。它們靠的是抵抗降解，**不是分泌毒素去殺細胞毒性 T 細胞**。沙門氏菌另能耐胃的酸性環境，活著抵達腸道。
- **直接攻擊免疫系統**：**人類免疫缺乏病毒（human immunodeficiency virus，HIV）**殺掉帶 CD4 的輔助 T 細胞，等於拆掉整條後天免疫的上游。

<RelatedNote title="受體、配體與膜蛋白" href="/bio-cell-4" to="細胞膜（構造與功能）">

- MHC、CD4、CD8 都是**膜蛋白**，露在細胞外的部分負責細胞之間的辨識。
- 抗原受體屬於穿膜蛋白，靠疏水的**跨膜區**固定在磷脂雙層裡。

</RelatedNote>

## 五、體液性免疫與細胞性免疫

<Figure src="/notes/bio-immune/humoral-cellular.webp" alt="適應性免疫反應整合圖。左半藍色區為體液免疫反應，右半綠色區為細胞媒介式免疫反應。抗原第一次暴露後被抗原呈現細胞吞入，抗原呈現細胞刺激輔助型 T 細胞，輔助型 T 細胞分別刺激 B 細胞與胞毒型 T 細胞，並產生記憶性輔助型 T 細胞。B 細胞產生漿細胞與記憶性 B 細胞，漿細胞分泌抗體。胞毒型 T 細胞產生記憶性胞毒型 T 細胞與活化的胞毒型 T 細胞。抗原第二次暴露時由各種記憶細胞快速反應" caption="圖中的胞毒型 T 細胞就是本篇的細胞毒性 T 細胞。左半靠抗體對付細胞外病原體，右半靠直接接觸殺死被感染細胞與腫瘤細胞，兩半的共同上游都是輔助型 T 細胞。" source="Campbell 生物學・下冊，圖 43.20" />

**輔助 T 細胞**是後天免疫的總開關，它自己不殺任何東西，而是分泌**細胞激素（cytokine）**去活化別人，自己分泌的主力是**白血球介白素 2（interleukin-2，IL-2）**。方向相反的是**白血球介白素 1（interleukin-1，IL-1）**，它由上游的巨噬細胞、樹突細胞等抗原呈現細胞分泌，作用是共同刺激輔助 T 細胞。**細胞毒性 T 細胞**才是動手殺的那個，殺法固定三步：

1. 活化的細胞毒性 T 細胞靠自身受體與 CD8，抓住被感染細胞上的**第一類 MHC 抗原複合體**。
2. 釋出**穿孔素（perforin）**在標的細胞膜上打孔，再送入**顆粒酶（granzyme）**。
3. 顆粒酶誘導標的細胞**凋亡（apoptosis）**，細胞核與細胞質碎裂。放開後這個 T 細胞可以再去殺下一個。這是「叫它自殺」，不是把它撐破。

B 細胞的活化需要**兩個訊號**：

1. 抗原直接與 B 細胞表面受體結合，B 細胞把它吞入切碎，用自己的**第二類 MHC** 呈現給輔助 T 細胞。
2. 輔助 T 細胞認出後分泌細胞激素刺激 B 細胞，B 細胞才增殖分化成**漿細胞（plasma cell）**與**記憶 B 細胞**。漿細胞的內質網極為發達，在 4 到 5 天的壽命中每秒可分泌約 2000 個抗體分子。

B 細胞當抗原呈現細胞時與其他人不同：巨噬細胞與樹突細胞什麼抗原片段都能呈現，**B 細胞只呈現與自己受體專一結合的那個抗原**。

**株落選擇（clonal selection，又譯株系選擇）**說明專一性從哪裡來：每個淋巴球在遇到抗原**之前**就已經帶著一種固定專一性的受體。抗原進來只是「挑中」剛好對得上的那一株，刺激它進行**有絲分裂**大量增殖，形成一群基因相同的後代，分別成為效應細胞與記憶細胞。抗體多樣性是 B 細胞發育時**受體基因隨機重組**做出來的，變異區由多段基因片段隨機拼接，少數幾百段就能組出上億種受體，不是抗原教出來的，也不是後天的基因突變造成的。B 細胞與 T 細胞在發育過程中都會進行這種基因重組。

**調節性 T 細胞（regulatory T cell，Treg）**是由轉錄因子 **Foxp3** 決定的一群 CD4 T 細胞，工作是壓下過度活躍的免疫反應、維持自我耐受、預防自體免疫疾病。CD4 T 細胞會依環境分化成不同亞型，各由一個轉錄因子決定，例如 Foxp3 對應 Treg，轉錄因子 **RORγt** 則對應 **Th17**（分泌白血球介白素 17、主要對抗細菌與黴菌的一種 CD4 T 細胞）。

<div class="overflow-x-auto print:overflow-visible">

| 比較項 | 體液性免疫 | 細胞性免疫 |
|---|---|---|
| 主角 | **B 細胞、漿細胞、抗體** | **細胞毒性 T 細胞** |
| 對付誰 | 體液中的**細胞外**病原體與毒素 | 已經躲進**細胞內**的病原體、腫瘤細胞、移植的外來細胞 |
| 手段 | 分泌抗體去中和或標記 | 直接接觸並殺死該細胞 |
| 上游 | 都需要輔助 T 細胞許可 | 都需要輔助 T 細胞許可 |

</div>

輔助 T 細胞同時是這兩條路的上游，所以它一垮，兩邊一起垮。**發炎反應屬於先天免疫**，不在「抗原呈現細胞用 MHC 呈現抗原、活化輔助 T 細胞、再活化 B 細胞與細胞毒性 T 細胞」這條專一性級聯裡。

<RelatedNote title="細胞激素怎麼被接收" href="/bio-cell-6" to="細胞訊號傳遞">

- 細胞激素是**訊息分子**，要靠標的細胞表面的受體接收才有作用。
- 訊號進到細胞內後經一連串中繼分子放大，最後改變基因表現，這正是 T 細胞被活化後大量增殖的機制。

</RelatedNote>

## 六、抗體的類別、作用與免疫記憶

抗體又稱**免疫球蛋白（immunoglobulin，Ig）**，依重鏈恆定區分成五類。同一個 B 細胞做出的五類抗體，**抗原專一性完全相同**，差別只在恆定區。

<div class="overflow-x-auto print:overflow-visible">

| 類別 | 分子形式 | 主要所在 | 功能 |
|---|---|---|---|
| **IgM** | 分泌型為**五聚體** | 血液 | **初次免疫反應最早合成**。五個 Y 共 **10 個抗原結合位**，單一分子結合位最多，凝集與活化補體的能力最強 |
| **IgG** | 單體 | 血液與組織液，**血中含量最多** | 中和、調理、活化補體。**唯一能通過胎盤**保護胎兒 |
| **IgA** | 分泌型為**雙聚體** | **唾液、淚液、母乳**，以及腸胃道、呼吸道、泌尿道**黏膜層** | 黏膜表面的第一線防禦 |
| **IgE** | 單體 | **血中含量最少**，多結合在肥大細胞與嗜鹼性球表面 | 引發**第 I 型過敏反應**，對抗**多細胞寄生蟲** |
| **IgD** | 單體 | 幾乎只在初始 B 細胞表面 | 與膜結合型 IgM 一起當 **B 細胞的抗原受體**，參與 B 細胞的啟動與免疫反應調節 |

</div>

初始 B 細胞表面同時帶著膜結合型的 **IgM 與 IgD** 當抗原受體，**T 細胞表面沒有抗體**。**IgD** 的辨識法是排除：IgG 最多且能過胎盤、IgM 最早且為五聚體、IgA 在分泌液與黏膜、IgE 管過敏與抗多細胞寄生蟲，剩下對不上任何描述的那個就是 IgD。

同一個 B 細胞之所以能改做別類抗體，靠的是**類型轉換（class switching，又稱同型轉換 isotype switching）**。

- 場所是次級淋巴器官的**生發中心（germinal center）**，需要**濾泡輔助 T 細胞（follicular helper T cell，TFH）**給訊號。
- 換掉的是重鏈的**恆定區基因**，從 IgM 換成 IgG、IgA 或 IgE。
- **變異區完全不動**，所以辨識的抗原一模一樣，只是換了執行方式。
- 這是 **B 細胞獨有**的事，T 細胞不做。
- 同一場合還會發生**體超突變（somatic hypermutation）**：變異區基因高頻率突變，結合力更強的那株被選出來，抗體親和力隨反應進行而提高。
- 若病人只做得出低量 IgM、無法類型轉換、淋巴結又缺乏生發中心，問題出在 B 與 T 細胞的協同作用。

抗體本身**不殺死病原體**，它只負責結合上去，讓別人動手。

<Figure src="/notes/bio-immune/antibody-action.webp" alt="清除抗原的抗體媒介機制三格圖。(a) 中和作用，抗體結合到病毒表面的抗原，阻斷病毒結合宿主細胞的能力。(b) 調理作用，抗體結合到細菌表面的抗原，促進巨噬細胞的吞噬作用。(c) 補體系統之活化作用及孔道生成，抗體與外來細胞表面抗原結合後激活補體蛋白，補體聚集成攻擊膜的複合體在細胞膜上穿孔，水和離子湧入使細胞溶解" caption="圖中三格是抗體作用機制中的三種，共同前提都是抗體先結合到抗原上。中和是擋住入侵、調理是裝上把手、補體活化才真正打洞。" source="Campbell 生物學・下冊，圖 43.19" />

- **中和作用（neutralization）**：抗體蓋住病毒表面蛋白或毒素，阻斷它結合宿主細胞的能力。
- **調理作用（opsonization）**：抗體結合細菌表面抗原，露出的尾端成為巨噬細胞與嗜中性球好抓的把手，促進吞噬。
- **凝集（agglutination）**：IgG 這類單體抗體有兩個抗原結合位，可以把多個病原體串成一團，一次解決。
- **活化補體**：抗原抗體複合體啟動古典途徑，最後由攻膜複合物把外來細胞打穿。
- 自然殺手細胞表面有 **IgG 的 Fc 受體**（**Fc** 是抗體 Y 形下半那段恆定區的尾端，免疫細胞抓的就是這裡），結合被 IgG 覆蓋的標的細胞後也會被活化，這是抗體與先天免疫細胞的合作。

<ImmuneResponse client:visible />

**初次反應（primary response）**需要 5 到 10 天才開始做得出抗體，濃度低、持續短，最早出現的是 **IgM**。**二次反應（secondary response）**因為記憶細胞已經在場，1 到 3 天內就大量增殖，抗體濃度更高、持續更久，主力換成 **IgG**。臨床上據此判讀感染時程：血中只驗到 IgM 代表剛感染不久，已有大量 IgG 代表感染過一段時間或已痊癒。

<div class="overflow-x-auto print:overflow-visible">

| 比較項 | 主動免疫 | 被動免疫 |
|---|---|---|
| 抗體誰做的 | **自己做** | **別人做好再給** |
| 怎麼取得 | 得過該病，或接種**疫苗** | 胎盤來的 IgG、母乳來的 IgA、注射**抗血清** |
| 有無記憶 | **有** | **無** |
| 生效速度 | 慢，數天到數週 | **立刻** |
| 維持多久 | 長 | 短，只到那批抗體被代謝掉，數週到數月 |

</div>

被毒蛇咬傷後注射的蛇毒血清，是從已對蛇毒免疫的羊或馬體內取得的抗體，屬於**人為的被動免疫**，目的是立刻中和毒素，不是讓身體自己生抗體。嬰兒從母乳得到的 IgA 同樣是被動免疫，不會產生記憶。

<div class="overflow-x-auto print:overflow-visible">

| 疫苗型式 | 內容 | 例子 |
|---|---|---|
| **減毒活疫苗** | 毒性減弱但仍會複製的病原體 | **口服沙賓小兒麻痺疫苗**、麻疹疫苗、卡介苗 |
| **不活化疫苗** | 殺死或去活化的病原體 | **注射式沙克小兒麻痺疫苗**、季節性流感疫苗 |
| **次單位蛋白質疫苗** | 只用病原體的一個蛋白質 | **B 型肝炎疫苗、HPV 疫苗** |
| **病毒載體疫苗** | 用無害病毒攜帶抗原基因 | **AZ 的 COVID-19 疫苗**用腺病毒載體 |
| **mRNA 疫苗** | 送入編碼抗原的 mRNA，由人體細胞自己做出抗原 | BNT 與 Moderna 的 COVID-19 疫苗 |

</div>

沙賓疫苗口服且是活的，能在腸道複製，因此**誘發得出腸道黏膜抗體**。沙克疫苗注射且是死的，只引起血中抗體，擋不住腸道帶原，這是小兒麻痺無法比照天花根除的原因之一。HPV 疫苗是次單位蛋白質疫苗、以多價方式施用，**男女皆可接種**。mRNA 疫苗成功的關鍵突破是**核苷修飾**，讓 mRNA 不易被降解，也不會過度活化先天免疫。B 型肝炎疫苗只含表面抗原，所以接種完成者驗出的是表面抗體陽性、核心抗體陰性，體內從未有過真正的病毒核心蛋白。

**單株抗體（monoclonal antibody）**是把免疫過的動物體內**會分泌抗體的 B 細胞**與**可無限增殖的骨髓瘤細胞**融合成融合瘤，既能永久培養又持續分泌同一種抗體，專一結合同一個抗原決定位。家用驗孕棒偵測人類絨毛膜性腺激素（hCG）用的就是它，癌症標靶治療與檢查點抑制劑也是。

## 七、免疫失調、移植與血型

**過敏（allergy，又稱過度敏感反應 hypersensitivity）**是免疫系統對本來無害的抗原反應過度。依主導者分成四型。

<div class="overflow-x-auto print:overflow-visible">

| 型別 | 主導者 | 機制 | 例子 |
|---|---|---|---|
| **第 I 型（立即型）** | **IgE** 加肥大細胞與嗜鹼性球 | 過敏原使細胞上的 IgE 交聯，肥大細胞去顆粒釋出組織胺 | 花粉症、氣喘、**過敏性休克** |
| **第 II 型（細胞毒性）** | **IgG 或 IgM** 對著**細胞表面**抗原 | 抗體結合細胞表面抗原後活化補體或引來吞噬，把該細胞毀掉 | **輸錯血型的溶血**、**Rh 新生兒溶血症** |
| **第 III 型（免疫複合體）** | **可溶性**抗原抗體複合體 | 複合體沉積在組織、活化補體引起發炎 | 血清病、部分腎絲球腎炎 |
| **第 IV 型（遲發型）** | **T 細胞**，不靠抗體 | 致敏的 T 細胞在數十小時後才引發發炎 | 結核菌素試驗、接觸性皮膚炎、移植排斥 |

</div>

<Figure src="/notes/bio-immune/ige-allergy.webp" alt="肥大細胞、IgE 和過敏反應的三步驟圖。第一步為回應最初接觸過敏原而產生的 IgE 抗體結合到肥大細胞表面的受體。第二步為再次暴露相同過敏原時，過敏原與肥大細胞上的 IgE 分子結合。第三步為相鄰 IgE 分子被交聯結合而啟動肥大細胞的去顆粒作用，囊泡釋出組織胺和其他化學物質造成過敏症狀" caption="第一次接觸只是把 IgE 裝上肥大細胞，此時沒有症狀。要第二次接觸、且過敏原同時抓住相鄰兩個 IgE 造成交聯，才會去顆粒。" source="Campbell 生物學・下冊，圖 43.22" maxW="26rem" />

前三型都由抗體主導、發作快，只有第四型由 T 細胞主導而且慢。組織胺讓微血管擴張並提高通透性，局部發生就是紅腫癢與流鼻水，全身同時發生就是**過敏性休克（anaphylactic shock）**：血管普遍擴張使血壓急遽下降，可以致命。IgE 與嗜酸性球同屬對抗多細胞寄生蟲的陣線，所以**寄生蟲感染者與過敏者的共同點是血中 IgE 濃度升高**。

**自體免疫疾病（autoimmune disease）**是失去自我耐受，做出攻擊自身分子的自體抗體。認得出被攻擊的標靶，就認得出是哪一種病。

<div class="overflow-x-auto print:overflow-visible">

| 疾病 | 被攻擊的標靶 | 結果 |
|---|---|---|
| **多發性硬化症（MS）** | 中樞神經的**髓鞘** | 髓鞘被破壞，神經傳導變慢 |
| **重症肌無力** | 運動終板上的**乙醯膽鹼受體** | 受體數目減少，肌肉收不到訊號而無力 |
| **第一型糖尿病** | 胰島 **β 細胞** | 不能分泌胰島素 |
| **全身性紅斑狼瘡（SLE）** | **DNA 與組蛋白**等細胞核成分 | 免疫複合體全身沉積 |
| **類風濕性關節炎（RA）** | 關節組織 | 慢性發炎與變形 |

</div>

**第二型糖尿病是胰島素阻抗，不屬於自體免疫**。女性罹患 SLE 的機率是男性的九倍，MS 與 RA 是二到三倍。有些感染會誘發自體免疫，例如 A 型鏈球菌咽喉炎之後的風濕熱。自體免疫是免疫反應過了頭，反方向的失調則是**免疫缺乏（immunodeficiency）**：先天性的來自遺傳，例如某種免疫細胞或某個蛋白的製造有缺陷，後天性的來自感染、營養不良或藥物。長期壓力下腎上腺皮質分泌的**糖皮質激素（glucocorticoid）**會抑制免疫功能，這是壓力大容易生病的原因。

**人類免疫缺乏病毒（human immunodeficiency virus，HIV）**是**有套膜的 RNA 反轉錄病毒**，套膜來自宿主的細胞膜，靠反轉錄酶把 RNA 抄成 DNA 再插入宿主基因體。

- 入侵路徑：表面蛋白 gp120 先接上細胞的 **CD4** 分子，再接上輔受體 **CCR5** 才進得去。天生 CCR5 有缺陷的少數人不會被感染。
- 標的細胞：凡是帶 CD4 的都是目標，包括**輔助 T 細胞**（Th1 與 Th2 兩個亞型都是 CD4 T 細胞）、**巨噬細胞**與腦中的微膠細胞。
- 後果：輔助 T 細胞被消滅後，B 細胞與細胞毒性 T 細胞都活化不起來，患者對各種病原失去抵抗力而出現伺機性感染，即**後天免疫缺乏症候群（AIDS）**。
- 對照：人類乳突瘤病毒（HPV）是**無套膜的 DNA 病毒**。

**移植排斥（transplant rejection）**來自 **MHC 不同**。MHC 由十多個基因決定，每個基因在人群中有超過 100 種對偶基因，除同卵雙胞胎外幾乎不可能有兩人整套完全相同，外來的 MHC 分子本身就是抗原。用病人自己的細胞誘導出來的組織不會被 MHC 排斥，但仍有癌化與難以定著的風險。

同樣是自己人與外來者的辨識，**ABO 血型**的抗原是紅血球表面的**碳水化合物**：A 型帶 A 醣、B 型帶 B 醣、AB 型兩種都有、O 型兩種都沒有。

- 血中的抗體並不是輸過血才產生的。腸道細菌表面帶有與 A、B 醣類似的抗原決定位，所以 A 型的人會對 B 醣那一類產生抗體，對 A 醣那一類不產生，因為會攻擊自身抗原的淋巴球在發育時已被刪除。
- A 型的人若輸入 B 型血，血中原有的抗體立刻結合輸入的紅血球、活化補體使其溶解，出現發冷、發燒、休克與腎衰竭。
- 這是**抗體打細胞表面抗原**，屬於第 II 型過敏反應。

**Rh 血型**的關鍵在「第幾胎」。Rh 陰性的母親懷第一胎 Rh 陽性胎兒時，胎兒紅血球多在生產時才進入母體，母親走的是初次反應、做出的是 **IgM**，而 IgM 是五聚體、分子太大**過不了胎盤**，所以第一胎通常沒事。之後再懷 Rh 陽性胎兒，記憶細胞發動二次反應做出 **IgG**，IgG 可以通過胎盤去攻擊胎兒紅血球，造成新生兒溶血症。所以問題出在**第二胎以後**。

癌症免疫治療走的是兩條路。**免疫檢查點（immune checkpoint）**是 T 細胞身上的煞車分子，本來用來避免免疫過度而傷及自身。腫瘤細胞表面表現 **PD-L1** 去接 T 細胞上的 **PD-1**，等於替 T 細胞踩下煞車，用抗 PD-1 抗體擋住這個結合就是**鬆開煞車**，恢復 T 細胞的毒殺能力。最早發現的兩個檢查點是 **CTLA-4 與 PD-1**（2018 年諾貝爾生醫獎）。**CAR-T 細胞療法**則是抽出病人的 T 細胞，在體外改造它的**受體辨識區域**裝上人工設計的嵌合抗原受體，再輸回病人體內，因為改造在體外進行，屬於體外基因治療。

  "體液性與細胞性免疫：<ul><li>體液性＝B 細胞、漿細胞、抗體，對付細胞外病原體與毒素</li><li>細胞性＝細胞毒性 T 細胞，殺被感染細胞與腫瘤細胞</li><li>兩條路的共同上游都是輔助 T 細胞</li><li>細胞毒性 T 放穿孔素打孔、顆粒酶誘導凋亡（不是撐破）</li><li>B 細胞活化需兩訊號：抗原結合，加上輔助 T 的細胞激素</li><li>IL-1 由巨噬細胞等抗原呈現細胞分泌以刺激輔助 T，IL-2 才由活化的輔助 T 自己分泌</li><li>株落選擇：受體專一性在遇到抗原前就決定，抗原只是挑中並刺激它有絲分裂</li></ul>",
  "五類抗體與類型轉換：<ul><li>IgG 血中最多、唯一過胎盤</li><li>IgM 初次反應最早、五聚體、10 個結合位、凝集最強</li><li>IgA 黏膜與外分泌液、分泌型為雙聚體</li><li>IgE 血中最少、第 I 型過敏、抗多細胞寄生蟲</li><li>IgD 與膜結合型 IgM 一起當初始 B 細胞的抗原受體</li><li>類型轉換只換重鏈恆定區、變異區不動，B 細胞獨有，需濾泡輔助 T 與生發中心</li></ul>",

## 名詞統整

<div class="overflow-x-auto print:overflow-visible">

| 英文（縮寫） | 中文 | 一句話 |
|---|---|---|
| innate / adaptive immunity | 先天免疫／後天免疫 | 前者無專一性、快、無記憶且所有動物都有，後者有專一性、慢、有記憶且只有脊椎動物 |
| barrier defense / lysozyme | 屏障／溶菌酶 | 皮膚、黏液、纖毛、胃酸等第一層阻擋，溶菌酶是眼淚與唾液中分解細菌細胞壁的酵素 |
| neutrophil / monocyte / macrophage | 嗜中性球／單核球／巨噬細胞 | 嗜中性球是血中最多也最主要的吞噬細胞，單核球進入組織後分化成巨噬細胞 |
| dendritic cell / eosinophil | 樹突細胞／嗜酸性球 | 前者在淋巴結成熟後專職呈現抗原，後者抗多細胞寄生蟲且靠釋出酵素而非吞噬 |
| mast cell / basophil | 肥大細胞／嗜鹼性球 | 前者在組織、後者在血中，顆粒帶組織胺與肝素 |
| natural killer cell (NK) | 自然殺手細胞 | 殺低表現第一類 MHC 的細胞，不吞噬也無記憶 |
| inflammatory response / septic shock | 發炎反應／敗血性休克 | 局部紅腫熱痛的先天免疫反應，全身失控時成為致命的敗血性休克 |
| histamine / heparin / prostaglandin | 組織胺／肝素／前列腺素 | 依序是肥大細胞放的血管擴張物、嗜鹼性球放的抗凝血物、與發炎的痛有關的物質 |
| PAMP / Toll-like receptor (TLR) | 病原相關分子模式／類鐸受體 | 前者是病原共有而宿主沒有的分子特徵，後者是辨識它的受體，認核酸的擺在囊泡內 |
| NF-κB | 核因子 κB | 類鐸受體接上配體後被活化的轉錄因子，進細胞核開啟發炎相關基因 |
| lipopolysaccharide (LPS) / flagellin | 脂多醣／鞭毛蛋白 | 前者是革蘭氏陰性菌外膜成分且屬耐熱的內毒素，兩者都由細胞膜表面的 TLR 辨識 |
| antimicrobial peptide / interferon (IFN) | 抗微生物肽／干擾素 | 前者破壞病原胞膜，後者由受感染細胞分泌以誘導鄰近細胞進入抗病毒狀態 |
| complement system / MAC | 補體系統／攻膜複合物 | 血漿中約 30 種不活化蛋白，三途徑匯流到 C3，攻膜複合物為 C5b 到 C9 組成的孔道 |
| C5 convertase / DAF | C5 轉換酶／衰變加速因子 | 前者古典為 C4b2a3b、替代為 C3b₂Bb，後者是認住 C3b 並把轉換酶拆散的煞車蛋白 |
| antigen / epitope | 抗原／抗原決定位（表位） | 前者能引發免疫反應，後者是抗原上真正被受體結合的一小段，一個抗原可有多個 |
| self-tolerance | 自我耐受 | 免疫系統不攻擊自身分子的性質 |
| primary / secondary lymphoid organ | 初級／次級淋巴器官 | 前者是骨髓與胸腺，淋巴球在此生成與成熟，後者是淋巴結、脾臟、扁桃腺與派爾斑，淋巴球在此遇到抗原被活化 |
| Peyer's patch | 派爾斑 | 小腸黏膜下的淋巴濾泡，含微皺褶細胞，屬腸道黏膜免疫系統 |
| positive / negative selection | 正選擇／負選擇 | 前者在胸腺皮質留下看得懂自身 MHC 者，後者在髓質刪掉會攻擊自身者 |
| heavy / light chain | 重鏈／輕鏈 | 抗體的兩長兩短四條多肽鏈，以雙硫鍵連成 Y 形 |
| variable / constant / hypervariable region | 變異區／恆定區／高度變異區 | 變異區構成抗原結合位，恆定區決定抗體類別，高度變異區是真正接觸抗原的幾小段 |
| B cell receptor (BCR) | B 細胞抗原受體 | B 細胞表面的膜結合型抗體，兩重鏈兩輕鏈，可直接結合完整的游離抗原 |
| T cell receptor (TCR) | T 細胞受體 | α 鏈加 β 鏈，只有一個結合位，只認 MHC 上的抗原片段 |
| MHC | 主要組織相容性複合體 | 細胞表面展示胜肽片段的自體標記蛋白，專一辨識的對象是 T 細胞受體 |
| CD4 / CD8 | CD4／CD8 | T 細胞的輔助蛋白，前者配第二類 MHC，後者配第一類 |
| antigen presentation / APC | 抗原呈現／抗原呈現細胞 | 把抗原片段裝進 MHC 凹槽展示到表面，做這件事的是樹突細胞、巨噬細胞與 B 細胞 |
| TAP | 抗原處理相關轉運蛋白 | 把胞內抗原片段送進內質網裝上第一類 MHC，被某些病毒抑制以逃避免疫 |
| antigenic variation / latency | 抗原變異／潛伏 | 病原體逃避免疫的兩種手段，前者週期性換掉表面抗原，後者把基因體藏在細胞核內幾乎不表現 |
| helper / cytotoxic T cell | 輔助 T 細胞／細胞毒性 T 細胞 | 前者帶 CD4 分泌細胞激素當總開關，後者帶 CD8 直接殺死被感染細胞 |
| perforin / granzyme / apoptosis | 穿孔素／顆粒酶／細胞凋亡 | 穿孔素在標的細胞膜打孔，顆粒酶進入後誘導凋亡，也就是有計畫的細胞自殺 |
| cytokine / IL-1 / IL-2 | 細胞激素／白血球介白素 1／白血球介白素 2 | 免疫細胞分泌的訊息分子，IL-1 由巨噬細胞等抗原呈現細胞分泌以刺激輔助 T 細胞，IL-2 由活化的輔助 T 細胞自己分泌 |
| plasma cell / memory cell | 漿細胞／記憶細胞 | 前者是 B 細胞分化成的抗體工廠，後者使二次反應更快更強 |
| clonal selection | 株落選擇 | 抗原挑中受體剛好對得上的那一株淋巴球，刺激它進行有絲分裂 |
| regulatory T cell (Treg) | 調節性 T 細胞 | 由 Foxp3 決定的 CD4 T 細胞，壓下過度反應以預防自體免疫 |
| Th17 / RORγt | 第 17 型輔助 T 細胞／RORγt | 由轉錄因子 RORγt 決定的另一種 CD4 T 細胞亞型，分泌白血球介白素 17 以對抗細菌與黴菌 |
| humoral / cell-mediated immunity | 體液性／細胞性免疫 | 前者靠抗體對付細胞外病原體，後者靠 T 細胞殺死被感染細胞 |
| immunoglobulin (Ig) | 免疫球蛋白 | 抗體的正式名稱，依重鏈恆定區分成五類 |
| IgM | IgM | 五聚體、初次反應最早、單分子結合位最多（10 個）、凝集最強 |
| IgG | IgG | 血中含量最多、唯一能通過胎盤 |
| IgA | IgA | 黏膜與外分泌液的主力，分泌型為雙聚體 |
| IgE | IgE | 血中最少，主導第 I 型過敏並對抗多細胞寄生蟲 |
| IgD | IgD | 與膜結合型 IgM 一起當初始 B 細胞的抗原受體 |
| class switching | 類型轉換 | 只換重鏈恆定區、抗原專一性不變，B 細胞獨有 |

| Fc region | Fc 區 | 抗體 Y 形下半那段恆定區的尾端，自然殺手細胞與吞噬細胞的受體抓的就是這裡 |
| primary / secondary response | 初次／二次免疫反應 | 前者 5 到 10 天以 IgM 為主，後者 1 到 3 天以 IgG 為主 |
| active / passive immunity | 主動／被動免疫 | 前者自己做抗體且有記憶，後者接受現成抗體且無記憶 |
| vaccine / monoclonal antibody | 疫苗／單株抗體 | 前者引發初次反應留下記憶細胞，後者由 B 細胞與骨髓瘤細胞融合後分泌，驗孕棒偵測的 hCG 就靠它 |
| hypersensitivity / anaphylactic shock | 過敏（過度敏感反應）／過敏性休克 | 對無害抗原反應過度，分四型，全身血管擴張使血壓急降者為過敏性休克 |

| type 1 diabetes / rheumatoid arthritis (RA) | 第一型糖尿病／類風濕性關節炎 | 自體免疫標靶依序是胰島 β 細胞與關節組織，第二型糖尿病是胰島素阻抗而不屬於自體免疫 |
| immunodeficiency / glucocorticoid | 免疫缺乏／糖皮質激素 | 免疫功能有缺陷，分先天性與後天性，長期壓力下的糖皮質激素會抑制免疫 |

| transplant rejection | 移植排斥 | 來自捐受雙方 MHC 不同，外來 MHC 本身就是抗原，由 T 細胞主導而屬第 IV 型過敏反應 |
| ABO / Rh blood group | ABO 血型／Rh 血型 | ABO 抗原是紅血球表面的碳水化合物且抗體來自腸道細菌的交叉表位，Rh 陰性母親第二胎起做出的 IgG 造成新生兒溶血症 |
| immune checkpoint / CAR-T | 免疫檢查點／嵌合抗原受體 T 細胞療法 | 前者是 T 細胞的煞車（CTLA-4、PD-1），後者在體外改造 T 細胞的受體辨識區域 |
