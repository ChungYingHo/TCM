## 一、作者與出處

劉基（1311–1375），字伯溫，浙江青田人。元末考中進士，後來輔佐朱元璋建立明朝，封誠意伯，與宋濂並稱明初文宗。

| 項目 | 內容 |
|---|---|
| 作者 | 劉基，字伯溫 |
| 出處 | 寓言集《郁離子》 |
| 選集 | 《古文觀止》卷十二・明文 |
| 文體 | 寓言體論說文，全篇靠一問一答推進 |

《郁離子》是劉基在元末棄官隱居時寫的寓言集，藉虛構的人物問答談治亂之理。書名的「郁離」取文明之意。

## 二、對話的兩個人

| 人物 | 身分 |
|---|---|
| 東陵侯 | 秦朝的召平，受封東陵侯。秦亡後失去爵位，在長安城東種瓜維生，瓜味甘美，世稱東陵瓜 |
| 司馬季主 | 漢初在長安東市卜卦的人。《史記・日者列傳》裡唯一被立傳的占卜者 |

這場對話是劉基虛構的，用來講道理，不是史書記載的事。李白〈古風〉「青門種瓜人，舊日東陵侯」用的就是召平失勢種瓜的典故，講的也是富貴無常。

## 三、原文與語譯

**第一段**

> 東陵侯既廢，過司馬季主而卜焉。季主曰：「君侯何卜也？」東陵侯曰：「久臥者思起，久蟄者思啟，久懣者思嚏。吾聞之蓄極則泄，閟極則達。熱極則風，壅極則通。一冬一春，靡屈不伸，一起一伏，無往不復。僕竊有疑，願受教焉。」

語譯：東陵侯失去爵位之後，去拜訪司馬季主求卜。季主問：「君侯要卜什麼呢？」東陵侯說：「躺久了就想起身，蟄伏久了就想活動，煩悶久了就想打噴嚏。我聽說積蓄到極點就會宣泄，閉塞到極點就會通達，熱到極點就起風，壅塞到極點就暢通。一個冬天接一個春天，沒有屈就不伸展的，一起一伏，沒有去了不回來的。我私下有疑惑，希望向您請教。」

**第二段**

> 季主曰：「若是，則君侯已喻之矣，又何卜為？」東陵侯曰：「僕未究其奧也，願先生卒教之。」

語譯：季主說：「照這樣說，君侯已經明白了，還卜什麼呢？」東陵侯說：「我還沒弄透其中的深意，希望先生把話說完。」

**第三段**

> 季主乃言曰：「嗚呼！天道何親？惟德之親；鬼神何靈？因人而靈。夫蓍，枯草也；龜，枯骨也，物也。人，靈於物者也，何不自聽而聽於物乎？且君侯何不思昔者也？有昔者必有今日，是故碎瓦頹垣，昔日之歌樓舞館也；荒榛斷梗，昔日之瓊蕤玉樹也；露蛬風蟬，昔日之鳳笙龍笛也；鬼燐螢火，昔日之金釭華燭也；秋荼春薺，昔日之象白駝峰也；丹楓白荻，昔日之蜀錦齊紈也。昔日之所無，今日有之不為過；昔日之所有，今日無之不為不足。是故一晝一夜，華開者謝；一秋一春，物故者新。激湍之下，必有深潭；高丘之下，必有浚谷。君侯亦知之矣，何以卜為？」

語譯：季主才說：「唉！天道親近誰呢？只親近有德的人。鬼神靈驗在哪裡呢？因為人相信才靈驗。蓍草不過是枯草，龜甲不過是枯骨，都只是死物。人比死物有靈性，為什麼不聽自己，反而去聽死物？何況君侯何不想想從前？有從前才有今天。所以破瓦頹牆，是從前的歌樓舞館；荒亂的雜木斷枝，是從前的美玉花樹；露中的蟋蟀、風裡的蟬，是從前的鳳笙龍笛；磷火與螢火，是從前的金燈華燭；秋天的苦菜、春天的薺菜，是從前的象脂駝峰；紅楓白荻，是從前的蜀錦齊紈。從前沒有的，今天有了不算過分；從前有過的，今天沒有了也不算欠缺。所以一晝一夜之間，開了的花會凋謝；一秋一春之間，舊的死去、新的長出。急流之下必定有深潭，高丘之下必定有深谷。君侯自己也知道了，還卜什麼呢？」

## 四、六組今昔對照

第三段最精采的是連下六組對比，每一組都是「眼前的破敗」對「從前的華美」，六組合起來把建築、草木、聲音、燈火、飲食、衣著六個面向掃完。

| 今（衰） | 昔（盛） | 屬於哪一面 | 白話 |
|---|---|---|---|
| 碎瓦頹垣 | 歌樓舞館 | 建築 | 破瓦倒牆，從前是歌舞樓臺 |
| 荒榛斷梗 | 瓊蕤玉樹 | 草木 | 荒亂雜木與斷枝，從前是美玉般的花樹 |
| 露蛬風蟬 | 鳳笙龍笛 | 聲音 | 露裡的蟋蟀、風中的蟬鳴，從前是笙笛樂聲 |
| 鬼燐螢火 | 金釭華燭 | 燈火 | 磷火與螢火，從前是金燈華燭 |
| 秋荼春薺 | 象白駝峰 | 飲食 | 秋苦菜、春薺菜，從前是象脂與駝峰的珍饌 |
| 丹楓白荻 | 蜀錦齊紈 | 衣著 | 紅楓與白荻，從前是蜀錦齊紈的華服 |

</div>

修辭上是**排比**加**對比**。六組的句型完全一樣，都是「今物，昔日之昔物也」，主語一律是眼前的衰敗景象，說明的卻是它從前的樣子，順序刻意倒過來寫，讀起來一組比一組重。

## 五、主旨

全篇的立論濃縮在三句：

| 原文 | 意思 |
|---|---|
| 天道何親？惟德之親 | 天道不偏愛任何人，只親近有德的人 |
| 鬼神何靈？因人而靈 | 鬼神本身不靈，是因為人相信才顯得靈 |
| 人，靈於物者也，何不自聽而聽於物乎 | 人比死物有靈性，該聽自己而不是聽枯草枯骨 |

所以這篇是**反對卜筮、主張人事與德行**的論說文。蓍與龜是占卜的兩樣工具，劉基直接點名它們只是「枯草」「枯骨」，把占卜的神聖性拆掉。

結尾的「激湍之下，必有深潭」與「高丘之下，必有浚谷」講盛衰相倚、循環往復，正好回頭呼應東陵侯自己開頭說的「蓄極則泄……無往不復」。**東陵侯其實早就懂了**，所以季主兩次反問「又何卜為」「何以卜為」，全文在這個反問裡收掉。

## 六、難字與句式

| 字詞 | 讀音 | 意思 |
|---|---|---|
| 蟄 | ㄓˊ | 動物冬眠、藏起來不動 |
| 懣 | ㄇㄣˋ | 煩悶 |
| 嚏 | ㄊㄧˋ | 打噴嚏 |
| 閟 | ㄅㄧˋ | 閉塞 |
| 蓍 | ㄕ | 蓍草，古代用來占卜的草 |
| 榛 | ㄓㄣ | 叢生的雜木 |
| 蕤 | ㄖㄨㄟˊ | 草木花下垂的樣子。瓊蕤指美玉般的花 |
| 蛬 | ㄑㄩㄥˊ | 蟋蟀 |
| 燐 | ㄌㄧㄣˊ | 磷火，俗稱鬼火 |
| 釭 | ㄍㄤ | 燈 |
| 荼 | ㄊㄨˊ | 苦菜 |
| 薺 | ㄐㄧˋ | 薺菜 |
| 紈 | ㄨㄢˊ | 細緻的白絹 |
| 湍 | ㄊㄨㄢ | 急流 |
| 浚 | ㄐㄩㄣˋ | 深 |

</div>

**「何……為」是反問句式**，意思是「為什麼要……呢」。本篇用了兩次，「又何卜為」與「何以卜為」，都是「還卜什麼呢」。同類的還有《史記》「何辭為」（還告辭什麼呢）。

「僕」是男子對人的謙稱，相當於「我」。東陵侯自稱「僕竊有疑」就是「我私下有疑惑」。
